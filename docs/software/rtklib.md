# 第一章 · 这软件是干什么的（场景故事）

## 1.1 两种「要坐标」的需求

实验室：低成本板卡 UBX → 想看静置单点漂不漂、网络 RTK 能否固定。空间天气：磁暴日 PPP 残差是否变大、换 GIM 改正坐标差多少。

**RTKLIB** 提供库 + GUI/CLI（`rnx2rtkp`/`convbin`/`str2str`…），做 SPP、RTK、PPP。电离层在这里是旋钮或误差源。要 ROTI/TEC 主产品请回 georinex/OASIS/教程02/05。
