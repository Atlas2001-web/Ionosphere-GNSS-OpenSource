# iri2016 · IRI-2016（space-physics）操作手册

目录：[`PROJECTS.json` → `iri2016`](../../PROJECTS.json) · 上游 <https://github.com/space-physics/iri2016> · 许可见仓内 `LICENSE.txt` · PyPI **`iri2016` 1.12.0** · 本机 tip **`ca523ad`** · Python **3.11** + gfortran/cmake **build-on-run**；`(40°N,80°W)` 2015-03-23 15:30 剖面实跑（2026-09-24 EDT）

> 岗位：调用 **官方 IRI-2016 Fortran** 的现代 Python（及 MATLAB）接口，输出 **xarray.Dataset**（`ne`/`Te`/峰值/`TEC`…）。冲突时：**仓内 README / `python -m iri2016.altitude -h` > 本文**。社区多模型包装见 [pyglow](./pyglow.md)；纯 Python IRI → [pyiri](./pyiri.md)。

## 1. 用途与边界

**做：**

- `IRI(time, altkmrange, glat, glon) → xarray.Dataset`：高度剖面 + F2/F1/E 峰值、`TEC`、`foF2`
- CLI：`python -m iri2016.altitude|latitude|time …`（画图需显示后端；可只取 Dataset）
- 首次调用自动 **CMake + gfortran** 编译 `iri2016_driver`

**不做：**

- **不是** 读 IONEX GIM → [ionex-gim](./ionex-gim.md)
- **不是** RINEX→校准 TEC → [pytecgg](./pytecgg.md)
- **不是** 球谐 GIM 求解 → [sh-gim](./sh-gim.md)
- **不是** 同时包装 HWM/MSIS 的气候态全家桶 → [pyglow](./pyglow.md)（绑 IRI-2012/2016 + 风/磁）
- **不是** Galileo NeQuick-G → [nequickg](./nequickg.md)
- **不是** 纯 Python 重写 IRI → [pyiri](./pyiri.md)
- JF 开关改动需改 `iri2016_driver.f90` 并触发重编译（见上游 README）

一句话：iri2016 = **IRI-2016 官方核心的 pip 友好驱动**，返回科学计算常用的 xarray。

| 术语 | 含义 |
| --- | --- |
| `altkmrange=(min,max,step)` | 高度网格三元组（km）；长度必须为 3 |
| `ne` 等 | Dataset 变量；密度默认 **m⁻³**（÷10⁶ → cm⁻³，便于对照 pyglow） |
| `NmF2`/`hmF2` | F2 峰值密度 / 峰高；坐标含 `time` |
| build-on-run | 首次 `IRI()` 调 `build()` 编出 `iri2016_driver` |

## 2. 安装

需 **gfortran**、**cmake**、**ninja**（或 cmake 默认生成器）、Python **≥3.9**（本机 3.11）。

```bash
sudo apt-get install -y gfortran cmake ninja-build   # 按缺补齐
export PATH="$HOME/.local/bin:$PATH"                 # 若用 uv
uv python install 3.11

mkdir -p ~/iono_ops && cd ~/iono_ops
git clone --depth 1 https://github.com/space-physics/iri2016.git
cd iri2016
uv venv -p 3.11 .venv && source .venv/bin/activate
uv pip install -e .
python -c "import iri2016; from iri2016 import IRI; print('ok', iri2016.__file__)"
# 或：pip install iri2016
```

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| `requires a different Python: … not in '>=3.9'` | 误用 3.8 venv | 换 ≥3.9 |
| 首次运行 cmake/编译失败 | 无 gfortran/cmake | 安装编译器；`export FC=gfortran` |
| `IRI failed … empty text output` | driver 未产出 | 查 `src/iri2016/build` 日志；清 build 重跑 |
| 想改 JF 开关 | 逻辑在 Fortran 驱动 | 改 `src/iri2016_driver.f90`（路径以仓内为准）后删 build 重编译 |

## 3. 端到端：高度剖面 → xarray（本机真跑）

与 [pyglow](./pyglow.md) 同点对照：2015-03-23 15:30 UT，**(40°N, 80°W)**，100–500 km、步长 50 km。

```bash
cd ~/iono_ops/iri2016 && source .venv/bin/activate
python - <<'PY'
from iri2016 import IRI

iono = IRI(time='2015-03-23T15:30', glat=40.0, glon=-80.0, altkmrange=(100, 500, 50))
print('data_vars', list(iono.data_vars))
print('alts_km', [float(a) for a in iono['alt_km'].values])
ne = iono['ne'].values
print('ne_m3', [float(x) for x in ne])
print('ne_cm3', [float(x)/1e6 for x in ne])
print('ne_250_cm3', float(iono['ne'].sel(alt_km=250))/1e6)
print('Te_250', float(iono['Te'].sel(alt_km=250)))
print('Ti_250', float(iono['Ti'].sel(alt_km=250)))
print('Tn_250', float(iono['Tn'].sel(alt_km=250)))

def s(k):
    return float(iono[k].values.reshape(-1)[0])
print('NmF2_cm3', s('NmF2')/1e6, 'hmF2', s('hmF2'))
print('foF2', s('foF2'), 'TEC', s('TEC'))
print('f107', float(iono.attrs['f107']), 'ap', float(iono.attrs['ap']))
print('nO+_250_cm3', float(iono['nO+'].sel(alt_km=250))/1e6)
PY
```

| 字段 | 含义 |
| --- | --- |
| `ne`/`nO+`… | 密度 **m⁻³**（上表另给 cm⁻³） |
| `Te`/`Ti`/`Tn` | 温度 **K** |

| `TEC` | 竖直 TEC（driver 积分，**m⁻²** 量级；本机 ≈2.03×10¹⁷） |
| `attrs f107`/`ap` | 运行采用的指数 |

### 3.1 CLI

```bash
python -m iri2016.altitude -h
# usage: altitude.py [-h] [-alt_km ALT_KM ALT_KM ALT_KM] time latlon latlon
python -m iri2016.altitude 2015-03-23T15:30 40 -80 -alt_km 100 500 50
# 无头显时 matplotlib 可能弹后端警告；算值仍以 IRI() 为准
```

README 另有 `latitude` / `time` 模块（纬度剖面、时间序列）。

### 3.2 关键 API

| 符号 | 作用 |
| --- | --- |
| `IRI(time, altkmrange, glat, glon)` | 主入口；`time` 为 ISO 字符串或 `datetime` |
| `iono['ne']` / `.sel(alt_km=250)` | xarray 选取 |
| `python -m iri2016.altitude` | 高度剖面 CLI |
| `build()` | 显式触发编译（通常不必） |

## 5. 坑（现象 → 原因 → 一条修复）

| # | 现象 | 原因 | 修复 |
| ---: | --- | --- | --- |
| 1 | Py3.8 拒绝安装 | `requires-python>=3.9` | 换 3.9+ |
| 2 | 首次极慢 / 刷 cmake | build-on-run | 正常；保留 `src/iri2016/build` |
| 3 | `ne` 与 pyglow 差 10⁶ | 单位 m⁻³ vs cm⁻³ | ÷10⁶ 再比 |
| 4 | `float(iono['NmF2'])` TypeError | 带 `time` 维 | `.values.reshape(-1)[0]` |
| 5 | 空输出 RuntimeError | driver 失败 | 查 Fortran/数据路径；重装 `-e .` |
| 6 | 改 JF 不生效 | 未重编译 | 删 build 后再 `IRI()` |
| 7 | 当 GIM/STEC 读取器 | 只会跑气候态模型 | [ionex-gim](./ionex-gim.md) / [pytecgg](./pytecgg.md) |
| 8 | 与 IRI-2020 论文比对失败 | 本包装是 **2016** | 换官方新版封装并写明版本 |
| 9 | CLI 无图 / 后端错 | 无显示 | 用 `IRI()` 取数；或设 `MPLBACKEND=Agg` |
| 10 | 与 pyglow 数值有小差 | 驱动/指数文件不同 | 固定单一工具链做论文图 |
