## 1. 场景

### 1.1 它是什么

BKG **Professional NtripCaster**：在 Linux 上按 NTRIP v1/v2 把多路 GNSS 实时流播给大量客户端（Icecast 血缘，GPL）。**只做播发与权限，不解码 RTCM 语义，不做 VRS。**

### 1.2 何时用

- 实验室/校园 CORS 多挂载点。  
- 课程需要真实的用户/组/源表。  
- 中继（relay）转发上级流到内网。  
- 客户端数量与权限模型超过 `gnssserver` 单挂载点试验。

### 1.3 何时不用

- 只拉公开流 → [BNC](./bnc.md)/[pygnssutils](./pygnssutils.md)。  
- 单挂载点 5 分钟演示 → `gnssserver`。  
- 需要 VRS/最近基站算法 → 换网络 RTK 方案。

### 1.4 故事

学院机房一台 Linux：三台教学接收机推流，学生用学号账号订阅；期中改密码；期末看 usage 日志谁在连。教师不用每人发串口线。

## 2. 概念

| 术语 | 人话 |
|---|---|
| sourcetable.dat | 源表 |
| users.aut / groups.aut | 用户与组 |
| clientmounts.aut | 谁能拉 |
| sourcemounts.aut | 谁能推 |
| encoder_password 等 | 推流/管理口令 |
| rehash / resync | 热加载配置思路（见手册） |
| relay | 中继拉取 |

容量：官网量级叙述约 100+ 源、2000+ 客户端（视硬件）。

## 3. 安装

仅 Linux。版本以 FTP 目录为准：

```bash
# 下载 ntripcaster-*.tar.bz2
bunzip2 ntripcaster-*.tar.bz2 && tar xf ntripcaster-*.tar
cd ntripcaster-*
./configure --prefix=/usr/local/ntripcaster
make && make install
```

配置目录把 `*.dist` 拷正式名（**勿用 Windows 记事本**，防 CRLF）：

```bash
cp ntripcaster.conf.dist ntripcaster.conf
cp sourcetable.dat.dist sourcetable.dat
cp users.aut.dist users.aut
cp groups.aut.dist groups.aut
cp clientmounts.aut.dist clientmounts.aut
cp sourcemounts.aut.dist sourcemounts.aut
```

## 4. 逐步例子 + 输出

### 4.1 改 ntripcaster.conf

核对：`server_name`（手册强调可解析主机名）、`port`（2101/80）、各类 password。

### 4.2 源表与权限

登记 STR；用户→组→clientmounts/sourcemounts 串起来。

### 4.3 启停

```bash
./ntripcaster start
./ntripcaster stop
./ntripcaster restart
```

**预期：** 浏览器 `http://host:port/home`；管理 `/admin`。

### 4.4 客户端冒烟

BNC 或 pygnssutils 订你的挂载点。**预期：** 有流；admin sources 可见。

### 4.5 推流侧

NtripServer/板卡/BNC 上传；核对 sourcemounts 密码。

### 4.6 relay（思路）

```text
relay pull -i user:pass -m /LOCAL1 remote.example:2101/REMOTE0
```

参数以当前手册为准。

### 4.7 日志

看 access/usage/ntripcaster 日日志，确认连接与流量。

## 7. 常见坑（≥12）

1. 源表空：流未上线或只显示在线。  
2. 能推不能拉：clientmounts 链断。  
3. 改配置不生效：未 rehash/重启。  
4. 端口不通：防火墙/<1024 权限。  
5. 期望 VRS：本软件不做。  
6. CRLF 损坏配置。  
7. server_name 乱填。  
8. 默认密码未改。  
9. 磁盘日志撑爆。  
10. 与 gnssserver 抢 2101。  
11. 只想拉 IGS：建 caster 过重。  
12. Windows 记事本编辑。  
13. 证书/HTTPS 未按手册。  
14. 用户并发限制误解。  
15. 时区日志难对。  
16. 无监控导致源静默。
