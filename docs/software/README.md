# 软件怎么用 · 超详细学习路径与索引

本目录把「目录里收录的软件」翻成**能动手的中文长文**（目标体量：主要工具文约两千行量级；维护者自有 SH-GIM 为准确中长述）。

固定结构：**场景 → 概念 → 安装 → 逐步例子（含预期输出）→ 格式 → 接到哪一步 → ≥8 坑 → 同类选型**。

不是源码大全，也不替代上游手册。链接与分类以 [`PROJECTS.json`](../../PROJECTS.json) 与 `lists/` 为准。

## 1. 五条主学习路径

### 路径 A · 尽快看到 TEC 曲线（科研入门最常用）

**目标：** 从公开 RINEX 得到可解释的 sTEC/vTEC，并与 GIM 量级对照。

| 步 | 读什么 | 做什么 | 完成标准 |
|---|---|---|---|
| A0 | [data-access.md](../data-access.md) | 下一站日 OBS+NAV | 文件能 `ls` 且非空 |
| A1 | [georinex.md](./georinex.md) | 确认双频相位、历元 | 能打印 sv/time |
| A2 | [anubis.md](./anubis.md) 可选 | lite QC | 完整性可接受 |
| A3 | [gfzrnx.md](./gfzrnx.md) 可选 | 抽稀/拼接 | 仅当需要 |
| A4 | [pytecgg.md](./pytecgg.md) | 校准 TEC | 有 stec/vtec 列 |
| A5 | 教程 [02](../tutorials/02-gnss-dualfreq-tec.md)·[09](../tutorials/09-dcb-biases-deep.md) | 理解为何要校准 | 能口述偏差 |
| A6 | [ionex-gim.md](./ionex-gim.md) | 对照 GIM | 日变化同向 |
| A7 | 教程 [16](../tutorials/16-practice-one-day-tec.md) | 一日实操闭环 | 图+笔记 |

**预计：** 3–7 天（含等数据与踩坑）。

## 3. 工具链总图（文字）

```text
公开/自建观测
    ├─ 实时 ─► pygnssutils / BNC ─► (可选) NtripCaster
    │              └─► RTKLIB / 板卡
    └─ 事后 RINEX
           ├─ GFZRNX（改） / Anubis（评） / georinex（读）
           ├─ PyTECGg / IonoMoni / OASIS ─► TEC·ROTI·AATR
           │         └─► IONEX / 定位残差对照
           └─ RTKLIB / PRIDE-PPPAR ─► 坐标·ZTD·模糊度
```

**口诀：** 改评读分离；拉拉播分离；绝对 TEC ≠ ROTI ≠ GIM 求解；PPP-AR ≠ 电离层产品。

## 9. 反模式（不要这样学）

- 跳过 QC 直接发表 TEC  
- 把 NTRIP 改正流当双频观测  
- 把 SH-GIM 公开仓写成可复现全球解  
- 把 PyTECGg 写成维护者论文工具而不署名 viventriglia  
- 同一天换五个软件比「谁 TEC 更大」却不对齐假设  
- 只调参不读教程 02/09
