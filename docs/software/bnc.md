# 第一章 · 这软件是干什么的（场景故事）

## 1.1 实时课上的「挂载点」

老师说：订阅 caster 上某站 RTCM3，录半小时，转成 RINEX 再算。浏览器下不了流；你需要 NTRIP 客户端。

**BNC（BKG Ntrip Client）** 是官方多流客户端：源表、多挂载点、端口转发、落盘、内置实时 PPP。轻量单流脚本可用 pygnssutils；自建播发看 BKG NtripCaster。
