## 1. 场景

### 1.1 它是什么

河南大学等相关团队开源的 **单站双频（多星座）电离层监测** 软件（C++17 / CMake，基于 GREAT-PVT 等）。XML 驱动，计算：

- STEC（CCL 载波到伪距整平；也可 UCPPP 路径）  
- VTEC（映射函数，含可选 Klobuchar 映射等）  
- **ROTI**、**AATR** 等扰动/不规则体指标  

含批处理与 Python 绘图脚本。

### 1.2 何时用

- 台站日处理、空间天气个例。  
- 需要编译型性能与批量站日。  
- 要「TEC 结构 + 不规则体」同一套配置。  

### 1.3 何时不用

- 只探活 RINEX → [georinex](./georinex.md)。  
- 可编程 Python TEC 校准流水线 → [PyTECGg](./pytecgg.md)（作者 viventriglia）。  
- 全球球谐 GIM 求解 → 其他开源 GIM / [SH-GIM](./sh-gim.md) 边界说明。  

### 1.4 故事

磁暴夜：业务 PPP 固定率断崖。IonoMoni 同站 ROTI/AATR 抬升与失锁同时段吻合，论文得以把「定位事故」写成「电离层不规则体证据链」。

## 2. 概念

| 术语 | 人话 |
|---|---|
| CCL | 载波到伪距整平估 STEC |
| hatch / arc_mean | 平滑策略（XML `<smoothing>`） |
| UCPPP | 非差非组合 PPP 类路径提 STEC |
| ROTI | TEC 变化率指标，不规则体常用 |
| AATR | 沿弧 TEC 变化率类扰动指标 |
| 映射函数 | STEC→VTEC；薄壳高度假设 |
| DCB | 硬件偏差；缺则弧段被剔或偏差大 |
| rec_dcb_corr | 是否改正接收机 DCB 的开关 |

## 3. 安装

### 3.1 Windows

Releases 常含 `bin/` 与 DLL（VS2022 / Win64）。

### 3.2 源码 CMake

```bash
git clone https://github.com/qiliu2025/IonoMoni.git
cd IonoMoni
cmake --preset <your-preset>
cmake --build build --config Release
```

### 3.3 Python 辅助

独立 venv，依赖见 `requirements.txt`；上游推荐较新 Python（如 3.13 方向，以当前 README 为准）。

`doc/IonoMoni_user_manual_*.pdf` 与样例 XML——**先读再改**。

## 4. 逐步例子 + 输出

### 4.1 准备输入

单站一日 OBS（RINEX 2/3）、手册要求的 SP3、DCB、EOP 等。

### 4.2 复制 XML 并改路径

启用模块：STEC/ROTI/AATR/VTEC；截止高度角；smoothing；rec_dcb_corr。

### 4.3 运行

```bash
./bin/IonoMoni path/to/your_config.xml
```

**预期：** 输出目录出现各模块结果文件（命名见手册）。

### 4.4 绘图

```bash
# 按 plot/ 说明把数据放入 data_roti 等目录后运行脚本
python plot/PythonScripts/...  # 以仓库实际脚本名为准
```

**预期：** ROTI/STEC 时序图。

### 4.5 批量

用 `batch_process` 脚本按站日循环。**预期：** 多站多天文件树。

### 4.6 与 OASIS 交叉

同站日两套 ROTI。**预期：** 扰动时段同向；绝对值因算法差不必强行一致。

### 4.7 与定位对照

高 ROTI 时段对齐 RTKLIB/PRIDE 固定率。**预期：** 叙事闭环。

## 7. 常见坑（≥12）

1. 未读手册改 XML。  
2. 脏观测当闪烁：先 QC。  
3. SP3 未覆盖弧段/PRN。  
4. 缺 DCB。  
5. smoothing 选错导致差异。  
6. 接收机 DCB 开关理解反。  
7. 映射函数/薄壳高度乱改。  
8. Windows DLL 路径。  
9. Linux 移植需自备依赖。  
10. GPLv3 合规。  
11. 批量覆盖输出。  
12. 把 AATR/ROTI 当同一指标。  
13. 低高度角多路径尖峰。  
14. 版本与手册不一致。  
15. 无 EOP 时某些模块。  
16. 绘图目录放错文件。
