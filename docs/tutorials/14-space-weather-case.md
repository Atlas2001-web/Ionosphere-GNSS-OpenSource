# 14 · 空间天气复盘课：如何读一场磁暴里的 TEC

> 前置：[03 GIM](./03-gim-ionex.md) · [05 闪烁/ROTI](./05-scintillation-roti.md) · [16 一日实战](./16-practice-one-day-tec.md)  
> 精通标志：换一个新事件，能按清单独立出图并写半页结论（不编造数字）。  
> 本课目标：学会「复盘方法论」，而不是背某次事件的 TEC 数字。

---

## 0. 先把黑话翻译成人话

读空间天气论文或业务简报时，你会撞上一堆缩写。本课**不假设你已经会这些词**。先用生活类比钉住直觉：

| 术语 | 人话直觉 | 为什么关心它 |
|---|---|---|
| **TEC** | 卫星信号穿过「电子雾」的厚度积分 | 雾厚会让测距变慢、定位漂 |
| **VTEC** | 把斜着穿雾的厚度，折算成「竖直往下看」的厚度 | GIM 地图上画的通常是它 |
| **STEC** | 某一颗星到接收机那条斜线的真实雾厚 | 单站估计先得到它 |
| **TECU** | 雾厚的单位（约 $10^{16}$ 电子/㎡） | 图上色标必须写它 |
| **GIM** | 全球电离层地图（格网或球谐） | 复盘时最常用的「公开底图」 |
| **IONEX** | GIM 的一种常用交换文件格式 | 下载后用读写库打开 |
| **磁暴** | 地磁场被太阳风「抽打」后剧烈抖动 | TEC 会跟着大范围变 |
| **耀斑** | 太阳突然喷一束强 X 射线/紫外 | 日侧电离可在分钟–小时尺度跳 |
| **IMF Bz** | 行星际磁场南北分量 | Bz 南向时常更容易「接上」磁层，驱动暴 |
| **SYM-H / Dst** | 量地磁暴强弱的指数（环电流） | 时间轴上标「主相/恢复相」 |
| **Kp** | 三小时地磁活动等级（0–9 粗档） | 挑安静日/扰动日很快 |
| **ROTI** | TEC 变化率指数，看「抖不抖」 | 不规则性，不是平均雾厚 |
| **S4** | 信号幅度闪烁指数 | 真正的闪烁强弱感 |
| **产品不确定性** | 同一天不同分析中心 GIM 本来就差几 TECU | 别把产品差当成物理发现 |

**厨房雾气类比（贯穿本课）**：

- VTEC ≈ 你站在灶台正上方，量「竖直方向有多厚的雾」。
- STEC ≈ 你斜着从窗口往灶台看，路径更长，雾显得更厚。
- GIM ≈ 气象局每天发的「全国雾厚填色图」。
- ROTI ≈ 「雾是不是在剧烈翻滚」——平均雾厚可能不变，但翻滚会让信号乱跳。
- 磁暴 ≈ 外面突然刮大风，整栋楼的通风系统被抽乱，雾的分布跟着变。

## 1. 你要练的能力（不是背答案）

课堂里最常见的失败模式是：打开一篇「2015 年某磁暴 TEC 升高 xx TECU」的论文，把数字抄进笔记，却不会换事件重做。

本课要你练的是五件事：

1. **会选对照日**（安静日 vs 太阳自转周对照，含义不同）。  
2. **会下公开产品**（IGS GIM、地磁指数、可选 ROTI）。  
3. **会做差分形态**（扰动日 − 对照日），并读出「在哪、何时、向哪迁」。  
4. **会把 TEC 与驱动时间线对齐**（Bz、太阳风速、SYM-H）。  
5. **会怀疑「这是物理还是产品假象」**（平滑过度、数据空洞、分析中心差）。

精通标志再强调一次：**换一个新事件，按同一清单出图 + 半页结论，且结论里不出现你没从图上读到的数字。**

## 2. 复盘总清单（打印可贴墙）

下面是**完整复盘检查表**。建议你每做一次事件就复制一份，逐项打勾。

### 2.1 事件钉钉（开场 20 分钟）

- [ ] 事件起止日期（UTC）写在笔记第一行  
- [ ] 事件类型勾选：耀斑 / CME 驱动磁暴 / 高速流 / 复合事件 / 不确定  
- [ ] 主相大致时段（看 SYM-H 或 Dst 谷值附近）  
- [ ] 最大地磁活动参考：Kp 峰值档位、SYM-H 最低值（写「来源链接」，勿凭记忆）  
- [ ] 若有耀斑：等级与峰值时刻（本课主线仍是 GNSS TEC，耀斑只作驱动旁注）  
- [ ] 研究区域预先声明：全球 / 中国区 / 低纬 / 高纬 / 某测站周边  

### 2.2 对照日选择（必须写清「用了哪种」）

- [ ] **方案 Q（Quiet day）**：事件前一个真正安静日（Kp 低、无大耀斑）  
- [ ] **或方案 R（Rotation）**：约 27 天前（太阳自转周近似对照）  
- [ ] 笔记里用一句话说明：为何选 Q 或 R，以及该对照**不能证明什么**  
- [ ] 对照日与扰动日的季节/地方时结构是否离谱（跨半年对照要额外小心）  

### 2.3 数据与工具（只用本仓库真实条目名）

- [ ] GIM：从 `CDDIS-IONEX` 下载至少一家；推荐再备 `JPL-IONEX-Rapid` 或 `ROB-IONEX-Products` / `GFZ-Global-Ionosphere-Maps` / `WHU-IGS-Ionosphere-AC` 作交叉  
- [ ] 读写：`ionex` / `ionex-rs` / `ionex_reader` / `ionex-analyzer`（任选其一先跑通）  
- [ ] 辅助拉取：`ionex-downloader`（以该仓库 README 为准）  
- [ ] 地磁/空间天气时间线：`GFZ-Kp-Index`、`NOAA-SWPC`、`NOAA-SWPC-Planetary-K`；太阳风可选 `NASA-OMNIWeb`  
- [ ] 近实时/业务 TEC 对照（可选）：`DLR-IMPC`、`DLR-IMPC-Products`、`ESA-TIO-NRT-TEC`、`NOAA-SWPC-GloTEC`  
- [ ] ROTI（可选）：`igs-roti`、`Okoh-MATLAB-ROT-ROTI`、`Ionospheric-TEC-ROTI-Interactives`  
- [ ] 注册与下载门槛已读 [`docs/data-access.md`](../data-access.md)  

### 2.4 出图最低集

- [ ] 安静日某时刻全球或区域 VTEC 填色图（色标 TECU，写分析中心与文件名）  
- [ ] 扰动日同地方时/同时刻 VTEC 图  
- [ ] **差分图** = 扰动 − 对照（同分析中心、同格网插值）  
- [ ] SYM-H（或 Dst）+ IMF Bz（若有）与区域平均 TEC 的同轴时间序列  
- [ ] （加分）两家分析中心同日差分直方图或 RMSE 表  
- [ ] （加分）同区域 ROTI 时间序列或 ROTI 地图，与 VTEC 差分对照  

### 2.5 结论写作门槛

- [ ] 全球一致还是区域性？日侧还是夜侧？与赤道异常（双峰）关系？  
- [ ] 增强/耗空谁先出现？相对 SYM-H 谷值有无延迟？  
- [ ] 是否可能来自 GIM 平滑、数据空洞、分析中心策略差？  
- [ ] 若看了 ROTI：不规则性增强是否与 VTEC 平均变化**同步**？（常常不同步——这是正常物理，不是你算错了）  
- [ ] 全文没有「论文里抄来的、自己图上看不见的」精确百分数

## 3. 复盘六步精讲（带「为什么」）

### 步骤 1：钉住事件

从 `NOAA-SWPC` 业务页面、空间天气文献常用事件表，或你课题组内部清单选一次。笔记模板：

```
事件：YYYY-MM-DD ~ YYYY-MM-DD (UTC)
类型：CME/磁暴（主相约 HH:MM）
地磁：Kp 峰值 = ?（来源：GFZ-Kp-Index / NOAA-SWPC-Planetary-K）
SYM-H 最低 ≈ ? nT（来源：……）
研究区：例如 20°N–50°N, 70°E–140°E
科学问题一句话：这次暴在东亚扇区是增强为主还是耗空为主？
```

**类比**：像写探案卷宗首页——先写清「案发时间与现场」，后面所有图都挂在这张封面上。

### 步骤 2：准备安静对照

两种对照**含义不同**，混用会自欺：

| 对照类型 | 像什么 | 适合回答 | 陷阱 |
|---|---|---|---|
| 事件前安静日 (Q) | 同一周「没刮风」的对照天 | 短期暴扰相对背景的变化 | 安静日其实不静；或暴前已有缓变 |
| ~27 天前 (R) | 太阳「转一圈」后的相似日 | 削弱季节/地方时气候背景 | 太阳活动本身在变，不是完美双胞胎 |

**强制动作**：在差分图标题写 `Storm − Quiet(Q)` 或 `Storm − Rot27(R)`，让读者一眼知道你在减什么。

### 步骤 3：下载产品

优先走公开、可复现路径：

1. 打开 [`lists/10-gnss-datasets.md`](../../lists/10-gnss-datasets.md)，定位 `CDDIS-IONEX`。  
2. 按 [`docs/data-access.md`](../data-access.md) 完成 Earthdata / CDDIS 授权（若需要）。  
3. 下载扰动日与对照日的 IONEX（注意最终/快速/预报产品差别：教学复盘优先**最终或事后分析**产品）。  
4. 用 `ionex` / `ionex_reader` / `ionex-rs` 读入，确认时间历元与经纬网。  
5. 地磁指数：`GFZ-Kp-Index`；空间天气综述：`NOAA-SWPC`；太阳风可选 `NASA-OMNIWeb`。

**产品层次直觉**：

- **最终 GIM**：事后用最多站、最稳策略做成的「慢但稳」地图。  
- **快速/近实时**：出图快，站网与平滑可能更糙——适合业务，复盘写论文要标明产品代次。  
- **业务 TEC**（`DLR-IMPC`、`ESA-TIO-NRT-TEC`、`NOAA-SWPC-GloTEC`）：延迟低，但算法与 IGS 分析中心不完全同一套；拿来对照可以，拿来当「唯一真理」危险。

### 步骤 4：画差分形态

核心运算（概念上）：

$$
\Delta\mathrm{VTEC}(\lambda,\varphi,t) = \mathrm{VTEC}_{\mathrm{storm}}(\lambda,\varphi,t) - \mathrm{VTEC}_{\mathrm{ref}}(\lambda,\varphi,t_{\mathrm{matched}})
$$

「时间匹配」常见两种：

- **同时刻 UTC**：简单，适合全球同帧对比。  
- **同地方时**：对「赤道异常双峰是否东移/西移」更友好，但实现稍烦。

读图时强迫自己回答：

1. 增强（正差分）主要在哪一地方时扇区？  
2. 耗空（负差分）是否出现在暴后夜侧/中纬？  
3. 结构是否沿纬度带迁移（像天气锋面扫过）？  
4. 换另一家分析中心，差分主瓣是否还在？（若主瓣搬家，先怀疑产品，再谈物理）

### 步骤 5：对齐驱动时间线

把下列量画在同一张时间轴（至少区域平均 TEC + 一个地磁指数）：

- IMF Bz（南向为负时常与能量注入相关）  
- 太阳风速 / 动态压（有则更好）  
- SYM-H 或 Dst  
- 你关心的区域平均 VTEC 或某测站 VTEC  

问三个「侦探问题」：

1. **谁先动？**（太阳风/Bz → 地磁指数 → TEC，延迟是否合理）  
2. **主相谷值附近 TEC 是升还是降？**（不同纬度答案可以相反）  
3. **恢复相是否出现「超安静」或长时间耗空？**

**红绿灯类比**：Bz 南向像「绿灯放行能量」，SYM-H 下跌像「路口开始堵」，TEC 变化像「街区雾浓度重分布」——三者不同步不代表你画错，可能是传播与局域动力。

### 步骤 6：套用结论模板（直接抄结构，填你自己的观察）

```
1) 形态：本次在【区域】表现为【增强/耗空/先增后耗】，主要出现在【日侧/夜侧/地方时 XX】。
2) 时间：相对 SYM-H 谷值，TEC 主要响应大约【领先/滞后约 N 小时】（仅基于本图，不外推）。
3) 结构：与赤道异常的关系是【双峰加强/抑制/偏移】。
4) 产品：同日两家 GIM 差约【X TECU 量级】；差分主瓣在换中心后【仍在/减弱/消失】，
   因此结论置信度为【高/中/低】。
5) ROTI（若有）：不规则性增强【与/不与】VTEC 平均变化同步；说明「抖」与「平均雾厚」是不同故事。
6) 局限：未使用测高仪/掩星交叉；GIM 平滑可能抹掉小于格网尺度的结构。
```

## 4. 安静日 vs 扰动日：你到底在比什么

### 4.1 安静日长什么样（直觉）

安静日的 GIM 通常能看到：

- 赤道附近两条「香蕉形」高 TEC 带（赤道异常双峰）随地方时东移；  
- 中纬日侧缓升、夜侧缓降；  
- 高纬冬季夜侧较低（还受季节影响）。

若你的「安静日」已经乱七八糟、Kp 不低，差分会把「假安静」减进去——等于探案时找错了对照组。

### 4.2 扰动日常见叙事（教学用，不是定律）

| 现象 | 时间尺度直觉 | 你优先看的产品 |
|---|---|---|
| 耀斑突然电离 | 分钟–数小时，偏日侧 | 日侧 TEC；本课主线仍是 GNSS TEC |
| CME/磁暴 | 更长，有初相/主相/恢复相 | GIM 差分 + SYM-H/Bz |
| 中纬暴扰增强/耗空 | 小时–天 | 区域平均 TEC 时间序列 |
| 低纬等离子体气泡/闪烁 | 夜侧，短时剧烈 | ROTI / S4，不是只看 VTEC 均值 |
| 高纬粒子沉降相关 | 暴时高纬 | 高纬扇区 + 闪烁产品；GIM 可能过滑 |

**重要纠错**：磁暴时「全球 TEC 一定升高」是谣言级简化。有的纬度增强，有的耗空；有的先增后耗。你的差分图才是法官，传说不是。

## 5. 产品不确定性：先承认「地图会吵架」

### 5.1 为什么两家 GIM 能差好几 TECU

IGS 分析中心（如 CODE、JPL、CAS、UPC、WHU 等，具体文件以 `CDDIS-IONEX` 当日名为准）各自有：

- 站网子集与加权；  
- 球谐阶数 / 格网分辨率 / 时间间隔；  
- DCB 估计与参考约束；  
- 平滑与约束强度；  
- 对数据空洞区的填补策略。

所以：**分析中心之间差数 TECU，常常是「正常产品噪声」，不是你发现了新物理。**

课堂实验建议（与 [18](./18-lab-compare-gims.md) 联动）：

1. 同一安静日、同一时刻，读两家 IONEX。  
2. 插值到同一经纬网，画 A、B、A−B。  
3. 记录 RMSE、均值、|Δ|>5 TECU 面积比例。  
4. 再对扰动日重复。问：暴日中心间差异是否系统性变大？

### 5.2 如何在结论里诚实表述

推荐句式：

> 「在 CODE 与 JPL 最终 GIM 上，该扇区暴扰差分主瓣方向一致；两中心绝对差的 RMSE 约 X TECU。因此我们只声称形态与符号，不声称精确到 1 TECU 的幅度。」

禁止句式：

> 「TEC 精确升高了 12.37%」（图上读不出这种精度时）。

## 6. ROTI vs VTEC：平均雾厚 ≠ 翻滚剧烈度

### 6.1 再讲一遍区别

- **VTEC**：某一时刻「有多厚」。适合讲增强/耗空、赤道异常形态。  
- **ROTI**：TEC 时间变化有多「毛」。适合讲不规则性、闪烁潜势、气泡边缘。

**高速公路类比**：

- VTEC 像「车道上平均车密度」；  
- ROTI 像「车流是否突然急刹加塞」。  
  密度高不一定乱；乱的时候密度也可能不高。

### 6.2 为什么暴时两者常常不同步

可能原因（教学列举，非穷尽）：

1. 大尺度增强由环电流/中性风重组驱动，GIM 平滑后仍可见，但小尺度不规则性另有触发条件（日落后天电、瑞利-泰勒等）。  
2. GIM 时间分辨率粗（如 1–2 小时），ROTI 常由 30 s / 更高采样站数据衍生——时间轴本来就不是同一尺子。  
3. 你的研究区夜侧低纬可能 ROTI 爆表，而同区平均 VTEC 只是缓变。

### 6.3 实操建议

1. 用 `igs-roti` 或 `Okoh-MATLAB-ROT-ROTI` 得到与事件重叠的 ROTI。  
2. 与同区域 VTEC 差分**分面板**画，不要硬叠成一张看不清的彩虹。  
3. 结论里强制写一句：「ROTI 与 VTEC 是否同步」。不同步时，优先相信「它们回答不同问题」，而不是「一定算错」。

更深闪烁背景见 [05](./05-scintillation-roti.md)、[13](./13-scintillation-modeling.md)。

## 7. 课堂小测验（先闭卷再对答案）

**Q1.** 差分图标题写了 `Storm − Quiet`，但对照日 Kp 其实到了 5。最大风险是什么？  
<details><summary>参考答案</summary>
对照不静，差分会把「对照日自身扰动」减进去或加进去，形态解释会被污染。应重选真正安静日，或改用明确标注的 Rot27 并讨论局限。
</details>

**Q2.** 两家 GIM 在赤道差 6 TECU，你能否据此写「发现赤道异常增强 6 TECU」？  
<details><summary>参考答案</summary>
不能直接这么写。先确认这是中心间产品差还是暴扰差分；至少做双中心一致性检查，并把产品不确定性写进结论。
</details>

**Q3.** 某夜侧低纬 ROTI 很高，但 VTEC 相对安静日几乎没变。这矛盾吗？  
<details><summary>参考答案</summary>
不矛盾。ROTI 反映不规则性/梯度抖动，VTEC 反映积分电子含量平均水平。气泡等结构可以「切碎」信号而不显著改变大尺度平均厚度。
</details>

**Q4.** 复盘时优先用近实时业务 TEC，还是事后最终 IONEX？为什么？  
<details><summary>参考答案</summary>
教学与论文式复盘优先事后最终/分析产品（如 CDDIS-IONEX 中的最终系列），可重复性与站网更稳。近实时适合业务演练，但必须标明产品代次。
</details>

**Q5.** 把 SYM-H 与 TEC 画在双轴图上，发现 TEC 峰值早于 SYM-H 谷值 2 小时。是否证明「因果反了、你画错了」？  
<details><summary>参考答案</summary>
不一定。不同物理量响应链长度不同；也可能是局域驱动或产品时间平滑造成的表观超前。应补充 Bz/太阳风，并检查时间配准与平均区域定义。
</details>

## 8. 作业（可交付物）

2. **一张时间轴**：至少 SYM-H（或 Kp）+ 区域平均 TEC。  
3. **十句结论**：必须覆盖「驱动 / TEC 形态 / 产品局限」三类句子。  
4. **工具清单**：写出你用过的 `PROJECTS.json` 中的 `name`（例如 `CDDIS-IONEX`、`ionex`、`GFZ-Kp-Index`）。

## 9. 常见翻车点（墙上贴纸）

1. **只贴暴日图、不做对照** —— 看不出「相对什么变了」。  
2. **色标任意拉伸、单位漏写** —— 审阅直接退回。  
3. **把分析中心差当成暴扰信号** —— 先做双中心检验。  
4. **只用 ROTI 或只用 VTEC 讲完整故事** —— 二者互补。  
5. **从论文抄精确幅度，自己图上没有** —— 违反本课诚实原则。  
6. **UTC / 地方时搞混** —— 赤道异常「东边升起」会讲反。  
7. **下载了预报 IONEX 却当最终产品写进结论** —— 代次必须标注。
