# 03 · GIM 是什么？从多站 STEC 到 VTEC 场，再到 IONEX

> **课堂定位**：接 01（TEC 概念）与 02（双频估 STEC）。你已经会说「斜的是 STEC、竖的是 VTEC」。这节课把**原理**钉死：全球电子含量图怎样从一堆斜路径观测**估计**出来；球谐系数在拧什么、Gibbs/振铃从哪来；IONEX 头与身子逐字段管什么；为何 CODE/JPL/UPC/WHU 会差几个 TECU；风暴−安静差值图在物理上到底在比什么。
>
> **写给谁**：第一次下载 IONEX、第一次听到各分析中心、第一次把 GIM 当「真值」的人；以及觉得「建图=插值上色」、原理过粗的人。

## 1. 这节课解决什么问题

### 1.1 三个现场

**现场甲**：领导要「今天全球 TEC 图」。你要的是某一时刻的 **VTEC 场（GIM）**，交换格式常见为 **IONEX**。  
**现场乙**：自建 STEC 与 GIM「同站」差十几 TECU——多半在比斜柱与格点竖柱，且未对齐时间、壳高、DCB。  
**现场丙**：用三天前 Final 假装「现在的空间天气」——时延档选错。

### 1.2 交付物

1. 口述从多站 STEC 到 VTEC 场的**观测方程**，并指出映射、DCB、时间参数角色；  
2. 用**三站玩具**说明欠定与正则的必要；  
3. 解释球谐系数含义与 **Gibbs/振铃**；  
4. **逐字段**读 IONEX 头 + 历元 map + RMS；  
5. 说出 AC 差异的 **WHY**（站网、壳高、约束等）；  
6. 解释风暴−安静差值的物理含义；  
7. 用 `PROJECTS.json` 真实 `name` 对照下图/读图/建图。

### 1.3 边界

不重讲 RINEX→STEC（02）；不把 IRI 当 GIM（04）；GIM 是观测反演**产品**，不是绝对真值。

## 2. 词表（原理向）

| 术语 | 人话 | 原理侧 |
|---|---|---|
| STEC / VTEC | 斜柱 / 天顶等效柱 | 观测单元 / 常用状态量 |
| GIM | 全球或大区域场产品 | 由许多 STEC 约束估计的时空场 |
| IPP / 壳高 \(h_s\) | 穿刺点 / 假想薄壳高度 | 3D→2D 挂钩；壳高改则 IPP 挪 |
| 映射 \(M(e)\) | 仰角相关换算 | 低仰角误差放大器 |
| DCB | 硬件延迟差 | 与 TEC 纠缠的慢变项；秩亏来源 |
| 球谐系数 / \(N_{\max}\) | 全球波形的旋钮 / 截断阶 | 控制可表示的最短空间波长 |
| Gibbs / 振铃 | 陡变附近过冲与旁瓣 | 截断级数副作用 |
| IONEX | 交换文本 | 头=说明书；身=历元格网 |
| AC、Final/Rapid/NRT | 分析中心、时延档 | 算法+站网+时效折中不同 |

**纪律**：禁止格点 VTEC 叫「我的 STEC」；禁止不看 EXPONENT；禁止 Final≡Rapid。

## 3. 原理核心：从许多 STEC 到 VTEC 场

### 3.1 问题与观测方程

手里是大量 \(\mathrm{STEC}_{r}^{s}(t)\)（02 课产物）。想要的是连续场 \(\mathrm{VTEC}(\lambda,\varphi,t)\)。薄壳近似下，课堂骨架为：

\[
\mathrm{STEC}_{r}^{s}(t)
\approx
M(e_{r}^{s})\,\mathrm{VTEC}(\lambda_{\mathrm{IPP}},\varphi_{\mathrm{IPP}},t)
+ b_{r} + b^{s} + \varepsilon
\]

逐项人话：

1. **左边**：斜路径柱（已含周跳、平滑等预处理假设）。  
2. **\(M(e)\)**：斜穿比竖直「更长」；仰角越低 \(M\) 越大，且对壳高越敏感。常见单层形式直觉为 \(M=\bigl(1-(\frac{R\cos e}{R+h_s})^2\bigr)^{-1/2}\) 一类（以软件为准）。  
3. **VTEC(IPP)**：把信息钉在穿刺点；\(h_s\) 一改，钉子的经纬就滑。  
4. **\(b_r,b^s\)**：接收机/卫星 DCB——与绝对 TEC 可互换「谁吃常数」，造成**基准秩亏**。  
5. **\(\varepsilon\)**：噪声、多路径、映射误差、薄壳误差、未模型化上层贡献等。

结论：GIM 不是「STEC 平均上色」，而是**带几何扭曲与偏差纠缠的空间场估计**。

### 3.2 映射：低仰角为何是放大器

- 高仰角：近竖直，壳高错一点伤得少。  
- 低仰角：IPP 滑远，\(M\) 大；水平梯度与多层结构被折进「等效 VTEC」。  

对比纪律：必须声明仰角截止与映射；低仰角时段单独评估。几何上可用 `Get_IPP` 等算穿刺点（以项目文档为准）。

### 3.3 DCB：慢变常数如何污染整张图

未约束时，整体抬升场与整体改偏差在观测方程里几乎同效果。实务靠：外部 DCB 产品、基准站、零均值约束、多系统策略。  
**自建 STEC（策略 A）减 GIM（策略 B）** 出现数 TECU 系统差，优先怀疑口径，不要先喊「GIM 错了」。

类比：未校准的零点不同的温度计联网画「全国气温图」——地图会吸收校准故事。

### 3.4 时间参数化直觉

电离层随地方时变，但单历元局部 IPP 可能不够。常用：

- 分片常数/线性（如 1 h、2 h 一张）；  
- 时间样条/基函数让系数慢变；  
- 近实时的递推更新（上一历元作先验）。

这是用「脸不会每分钟无关乱换」换稳定；代价是短时 TID、耀斑边缘被抹钝——**产品时间分辨率必须写进方法**。

### 3.5 空间未知数：有限维才能解

IPP 离散约束 → 必须选有限未知数：格网节点、球谐系数、或区域基。未知太少→抹真结构；太多→拟合噪声；海洋极区永远更欠定。建图=正则化估计，不是拍照。

### 3.6 数值玩具：三站看欠定

刻意简化（非真实算法）：

- 映射已做完，三站给出 IPP 上等效竖直观测：欧洲 \(y_A=20\)、东亚 \(y_B=35\)、太平洋 \(y_C=28\)（单位 TECU）。  
- 「全球场」却有成百上千格点，或几十个球谐系数。

**问 1**：三数能否唯一定全球图？  
不能。无数曲面穿过三钉——三颗钉子定不了一整张床垫。

**问 2**：若强行 \(\mathrm{VTEC}=c\) 全球常数且无偏差？  
三式矛盾，最小二乘得折中常数、残差巨大——模型过粗。

**问 3**：若 \(y=\mathrm{VTEC}(\mathrm{IPP})+b\)（公共偏差）+ 两三个低阶系数？  
未知数仍可能 ≥ 有效约束；解依赖先验（系数别太大、邻点别太陡）。**换先验，图换脸**——这是多 AC 差异的玩具版。

**问 4**：太平洋点为何「虚」？  
四周无站时颜色主要靠外推/平滑；差值图上大洋斑要降级。

**收束**：欠定是问题本性。IGS GIM 用站网+映射+DCB+时空正则把欠定压成可用产品；颜色连续 ≠ 处处被观测钉死。

相关 `name`：建图 `mosgim`、`mosgim2`、`SH-GIM`、`csonde-gnss-ionosphere`、`GNSS.IonosphereMaps`、`m_gim`、`M_GIM`；STEC 侧 `gnss-tec`。

## 4. 球谐 vs 格网：系数含义与 Gibbs/振铃

### 4.1 对照表

| | 格网 | 球谐 |
|---|---|---|
| 未知数 | 节点 VTEC | \(a_{nm},b_{nm}\) 至 \(N_{\max}\) |
| 直觉 | 位图像素 | 有限全球波形叠加 |
| 用户常见下载 | IONEX 格网 | 常已由系数合成格网 |
| 擅长 | 直观、区域加密 | 全球尺度、紧凑、周期边界自然 |

### 4.2 系数在拧什么？

- **低阶**：全球平均、粗日夜差、粗纬度结构。  
- **中阶**：大陆尺度起伏、EIA 两驼峰轮廓。  
- **高阶**：更窄的脊谷与区域梯度——前提是 \(N_{\max}\) 真开到那儿。

\(N_{\max}\) 决定可表示的最短波长。格网步长很细、但截断阶对应波长很粗时，**多出来的格点只是光滑插值**，不是新观测信息。

### 4.3 Gibbs / 振铃：陡变遇见截断

真场有准跳变或很陡梯度（空洞边界、强 EIA 边缘、风暴锋）时，有限项级数在附近出现**过冲/欠冲**和**旁瓣波纹**。图上的危险翻译：

- 密站区与空洞交界的「假波纹」；  
- 被低阶硬切的陡锋变成一串假脊；  
- 两边截断/平滑不同的差值图把振铃写进 ΔVTEC。

纪律：漂亮小尺度同心纹，先问 TID 还是旁瓣——用多站 STEC、ROTI 或区域产品交叉，勿仅凭全球球谐等值线认领。

### 4.4 格网也不是免检

空间平滑、变程、扩散约束同样抹峰、填海、造假梯度。许多流水线是 STEC→IPP→球谐/基函数→IONEX 格网；你看见格网，背后仍有截断。

## 5. IONEX 逐字段：头 + 历元 map + RMS

> 关键字以规范与具体文件为准；下列是「打开必须会找」的课堂字段级清单。生产读取优先：`ionex`、`ionex_reader`、`ionex-rs`、`Ionex_Parser`、`MathWorks-ionex_reader`。

### 5.1 头段字段直觉

| 字段直觉 | 你要回答 | 读错后果 |
|---|---|---|
| 版本/类型 | 是否 IONEX？产品类型？ | 解析假设错 |
| 分析中心 | 哪家 AC？ | 引用串台 |
| 首末历元与间隔 | 时间范围与切片 | 插错时刻 |
| 经纬起止步长 | 格网几何；0–360 还是 ±180？ | 太平洋镜像 |
| 壳高/高度行 | 薄壳或层高 | IPP/映射理解错 |
| 地球半径等 | 与映射一致吗？ | 自建对比系统偏 |
| **EXPONENT** | 整数如何还原 TECU？ | **数量级灾难** |
| map 数、是否 RMS | 循环多少张？有无不确定度？ | 只读首张；RMS 当 TEC |
| DCB 表（若有） | 是否附带偏差？ | 与自建口径冲突未声明 |
| 注释/模型简述 | 壳高、方法线索 | 漏掉关键假设 |

头=坐标轴+单位+作者+快门间隔；未读完就渲染，等于没看色标开发布会。

### 5.2 历元 map 怎么读

1. 历元标记开启一张图；  
2. 按纬度带（或规范次序）列各经度**整数**编码；  
3. × EXPONENT 还原 TECU；  
4. 拼成该时刻二维场；  
5. 用户点（时,纬,经）→ 时间插值 + 空间双线性等。

口诀：先时间片，再四个格点，再插值；有 RMS 别装误差为零。

### 5.3 RMS map

伴生不确定度/离散度，**不是**第二张 TEC。用于质控与差分显著性保守判断。写出/编辑：`ionex_formatter`、`INX_Editor`；`rtcm2ionex`；画图 `IonMap`、`INPE-TEC-Maps-IONEX`；差分 `DiffIonMap`。

### 5.4 使用者最小检查单（建议打印）

1. AC 与时延档是否正是我要引用的？  
2. EXPONENT 是否已乘？抽一格手算验证。  
3. 经度约定是否与我的脚本一致？  
4. 壳高是否写入方法？  
5. 是否按历元循环而非只读第一张？  
6. 若做相减，两边是否同 AC、同档、同格网定义？

## 6. IGS AC 差异的 WHY

框架入口：`IGS-Ionosphere-WG`；综合/验证相关：`UWM-IGS-Iono-Combination`。下载：`CDDIS-IONEX`（常需 `NASA-Earthdata-Login`）、`CODE-AIUB-Analysis-Center`、`CODE-AIUB-Product-Download`、`JPL-IONEX-Rapid`、`UPC-IONEX-Archive`、`WHU-IGS-Ionosphere-AC`、`GFZ-Global-Ionosphere-Maps`、`CAS-BDsmart-Iono-Products`、`CAS-BDsmart-RTS-Iono`、`ROB-IONEX-Products` 等。

**为何不同（背这六条）：**

1. **站网**：哪些站/星座/质控门槛 → IPP 密度地图不同；欧密洋疏是结构性的。  
2. **壳高与映射**：\(h_s\) 差几十公里，低仰角 IPP 可水平大挪；映射族不同=改观测方程系数。  
3. **DCB/偏差约束**：基准、外部 DCB、多系统策略 → 绝对水平与站偏置不同。  
4. **空间模型与正则**：\(N_{\max}\)、格距、平滑强度、区域加密 → 抹多少真梯度、造多少假光滑。  
5. **时间参数与时延档**：1 h/2 h、Final/Rapid/NRT → 噪声与时效折中不同。  
6. **上层/等离子体层口径**：斜路径高高度贡献处理不同 → 绝对 TEC 可差一截。

引用写清：`AC + 档 + 日期 + 文件名`。差 2–5 TECU 常见；更大时先查自己的 EXPONENT/经度/映射。

时延：事后精密→Final；较快→Rapid；准实时→NRT/RTS 并多源降级；勿用过期 Final 装「现在」。

## 7. 差值图：风暴 − 安静的物理含义

### 7.1 公式

\[
\Delta\mathrm{VTEC}(\lambda,\varphi,t)
=\mathrm{VTEC}_{\mathrm{storm}}(\lambda,\varphi,t)
-\overline{\mathrm{VTEC}}_{\mathrm{quiet}}(\lambda,\varphi,t)
\]

绝对场永远带着气候日变化。相减是为了**掀气候底子**，让相对安静基线的扰动笔迹显形。ΔVTEC 可与正暴抬升、负相耗空、EIA 变形等叙事相容，但**色斑≠唯一机理证明**——还要指数窗口（`GFZ-Kp-Index`、`NOAA-SWPC-Planetary-K`、`NASA-OMNIWeb`）与多源。

### 7.2 走查要点

写清问题→锁事件与指数→选同 AC 同档安静日（宜 3–5 日均）→读头核对→时间对齐相减→对称色标→换 AC/换基线/单站交叉→大洋降级。  
工具：读 `ionex`/`ionex_reader`；差 `DiffIonMap`；近实时 `ESA-TIO-NRT-TEC`、`NOAA-SWPC-GloTEC` 仅定性。

### 7.3 假象

红≠绝对很高；跨档/跨 AC 相减可造假风暴；色标不对称吞负相；振铃与填海造假结构；经度约定混乱出鬼影；脚本只减第一张 map。

### 7.4 与「模型残差」分工（预告 04）

安静日差值=**实况−实况**；IRI 残差=**实况−气候**。问题不同，不可偷换。

## 附录 A · 把观测方程「展开成估计问题」再看一眼

把所有历元、所有站星堆起来，形式上像：

\[
\mathbf{y} = \mathbf{A}\,\mathbf{x} + \mathbf{B}\,\mathbf{b} + \boldsymbol{\varepsilon}
\]

- \(\mathbf{y}\)：STEC 观测向量；  
- \(\mathbf{x}\)：VTEC 场参数（格节点或球谐系数，可含若干时间片）；  
- \(\mathbf{b}\)：DCB 等偏差；  
- \(\mathbf{A}\)：由映射与 IPP 几何决定——哪条斜路径「看见」场的哪一部分；  
- \(\mathbf{B}\)：把偏差吸进方程的设计阵。

若只最小化 \(\|\mathbf{y}-\mathbf{A}x-\mathbf{B}b\|^2\)，在 \(\mathbf{A}\) 列相关、海洋空洞、偏差与场耦合时，解不稳定。于是加正则：

\[
\min\;
\|\mathbf{y}-\mathbf{A}x-\mathbf{B}b\|^2
+
\lambda_s \,\mathrm{Smooth}(x)
+
\lambda_t \,\mathrm{TimePen}(x)
+
\lambda_b \,\mathrm{Constr}(b)
\]

\(\lambda\) 不是宇宙常数，是各 AC 的「审美与工程折中」。**这正是「同日多中心图不完全重合」的线性代数故事**：大家解的是相近物理，罚函数与站网不同。

三站玩具对应：\(\mathbf{y}\in\mathbb{R}^3\)，若 \(x\) 维度 ≫ 3，哪怕 \(\mathbf{b}\) 再简单，也必须靠 Smooth/截断把可行解集合捏小。课堂若只能记住一句：**观测方程告诉我们「测的是什么」；正则告诉我们「在欠定时偏爱什么长相的场」。**

### 附录 A.1 映射误差如何进入 \(\mathbf{A}\)

\(M(e)\) 写错，等于整行 \(\mathbf{A}\) 乘错系数。低仰角行权重若仍很大，错误映射会把错误竖直场「拧」进解。故有的中心提高仰角截止，或降权低仰角——这又改变有效站网几何。

### 附录 A.2 时间参数与「假静稳」

若时间罚过强，风暴主相快速抬升会被拖成钝坡；差值图幅度可能系统性偏小。若时间罚过弱，图表观更「活」，也更易吃噪声。读 Rapid/NRT 时，把「时间平滑策略未知」写成局限，比假装知道更好。

---

## 附录 B · 球谐阶数、格距与「假分辨率」对照直觉

假设某产品 \(N_{\max}\) 大致只能稳妥表示数千公里量级的结构，却输出 2.5°×5° 格网。2.5° 纬度约几百公里，看起来很细，但**有效自由度**仍由 \(N_{\max}\) 与约束决定。作业里禁止写「本 GIM 分辨率为 2.5°」而不提方法截断——应写「输出格距 2.5°，空间表示受球谐截断/平滑约束，有效分辨率随地区站网变化」。

Gibbs 旁瓣的空间尺度往往与截断波长同量级。若你声称探测到的 TID 波长短于产品可靠波长，审稿人有权要求原始高采样 STEC 证据。

## 附录 D · 差值图物理叙事的合格句式

合格：「在 `CODE` Final、世界时 12:00，相对 3 个安静日同时刻平均，东亚中纬 ΔVTEC 约为 +10 TECU，与主相时间对齐；UPC 同档差值同号、幅度差约 3 TECU；太平洋中部大斑 RMS 高，仅作提示。」

## 12. 原理加厚：观测方程里的每一项「如果错了会怎样」

上一节给出了骨架方程。这里用「故障树」方式加深：某一项处理错，图上会出现什么可识别的症状。初学者最需要的不是更多符号，而是**症状 → 嫌疑部件**的对照。

### 12.1 映射 \(M(e)\) 错了

**症状**：低仰角时段自建 VTEC 与 GIM 差急剧变大；高仰角却还好；或某地全日曲线在卫星东升西落低仰角段出现「喇叭口」残差。  
**原理**：\(M\) 是把斜观测折成竖直场的杠杆。杠杆比写错，等于把错误的竖直高度硬塞进 IPP。壳高与映射通常绑定——只改一个不改另一个，等于改几何故事的一半。  
**处理直觉**：统一映射族与壳高；提高截止仰角做对比实验；把低仰角权重降低后再看场是否还「需要」那些夸张梯度。

### 12.2 DCB / 基准错了

**症状**：整张图或某个区域相对其它 AC **整体平移**数 TECU，但空间型（哪里高哪里低）大体相似；或某接收机相关的一片 IPP 长期偏高/偏低。  
**原理**：偏差项与场的零点可互换。你「钉死」偏差的方式不同，场的零点就不同。三站玩具里那个公共 \(b\) 被不同先验吃掉，就会得到不同的平均高度。  
**处理直觉**：对比前先做相对量（差值、梯度、日变化振幅），或明确双方 DCB 策略；不要把绝对水平差立刻写成「物理增强」。

### 12.3 时间参数过硬或过软

**过硬（平滑太强）症状**：磁暴主相抬升被削峰，差值图幅度偏小，事件「看起来没那么猛」。  
**过软症状**：图表观热闹，但海洋空洞区出现随噪声跳动的斑块，换一天随机种子（或换一批站）斑块就换地方。  
**原理**：时间正则是在「信物理连续性」与「信瞬时观测」之间投票。

### 12.4 空间截断 / 平滑过强

**症状**：EIA 两峰粘成一座高原；已知的尖锐耗空通道被抹成浅碟；或相反，在数据边界出现振铃波纹。  
**原理**：\(N_{\max}\) 与 Smooth 决定场的函数空间。你不在那个空间里的真结构，要么进残差，要么被投影成「最像的假结构」（含 Gibbs）。

### 12.5 站网空洞

**症状**：大洋、极区、部分南半球内陆颜色仍光滑美丽；RMS（若有）偏大；换 AC 后这些区域是分歧最大的地方。  
**原理**：那些格点的信息主要来自外推与先验，不是来自当地钉死的 IPP。差值图在这些区域的「物理叙事权」应被降权。

## 13. 三站玩具的「加站」实验（继续欠定直觉）

在原三站基础上，想象你逐步加站，观察「解的自由度」如何被压缩。仍是思想实验。

### 13.1 加到十个站，但仍在同一经度带

若新站的 IPP 都挤在欧亚大陆同一窄经度带，你对「该经度带的纬度剖面」约束变好，但对太平洋、美洲仍几乎没有新信息。结论：**站数 ≠ 全球可观测性**；要看 IPP 的空间覆盖。

### 13.2 加一批低仰角跨洋链路

表面覆盖变好，但这些观测对壳高与映射极敏感，且多路径更重。它们提供的是「强杠杆、高噪声」的方程行。是否纳入、如何降权，又是各 AC 分歧点。

### 13.3 加约束：邻点差分惩罚

哪怕只有三站，加上「相邻格点差的平方和要小」，也能得到唯一的一张光滑图。那张图会漂亮地穿过三钉并在别处尽量平坦——**漂亮来自罚函数，不来自观测**。这是对「颜色好看=测得真」的最终警告。

### 13.4 与真实 GIM 的对应

真实 IGS 产品用的是全球数千站量级的可能观测（经质控后仍极多），但有效独立信息仍受几何、偏差、时间相关噪声限制。所以「大数据」没有取消欠定，只是把欠定从「全局瞎猜」推进到「局部仍虚、全局大体稳」。

## 14. 球谐系数：再往下挖一层直觉

### 14.1 「阶」与「位」

口头区分：

- **阶 \(n\)**：大致对应空间波长——\(n\) 大，纹波更碎。  
- **位 \(m\)**：大致对应经度方向有多少瓣、是否随经度变化（\(m=0\) 常与经度无关的纬向结构相关）。

你不必会推缔合勒让德，但要能说：截断到低 \(n\)，等于宣布「我不相信更碎的结构是可由这些数据稳定估计的」。这是科学诚实，也是分辨率上限。

### 14.2 系数的时间序列

有的中心估的是每个时间片一套系数，有的让系数在时间上平滑。风暴来临时，某些低阶系数会显著抬升/改变——这可以当作「全球型响应」的压缩表示。但把单一系数曲线写成「发现了新波动模式」前，先排除：是不是站网昼夜变化、DCB 日变、或映射在地方时结构上的投影。

### 14.3 Gibbs 的电离层专属例子

设想夜侧突然出现一条窄的耗空通道（泡崩塌后的 TEC 谷），宽度窄于截断波长。球谐会：

1. 用一系列宽波去「凑」这条窄谷；  
2. 在谷两侧造出过冲的假脊；  
3. 在更远处留下弱波纹。

若你对差值图做高通滤波，可能把这些旁瓣当成一串 TID。**正确动作**：回到沿通道穿越的密集站 STEC 时间序列，看是否有传播延迟；没有，就不要用全球 GIM 认领。

### 14.4 格网估计的「隐式球谐」

即使直接估格网，强平滑的格林函数效应也类似低通；在尖锐边界同样可能出现数值波纹。名字不叫 Gibbs，病同类。

## 15. IONEX 字段级「对照实物」阅读剧本

假设你打开一份文本，按下面顺序喊字段（名称以实际文件为准，这里用课堂别名）：

1. **我是谁**：文件类型、版本、生成程序或中心名。  
2. **我何时**：第一张与最后一张图的时间、间隔秒/小时。  
3. **我哪家**：AC 代码——后面所有引用跟着它。  
4. **我的网**：纬度从南到北还是反过来、起止、步长；经度同理；是否跨日界线。  
5. **我的尺子**：EXPONENT；手算：看见整数 123，指数 −1，则 12.3 TECU。  
6. **我的壳**：HGT 或注释中的壳高。  
7. **我有几张**：TEC map 数；RMS map 数是否相同。  
8. **我是否附带偏差表**：有则记下，对比自建时声明。

然后进入第一张 map：确认纬度带标题与数据个数 = 经度点数；抽查边缘点是否在合理 TECU 范围（例如全球常见个位数到数十，极端可更高，但 1000 量级要怀疑没乘指数）。再跳到文件中部某历元，确认脚本循环正确。最后若有 RMS，确认其动态范围与 TEC 不同，避免色标混用。

下载与登录提醒：`CDDIS-IONEX` 常需 `NASA-Earthdata-Login`；也可用 `JPL-IONEX-Rapid`、`UPC-IONEX-Archive`、`CODE-AIUB-Product-Download` 等作对照源。

## 16. 多 AC 差异：把 WHY 写成「实验设计」

如果你要写半页「为何我选这家产品」，可用下列实验设计句式：

1. **覆盖需求**：我关心东亚陆地 → 检查该区域 IPP 是否通常较密；若关心太平洋中部，承认任何全球 GIM 都偏软。  
2. **时延需求**：论文事后分析 → Final；业务次日 → Rapid；值班 → NRT 并写降级策略。  
3. **交叉需求**：主结论必须在至少两家 AC 同号；幅度取范围而非单点。  
4. **壳高需求**：若我自建也用 450 km，优先选头段壳高接近者，减少映射口径差。  
5. **RMS 需求**：若要做「显著性」，优先有 RMS 或可多日统计离散度的产品。

相关中心入口再次点名：`WHU-IGS-Ionosphere-AC`、`GFZ-Global-Ionosphere-Maps`、`CAS-BDsmart-Iono-Products`、`CAS-BDsmart-RTS-Iono`、`ROB-IONEX-Products`、`Beihang-Ionosphere-CN`（展示/门户，与 AC 产品树区分引用）。

## 17. 风暴−安静：物理含义的分层解释

### 17.1 第一层（必须会）

ΔVTEC 是**相对近期安静实况的偏离场**。它去掉大部分规则日变化，让事件扰动更好读。

### 17.2 第二层（原理加一层）

安静日并不是「零物理」，只是地磁安静、太阳条件相近。若安静日选在不同季节或不同 F10.7 周相，差值会混入气候差。故「同季节、同档产品、多日平均」是在减少**基线污染**。

### 17.3 第三层（与驱动对齐）

正异常区若出现在日侧中低纬、时间贴主相，可与穿透电场/风场扰动等机制「候选列表」对齐；负异常在中纬恢复相常见于负相风暴叙事。但 GIM 差值不能单独排除别的候选——需要测高仪 foF2、掩星 Ne、单站 STEC、ROTI 等。现象课 19–20 会继续；本课只要求：**差值是证据板，不是判决书**。

### 17.4 第四层（产品伪差）

若风暴日用 Final、安静日误用 Rapid，或一边 CODE 一边 JPL，ΔVTEC 含产品系统差。这在法庭上应归「假风暴」而非「地球物理」。

## 20. 终章朗读稿

从许多斜路径到一张全球图，中间隔着映射、偏差、壳高、时空正则和站网几何。方程告诉我们测到了什么；欠定告诉我们为何必须偏爱某种光滑；球谐系数告诉我们偏爱了哪些波长；Gibbs 提醒我们截断会说谎；IONEX 头告诉我们尺子与作者；分析中心差异告诉我们方法选择不是噪音而是产品身份；风暴减安静告诉我们如何掀开气候底子看笔迹。读图的人若只记住彩虹，便停在海报；若记住观测方程与欠定，才算进入 03 课的原理门。
