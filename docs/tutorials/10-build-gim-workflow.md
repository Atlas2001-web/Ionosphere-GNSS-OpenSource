# 10 · 从多站 GNSS 到 GIM：一条能落地的流水线

目标：不是背「球谐阶数」，而是能画出**自己的区域/全球电子含量图**该经过哪些站。

## 总流程图（记这个）

```
连续跟踪站 RINEX
    → 质量检查 / 周跳
    → 每站每星 STEC（处理 DCB）
    → 穿刺点 IPP + 映射函数 → VTEC 采样
    → 空间表示（格网插值 或 球谐/其他基函数）
    → 时间滑动或逐时段解算
    → 和 IGS GIM / 测高仪 / 掩星交叉验证
```

## 每一步在干什么

### 1. 选站与数据

- 全球：IGS / 区域连续运行站网；中国区常看 CORS、陆态网等（注意数据申请）。
- 时间分辨率：科学分析常用 30 s 或更高；出图可以先 15 min / 1 h 一帧。
- 数据入口见 [`lists/10-gnss-datasets.md`](../../lists/10-gnss-datasets.md) 与 [`docs/data-access.md`](../data-access.md)。

### 2. 单站 TEC

用 `gnss-tec` 一类工具从双频观测量到 STEC。先求「能复现文献图的量级」，再抠绝对标定。

### 3. 穿刺点与薄壳

常用简化：假设电子集中在某一高度薄壳（如 350–450 km），把斜路径 TEC 映射成天顶方向 VTEC，并把贡献记在穿刺点经纬度上。

局限（课堂必须说）：真实有厚层、有倾斜梯度；低高度角误差大。所以高度角截止（如 15°–20°）很常见。

### 4. 空间模型怎么选

| 做法 | 适合 | 代价 |
|---|---|---|
| 格网 + 插值（IDW/Kriging 等） | 区域网、实现快 | 边界与稀疏区易假结构 |
| 球谐展开 GIM | 全球/大区域、与 IGS 传统接近 | 要理解阶次截断与 Gibbs 假振荡 |
| 其他基函数 / 层析 | 研究型 | 见第 11 课 |

维护者仓库 `SH-GIM` 属于球谐路线的实现之一；学习时以公开 IGS 产品与通用读写库为主即可。

### 5. 验证清单（精通的人天天做）

- 和 CODE/JPL/CAS 等 GIM 的差分直方图
- 安静日日变化是否合理（地方时结构）
- 磁暴日是否出现「假空洞」（往往是映射/数据空洞）
- 与测高仪 foF2、掩星电子密度积分是否同向变化
