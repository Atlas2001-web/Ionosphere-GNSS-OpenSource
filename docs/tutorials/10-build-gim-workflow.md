# 10 · 从多站 GNSS 到自建 GIM：一条能落地的流水线

> **课堂定位**：接 [02](./02-gnss-dualfreq-tec.md)、[03](./03-gim-ionex.md)、[09](./09-dcb-biases-deep.md)。你已会「单站双频 TEC」与「打开别人的 IONEX」。本课回答：**站网观测怎样收成一张自建/可理解的 GIM**，以及每一步为什么会漂亮地出错。
> 路线固定为四段：
> **机制 → 公式拆解（逐步推导）→ 观测签名 → 分析步骤**。
> 你会听到「做菜」「保鲜膜」「雾里采样」「监控录像认人」类比；每条后面立刻配符号、单位与可追问的机制。
>
> **写给谁**：第一次想「自己出一张 TEC 图」就被球谐阶数、壳高、DCB 基准绕晕的人；以及想分清「读现成 IONEX」与「自建流水线」分工的人。
>
> **学完交付**：用因果链默画「站网→IPP→薄壳/VTEC→格网→时间片」；解释为何必须处理 DCB/基准；手算映射与格网权重小例；一眼区分「合理 GIM / 站网空洞伪影 / 日界线假锋」；按最小可行流水线与质控门禁跑通一日试生产；说出至少 2–3 条误解与测验要点。
>
> **项目名**均来自根目录 [`PROJECTS.json`](../../PROJECTS.json) 的 `name` 字段。

## 0. 开场：三个真实场景

请先合上笔记本，想三件事：

1. **领导要「我们自己的全球 TEC 图」**：有人直接下载 CODE/JPL 的 IONEX 贴色图（那是**读产品**，见 [03](./03-gim-ionex.md)）；有人拿 3 个站做 Kriging，海洋上仍出现精致涡旋；有人喊「球谐阶数再加高」。三种都能出图，但**主标签只能有一个**——本课钉死：自建 GIM = 站网观测经质控、偏差、映射、空间表示与时间片后的估计场。
2. **你的图和官方差 8 TECU**：是你错了，还是 DCB 基准不同、时间没对齐、空洞区被插值填满了？链式回 [09](./09-dcb-biases-deep.md) 与本课观测签名段。

## 1. 词表（先扫一遍，主讲后再回看）

### 1.1 建图核心物件

| 术语 | 人话 | 稍严 |
|---|---|---|
| **GIM** | 全球或大区域电离层「柱总量」图 | Global Ionosphere Map；通常给 VTEC，≠ 三维密度 |
| **IONEX** | 交换 GIM 的常用文本格式 | 不会读写就难与社区互操作（[03](./03-gim-ionex.md)） |
| **IPP** | 射线与薄壳的交点 | Ionospheric Pierce Point；VTEC「采样点」落在地图上的位置 |
| **薄壳（thin shell）** | 假设电子集中在某一高度的薄层 | 把 STEC→VTEC 的常用简化；本身是误差源 |
| **壳高 $h_{\mathrm{ion}}$** | 那张「保鲜膜」的高度 | 常取 350–450 km；选错会扭赤道异常等结构 |
| **映射函数 $M$** | 「斜路有多斜」的几何因子 | STEC ≈ VTEC × $M$；低仰角 $M$ 大、误差放大 |
| **高度角截止** | 丢弃过低仰角观测 | 常用 15°–20°；用数据量换映射/多路径稳健性 |
| **VTEC 采样** | 落在 IPP 上的垂直 TEC 估计 | 建图的「原料点」；不是最终格网产品 |
| **格网 / 球谐 GIM** | 把采样收成连续场的两种常见做法 | 插值快、稀疏易假；球谐贴近 IGS 传统、阶次有截断 |
| **时间片** | 某一时段的一张图 | 太粗糊掉 TID；太细噪声主导 |
| **分析中心（AC）** | 产出官方/准官方 GIM 的机构 | 你的验证「真值」其实也是估计 |

### 1.2 偏差与基准（建图时要命）

| 术语 | 人话 | 稍严 |
|---|---|---|
| **DCB** | 硬件延迟差，像尺子零点偏了 | 卫星/接收机差分码偏差；详见 [09](./09-dcb-biases-deep.md) |
| **基准 / 零点约束** | 把「整图抬高或压低」钉住 | 常用卫星 DCB 和为零、或对齐某家产品 |
| **系统偏差 vs 结构差** | 整图平移 vs 形状不对 | 差分时要分报 bias 与 std |

### 1.3 邻居们（别认错门）

| 术语 | 人话 | 稍严 |
|---|---|---|
| 读现成 IONEX | 别人已经建好的图 | [03](./03-gim-ionex.md)；本课上游产品 |
| 单站 TEC | 一条视线/一个站的柱量 | [02](./02-gnss-dualfreq-tec.md)；建图原料 |
| 层析 | 追高度上的 $N_e$ | [11](./11-tomography-basics.md)；比 GIM 更病态 |
| 同化 | 模式背景 + 观测更新 | [12](./12-data-assimilation-intro.md) |
| ML 贴图 | 从历史学出场 | 可有用，≠ 基于站网 STEC 的经典 GIM |

**纪律**：未声明站网、壳高、截止角、DCB/基准、空间模型前，禁止把任意色图叫「自建 GIM」；禁止把下载裁剪 IONEX 写成「构建」；禁止只用「换网格重跑」当验证。

## 3. 因果链：站网 → IPP → 薄壳/VTEC → 格网 → 时间片

把建图想成做菜：

| 步骤 | 在干什么 | 类比 | 失败时图会长什么样 |
|---|---|---|---|
| 选站网 | 决定哪里有「探针」 | 选菜：产地决定鲜度与覆盖 | 大片平滑色块（其实没菜） |
| QC / 周跳 | 扔掉脏观测 | 洗净 | 台阶/麻点被当成「真结构」 |
| STEC + DCB | 得到斜路径柱量并钉零点 | 切配 + 调味基准 | 整站偏高/偏低，低阶「背锅」 |
| IPP + 映射 | 把斜量变成壳上一点的 VTEC | 把雾厚换算到保鲜膜位置 | 低纬结构搬家；边界假梯度 |
| 空间模型 | 从离散采样估连续场 | 摆盘：插值或球谐「抹平」 | 空洞假涡旋；球谐环状振荡 |
| 时间片 | 按时段出图 | 一道菜一道上 | 糊掉 TID，或把噪声当行进波 |
| 写 IONEX / 验证 | 互操作 + 证明不是幻觉 | 尝味、贴标签 | 自嗨色图；审稿人打不开 |

### 3.1 站网决定「采样足迹」，不是「分辨率口号」

陆密洋疏是结构性的：太平洋上没有魔法 GNSS 站。你宣称的「全球 2.5°×5° 格网」在无 IPP 的地方，只是算法在说话。

![GNSS 站网与海岸：选站覆盖](./images/fig-gnss-network-coast.png)

> **看图要点（为什么选站是第一步）**
> - **机制**：选站决定 IPP 能钉住哪里；陆密洋疏不是画图软件的锅。
> - **看什么**：目标区周围有没有站；大片空白就要接受平滑外推。
> - **别误判**：示意站网；点得多 ≠ 质控都过关。
> 图源：自制 CC0 + Natural Earth 海岸线。

### 3.2 IPP：VTEC「钉子」钉在哪里

射线从卫星斜穿大气，与你假设的薄壳相交——交点的经纬度就是 IPP。壳高一变，同一条射线的 IPP 会水平挪动（斜路径与更高膜相交更远）。

![穿刺点几何：射线与薄壳相交](./images/fig-ipp-pierce-point.png)

> **看图要点（为什么要认 IPP）**
> - **机制**：建图原料不是测站正上方，而是壳上的穿刺点。
> - **看什么**：站在地面、钉在壳上——两者水平位置常不一致。
> - **别误判**：站很密但低仰角 IPP 全滑到区外，目标区仍可能采样不足。
> 图源：自制 CC0。

![IPP 地面轨迹海岸图](./images/fig-ipp-tracks-coast.png)

> **看图要点（为什么轨迹图是第一眼工具）**
> - **机制**：壳高与仰角决定 IPP 落点；轨迹图检查「采样是否围住研究区」。
> - **看什么**：弧线是否盖住目标海岸带；低仰角是否滑出区外。
> - **别误判**：示意几何；壳高一改，弧线会挪。
> 图源：自制 CC0 + Natural Earth 海岸线。

### 3.3 薄壳：把厚雾压成保鲜膜

真实电离层有厚度、有倾斜梯度。薄壳说：「先假装雾只存在于高度 $h_{\mathrm{ion}}$ 的一张膜上。」这样 STEC→VTEC 有闭式几何，IPP 有明确落点——**代价是系统性近似误差**，在强水平梯度与低仰角时更大。

![薄壳路径：整柱压到壳上一点](./images/fig-shell-ipp-path.png)

> **看图要点（为什么薄壳是工程近似）**
> - **机制**：斜路径穿过整层，产品却只在壳高记一个点。
> - **为什么**：GIM 要的是柱总量图，不是高度剖面；高度问题留给 11 课。
> - **别误判**：壳图画得漂亮 ≠ 你知道 200 km 与 400 km 谁多谁少。
> 图源：自制 CC0。

![STEC / VTEC 与薄壳关系](./images/fig-stec-vtec-shell.png)

> **看图要点（为什么还要映射）**
> - **看什么**：斜积分（STEC）与垂直柱（VTEC）的几何关系。
> - **为什么**：同一「雾厚」斜着看读数更大，必须除以映射因子。
> - **别误判**：映射再准也只是柱量变换，不是层析。
> 图源：自制 CC0。

### 3.4 格网：从钉子到连续场

有了散落在地图上的 VTEC 采样，你还要估计每个格点的值——IDW、Kriging、球谐展开等都是「把离散采样收成场」的不同规矩。**点的疏密直接决定哪里可信**；空洞处的漂亮等值线要降权。

![GIM 格网与 IPP 采样点](./images/fig-gim-grid-ipps-coast.png)

> **看图要点（为什么格网图要叠 IPP）**
> - **机制**：建图 = 把 IPP 上的 VTEC 估计到格网；覆盖决定可信区。
> - **看什么**：场与红点是否匹配；空洞处精致涡旋要怀疑。
> - **别误判**：换网格重跑漂亮 ≠ 独立验证。
> 图源：自制 CC0 + Natural Earth 海岸线。

### 3.5 时间片：何时出一张图

可逐小时独立解，或滑动窗口。入门先固定 1 h 或 2 h，能画出地方时结构再说。用 2 h 平均图去「发现」20 分钟 TID，是时间维的经典翻车。

## 4. 为什么需要 DCB / 基准？（机制因果）

双频几何无关组合消掉了几何与钟差的主导项，却把卫星与接收机的硬件延迟差（DCB）留在 STEC 里。像一排厨房秤，每台零点都偏一点：

- **不改正**：整站系统性偏高/偏低；球谐低阶或大尺度场会「背锅」。
- **改正但基准不一致**：你的图与 CODE 差一个近似常数——看起来像「错了 8 TECU」，其实是零点约定不同。
- **码类型与 DCB 产品不一致**：零点改正变成零点破坏。

深潜公式与分离策略见 [09](./09-dcb-biases-deep.md)。本课只要你记住建图纪律：**方法节必须写清 DCB 来源与零点约束**；差分官方产品时先报告系统偏差（bias），再报告结构差（std）。

![DCB 像平行抬升：整图平移 vs 结构扭曲](./images/fig-dcb-parallel-shift.png)

> **看图要点（为什么先分 bias 与结构）**
> - **机制**：未处理或基准不同的 DCB，常表现为近乎平行的抬升/压低。
> - **看什么**：差分直方图均值是否远离 0；形状（梯度、双峰）是否仍对得上。
> - **别误判**：均值接近 0 ≠ 结构也对；结构对 ≠ 绝对水平已标定。
> 图源：自制 CC0。

## 6. 空间模型怎么选？（机制层，不堆公式）

| 做法 | 适合 | 代价 | 目录可对号 |
|---|---|---|---|
| 格网 + 插值（IDW/Kriging 等） | 区域网、实现快 | 边界与稀疏区易假结构 | 思路参考 `Ionospheric-TEC-Kriging-Turkiye` |
| 球谐展开 | 全球/大区域、贴近 IGS 传统 | 阶次截断、Gibbs 假振荡、空洞处环状假波 | `SH-GIM`、`mosgim`、`mosgim2`、`m_gim`、`M_GIM` |
| 其他基函数 / 层析 | 研究型三维 | 病态、要先验 | [11](./11-tomography-basics.md) |

机制口诀：**插值听附近的钉子；球谐听全球的波；层析还想拆高度。** 钉子不够时，插值会编故事，球谐会振荡——两者假象长相不同（见第三段）。

## 7. 公式路线图（建图最常落地的三段）

**链 A（单点映射）：**

$$
\mathrm{STEC}
\;\xrightarrow{M(E,h_{\mathrm{ion}})}\;
\mathrm{VTEC}\approx\frac{\mathrm{STEC}}{M}
\;\xrightarrow{\mathrm{IPP}}\;
(\varphi,\lambda).
$$

读法（中文在公式外）：斜 TEC 除以映射因子得垂直 TEC，并记在穿刺点经纬度 $(\varphi,\lambda)$ 上，成为建图采样。

**链 B（格网聚合直觉）：**

$$
\hat{v}(\mathbf{r})
=\sum_i w_i\,v_i\Big/\sum_i w_i,
\qquad
w_i=f(d_i).
$$

读法（中文在公式外）：格点估计 = 邻近 IPP 采样的加权平均；权重随距离衰减。

**链 C（与官方差分礼仪）：** 时间对齐 → 空间插到同网格 → 掩膜有效区 → 分带报 bias 与 RMSE。

## 8. 解剖台 A：薄壳映射（STEC → VTEC）

> 格式：**符号表 → 逐步推导 → 小数值例**。把「斜着看雾」翻译成可手算的 $M$。

### 8.1 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $E$ | 高度角（elevation） | 度或 rad；计算时统一 |
| $R_e$ | 地球平均半径 | ≈ 6371 km |
| $h_{\mathrm{ion}}$ | 薄壳高度 | 常用 350–450 km |
| $M$ | 映射因子 | 无量纲；天顶 → 1 |
| $\mathrm{STEC}$ | 斜路径总电子含量 | TECU（1 TECU = $10^{16}\,\mathrm{el\,m^{-2}}$） |
| $\mathrm{VTEC}$ | 垂直柱总量 | TECU |
| $z'$ | 穿刺点处的天顶距类角 | 由 $E$ 与壳高几何决定 |

### 8.2 逐步推导（每步人话）

1. **几何图像**：卫星不在头顶时，射线斜穿「雾层」，路径更长 → 读数更大。  
2. **薄壳闭式**：假设雾只在高度 $h_{\mathrm{ion}}$ 的膜上，可用球几何写出映射因子。教学常用单层形式之一（变体以你所用工具/论文为准）：

$$
M(E)=\frac{1}{\sqrt{1-\left(\dfrac{R_e\cos E}{R_e+h_{\mathrm{ion}}}\right)^{2}}}.
$$

3. **换算**：

$$
\mathrm{VTEC}\approx\frac{\mathrm{STEC}}{M(E)}.
$$

等价地，有人写成 $\mathrm{STEC}\approx\mathrm{VTEC}\times m$，并令 $m=M$。  
4. **极限检查**：天顶 $E\to 90^\circ$，$\cos E\to 0$，$M\to 1$，STEC≈VTEC。低仰角 $M$ 增大，同样噪声被放大进 VTEC。  
5. **壳高进入两处**：既改 $M$，也改 IPP 水平位置——所以壳高不是「调色滑杆」。

### 8.3 小数值例（请手算一遍）

取 $R_e=6371\,\mathrm{km}$，$h_{\mathrm{ion}}=450\,\mathrm{km}$，$E=30^\circ$（$\cos 30^\circ\approx 0.866$）：

$$
\frac{R_e\cos E}{R_e+h_{\mathrm{ion}}}
=\frac{6371\times 0.866}{6821}\approx 0.809,
\qquad
M=\frac{1}{\sqrt{1-0.809^{2}}}\approx 1.70.
$$

若该历元 $\mathrm{STEC}=34\,\mathrm{TECU}$，则

$$
\mathrm{VTEC}\approx\frac{34}{1.70}\approx 20\,\mathrm{TECU}.
$$

**对照实验（同一 STEC，只改仰角）**：若 $E=15^\circ$，则 $M$ 明显更大（约 2.5 量级，手算验证），估出的 VTEC 对仰角误差与多路径更敏感——这就是 **15°–20° 截止角** 的几何理由。

![映射因子随高度角变化](./images/fig-mapping-me-curve.png)

> **看图要点（为什么要手算一笔 $M$）**
> - **看什么**：$M(E)$ 在低仰角上扬。
> - **为什么**：把「我跟文献差 20%」从玄学变成「壳高/仰角是否同设定」。
> - **别误判**：曲线形态对 ≠ 你的壳高已最优；还须做 350/450 km 对照。
> 图源：自制 CC0。

![映射几何示意](./images/fig-mapping-function.png)

> **看图要点（为什么斜路径需要 $M$）**
> - **机制**：斜路径比竖直路径长，才需要除以映射因子。
> - **为什么**：不画新流程图——用已有几何图钉因果。
> 图源：自制 CC0。

### 8.4 壳高敏感的课堂口述

同一条 STEC：

- 壳高抬高 → IPP 外移，映射因子也变；  
- 赤道异常峰在图上可能「搬家」；  
- 若站网只在大陆一侧密，海洋空白区的插值会跟着变脸。

因此：**壳高是模型假设，必须写进方法节，并做 350/400/450 km 稳健性对照。**

## 9. 解剖台 B：格网聚合 / 权重直觉（IDW 课堂版）

> 格式：**符号表 → 逐步推导 → 小数值例**。说明「空洞里的漂亮颜色从哪来」。

### 9.1 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $\mathbf{r}$ | 待估格点位置 | 经纬度或平面近似 |
| $v_i$ | 第 $i$ 个 IPP 的 VTEC 采样 | TECU |
| $d_i$ | 格点到第 $i$ 个 IPP 的距离 | km（平面近似教学） |
| $w_i$ | 权重 | 无量纲；常 $w_i=d_i^{-p}$ |
| $p$ | 距离幂 | 常用 2；越大越「只听最近的钉子」 |
| $\hat{v}(\mathbf{r})$ | 格点估计 VTEC | TECU |
| $d_{\max}$ | 影响半径 / 最大搜索距 | km；超出则该点不参与或标缺失 |

### 9.2 逐步推导（每步人话）

1. **目标**：没有测到的格点，用附近 IPP 的 $v_i$ 估一个数。  
2. **直觉**：近处的钉子更可信 → 权重大；远处权重小。最简单的逆距离权重（IDW）：

$$
w_i=d_i^{-p},\qquad
\hat{v}(\mathbf{r})=\frac{\sum_{i\in\mathcal{N}} w_i v_i}{\sum_{i\in\mathcal{N}} w_i}.
$$

其中 $\mathcal{N}$ 是落在影响半径内的邻居集合。  
3. **$p$ 的性格**：$p$ 大 → 几乎只听最近一点（易出「牛眼」）；$p$ 小 → 更平滑，但也更容易把远处结构抹进空洞。  
4. **Kriging 等**：用空间相关结构定权，思想仍是「加权聚合」，但权由变差函数决定——实现更重，空洞假结构风险仍在。  
5. **与球谐对比**：球谐不是局部加权平均，而是全球基函数拟合；空洞处假象常呈环状/振荡，而非局部牛眼。

### 9.3 小数值例（三枚钉子估一格）

设平面教学坐标，待估格点在原点。三个 IPP：

| IPP | 位置 $(x,y)$ / km | $d_i$ / km | $v_i$ / TECU |
|---|---|---|---|
| A | (100, 0) | 100 | 22 |
| B | (0, 100) | 100 | 18 |
| C | (300, 0) | 300 | 40 |

取 $p=2$，$w_i=1/d_i^{2}$：

$$
w_A=w_B=10^{-4},\quad w_C=\frac{1}{9}\times 10^{-4}.
$$

则

$$
\hat{v}
=\frac{10^{-4}\cdot 22+10^{-4}\cdot 18+\frac{1}{9}\times 10^{-4}\cdot 40}{10^{-4}+10^{-4}+\frac{1}{9}\times 10^{-4}}
\approx\frac{22+18+4.44}{2+0.111}\approx 21.1\,\mathrm{TECU}.
$$

**读这个数**：C 的 40 TECU 很「夸张」，但因更远，只把估计从 20 拉到约 21——合理。  
**翻车设定**：若删掉 A、B，只剩远在 300 km 外的 C，且你仍强制出图，则 $\hat{v}=40$ TECU 会铺满空洞——**这就是站网空洞伪影的算术原型**。

实务门禁：规定 $d_{\max}$（如 500–1000 km，视站网密度），邻居为空则写缺失值，而不是「全局最近一点硬填」。

## 10. 解剖台 C：高度角截止的三维权衡（半定量）

> 格式：**符号表 → 逐步 → 小例手感**。把截止角从「玄学」变成可写进方法节的折中。

### 10.1 符号表

| 符号 | 含义 | 备注 |
|---|---|---|
| $E_{\mathrm{cut}}$ | 高度角截止 | 常用 15°–20° |
| $N_{\mathrm{obs}}$ | 有效 IPP 数 | 随 $E_{\mathrm{cut}}$ 升而降 |
| $\sigma_M$ | 映射相关误差感度 | 低 $E$ 时更大 |
| 覆盖半径 | 站网有效足迹 | 截止越高，足迹越缩 |

### 10.2 逐步（三角形三个角）

1. **数据量**：截止越高，点越少。  
2. **观测质量**：截止越高，多路径与映射误差通常越小。  
3. **空间覆盖**：截止越高，站网有效足迹收缩，边界更破。

没有免费午餐。区域网若本身就稀，盲目 30° 可能「没东西可画」；全球网在低纬若保留 5°，假结构风险上升。

### 10.3 小例手感

假设某站一天内仰角 $>5^\circ$ 的有效历元为 100% 基准：

| $E_{\mathrm{cut}}$ | 相对留存（示意） | 映射风险 | 覆盖 |
|---|---|---|---|
| 5° | ~100% | 高 | 最广 |
| 15° | ~70%–85% | 中 | 课堂默认区 |
| 30° | ~40%–60% | 较低 | 明显收缩 |

（具体比例随纬度、季节、星座而变；表只练「方向感」。）  
**作业动作**：同一天分别用 10°/20°/30° 出 IPP 覆盖图与 VTEC 图，写三句话：多了什么假梯度、少了什么真实边缘结构。

## 12. 三种长相（必背）

| 签名 | 你在图上看到什么 | 机制一句话 | 先查什么 |
|---|---|---|---|
| **A. 合理 GIM** | 地方时白天高、夜里低；低纬可见赤道异常双峰趋势；与多家 GIM 差分以平滑偏差为主；IPP 密区结构与稀疏区「可信度」匹配 | 观测钉住的地方听观测，空白处诚实平滑或标缺失 | IPP 覆盖；安静日气候形态；分带 RMSE |
| **B. 站网空洞伪影** | 海洋/荒漠无站区出现精致涡旋、假峰、假梯度；关掉边界站后结构几乎不变或乱跳；等值线「绕开」陆地站呈牛眼 | 插值/球谐在无钉区自由发挥；权重或基函数在外推 | IPP 点图；掩膜无覆盖区；换 $d_{\max}$ / 阶次 |
| **C. 日界线 / 时段假锋** | 沿 180° 经线或某整点时间边界出现不合理的陡峭锋面；地方时结构在日界线两侧错位；相邻时间片「跳变」像刀切 | 网格经度拼接、时间窗不对齐、或跨日文件拼接未平滑 | 经度约定；epoch 列表；跨日衔接；时间插值假设 |

### 12.1 「一眼区分」操作口诀

1. **先叠 IPP**：没有钉子的漂亮结构，默认有罪，直到证明清白。  
2. **再看地方时**：把图转到地方时或看磁纬–地方时切片；气候形态在不在。  
3. **最后差分官方**：只在双方有效、且你覆盖足够的区域比；分报 bias 与 std。

### 12.2 假阳性指纹速查

| 看起来像 | 其实可能是 |
|---|---|
| 「全球分辨率超细、处处有涡旋」 | 空洞填数 / 过高阶球谐振荡 |
| 「和某家 GIM 完美一致」 | 你可能直接读了产品，或验证集与训练集同源 |
| 「磁暴日赤道大洞」 | 映射/数据空洞的假洞；先查 IPP 与截止角 |
| 「180° 经线一道墙」 | 日界线拼接或经度网格约定 |
| 「换壳高整图面目全非」 | 结构不稳健；方法节须报告敏感性 |
| 「球谐阶数加高后细节爆发」 | 拟合噪声；空洞环状假波 |

## 13. 和官方产品对齐时的「差分礼仪」

初学者常把「我的图减 CODE」直接当误差。更干净的做法：

1. **时间对齐**：同一 epoch（IONEX 常为整点或 1–2 h）；需要时做时间插值并记录假设。  
2. **空间对齐**：插到同一经纬网格；注意 180° 经线、纬度方向约定。  
3. **掩膜**：只在双方都有有效值、且你的 IPP 覆盖足够的地方比。  
4. **分带统计**：低纬 / 中纬 / 高纬分开报 RMSE，避免「全球一个数」掩盖低纬灾难。  
5. **bias 与 std 分开写**：前者常连着 DCB/基准，后者连着噪声与结构差。

业务近实时产品（`DLR-IMPC`、`ESA-TIO-NRT-TEC`、`NOAA-SWPC-GloTEC` 等）可对照，但要读清分析场 / 预报 / 同化混合（预习 [12](./12-data-assimilation-intro.md)）。中心间本身有差，见 `UWM-IGS-Iono-Combination`。

## 18. 常见误解专节（请打假）

| 编号 | 误解 | 纠正 |
|---|---|---|
| M1 | 插值很漂亮 = 物理真实 | 先叠 IPP；空洞精致结构默认有罪 |
| M2 | 和某家 GIM 差 8 TECU 就是我错了 | 先查 DCB 基准与时间对齐；分报 bias/std |
| M3 | 全球球谐阶数越高越好 | 过高拟合噪声并在空洞振荡 |
| M4 | 只用一个安静日调参即可 | 扰动日才暴露映射与站网漏洞 |
| M5 | 物理模式输出可以直接当 GIM | `TIE-GCM` / `GEMINI3D` 是正演/研究工具 |
| M6 | 薄壳是真理 | 工程近似；强梯度与三维进 11/12 |
| M7 | 截止角是玄学 | 噪声、映射、覆盖的显式折中，必须写入方法节 |
| M8 | 下载 IONEX 裁剪 = 构建 GIM | 读产品 ≠ 自建流水线；摘要勿冒名 |
| M9 | 换网格重跑 = 独立验证 | 同一观测的不同光滑版本 |
| M10 | VTEC 图旋转成柱 = 三维电离层 | 柱总量无高度；见 [11](./11-tomography-basics.md) |

课堂最低要求：能口头打假 **M1、M2、M8** 三条。

## 19. 测验

**Q1.** 默念总链路（至少 7 环），并在「映射」与「空间模型」旁各写一条失败模式。

**Q2.** 为什么需要 DCB/基准？用「厨房秤零点」类比答两句，并指出差分官方产品时应分报哪两个统计量。

**Q3.** 手算解剖台 A：在 $h_{\mathrm{ion}}=450\,\mathrm{km}$、$E=30^\circ$ 时 $M$ 约多少？若 STEC = 34 TECU，VTEC 约多少？

**Q4.** 解剖台 B：若格点附近 500 km 内没有任何 IPP，IDW 实现应输出什么？若强行用 2000 km 外一点填满，图上属于哪类观测签名？

**Q5.** 「合理 GIM / 空洞伪影 / 日界线假锋」三列各给一个「一眼」判据。

**Q6.** 壳高从 350 km 改到 450 km，同一套 STEC 的图可能差在哪里？验证清单会看哪一项？

**Q7.** 指出本仓库：两个估 TEC 条目、两个球谐/GIM 实现、两个官方 IONEX/TEC 产品入口。

**Q8.** 读现成 IONEX（03）与自建流水线（10）的分工各用一句话概括；何种情况下你只应做前者？

## 20. 迷你项目规格书（可当作业提交模板）

**标题**：一日区域 VTEC 试生产  
**输入**：日期 D；站表（≥8 站）；壳高；截止角；DCB 来源声明  
**流程**：按 §14 执行并截图 IPP 覆盖  
**输出**：

1. 一张 VTEC 图（注明色标单位 TECU；缺失区诚实）；  
2. 与 `CDDIS-IONEX` 当日产品差分直方图（bias + std，最好分带）；  
3. 失败模式表：至少勾选 3 条最危险的，并说明缓解；  
4. 半页讨论：壳高 ±50 km、截止角 10°/20°/30° 各做一组，结论哪些不变、哪些变；  
5. （可选）指出图上若出现空洞伪影或日界线假锋，你会如何一票否决「新物理」叙事。

评分更看「你是否知道图可能错在哪」，而不是色图是否炫。
