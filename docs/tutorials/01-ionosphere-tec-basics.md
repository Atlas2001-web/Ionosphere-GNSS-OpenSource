## 1. 这节课要解决什么

同学们，先把手机锁屏。三个真实场景：

1. **导航漂了**：晴天郊外，单频轨迹几分钟漂十几米。有人说多路径，有人说「电离层活跃」。后者在砸什么？卫星信号穿过带电介质，自由电子让**群路径**变长；改正不准就进位置误差。双频可消一阶项，但你仍要懂 TEC，才能读残差、完好性与空间天气产品。
2. **领导要 TEC 图**：要的是某时刻某区域**竖直电子柱有多厚**（VTEC 场）。GNSS 直接给的却是斜路径 STEC。中间隔着映射与建图——本课先把「柱」说透；画图留给 03 课。
3. **单频能不能省钱**：单频 + 模型可以，但模型在猜延迟，延迟的一阶驱动是 TEC/\(f^2\)。不会区分「猜」和「测」，后面全盘对比都会歪。Klobuchar、NeQuick-G、IRI 给经验/广播答案；双频 GNSS 给观测答案。

**学完交付**：指出电离层高度量级；区分 \(N_e\) 与 TEC；默写 TECU；解释 Appleton–Hartree 一阶群延迟每个符号；口头画出 \(M(E)\) 与 IPP 几何；用因果讲昼夜/纬度/太阳周期；完成带演算的测验；能在 `PROJECTS.json` 点名若干真实工具。

## 3. 大气分层：电离层不是「新盖的一层楼」

请画地球圆弧，向外标高度。

**步骤 1 — 对流层（约 0–10/18 km）**  
我们生活的楼层。空气密、有天气。GNSS 信号穿过时，中性大气与水汽造成**对流层延迟**。关键对比：对流层在 L 波段几乎**不色散**（两频延迟几乎一样）；电离层**强烈色散**（\(\propto 1/f^2\)）。所以双频能「看见」电离层，却几乎消不掉对流层——这是后面几何无关组合只留电离层信息的物理前提之一。

**步骤 2 — 平流层（约 10–50 km）、中间层（约 50–90 km）**  
本课不展开臭氧化学与中间层动力学，只防止你以为「对流层上面直接就是电离层薄片」。白天 D 区电离可从约 60–90 km 开始出现，对高频吸收重要；对 GNSS L 波段一阶 TEC，D 区柱贡献通常远小于 F 区，但耀斑时可相对变显眼。

**步骤 3 — 热层（约 90 km 以上）**  
气体极稀，太阳 EUV 强。「稀」≠「不能电离」：粒子少，光子照样拆电子；碰撞对手少，复合也相对慢，电子能维持。F 区峰值常落在热层高度段。

**步骤 4 — 命名「电离层」**  
电离层不是物流公司新盖的楼，而是**原有高层大气进入电离状态**后单独命名的物理区域。约从 60 km 量级到 1000 km 以上；对 GNSS TEC 贡献最大的往往在 F2 峰附近（约 200–400 km 量级，随地方时、纬度、季节变）。再往上仍有电子（含等离子体层贡献），是否单独建模看应用。

**类比**：干空气是关着的雾机；太阳开机后出现带电雾——浓度随高度变，不是匀浆。E、F1、F2 等「层」是密度廓线上的峰/肩，不是水泥楼板。

## 4. 电离从哪里来？电子 vs 离子

### 4.1 三个必要条件

1. **有中性成分可电离**（O、N₂、O₂ 等）；  
2. **有电离能源**——主线是太阳 **EUV** 与 **X 射线**（光致电离）；高纬还有沉降粒子；  
3. **复合与输运没有快到让电子瞬间清零**。

光致电离：光子能量高于某成分电离能时，打出自由电子并留下正离子。EUV 对 F 区/E 区至关重要；硬 X 射线更容易在更低高度沉积（与 D 区相关）。夜晚光致电离几乎关掉，复合与化学过程让电子下降——但高层复合慢，夜侧仍可有可观 TEC。

输运（中性风、电场 \(\mathbf{E}\times\mathbf{B}\) 漂移、扩散）可以把电子「搬走」而不是就地产生/消灭。赤道喷泉就是输运塑造形态的经典例子。

### 4.2 为什么公式写 \(N_e\)，不是离子密度？

等离子体**准中性**：宏观上电子数密度 ≈ 正离子数密度。但无线电一阶折射里，关键是**质量小、对交变电场响应快**的自由电子：\(m_e\) 远小于离子质量，同样电场下加速度大得多，对介电响应主导。因此 TEC 定义为自由电子柱积分；离子当然在，但不作为 GNSS 一阶 TEC 的积分对象。

### 4.3 等离子体频率直觉

\[
\omega_p=\sqrt{\frac{N_e e^{2}}{\varepsilon_0 m_e}},\qquad f_p=\frac{\omega_p}{2\pi}.
\]

| 符号 | 含义 |
|---|---|
| \(\omega_p\) | 等离子体角频率（rad/s） |
| \(f_p\) | 等离子体频率（Hz） |
| \(N_e\) | 电子数密度（\(\mathrm{m}^{-3}\)） |
| \(e\) | 元电荷（C） |
| \(\varepsilon_0\) | 真空介电常数（F/m） |
| \(m_e\) | 电子质量（kg） |

人话：\(N_e\) 越高，\(f_p\) 越高——雾越浓，介质特征振荡越快。数量级：\(N_e\sim10^{11}\,\mathrm{m}^{-3}\) 时 \(f_p\) 约几 MHz 量级，远低于 GNSS 的 ~1.2–1.6 GHz。因此波能穿过（\(f\gg f_p\)），但折射率仍偏离 1，偏离量 \(\propto f_p^2/f^2\propto N_e/f^2\)。

**课堂追问**：若某处 \(N_e\) 突然高到 \(f_p\) 接近载波频率，会发生什么？——反射/截止风险上升（短波通信常见；GNSS 正常电离层通常仍 \(f\gg f_p\)）。这帮助你理解「为什么公式里是 \(N_e/f^2\) 这种结构」。

## 5. 从 Appleton–Hartree 到一阶群延迟（每个符号）

### 5.1 完整公式在怕什么？我们保留什么？

完整 Appleton–Hartree 含：地磁场（电子回旋频率 \(f_B\)）、碰撞频率、波法向与磁场夹角、寻常/非常波。GNSS TEC 工程一阶主项，走**无磁场、无碰撞**极限已够用；地磁场带来的高阶/二阶项在精密应用才细抠。本课把一阶主项钉死。

无磁、无碰撞：

\[
n^{2}=1-X,\qquad X=\frac{\omega_p^{2}}{\omega^{2}}=\frac{f_p^{2}}{f^{2}}.
\]

- \(n\)：相折射率；  
- \(X\)：无量纲等离子体参数；  
- \(\omega=2\pi f\)：载波角频率；\(f\) 载波频率（Hz）。

因 GNSS 上 \(X\ll1\)，二项式展开：

\[
n=\sqrt{1-X}\approx1-\frac{X}{2}=1-\frac{1}{2}\frac{f_p^{2}}{f^{2}}.
\]

把 \(f_p^{2}=N_e e^{2}/(4\pi^{2}\varepsilon_0 m_e)\) 代入，并整理常数，工程上写成：

\[
n_p\approx1-\frac{40.3\,N_e}{f^{2}}.
\]

其中系数 **40.3**（约 \(40.3\,\mathrm{m}^{3}\mathrm{s}^{-2}\)）来自 \(e^{2}/(8\pi^{2}\varepsilon_0 m_e)\) 等常数组合；当 \(N_e\) 用 \(\mathrm{m}^{-3}\)、\(f\) 用 Hz 时，\(40.3 N_e/f^{2}\) 无量纲。

### 5.2 群折射率：码为什么「变慢」？

色散介质中，群速度对应信息/能量传播，群折射率

\[
n_g=n+f\frac{\mathrm{d}n}{\mathrm{d}f}.
\]

对 \(n\approx1-\frac{1}{2}f_p^{2}/f^{2}\)（\(f_p\) 与 \(f\) 无关的冷等离子体近似），求导后得到：

\[
n_g\approx1+\frac{1}{2}\frac{f_p^{2}}{f^{2}}\approx1+\frac{40.3\,N_e}{f^{2}}.
\]

对照：

| 量 | 一阶结果 | 对 GNSS 观测的含义 |
|---|---|---|
| \(n_p-1\) | \(-\,40.3 N_e/f^{2}\) | 相路径变短 → **相位超前** |
| \(n_g-1\) | \(+\,40.3 N_e/f^{2}\) | 群路径变长 → **码/伪距延迟** |

**同一份电子柱，一阶码延迟与相位超前符号相反。** 这不是口诀炫技，是色散关系的直接推论；02 课观测方程会写成 \(+I\) 与 \(-I\)。

### 5.3 路径积分 → 一阶群延迟（等效距离）

\[
I_{\mathrm{group}}(f)=\int(n_g-1)\,\mathrm{d}s\approx\frac{40.3}{f^{2}}\int N_e\,\mathrm{d}s=\frac{40.3}{f^{2}}\,\mathrm{STEC}.
\]

| 符号 | 含义 |
|---|---|
| \(I_{\mathrm{group}}\) | 电离层一阶群延迟，等效距离（m） |
| \(f\) | 载波频率（Hz） |
| \(40.3\) | 常数系数（\(\mathrm{m}^{3}\mathrm{s}^{-2}\) 量级） |
| \(N_e(s)\) | 路径上电子数密度（\(\mathrm{m}^{-3}\)） |
| \(\mathrm{d}s\) | 路径微元（m） |
| \(\mathrm{STEC}\) | \(\int N_e\,\mathrm{d}s\)（\(\mathrm{m}^{-2}\)） |

**推论**：同一路径同一 STEC，\(f\) 越低延迟越大；两频延迟差携带 STEC——双频测 TEC 的根。单频没有第二把尺子，只能用模型猜 \(I\)。

### 5.4 迷你数值（建立量感）

取 GPS L1 \(f_1=1575.42\times10^6\,\mathrm{Hz}\)，STEC \(=10\,\mathrm{TECU}=1.0\times10^{17}\,\mathrm{m}^{-2}\)：

\[
I_1\approx\frac{40.3\times1.0\times10^{17}}{(1.57542\times10^9)^{2}}\approx1.62\,\mathrm{m}.
\]

同一 STEC 在 L2 \(f_2=1227.60\times10^6\,\mathrm{Hz}\)：

\[
I_2\approx\frac{40.3\times10^{17}}{(1.22760\times10^9)^{2}}\approx2.67\,\mathrm{m}.
\]

差额 \(I_2-I_1\approx1.05\,\mathrm{m}\)——这就是几何无关组合「能看见」的东西（还混着偏差，见 02 课）。若 STEC 变为 40 TECU，延迟大约×4。所以空间天气里「TEC 暴涨」对单频用户可以是米级故事。

## 6. STEC、TECU、薄壳映射 \(M(E)\) 与 IPP

### 6.1 精确定义

\[
\mathrm{STEC}=\int_{\mathrm{receiver}}^{\mathrm{sat}} N_e(s)\,\mathrm{d}s\quad[\mathrm{m}^{-2}],\qquad
1\,\mathrm{TECU}=10^{16}\,\mathrm{m}^{-2}.
\]

人话：横截面积 \(1\,\mathrm{m}^2\) 的柱子里，电子按 \(10^{16}\) 一包数。32 TECU \(=3.2\times10^{17}\,\mathrm{m}^{-2}\)。

**VTEC**：沿当地天顶的柱积分；在薄壳流程里，更常是由斜路径映射得到的**等效**竖直量——措辞要诚实。

**电子密度 vs TEC**：\(N_e(h)\) 像「某一楼层每立方米多少人」；TEC 像「从一楼走到顶，把一路的人按规则加总」。测高仪/雷达/掩星更常谈廓线；GNSS 双频更直接给路径积分。把 GNSS TEC 说成「测到了 F2 峰密度」是口误。

### 6.2 水管与雾（主类比，配符号）

| 类比 | 符号 |
|---|---|
| 水管 | 站星视线路径 |
| 雾浓度 | \(N_e\) |
| 管内雾总量 | STEC |
| 竖直水管 | VTEC |
| 雾挤在某一楼层薄壳 | 薄壳假设，壳高 \(H\) |
| 斜管与壳交点 | IPP |
| 水流变慢 | \(I_{\mathrm{group}}\) |
| 碎涡乱闪 | 闪烁（另一课） |

### 6.3 薄壳几何：用文字把图画出来

1. 地球半径 \(R_E\approx6371\,\mathrm{km}\)；壳高 \(H\)（常见 350–450 km，**以产品为准**）。  
2. 接收机在地面；卫星仰角 \(E\)；视线与半径 \(R_E+H\) 的球壳相交 → **IPP** 的经纬与时间。  
3. 在 IPP，视线相对当地竖直的天顶角为 \(z'\)。球面几何：

\[
\sin z'=\frac{R_E}{R_E+H}\cos E.
\]

4. 映射函数（斜路径相对竖直的放大）：

\[
M(E)=\frac{1}{\cos z'}=\left(1-\left(\frac{R_E}{R_E+H}\cos E\right)^{2}\right)^{-1/2},
\]

\[
\mathrm{STEC}\approx M(E)\cdot\mathrm{VTEC}_{\mathrm{IPP}}.
\]

**几何直觉逐步推**：

- **A**：固定当地竖直雾厚 = VTEC。  
- **B**：卫星在天顶，\(E=90^\circ\)，\(\cos E=0\)，\(z'=0\)，\(M=1\)，STEC≈VTEC。  
- **C**：卫星往地平倒，斜管变长，\(M>1\)，STEC 变大。  
- **D**：低仰角不仅 \(M\) 大，多路径、水平梯度、壳高敏感也放大 → 设截止仰角（常见 10°–20° 量级，视应用）。  
- **E**：两家软件壳高差 50 km，低仰角 IPP 水平位置与 \(M\) 都可能差一截——比 VTEC 前先对齐假设。

### 6.4 薄壳的香与臭

- **香**：降维；全球建模、IONEX、实时播发变可行。  
- **臭**：真实电子有厚度、可多层、可强梯度；扰动期误差放大。  
- **三问**：壳高？映射形式？仰角截止？三问不清，没有资格百分比对比「我的 VTEC vs 官方 GIM」。

本仓库 `Get_IPP`（已核验）帮你算穿刺点几何，不自动等于 TEC 流水线完成。

## 7. 形态学：昼夜、纬度、太阳周期——讲为什么

### 7.1 昼夜（能源开关 + 复合时标）

白天：EUV/X 射线持续光致电离 → 产生率高 → \(N_e\) 升 → 柱积分 TEC 常升高。  
夜晚：光致电离关掉，电子通过复合（及化学）减少。F 区高层密度低、复合慢，夜侧仍可维持可观 TEC；等离子体层/管贡献、中纬谷、极光粒子沉淀都会改写「夜里≈0」。

地方时结构：全球同一时刻，东经与西经的「当地几点」不同，TEC 图上的昼夜分界大体跟地方时走，而不是跟 UTC 钟面走。

### 7.2 纬度（输运塑造空间结构）

- **低纬 / 赤道异常（EIA）**：赤道附近电场把等离子体向上「喷泉」抬升，再沿磁力线向南北扩散，在磁纬约 ±15°–20° 形成两侧 TEC 驼峰。下午地方时常常很显眼。所以低纬不是「一个赤道热点」，而是**双峰结构**——读图时找驼峰，而不是只看赤道点。  
- **中纬**：日变化相对规矩，仍受季节、磁暴负/正相影响。  
- **高纬**：粒子沉降与对流电场可快速改写 \(N_e\)；机制与低纬光化学+喷泉不同。  

「纬度越高 TEC 越小」不是定律；要问磁纬、地方时、是否风暴。

### 7.3 太阳周期（约 11 年）与季节

太阳 EUV 输出随活动周升降。高年：电离源更强 → 气候态 TEC 基线抬升。低年相反。**因果链**：光子流量 → 光致电离率 → \(N_e\) 廓线 → 柱积分；不是神秘年份标签。

季节：太阳天顶角与中性大气成分（如 O/N₂）季节变化，改变产生率与损失率，中纬常有明显半年/季节调制。细节可留给模型课；本课抓住「能源几何 + 中性背景」两条。

### 7.4 扰动预告（本课只认长相）

耀斑：短时 X 射线增强，白天低高度电离可突增。  
磁暴：电动力学与中性成分变化，区域 TEC 可正可负（正暴/负暴），强烈依赖地方时与纬度。  
行进式扰动（TID）：像波纹在 TEC 场上扫过——见后续课。  
分析纪律：**没有安静日基线，就没有资格说「增强了 30%」**。

## 10. 课堂测验（带演算的完整答案）

**题 1.** 定义 STEC 并写积分式；TECU 定义。  
**答：** \(\mathrm{STEC}=\int N_e\,\mathrm{d}s\)（\(\mathrm{m}^{-2}\)）；\(1\,\mathrm{TECU}=10^{16}\,\mathrm{m}^{-2}\)。

**题 2.** 写出 \(I\approx(40.3/f^2)\,\mathrm{STEC}\)。\(f\) 加倍，\(I\) 如何变？若 STEC 从 10 增到 40 TECU（\(f\) 不变），\(I\) 如何变？  
**答：** \(f\to2f\Rightarrow I\to I/4\)；STEC×4 ⇒ \(I\)×4。

**题 3.** 用 \(n_g\) 与 \(n_p\) 各一句说明码延迟与相位超前为何一阶符号相反。  
**答：** \(n_g-1>0\) 群路径变长（码延迟）；\(n_p-1<0\) 相路径变短（相位超前）。

**题 4.** 仰角 \(E=30^\circ\)，\(R_E=6371\,\mathrm{km}\)，\(H=450\,\mathrm{km}\)。计算 \(\sin z'\)、\(\cos z'\)、\(M(E)\)（三位小数）。若 IPP 处 VTEC=20 TECU，STEC 约多少？  
**答：** \(\cos30^\circ\approx0.866\)；\(R_E/(R_E+H)=6371/6821\approx0.934\)；\(\sin z'\approx0.809\)；\(\cos z'\approx0.588\)；\(M\approx1.701\)；STEC≈34.0 TECU。

**题 5.** 天顶时 \(M\) 等于多少？为何低仰角要截止？  
**答：** \(M=1\)。低仰角 \(M\) 大且多路径/梯度/壳高误差放大。

**题 6.** IPP 是卫星星下点吗？薄壳「壳」指什么？三问是什么？  
**答：** 一般不是。壳=假定高度 \(H\) 的电子薄球壳。三问：壳高、映射、仰角截止。

**题 7.** 用因果解释：白天 TEC 常更高；太阳活动高年气候态 TEC 常更高；低纬下午常现双峰。  
**答：** 白天电离源打开；高年 EUV 更强→产生率高；赤道喷泉+沿磁力线扩散形成 EIA 驼峰。

**题 8.** \(f_p\propto\sqrt{N_e}\)。\(N_e\to4N_e\) 时 \(f_p\) 与 \((n_g-1)\)（\(f\) 固定）各如何变？  
**答：** \(f_p\to2f_p\)；\(n_g-1\propto N_e\to4\) 倍。

**题 9.** TEC 大是否等于闪烁强？对流层延迟能否用 TEC 公式改？GIM 格点常见给 STEC 还是 VTEC？  
**答：** 否；不能；多为 VTEC。

**题 10.** 指出两个 RINEX→TEC 的 name、两个 IONEX 相关 name（须真实存在于本仓）。  
**答：** 如 `gnss-tec`、`Seemala-GPS-TEC`；如 `CDDIS-IONEX`、`JPL-IONEX-Rapid`。

**题 11.** 取 L1，STEC=10 TECU，课文近似 \(I_1\approx1.62\,\mathrm{m}\)。若某单频用户未改正，这笔延迟主要污染什么？双频用户消掉一阶后还要不要懂 TEC？  
**答：** 污染伪距→位置（与钟差等耦合）。要：解释残差、高阶、完好性、空间天气与单频场景。

**题 12.** 软件全日输出 VTEC=500 且声称平静中纬，首先怀疑什么？出现显著负 TEC 首先查什么？  
**答：** 单位/缩放或解析错误；周跳、DCB、符号与单位，而不是「负电子」。

## 13. 加深层：把「一阶公式」真正讲透（必读）

### 13.1 从介电常数到折射率（直觉阶梯）

真空中电磁波以 \(c\) 传播。等离子体中，自由电子被电场加速，产生极化电流，等效介电常数小于 1：

\[
\varepsilon_r\approx1-\frac{\omega_p^{2}}{\omega^{2}}=1-X.
\]

折射率 \(n=\sqrt{\varepsilon_r\mu_r}\)（非磁介质 \(\mu_r\approx1\)）于是 \(n=\sqrt{1-X}\)。这就是 Appleton–Hartree 无磁极限的「物理入口」：不是背公式，而是**电子响应削弱了有效介电常数**。

当 \(X\to1\)（\(f\to f_p\)），\(n\to0\)，相速度形式发散、波难以穿透——短波垂直探测的「临界频率」故事就在这里。GNSS 频率远高于典型 \(f_p\)，所以我们工作在 \(X\ll1\) 的微扰区：波能过，但迟到一点点。

### 13.2 系数 40.3 从哪来？（不要求手算，要求会解释）

把

\[
\frac{1}{2}\frac{f_p^{2}}{f^{2}}=\frac{1}{2}\cdot\frac{N_e e^{2}}{4\pi^{2}\varepsilon_0 m_e}\cdot\frac{1}{f^{2}}
\]

中的物理常数收成一个数，得到工程常用的 \(40.3\,N_e/f^{2}\)。你考试若被问「40.3 是什么」，合格答法是：**由元电荷、电子质量、真空介电常数等组合而成的系数，使 \(N_e\)（m⁻³）与 \(f\)（Hz）代入后给出无量纲的折射率改正，再沿路径积分得到米级延迟。** 不要假装它是「随便取的整数」。

文献里也能见到 \(40.308\) 或把 STEC 用 TECU、频率用 GHz 改写的等价形式，例如

\[
I[\mathrm{m}]\approx\frac{40.3}{f_{\mathrm{Hz}}^{2}}\cdot(\mathrm{STEC}_{\mathrm{m}^{-2}})
=\frac{0.403}{f_{\mathrm{GHz}}^{2}}\cdot(\mathrm{STEC}_{\mathrm{TECU}})
\]

（请自己核对单位：\(10^{16}\) 与 GHz 换算会改变数值前因子）。**读软件时以该软件文档的单位约定为准**，不要混用两套前因子。

### 13.3 高阶项课堂上怎么诚实表态？

一阶 \(\propto1/f^{2}\) 是主食。地磁场、弯曲路径、\(1/f^{3}\) 等项是配菜。对大多数入门 TEC 估计与单频改正，一阶够用；对精密定位与某些空间天气极端条件，才需要声明「残差里可能有高阶」。本课不把高阶公式摊开，但要求你以后看到「一阶电离层」六个字时知道：作者在说 \(40.3\,\mathrm{STEC}/f^{2}\) 这一层。

### 13.4 为何双频能测、单频只能猜？——用方程说

单频伪距（极简）：

\[
P_1=\rho+c(\mathrm{d}t-\mathrm{d}T)+T_{\mathrm{trop}}+I_1+\varepsilon_1,
\]

其中 \(\rho\) 几何距离，钟差、对流层、电离层缠在一起。只有一个方程，无法分离 \(I_1\)。

双频有 \(I_2=(f_1^{2}/f_2^{2})I_1\)（同一 STEC），于是 \(P_1-P_2\) 中 \(\rho\)、对流层、钟差（一阶公共）消掉，留下与 STEC 成比例的项——这是 02 课几何无关的预告。单频用户只能从模型插入一个猜的 \(I_1\)（如广播 Klobuchar）。

## 14. 映射函数再练：三个仰角对照表

取 \(R_E=6371\,\mathrm{km}\)，\(H=450\,\mathrm{km}\)，\(R_E/(R_E+H)\approx0.934\)。

| 仰角 \(E\) | \(\cos E\) | \(\sin z'\) | \(\cos z'\) | \(M(E)\) | 若 VTEC=15 TECU，STEC≈ |
|---|---|---|---|---|---|
| \(90^\circ\) | 0 | 0 | 1 | 1.00 | 15.0 |
| \(60^\circ\) | 0.500 | 0.467 | 0.884 | 1.13 | 17.0 |
| \(30^\circ\) | 0.866 | 0.809 | 0.588 | 1.70 | 25.5 |
| \(15^\circ\) | 0.966 | 0.902 | 0.431 | 2.32 | 34.8 |
| \(10^\circ\) | 0.985 | 0.920 | 0.392 | 2.55 | 38.3 |

**读表训练**：仰角从 90° 降到 15°，同样 VTEC=15，斜路径 STEC 从 15 涨到约 35——不是电离层「突然变厚了一倍多」，而是**几何放大**。若你不懂 \(M\)，会把低仰角的几何效应讲成空间天气事件。

**壳高敏感直觉**：\(H\) 变大，\(R_E/(R_E+H)\) 变小，同样低仰角下 \(z'\) 略变，\(M\) 与 IPP 水平位置都变。高仰角不敏感，低仰角敏感——这就是「低仰角别硬刚」的几何理由。

## 15. 形态学课堂案例（因果链写完整）

### 案例 A：中纬晴日

地方时正午前后 TEC 升高，夜间下降。因果：太阳天顶角小 → 单位面积 EUV 强 → 产生率高；夜间产生率≈0，复合主导。季节上，夏季白天更长但中性成分变化也会调制峰值——不要只用「热」解释一切。

### 案例 B：低纬下午双峰

在 TEC 地图上看到赤道两侧两个亮带。因果：白天赤道电场东向 → \(\mathbf{E}\times\mathbf{B}\) 抬升 → 沿磁力线扩散到南北 → EIA。若你只在地理赤道取一个点的时间序列，可能错过驼峰主体。

### 案例 C：太阳活动高年 vs 低年同一天（气候态）

同一日历日、相似地磁安静条件，高年全球 TEC 基线往往更高。因果：太阳 EUV 代理指数（如 F10.7）更高 → 光致电离更强。对比两张 GIM 时，先问是不是在比「天气」还是在比「气候」。

### 案例 D：磁暴后某中纬区域 TEC 低于安静日

这叫负相暴效应的一种常见长相。因果不只有「多电离」：中性成分变化（如分子氮增多）可加速损失，电动力学可搬运等离子体。本课要求：看到「暴了所以 TEC 一定升」要举手反对。

## 18. 最后一道综合演算（建议当作业）

某中纬测站，某历元跟踪一颗 GPS 卫星，仰角 \(E=40^\circ\)。设壳高 \(H=400\,\mathrm{km}\)，\(R_E=6371\,\mathrm{km}\)。由双频（假设已完美改正偏差与模糊度，本课只练几何与延迟）得到 STEC \(=28.0\,\mathrm{TECU}\)。

**(1)** 计算 \(M(E)\) 与 IPP 处等效 VTEC。  
**(2)** 估算 L1 与 L2 一阶群延迟（米）。取 \(f_1=1575.42\,\mathrm{MHz}\)，\(f_2=1227.60\,\mathrm{MHz}\)，\(I=40.3\cdot\mathrm{STEC}_{m^{-2}}/f^{2}\)。  
**(3)** 若有人把 28 TECU 直接当成 VTEC 填进地图，错在哪里？误差大约多少 TECU？

**参考答案：**

(1) \(\cos40^\circ\approx0.766\)；\(R_E/(R_E+H)=6371/6771\approx0.941\)；\(\sin z'\approx0.721\)；\(\cos z'\approx0.693\)；\(M\approx1.443\)。  
\(\mathrm{VTEC}\approx\mathrm{STEC}/M\approx28.0/1.443\approx19.4\,\mathrm{TECU}\)。

(2) \(\mathrm{STEC}=2.8\times10^{17}\,\mathrm{m}^{-2}\)。  
\(I_1\approx40.3\times2.8\times10^{17}/(1.57542\times10^9)^{2}\approx4.55\,\mathrm{m}\)。  
\(I_2\approx40.3\times2.8\times10^{17}/(1.22760\times10^9)^{2}\approx7.49\,\mathrm{m}\)。

(3) 错在把斜路径值当竖直值；偏高约 \(28.0-19.4=8.6\,\mathrm{TECU}\)（相对真等效 VTEC 约 44%）。低仰角时这类错误更夸张。

把这道题独立做完，比再读十页「加长精讲」更接近真懂。

## 19. 本课收束朗读稿（可闭眼听）

电离层是地球高层大气被太阳 EUV/X 射线等电离后形成的带电区域。自由电子密度 \(N_e\) 决定等离子体频率；在 GNSS 频段，波能穿透，但群折射率略大于 1，相折射率略小于 1。沿站星路径积分 \(N_e\) 得 STEC，单位常用 TECU。一阶群延迟 \(I\approx40.3\,\mathrm{STEC}/f^{2}\)，故延迟色散、双频可测。为把 STEC 钉到地图，常用薄壳与映射 \(M(E)\)，交点为 IPP——这是工程压缩。昼夜、纬度（含赤道异常）、太阳周期的形态，要用「能源与输运」解释，而不是背地名。常见错误是混淆密度与柱含量、斜与竖、以及把几何放大当成空间天气。下一课进入双频观测方程与几何无关组合。
