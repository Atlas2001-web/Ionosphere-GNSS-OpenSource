# 01 · 电离层是什么？TEC / STEC / VTEC 怎么读

> **课堂定位**：零基础第一课。不假设你学过大气物理，不假设你会 GNSS。学完这节，你应能用自己的话讲清：电离层在哪、电子是什么角色、TEC/STEC/VTEC/TECU 各是什么、穿刺点和薄壳假设在怕什么、为什么工程上要测 TEC。
>
> **写给谁**：第一次碰到「空间天气」「电离层延迟」「TEC 图」这些词就被劝退的人；以及要用本仓库 `PROJECTS.json` 里工具、却还没建立量感的人。

---

## 1. 这节课要解决什么（生活 / 工程问题）

同学们，先把手机锁屏，听三个会真实发生的故事。这节课不是为了背定义，是为了让你以后听到这些故事时，脑子里有图。

### 1.1 故事一：导航突然「漂」了

晴天，郊外，遮挡不多。一台单频 GNSS 接收机（或普通手机定位）给出的轨迹，却在几分钟里漂了十几米。有人说「卫星几何不好」，有人说「多路径」，还有人说「今天电离层活跃」。

第三种说法里的「电离层」到底在砸你的定位？粗线条答案是：卫星信号从两万公里量级的轨道飞回地面，要穿过一层「带电的雾」。雾里的自由电子会让信号传播变慢一点点（对码伪距来说像路径被拉长）。单频接收机如果改正不准，多出来的那一点就会变成位置误差。双频可以消掉一阶效应，但你仍需要理解 TEC，才能读懂残差、完好性与空间天气产品。

### 1.2 故事二：领导要一张「电子含量图」

课题组、业务值班或课程作业常出现这句话：「把今天的 TEC 图画出来。」  
你打开搜索，跳出 STEC、VTEC、GIM、IONEX、IRI、DCB……缩写像砖头。  
其实甲方要的常常只有一件事：**某一时刻、某一区域，竖直方向电子柱有多厚**——也就是 VTEC 场。从 GNSS 站星观测直接出来的却是斜路径上的 STEC。中间隔着映射、建图、格式。本课先把「柱有多厚」说清楚；画图留给 03 课。

### 1.3 故事三：单频能不能省钱？

双频板卡更贵。有人问：单频 + 模型行不行？  
行，但是「行」的前提是你知道模型在猜什么——猜的是电离层延迟，而延迟的核心驱动量之一就是 TEC（再乘频率因子）。模型（Klobuchar、NeQuick-G、IRI 等）给的是经验/广播意义上的答案；GNSS 双频给的是观测意义上的答案。不会区分「猜」和「测」，后面全盘对比都会歪。

### 1.4 这节课的交付物（你学完应能做到）

1. 指着一张「地球剖面草图」，指出电离层大致高度量级；  
2. 区分电子密度与 TEC；  
3. 默写 TECU 定义；  
4. 用「雾」的类比解释 STEC vs VTEC；  
5. 说出穿刺点、薄壳假设各解决什么、各牺牲什么；  
6. 列举至少三个「为什么要测 TEC」的工程动机；  
7. 知道本仓库里哪些 `name` 和「估 TEC / 下 GIM」相关（只点名，不深挖用法）。

## 2. 先备齐「词表」：本节每个术语用人话定义

老师要求：下面这张表，上课第一遍先快速扫；听完主讲解再回看第二遍。遇到不懂的缩写，先回表，再问人。

### 2.1 大气与电离层

| 术语 | 人话（先记这个） | 稍严一点的说法 |
|---|---|---|
| 大气 | 包住地球的气体毯子 | 随高度变稀的中性气体包层 |
| 对流层 | 呼吸、云雨、低空飞行的那一层 | 约 0–10/18 km，天气层；GNSS 另有对流层延迟 |
| 平流层 | 民航巡航高度附近的一层 | 约 10–50 km |
| 中间层 | 再往上更稀的过渡 | 约 50–80/90 km |
| 热层 | 很高、很稀、被太阳烤得很「热」的区域 | 约 90 km 以上 |
| 电离层 | 被太阳「打出自由电子」的带电区域 | 约 60–1000+ km 存在显著等离子体 |
| 电离 | 中性粒子被拆出电子 | 光致电离/碰撞电离等 |
| 自由电子 | 能影响电波的负电荷载体 | 非束缚电子 |
| 离子 | 丢掉或得到电子后的带电原子/分子 | 与电子共同构成等离子体 |
| 等离子体 | 「带电粒子气体」的统称 | 准中性的电离气体 |

### 2.2 TEC 家族

| 术语 | 人话 | 稍严一点的说法 |
|---|---|---|
| 电子密度 \(N_e\) | 某点附近 1 m³ 有多少电子 | 局地浓度 |
| TEC | 沿一条柱子把电子数加总 | 路径积分电子含量 |
| TECU | TEC 的常用大单位 | \(1\,\mathrm{TECU}=10^{16}\) 电子/\(m^2\) |
| STEC | 沿卫星视线斜着积分的 TEC | Slant TEC |
| VTEC | 换到天顶竖直方向的等效 TEC | Vertical TEC |
| 斜路径 / 视线 | 天线指向卫星的那条路 | line-of-sight（近似直线） |

### 2.3 几何与假设

| 术语 | 人话 | 稍严一点的说法 |
|---|---|---|
| 仰角 | 卫星抬离地平线的角度 | 0° 地平，90° 天顶 |
| 天顶角 | 离头顶有多远 | 约 90°−仰角 |
| 穿刺点 IPP | 斜线戳到「假定电离层壳」的点 | Ionospheric Pierce Point |
| 薄壳假设 | 假装电子都挤在某一高度薄壳上 | 三维→壳上二维的压缩 |
| 映射函数 | STEC↔VTEC 的换算关系 | 常含穿刺点天顶角 |

### 2.4 GNSS 与效应

| 术语 | 人话 | 稍严一点的说法 |
|---|---|---|
| GNSS | 导航卫星系统总称 | GPS/BDS/Galileo/GLONASS 等 |
| 伪距（码） | 用码相关估的「看起来的距离」 | 含钟差、延迟等 |
| 载波相位 | 用载波波峰波谷数的精密测量 | 精密但有模糊度 |
| 电离层延迟 | 电子柱造成的额外传播效应 | 一阶 ∝ TEC/\(f^2\) |
| 闪烁 | 信号发抖、强度乱晃 | 小尺度不规则性；≠ TEC 本身 |
| GIM | 全球/区域电子含量图 | 格点多为 VTEC |
| 空间天气 | 太阳–地球空间的「天气」 | 耀斑、磁暴等可剧烈改电离层 |

### 2.5 词表使用规则（课堂纪律）

1. **禁止**在还没定义时，把 TEC 说成「电子密度」。  
2. **禁止**把 STEC、VTEC 口头互换还不提映射。  
3. **允许**先用错误直觉，但必须在「常见误解」节自我纠正。

## 3. 主讲解：大量类比，小步骤推进

### 3.1 板书一：大气是分层的楼，电离层是某几层里的「带电状态」

请在笔记本画地球圆弧，向外标高度。

**步骤 1**：标对流层。说人话——「我们生活的楼层」。这里空气密，有天气。GNSS 信号穿过时，中性大气和水汽造成**对流层延迟**。注意：它和电离层延迟是两条账。

**步骤 2**：标平流层、中间层。本课不展开，只为了避免你以为「对流层上面直接就是电离层薄片」。

**步骤 3**：标热层。空气极稀，但太阳辐射强。稀薄气体照样能被电离。

**步骤 4**：用阴影标「电离层」。强调：电离层不是从物流公司新盖的一层楼，而是**原有高层大气进入电离状态**后，我们单独命名的物理区域。大约从 60 km 量级延伸到 1000 km 以上（边界教材略有出入，记量级即可）。

类比加深：  
把中性大气想成「干雾机器还没开」的空气；太阳一「开机」，局部出现带电的雾——那就是电离层。雾的浓度随高度变化，不是从上到下一桶匀浆。

### 3.2 电离层为何存在？三个必要条件

1. **有中性成分可电离**（高层仍有气体，尽管很稀）；  
2. **有电离能源**（太阳 EUV、X 射线；高纬还有粒子）；  
3. **复合与输运没有快到让电子瞬间清零**。

白天能源强 → 许多地区 TEC 更高；夜晚能源弱 → 常下降。但低纬赤道异常、极区过程会打破「白天高晚上低」的顺口溜，所以顺口溜只能当脚手架，不能当定律。

再类比：阳光下的阳台更容易晒干衣服（电离强）；阴雨天衣服也干得慢（复合/缺少能源）。但若有风机（输运），湿衣服可能被「搬」到另一侧——电离层电子也会被电磁场和风重新分布。

### 3.3 电子密度 vs TEC：点和路

**电子密度 \(N_e(h)\)**：高度 \(h\) 处，单位体积电子数。像「某一楼层走廊里每立方米有多少人」。

**TEC**：沿路径 \(\int N_e\,ds\)。像「从一楼走到顶楼，把一路遇到的人按规则加总」。

测高仪、非相干散射雷达、掩星，更常讨论廓线形状（哪一层峰值多高）。  
GNSS 双频，更直接给出路径积分（柱总量）。  
两者相关，但**不是同一个观测量**。把 GNSS TEC 说成「测到了 F2 峰密度」是常见口误。

### 3.4 TECU：为什么要这个单位？

\[
1\ \mathrm{TECU} = 10^{16}\ \mathrm{电子}/\mathrm{m}^{2}
\]

人话：横截面积 1 平方米的柱子里，电子数按 \(10^{16}\) 为一个「包」来数。  
32 TECU 就是 \(3.2\times10^{17}\) 电子/\(m^2\)。

类比：人不说「全国人口 1400000000」，而说「约 14 亿」。TECU 就是 TEC 界的「亿」。

### 3.5 水管与雾：贯穿全课的主类比

- **水管** = 卫星到接收机的信号路径；  
- **雾的浓度** = 电子密度；  
- **整根水管里雾的总量** = TEC；  
- **竖直水管** = VTEC；  
- **斜插的水管** = STEC；  
- **假定雾全挤在某一楼层薄薄一层** = 薄壳假设；  
- **斜管与那一层的交点** = 穿刺点 IPP；  
- **雾总量引起的「水流变慢」** ≈ 电离层延迟（直觉级）；  
- **雾里有很多碎涡导致光乱闪** ≈ 闪烁（另一课）。

请把这八条抄下来。后面所有公式都是在给这些话配符号。

### 3.6 STEC 与 VTEC：小步骤推导直觉（不堆严式）

**步骤 A**：固定当地竖直雾厚 = VTEC。  
**步骤 B**：卫星在天顶，斜管≈竖管，STEC≈VTEC。  
**步骤 C**：卫星往地平线倒，斜管变长，穿过更多雾，STEC 变大。  
**步骤 D**：工程上写 \( \mathrm{STEC} \approx \mathrm{VTEC}/\cos z' \)（\(z'\) 为穿刺点天顶角；具体映射函数会加地球半径、壳高等修正）。  
**步骤 E**：低仰角时不仅比值大，误差源（多路径、梯度、壳高敏感）也大 → 设截止仰角。

### 3.7 穿刺点 IPP：一步一步钉在地图上

1. 已知接收机近似位置、卫星位置 → 得到视线方向。  
2. 选定壳高 \(H\)（常见量级 350–450 km，**以产品为准**）。  
3. 求视线与半径 \(R_E+H\) 球壳的交点 → IPP 的经纬（与时间）。  
4. 若要建 VTEC 图：把该视线的 STEC 经映射变成 VTEC，作为对 IPP 附近的约束。

本仓库中名称 `Get_IPP` 即与穿刺点几何相关（已在 `PROJECTS.json` 核对）。它帮你算「戳在哪」，不自动等于「TEC 流水线全做完」。

### 3.8 薄壳假设：香与臭

**香**：降维；全球建模、IONEX 交换、实时播发都变可行。  
**臭**：真实电子有厚度、可多层、可水平梯度极强；低仰角与扰动期误差放大。  
**课堂裁决**：薄壳是工程压缩，不是自然定律。使用时要会问：「壳高多少？映射哪一种？低仰角我截断了吗？」

### 3.9 延迟与频率：为什么双频能「看见」TEC？

一阶直觉：

\[
I \propto \frac{\mathrm{TEC}}{f^{2}}
\]

同一路径、同一 TEC：频率低 → 延迟大。两个频率延迟不同，差分后几何距离、对流层等公共项大体消掉，剩下与 TEC（以及仪器偏差）有关的部分。这就是 02 课「几何无关组合」的物理根。  
单频没有第二个频率可减，只能用模型给 \(I\)。

码与载波对电离层的一阶符号相反倾向：伪距「变长」，相位「超前」。细节与组合方式留给 02 课；本课只要求你听说过「符号不同」。

### 3.10 为什么要测 TEC？（扩写成可对外汇报的四条）

1. **导航定位**：单频改正、双频残差解释、区域增强、完好性。  
2. **空间天气**：监测磁暴、耀斑后效应、行进式扰动等。  
3. **科研对比**：与 IRI/NeQuick、掩星、测高仪、GIM 互校。  
4. **数据同化 / 层析**：把 TEC 当约束，反演三维或改进背景场（后续课）。

### 3.11 常见误解专节（逐条「打假」）

**误解 A：TEC = 电子密度。**  
打假：一个是积分，一个是局地。  

**误解 B：STEC、VTEC 可随便换。**  
打假：必须映射；低仰角更危险。  

**误解 C：GIM 读数 = 我的站星 STEC。**  
打假：GIM 多为格点 VTEC；要插值+映射才对得上你的视线。  

**误解 D：TEC 大 ⇒ 闪烁强。**  
打假：闪烁看不规则性；高 TEC 也可平静。见 `05-scintillation-roti.md`。  

**误解 E：开源 TEC = IGS 官方产品。**  
打假：DCB、周跳、平滑、壳高都不同，差几 TECU 常见。  

**误解 F：电离层是薄饼，只在某一个精确高度。**  
打假：有厚度；薄壳只是建模假说。  

**误解 G：TECU 是国际基本单位制里的「基本单位」。**  
打假：是实用单位，类似「万人」。  

**误解 H：对流层延迟用 TEC 也能改。**  
打假：机制不同、频率依赖不同，不能张冠李戴。  

**误解 I：夜里 TEC 一定接近 0。**  
打假：常降低，但不是归零；区域与季节差异大。  

**误解 J：只要仰角高，映射就完美。**  
打假：高仰角更舒服，不是零误差；水平梯度仍在。

### 3.12 数字感觉（防单位事故）

- 看到软件输出几百上千 TECU 还当平静中纬白天：先查单位与缩放。  
- IONEX 内部常以 0.1 TECU 为存储单位（03 课详述）：读错会差 10 倍。  
- 对比两家 GIM：先对齐时间、壳高、是否综合产品，再比数值。

## 5. 课堂检查题（带简短答案）

**题 1.** 用一句话定义 TEC。  
**答：** 沿指定路径、单位横截面积柱内自由电子总数（路径积分电子含量）。

**题 2.** 1 TECU = ?  
**答：** \(10^{16}\) 电子/\(m^2\)。

**题 3.** 为何低仰角 STEC 常大于 VTEC？  
**答：** 斜路径更长，积分路径上电子更多；映射上相当于除以较小的 \(\cos z'\)。

**题 4.** IPP 是什么？是不是卫星星下点？  
**答：** 视线与假定电离层壳的交点；一般不是卫星星下点，也不是测站天顶。

**题 5.** 薄壳假设的「壳」指什么？  
**答：** 假定电子集中在某一固定高度的薄球壳，以便把 STEC 映射为壳上 VTEC。

**题 6.** 为何双频有助于测 TEC？  
**答：** 延迟 ∝ TEC/\(f^2\)，两频差分可突出 TEC（及偏差）信息。

**题 7.** TEC 大是否等于闪烁强？  
**答：** 否。

**题 8.** GIM 格点常见给 STEC 还是 VTEC？  
**答：** 多为 VTEC。

**题 9.** 对流层延迟能否用 TEC 公式直接改？  
**答：** 不能。物理机制不同。

**题 10.** 指出本仓库中两个与「RINEX→TEC」相关的 name。  
**答：** 例如 `gnss-tec`、`pygnss-tec`（其他如 `Seemala-GPS-TEC`、`tec-suite` 等也对）。

**题 11.** 指出两个 IONEX 数据相关 name。  
**答：** 例如 `CDDIS-IONEX`、`JPL-IONEX-Rapid`。

**题 12.** 若软件输出全日 VTEC=500 且声称平静中纬，你首先怀疑什么？  
**答：** 单位/缩放读错，或文件解析错误，或未排除异常处理。

## 7. 加长精讲：把「第一课」上成真正的课堂（必读加餐）

### 7.1 开场十分钟：从「看不见的雾」说起

同学们，今天先不要碰电脑。请大家闭上眼睛三十秒，想象你站在操场上抬头。肉眼看到的是蓝天或云，但导航卫星的无线电波正在穿过你头顶上方几十到上千公里的区域。那片区域里，有一部分气体被太阳辐射打成了带电状态。对电波而言，那些自由电子就像半透明的雾。雾可以很淡，也可以突然变浓；可以一大片均匀，也可以局部扯碎。你的接收机并不「看见」雾的颜色，它只是发现：信号到得晚了一点点，或者相位对不齐那么一点点。把「晚了一点点」翻译成「路径上有多少电子」，就是本课的核心翻译工作。

有同学问：为什么偏偏是电子？离子不也带电吗？课堂级别的回答是：在讨论 GNSS 载波在等离子体中的一阶折射/延迟时，工程上最常用、也最直接进入 TEC 定义的，是自由电子沿路径的积分。你先把「电子柱」建立起来；更完整的等离子体物理留给专门课程。

### 7.2 高度数字怎么记才不晕？

不要死记「电离层从精确多少公里开始」。请记三档：

第一档，十公里量级：对流层，天气与对流层延迟。  
第二档，几十到一百公里量级：开始出现显著电离的过渡。  
第三档，两百到几百公里量级：常常是电子密度峰值附近，对 TEC 贡献很大。  
再往上，仍然有电子，积分时一并算进路径，但是否单独建模，看你的应用。

考试若问「电离层大约在什么高度」，答「大约从六十公里量级延伸到一千公里以上，主体贡献常在热层高度段」就比背一个假精确数字更科学。

### 7.3 把 TEC 讲给文科同学听的版本

假设有一条从地面伸向卫星的透明管子，管子横截面积正好一平方米。把管子里出现的每一个自由电子都数一遍，得到一个很大的整数。这个整数就是该路径的总电子含量。由于数字太大，我们规定：每累计满一万亿亿（也就是十的十六次方）个电子，记作一个 TECU。于是「三十二个 TECU」是人话，「三点二乘十的十七次方个电子每平方米」是同一件事的科学写法。

如果管子竖直朝天，数出来的叫竖直总电子含量。如果管子斜着指向某颗卫星，数出来的叫斜路径总电子含量。斜管子更长，通常数到更多电子，所以斜路径值常常更大。为了把斜的结果画到地图上，人们常常假装：电子都挤在某一个固定高度的薄球壳上，斜管子戳到壳的那一点叫穿刺点，再用一个简单的几何因子把斜的换算成竖的。这个假装，就叫薄壳假设。

### 7.4 工程上「差几米」和 TEC 怎么对感觉？

不同频率上，同样 TEC 造成的等效距离延迟不同。你现在不必会换算表，只要建立：TEC 变化几到几十 TECU，对单频 L 波段用户来说，完全可以对应到米级或更大的延迟变化量级（具体数随频率与公式系数而定）。所以空间天气值班里「TEC 暴涨」不是学术炫技，是真的可能让单频定位变差。双频用户消掉一阶项后，仍然可能关心高阶、闪烁、完好性与模型残差——那些建立在你先懂 TEC 的前提上。

### 7.5 穿刺点的课堂演算（只讲几何，不算代码）

设测站在中纬度某城市。某颗卫星仰角三十度，方位朝南。你选定壳高四百五十公里。从测站沿视线往外走，与「地球半径加四百五十公里」的球壳相交，交点的经纬度就是穿刺点。注意：穿刺点通常不在测站正上方，也不在卫星正下方，而在两者之间的某个偏南位置（此例）。仰角越低，穿刺点离测站水平距离往往越远，壳高选错带来的水平位置误差也更敏感。因此，两家软件若壳高差五十公里，低仰角 IPP 可能差一截，后面网格化再吵「谁的 VTEC 对」就没有共同地基。

### 7.6 薄壳假设的三个「必须问」

第一问：壳高多少？  
第二问：映射函数是简单余弦，还是顾及地球曲率的修正形式？  
第三问：仰角截止多少？有没有把低仰角强行映射进图里？

三问不清，就没有资格说「我的 VTEC 和官方 GIM 差百分之多少」——因为你可能在比两件不同假设下的东西。

### 7.7 为什么 GNSS 特别适合做 TEC 监测网？

因为全球有大量连续运行的双频参考站，观测时间连续、站点相对密集（尤其欧洲、北美、东亚部分地区），并且数据格式相对标准化（RINEX）。每一个「测站—卫星」对，都是一条斜管子。成千上万条斜管子，在穿刺点处给电离层图提供约束。这就是从 STEC 走向 GIM 的数据土壤。测高仪站点少、掩星是轨迹采样、雷达更贵——它们各有不可替代处，但论「全球柱总量监测的性价比与连续性」，GNSS TEC 非常强。

### 7.8 本课与仓库索引的正确使用姿势

本仓库的 `PROJECTS.json` 里有数百个项目名称。第一课你只需要认识两类：一类名字里带 TEC、看起来像从观测估电子含量；一类名字里带 IONEX 或分析中心，看起来像产品与数据入口。不要第一天把层析、闪烁、同化、机器预测全打开。目录的意义是「以后你用得着时能检索」，不是「今天全部学会」。

### 7.9 长问答：学生最容易卡的十个追问

追问一：TEC 有没有负值？  
正常物理的电子柱不应为负。若软件给出显著负 TEC，优先查周跳、DCB、周跳修复失败、单位与符号约定，而不是先写「发现负电子」。

追问二：VTEC 是不是「真实竖直剖面上的积分」？  
在薄壳流程里，它常常是「由斜路径映射得到的等效竖直量」。若你有真正的竖直剖面（例如某些雷达），那是另一类观测。措辞上要诚实。

追问三：等离子体层要不要算进 TEC？  
部分 GNSS 视线会受到更高处等离子体贡献；产品是否包含、如何处理，因方法而异。对比模型与 GIM 时，这是隐性差异源之一。

追问四：多系统（GPS加北斗加 Galileo）TEC 能否直接平均？  
要统一频率组合、偏差口径、时间对齐与权重，不能「几个系统的数加起来除以几」这么朴素。

追问五：单频手机测得到 TEC 吗？  
一般得不到几何无关的双频 TEC。现代部分多频手机另说，但概念课仍按「双频测、单频猜」来建立地基。

追问六：TEC 和总电子含量里的「总」是对全宇宙积分吗？  
不是。是对你定义的那条路径（从接收机到卫星方向上电离层有贡献的区段）积分。

追问七：为什么文献里壳高有的三百五十、有的四百五十？  
经验与区域、用途、历史习惯不同。关键是一致性：建图与应用用同一套，对比时声明。

追问八：映射函数是不是唯一的？  
不是。课堂用余弦直觉入门；研究与业务有多种映射。读软件文档时要找映射一节。

追问九：GIM 是「真值」吗？  
GIM 是产品，是反演与组合结果，有误差与平滑。常当参考，不等于实验室绝对真值。

追问十：我只做测绘定位，要不要学 TEC？  
若你只用双频无电离层组合且从不看残差、从不做单频、从不读空间天气通报，可以暂时浅尝。一旦要解释「为什么今天残差大」、要做单频或完好性，TEC 概念就不再可选。

### 7.13 延伸思考（不做硬性作业）

思考题甲：若两颗卫星仰角相同、方位角差一百八十度，STEC 是否一定相同？为什么？  
提示：本地水平梯度、赤道异常结构、地方时差异都可能导致不同。

思考题乙：若壳高从四百公里改到五百公里，高仰角与低仰角谁的 VTEC 变化可能更明显？  
提示：从几何敏感度直觉思考。

思考题丙：为何空间天气事件期间，用平静期标定的接收机偏差策略可能出问题？  
提示：偏差与 TEC 耦合；事件期难分离——02 课会再遇。

### 7.14 中文讲授中的用词纪律

尽量说「斜路径总电子含量」「竖直总电子含量」，少在口语里只丢三字母缩写。缩写是板书压缩，不是思维压缩。对学生第一次出现的英文全称，必须给中文。本教程故意反复出现人话，就是为了对抗「缩写堆叠造成的假懂」。

### 7.15 和「大气折射」日常经验的连接

夏天公路远处发烫，景物晃动，那是对流层近地层的折射与湍流。电离层闪烁是更高处等离子体不规则性造成的电波抖动。两者都叫「折射/散射家族」的直观亲戚，但高度、频率依赖、观测量完全不同。用生活经验帮忙建立「介质不均匀会让波变坏」，然后立刻声明：不要用公路热浪去硬套 TEC 公式。

### 7.16 小结段（可当作朗读稿）

电离层是地球高层大气被太阳辐射电离后形成的带电区域。自由电子沿卫星到接收机路径的积分叫总电子含量，单位常用 TECU。沿视线的叫斜路径总电子含量，换到天顶的叫竖直总电子含量。为了把斜路径信息标到地图上，常用薄壳假设与穿刺点。电离层延迟近似与总电子含量成正比、与频率平方成反比，因此双频观测能提取与电子柱相关的信息。测量它，是为了定位改正、空间天气监测、科学研究与后续建模。常见错误是把总电子含量当成电子密度、把斜的和竖的随便互换、把全球离子图上的竖直值当成自己的斜路径值、以及把高总电子含量直接等同于强闪烁。学完本课，请带着词表进入双频估计课。


### 7.17 再补一段：从「听到电离层」到「会提问」

许多同学的学习卡点，不是公式太难，而是不会提问。学完第一课，你至少应会问出下面这些合格问题：

「这份结果是斜路径还是竖直？」  
「单位是 TECU 吗？有没有零点一的缩放？」

会问这些问题，你就已经比「只会跑一条命令出一张彩色图」的人更接近可靠研究。彩色图很美，但提问清单更重要。

### 7.19 生活化总复习对话（可两人分角色朗读）

甲：今天导航飘，是不是卫星坏了？  
乙：先别定论。也可能是高层那层带电的雾变厚或变乱了。  
甲：雾？我看不见啊。  
乙：肉眼看不见，无线电波看得见。雾的「厚度积分」叫总电子含量。  
甲：厚度是竖直的还是斜的？  
乙：地图产品常给竖直；你接收某颗卫星时测的是斜的。斜着看通常更厚。  
甲：那怎么画到地图上？  
乙：假装雾挤在某一高度的薄壳，斜线戳到的点叫穿刺点，再换算成竖直。  
甲：所以薄壳是真的？  
乙：是方便计算的假说，有用，但不完美。  
甲：我要自己测吗？  
乙：有双频观测可以估；也可以先下载全球离子图看天气。下一课讲双频怎么估。  
甲：总电子含量大就一定闪烁？  
乙：不一定。闪烁是碎斑在抖，不是柱子厚就一定抖。  
甲：好，我记住单位了：一 TECU 等于十的十六次方个电子每平方米。  
乙：对，这就是第一课的毕业台词。

## 8. 现象分析入门：把 TEC 当成「天气语言」来读（本课加长 · 必读）

> **本节目标**：在你还不会双频估 TEC、还不会读 IONEX 之前，先养成「现象分析」的眼睛。空间天气论文与值班报告，最终都要把耀斑、磁暴、赤道异常、行进式扰动等，翻译成 TEC 语言里可核对的形状与数字。不会翻译，就只会说「今天电离层活跃」——这句等于没说。

### 8.1 先补词表：现象分析专用（人话）

| 术语 | 人话 | 稍严一点 |
|---|---|---|
| **现象（phenomenon）** | 你想解释的「一件事」：暴、异常增强、局部凹陷…… | 可观测、可复述的电离层响应 |
| **基线（baseline）** | 「若没有这件事，平时大概长这样」 | 对照态；常取安静日或气候平均 |
| **异常 / 扰动** | 相对基线多出来或少掉的那一块 | 不是「曲线抖了一下」的同义词 |
| **安静日（quiet day）** | 地磁与太阳相对平静、结构「规矩」的日子 | 常用低 Kp/Ap、无强耀斑窗口挑选 |
| **扰动日 / 风暴日** | 发生磁暴或强太阳事件的日子 | 要写清指数与起止时间 |
| **地方时结构** | 同一全球时刻，东经西经「当地几点」不同 | TEC 图上的昼夜分界常跟地方时走 |
| **赤道异常（EIA）** | 低纬两侧各有一个 TEC 高峰的「驼峰」 | 并非全球均匀抬升 |
| **负暴 / 正暴效应** | 风暴后某些区域 TEC 相对安静日偏低或偏高 | 区域与地方时依赖极强 |
| **行进式扰动（TID 直觉）** | 像水波一样在 TEC 场上「扫过去」的起伏 | 细节见后续课；本课只认「会动的波纹」 |
| **读图优先序** | 打开 TEC 图后先看什么、后看什么 | 防「颜色炫技、结论空洞」 |

**词表纪律：** 没有基线，就没有资格说「增强了 30%」。增强是相对的。

### 8.2 现象如何「长成」TEC 语言？六种常见长相

同学们，把现象想成不同天气在「雾厚图」上留下的笔迹。下面六种，是入门最常遇到的笔迹。每一种都先给**人话**，再给**你在图上该找什么**。

**长相 A：整体抬升（像整盆水被抬高）**  
人话：一大片区域的 VTEC 同时比安静日高一截，形状轮廓还在，只是「底子」厚了。  
图上找：同地方时、同纬度带，颜色整体偏暖；差值图（扰动−安静）大面积正值。  
常联想到：太阳 EUV 增强后的日侧增强、某些正暴阶段。  
**切勿**：把「整盆抬高」直接说成「出现了赤道异常」——驼峰是形状问题，抬高是幅度问题。

**长相 B：驼峰加强或变形（赤道异常）**  
人话：低纬不是一个馒头，而是南北两个肩峰，中间磁赤道附近相对凹一点。  
图上找：沿纬度切开一条剖面，看是否出现双峰；风暴日双峰间距、峰高是否异常。  
**切勿**：在中纬单站时间序列上看见白天高峰，就宣称「观测到了赤道异常」。

**长相 C：局部凹陷或「空洞感」**  
人话：周围不低，某一带突然明显偏低。  
图上找：差值图上的负值斑块；要排除测站空洞导致的产品假凹陷（03 课再深挖）。  
常联想到：负暴效应、某些屏蔽过程（高级话题，本课只认长相）。

**长相 D：晨昏边界附近的陡变**  
人话：跟着地方时走的「白天厚、夜里薄」分界，在某些天变得更陡或错位。  
图上找：沿经度或地方时切片；比较安静日与扰动日的梯度。  
**切勿**：把投影与色标造成的假锐利边界写成科学发现。

**长相 E：可移动的波纹（TID 级直觉）**  
人话：不是整盆抬高，而是一串起伏按某个方向扫过。  
图上找：连续时间片动画；或固定纬度带的「时间−经度」图上看斜条纹。  
**切勿**：把单站噪声尖峰叫做行进式扰动。

**长相 F：高纬不规则碎斑**  
人话：高纬颜色碎、梯度乱，和中纬平滑日变化很不一样。  
图上找：先确认产品在高纬是否测站稀疏；碎斑可能是真扰动，也可能是反演不稳。  
**切勿**：高纬碎斑一律写成「极光引起的 TEC 暴涨」而不查指数与产品说明。

### 8.3 安静日基线：现象分析的「对照组」

#### 8.3.1 为什么必须有基线？

类比：你说「今天血压高」，医生会问「你平时多少？」没有平时，就没有「高」。  
电离层同理：你说「风暴使 TEC 增强 15 TECU」，必须回答「相对哪一天、哪个地方时、哪个产品」。

#### 8.3.2 怎么挑安静日？（课堂可操作清单）

1. **先看地磁**：优先低 Kp、低 Ap 的日子；避开主相、恢复相附近。指数入口本仓库可点名 `GFZ-Kp-Index`、`NOAA-SWPC-Planetary-K`、`NASA-OMNIWeb`（名称已在 `PROJECTS.json` 核对）。  
2. **再看太阳**：避开强耀斑与明显质子事件窗口（值班产品见 `NOAA-SWPC` 等）。  
3. **季节邻近**：尽量选风暴日前后几周内、季节相近的安静日，减少「冬夏气候差」冒充「风暴效应」。  
4. **地方时对齐**：比较时用相同世界时切片，并讨论地方时；或直接按磁地方时/地方时重采样。  
5. **产品一致**：安静日与风暴日用同一分析中心、同一时延档（Final 对 Final），不要 Rapid 减 Final。  
6. **多安静日更稳**：能平均 3～5 个安静日更好；单一「看起来挺平」的日子可能有隐藏结构。

#### 8.3.3 基线的三种常见做法（由浅入深）

| 做法 | 人话 | 优点 | 风险 |
|---|---|---|---|
| **单安静日** | 挑一天当对照 | 简单 | 那天可能并不「普通」 |
| **多安静日平均** | 几张安静图平均成「典型安静」 | 更稳 | 平均会抹掉真实日变化细节 |
| **气候模型场** | 用 IRI/NeQuick 当气候底（见 04 课） | 可重复 | 模型偏差会进「异常」 |

课堂建议：作业与值班入门用「多安静日 + 同产品」；论文若用模型气候，必须声明「异常 = 实况 − 气候」，不是「异常 = 真理」。

#### 8.3.4 基线误解专打

**误解：** 安静日就是 TEC 处处很低。  
**打假：** 安静日仍有很强的昼夜与纬度结构；「安静」指扰动水平低，不是「雾消失」。

**误解：** 风暴前一天一定可当安静日。  
**打假：** 有时主相前已有初相或别的活动；要看指数，不能只看日历相邻。

**误解：** 全球平均 TEC 升高 = 我的测站也升高。  
**打假：** 正负暴可区域相反；全球均值会掩盖分区故事。

### 8.4 打开一张 TEC 图：先看什么？（强制优先序）

请把下面顺序当成「读图交规」。违反交规的结论，组会上站不住。

**第 1 眼：元数据，不是颜色。**  
问：哪家产品？哪一天哪个时刻？Final 还是 Rapid？单位是否 TECU？壳高多少？  
本仓库读图工具可点名：`ionex`、`ionex_reader`、`MathWorks-ionex_reader`；数据入口：`CDDIS-IONEX`、`JPL-IONEX-Rapid`、`UPC-IONEX-Archive`。

**第 2 眼：色标与数值范围。**  
同一场，色标从 0–50 与 0–100，观感完全不同。先读 colorbar 数字，再谈「红得很猛」。

**第 3 眼：地方时 / 昼夜。**  
找到日侧与夜侧。问：我看到的高峰，是不是只是「当地下午」的正常气候？

**第 4 眼：纬度结构。**  
中纬？低纬驼峰？高纬碎斑？先给结构命名，再给风暴命名。

**第 5 眼：与安静日并排，或看差值图。**  
没有并排/差值，不允许说「明显增强」。差值图思想在 03 课展开；本课先建立「必须有对照」的肌肉记忆。本仓库与差分制图相关可点名 `DiffIonMap`（具体用法以该项目文档为准）。

**第 6 眼：测站覆盖直觉。**  
海洋、极区、南半球部分区域更易「看起来有结构其实是平滑填充」。颜色连续 ≠ 观测密集。

**第 7 眼：才允许写科学句子。**  
合格句式示例：「在某某产品、某某世界时，相对某某安静日平均，某某纬度带日侧 VTEC 高约 N TECU，表现为整体抬升而非新的双峰结构。」

### 8.5 把生活天气对照到 TEC 现象（加深类比）

| 生活天气 | TEC 语言 |
|---|---|
| 今天比往年七月平均热 3 度 | 相对气候/安静基线的正异常 |
| 冷锋过境，温度先升后降 | 风暴主相—恢复相的时间演变 |
| 城市热岛（局部） | 区域正异常斑块 |
| 台风眼附近相对静 | 局部凹陷（须防假空洞） |
| 波纹从湖面一侧扫到另一侧 | 行进式扰动的动画感 |
| 雾浓度计坏了读数乱跳 | 数据质量假现象（02 课主题） |

### 8.6 现象分析课堂小流程（十五分钟可练）

1. 选定一个公开风暴日（只需会说日期与「有磁暴」）。  
2. 用 `CDDIS-IONEX` 或 `NOAA-SWPC-GloTEC` / `ESA-TIO-NRT-TEC` 等入口找到可看的 TEC 图或产品。  
3. 按 8.4 的七眼顺序口述一遍。  
4. 强制完成填空：「相对 ______（基线），在 ______（区域/地方时），出现 ______（长相 A–F），幅度约 ______ TECU。」  
5. 写出两个「我还不能下的结论」（例如还没做 QC、还没用多中心交叉）。

### 8.7 本节新增检查题

**题 A.** 为什么没有安静日基线就不能说「TEC 增强」？  
**答：** 增强是相对量；缺对照就无法区分气候日变化与扰动响应。

**题 B.** 打开 TEC 图第一眼应看颜色还是元数据？  
**答：** 元数据（产品、时间、单位、档次、壳高等）。

**题 C.** 赤道异常在 TEC 语言里最关键的「长相」是什么？  
**答：** 低纬双峰（驼峰）结构，而不是「某处数值变大」一句话。

**题 D.** 举出一个本仓库中与 IONEX 数据入口相关的 `name`、一个读库 `name`。  
**答示例：** `CDDIS-IONEX`；`ionex`。

**题 E.** 「全球平均 TEC 升高」能否直接写成你所在城市的风暴效应？  
**答：** 不能。正负效应可分区；须看区域与地方时。

### 8.9 本节朗读稿（可收束）

总电子含量图是空间天气的一种语言。现象不会自己写成论文标题，它只会变成抬升、驼峰、凹陷、陡变、波纹与碎斑。安静日基线是对照组；没有对照，就没有「增强」或「削弱」。打开图时，先读元数据与色标，再读地方时与纬度结构，最后才允许说现象。把这个顺序练成本能，你就已经在用现象分析的心态学习第一课，而不是只在背 TECU 定义。
