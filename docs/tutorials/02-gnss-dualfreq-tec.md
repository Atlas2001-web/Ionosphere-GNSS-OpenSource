# 02 · 双频 GNSS 怎么估 TEC（几何无关、平滑、DCB）

> **课堂定位**：接第一课。你已经知道 TEC/STEC/VTEC/TECU 是什么。这节课回答：手里有双频观测文件时，脑子里应该按什么顺序走到 STEC。公式少而精，重点是每一步在干什么、常见坑在哪里。
>
> **写给谁**：第一次打开 RINEX、第一次听到「几何无关」「整周模糊度」「DCB」的人。

---

## 1. 这节课要解决什么（生活 / 工程问题）

### 1.1 三个会卡住你的现场

**现场甲：师兄丢给你一天的 RINEX，说「算一下 TEC」。**  
文件能打开，里面全是字母数字。你不知道该用哪两列、要不要先改周跳、算出来的数为什么和网上 GIM 对不上。

**现场乙：你用开源软件出了一条 STEC 曲线，白天比官方产品高七八个 TECU，晚上还是高。**  
有人说「你没改正 DCB」。DCB 是什么？它怎么能假装成电子柱？

**现场丙：相位曲线很漂亮，伪距曲线像心电图。**  
师兄说「做载波平滑」。平滑是把数据糊成一条直线吗？还是有正经含义？

### 1.2 这节课交付什么

学完你应能：

1. 用「两把尺子量同一根杆」讲清双频为何能提取电离层信息；  
2. 区分码伪距与载波相位各自的优缺点；  
3. 解释几何无关组合在消什么、留什么；  
4. 用人话说明相位整周模糊度与周跳；  
5. 说出相位平滑伪距的直觉；  
6. 解释 DCB/IFB 为何污染 TEC，并知道下一层课/专题还会深挖；  
7. 按清单从 RINEX 走到 STEC（头脑清单，不要求当堂写完代码）；  
8. 能在本仓库 `PROJECTS.json` 里点名若干真实工具。

### 1.3 先划清边界

- **有双频（或更好：多频）观测** → 可以谈几何无关 TEC。  
- **只有单频** → 做不了本课主流程，只能用模型改正（见后续定位课与 04 课模型）。  
- 本课**不**教你建全球 GIM（那是 03），**不**把 IRI 当实测（那是 04），**不**把闪烁当 TEC（那是 05）。

## 2. 先备齐「词表」：本节每个术语用人话定义

| 术语 | 人话 | 稍严一点 |
|---|---|---|
| **双频** | 同一颗卫星、同一时刻，至少两个载波频率上有观测 | 例如 GPS L1 与 L2（或 L1 与 L5 等组合，以数据为准） |
| **频率 \(f_1,f_2\)** | 两把「无线电尺子」的刻度密度不同 | 载波频率，单位 Hz |
| **伪距 / 码观测** | 用测距码相关估出来的「看起来的距离」 | 噪声与多路径通常较大，但有绝对尺度感 |
| **载波相位** | 数载波波峰波谷得到的精密测量 | 噪声小，但有整周未知数 |
| **整周模糊度** | 相位尺子「不知道从第几格开始数」 | 在连续跟踪且无周跳时，像一个常数偏置 |
| **周跳** | 跟踪突然丢了若干整周 | 相位时间序列出现跳变，模糊度改变 |
| **几何距离** | 卫星到接收机的真实几何路程（近似） | 与频率无关的公共项之一 |
| **对流层延迟** | 中性大气造成的额外延迟 | 对两频近似相同（一阶） |
| **接收机钟差 / 卫星钟差** | 钟不准造成的等效距离误差 | 对两频近似相同（一阶） |
| **几何无关组合** | 两频观测相减（或按系数组合），把「公共几何」消掉 | geometry-free；留下电离层 + 偏差等 |
| **电离层延迟** | 电子柱造成的频率相关延迟 | 一阶 ∝ TEC/\(f^2\)，码与相位符号倾向相反 |
| **相位平滑** | 用精密相位约束粗糙伪距的时间变化 | 得到更干净的绝对水平时间序列 |
| **DCB** | 两个频率码延迟差（卫星或接收机） | Differential Code Bias；会伪装成 TEC |
| **IFB** | 接收机端跨频偏差（口语里常与接收机 DCB 家族一起说） | Inter-Frequency Bias |
| **OSB** | 可观测值偏差产品的一种现代口径 | Observable-Specific Bias；与 DCB 产品体系相关 |
| **RINEX** | GNSS 观测与导航数据的常见交换格式 | 文本（或压缩）；含观测类型、时间、卫星号 |
| **观测类型** | 如 C1C、C1W、L1C、L2W… | 不同码/相位跟踪方式；偏差产品必须对齐类型 |
| **STEC** | 本课主要产出：斜路径总电子含量 | 见 01 课 |
| **仰角截止** | 太低的卫星先扔掉 | 减少多路径与映射灾难 |
| **弧段** | 连续跟踪、无周跳（或已修复）的一段时间 | 平滑与模糊度处理常按弧段进行 |

**词表纪律：** 没改 DCB 就说「我测到了真 TEC」，在本课堂算不合格表述；应说「几何无关观测量换算值（尚未分离偏差）」或明确「已用某某产品改正」。

## 3. 主讲解

### 3.1 双频：为什么要两把尺子？

第一课写过：

\[
I \propto \frac{\mathrm{TEC}}{f^{2}}
\]

同一条路径、同一份 TEC，频率低则电离层延迟大。若你只有一个频率，延迟和几何距离、钟差、对流层缠在一起，像一锅粥。若你有两个频率，两锅粥里「几何、钟差、对流层」近似相同，「电离层」不同——相减之后，公共项淡出，电离层信息浮出。

**类比：** 两个人用不同网孔的筛子筛同一袋沙。沙子总量（几何）一样；网孔不同导致「卡住的方式」不同。对比两只筛子的差异，能推断沙子之外某种与网孔相关的性质——对 GNSS，那就是与频率相关的电离层效应。

### 3.2 码与载波：粗糙有刻度的尺 vs 细密没零点的千分尺

**码伪距：**  
像超市里印着厘米刻度的木尺。你可以读出「大约多少」，但抖得厉害，墙角反射（多路径）会骗你。

**载波相位：**  
像精密千分尺，格很细，抖得小。但开机锁定时，你不知道「整周数从几开始」，只知道之后相对走了多少。这个未知整周，就是**整周模糊度**。若跟踪中断，整周数可能跳一下，叫**周跳**。

课堂口诀：

> **伪距稳在「绝对水平」但吵；相位准在「相对变化」但缺零点。**

### 3.3 几何无关组合：把「有多远」减掉

伪距 \(P_1,P_2\) 在频率 \(f_1,f_2\) 上。直觉写法：

\[
P_{GF} = P_1 - P_2 \propto \mathrm{STEC} + \mathrm{偏差项}
\]

人话：两个伪距一减，卫星有多远、对流层有多厚、钟差有多大，大体消掉；差里主要是「这条斜路径的电子」以及仪器/频率相关偏差。

载波相位也有对应的几何无关组合：更平滑，但带着模糊度（在无周跳弧段内像常数），周跳时会台阶状跳变。

**常见误解：** 「几何无关 = 完全没有误差」。错。多路径、噪声、偏差、高阶项、跟踪异常都还在。它只是把**与频率无关的几何公共项**压下去。

### 3.4 相位整周模糊度：再讲人话一遍

想象你从黑屋子摸一把千分尺去量桌面高度。你能感觉「转了多少格」，但不知道起点对应墙上哪条刻度。只要你手不离开、尺不掉，相对变化可信；一旦尺掉了重拿（周跳），零点可能换了。

对几何无关相位：弧段内相对 STEC 变化很漂亮；要钉绝对 TEC，还得靠伪距几何无关（或其它约束）来定水平，并处理偏差。

### 3.5 相位平滑：不是「把线抹直」

实务常见策略：

1. 用**伪距几何无关**提供绝对水平（吵）；  
2. 用**相位几何无关**提供相对变化（准）；  
3. 在无周跳弧段内，让伪距的绝对值被相位的形状「带着走」——这就是载波平滑伪距的一种应用场景。

**类比：** 木尺告诉你「大概在 1 米附近」，千分尺告诉你「这一分钟里慢慢升了 2 毫米」。平滑 = 用千分尺描波形，用木尺钉高度。

**误解：** 平滑会消灭所有周跳。错。周跳不处理，平滑会把错误台阶抹进结果。先做周跳探测/修复或按弧段断开，再平滑。

### 3.6 DCB / IFB：为什么必须管（本课预告级深度）

几何无关组合里，除了 STEC，还有：

- **卫星 DCB**：卫星端两个频率码延迟差；  
- **接收机 DCB/IFB**：接收机端类似偏差。

它们会**伪装成 TEC**。不管偏差，你的「TEC」可能系统性偏高或偏低好几 TECU，白天夜里一起偏——看起来像「电离层整体抬了一层楼」，其实是仪器账没算清。

实务直觉：

1. 卫星端优先用公开 DCB/OSB 产品改正；  
2. 接收机端常在估计里当未知数，或用标定/约束策略；  
3. 观测类型必须与偏差产品对齐（C1C 与 C1W 不是自动同一套账）；  
4. 深度专题见本目录 `09-dcb-biases-deep.md`（若你继续往下读）。

本仓库与偏差相关可点名：`Gkit-Bias`（已在 `PROJECTS.json` 核对）。数据侧分析中心与产品入口见数据集列表与 `docs/data-access.md`。

### 3.7 从 RINEX 到 STEC：逐步清单（请当作业流程图）

把流水线想成九步。每一步都问「我不做会怎样」。

**第 1 步：确认你真有双频。**  
打开 RINEX 头或用软件列观测类型。若只有单频，停止本流程。  
不做会怎样：后面组合无意义。

**第 2 步：读观测。**  
解析时间、卫星号、伪距、相位、（若有）载噪比等。可用本仓库已收录的 `georinex`、`rinex`、`PyRINEX` 等（名称已核验）。  
不做会怎样：垃圾进垃圾出。

**第 3 步：时间与系统对齐。**  
多系统混用时注意时间系统、观测历元对齐。  
不做会怎样：组合到错误的卫星/历元。

**第 4 步：仰角与粗差预筛选。**  
算仰角（需大致坐标与星历），丢弃过低仰角；剔除明显野值。  
不做会怎样：低仰角多路径与映射误差主导故事。

**第 5 步：周跳探测与弧段划分。**  
相位几何无关序列、或多频组合、或专用周跳工具。本仓库可点名：`cycle-slip-correction`、`DRCycleSlip`；质量检查还可看 `TEQC`、`Anubis`。  
不做会怎样：平滑与 STEC 出现假台阶。

**第 6 步：组几何无关组合。**  
伪距、相位分别做两频差（或标准系数组合），得到与 STEC 成比例的观测量。  
不做会怎样：还在和几何距离缠斗。

**第 7 步：相位平滑伪距（按弧段）。**  
得到更干净的时间序列。  
不做会怎样：绝对水平吵，短时结构被噪声淹。

**第 8 步：改正 DCB（及必要频率相关项）。**  
卫星 DCB/OSB 优先产品；接收机偏差按策略估计或标定。类型对齐。  
不做会怎样：整条曲线整体平移，像假 TEC。

**第 9 步：换算到 TECU，得到 STEC(t)。**  
用频率因子把「米」量纲组合值换成 TECU。  
可选第 10 步：薄壳 + IPP 映射到 VTEC，通向 GIM（03 课）。穿刺点几何可参考 `Get_IPP`。

**课堂提醒：** 不同软件在第 5、8、10 步默认假设不同。**不要混用结果却不看 README。**

### 3.8 压缩版「体检表」：算出 STEC 后先自检

1. 单位是不是 TECU？有没有差 10 倍？  
2. 夜间是否出现大量离谱负值？  
3. 同一测站多颗高仰角卫星，映射后的 VTEC 是否大致接近（允许差异，但不应荒唐）？  
4. 与当日 GIM 插值对比，偏差是「整体平移」还是「形状全拧」？整体平移优先查 DCB；形状全拧查周跳、频率选错、时间错位。  
5. 低仰角段是否单独染色检查？

### 3.9 常见误解专节

**误解 1：几何无关以后就没有误差了。**  
仍有噪声、多路径、偏差、高阶、跟踪问题。

**误解 2：相位 TEC 比伪距 TEC「更真」所以可以不要伪距。**  
相位缺绝对零点（模糊度）。相对变化漂亮 ≠ 绝对水平已钉死。

**误解 3：平滑 = 低通滤波随便抹。**  
载波平滑有特定构造；乱滤波可能破坏物理跳变或引入滞后。

**误解 4：DCB 很小可以忽略。**  
几纳秒量级的码偏差换算到 TECU 可以很可观；区域对比、建图、和模型比都会歪。

**误解 5：任何两个频率都能随便减。**  
要匹配可用观测、噪声、偏差产品定义；现代多频还有更优组合，但入门先把双频经典路径走通。

**误解 6：RINEX 里有 L1/L2 就等于高质量双频。**  
还要看实际跟踪是否连续、是否大量周跳、码类型是否怪异、接收机是否半成品配置。

**误解 7：我的 STEC 和 GIM 的 VTEC 差很多，所以我的算法废了。**  
先统一：是否映射、IPP 哪里、时间、壳高、DCB。苹果与橘子的差，不能直接判死刑。

**误解 8：周跳修好了就等于模糊度固定成正确整数了。**  
探测/修复与「模糊度固定成功」不是同一难度等级。TEC 流程里常按弧段处理相对量 + 伪距定水平，策略要读软件说明。

### 3.10 类比总集（方便背）

| 对象 | 类比 |
|---|---|
| 双频 | 两把网孔不同的筛子 |
| 伪距 | 粗糙但有刻度的木尺 |
| 相位 | 细密但不知零点的千分尺 |
| 几何无关 | 两尺相减，把「杆有多长」消掉 |
| 模糊度 | 千分尺没对齐墙上的零刻度 |
| 周跳 | 尺子掉了重拿 |
| 平滑 | 木尺钉高度，千分尺描波形 |
| DCB | 两把尺的「起点差」被当成雾的厚度 |

### 3.11 如果只给你二十分钟演示

分钟 0–3：复习 \(I\propto\mathrm{TEC}/f^{2}\)。  
分钟 3–8：木尺/千分尺，画几何无关。  
分钟 8–12：周跳台阶手绘。  
分钟 12–16：DCB 整体平移手绘。  
分钟 16–20：投影九步清单，点名仓库工具两行。

## 5. 课堂检查题（带简短答案）

**题 1.** 为何双频差分能突出电离层信息？  
**答：** 电离层延迟随 \(1/f^{2}\) 变，几何/对流层/钟差等对两频近似公共，相减后公共项淡出。

**题 2.** 伪距与相位在 TEC 流程里各擅长什么？  
**答：** 伪距给绝对水平（噪）；相位给相对变化（精，但有模糊度）。

**题 3.** 整周模糊度用人话说是什么？  
**答：** 相位测量不知道从第几整周起算的那个未知整数偏置。

**题 4.** 周跳对几何无关相位序列通常长什么样？  
**答：** 出现台阶状跳变，弧段内「常数模糊度」假设被破坏。

**题 5.** 相位平滑是不是把曲线强行抹直？  
**答：** 不是。是用相位约束伪距时间变化，保留物理变化、压噪声。

**题 6.** DCB 不管会怎样？  
**答：** 偏差被当成 TEC，曲线可能整体偏好几 TECU。

**题 7.** 从 RINEX 到 STEC，列出至少五步。  
**答：** 读观测→筛选/仰角→周跳与弧段→几何无关→平滑→DCB→换算 TECU（可再映射）。

**题 8.** 举出两个 `PROJECTS.json` 中用于 RINEX→TEC 的 name。  
**答：** 如 `gnss-tec`、`Seemala-GPS-TEC`（或 `pygnss-tec`、`tec-suite` 等）。

**题 9.** 你的 STEC 与 GIM 的 VTEC 直接相减前要先问什么？  
**答：** 是否已映射、壳高、时间、IPP、DCB 是否一致。

**题 10.** 只有单频能否做本课几何无关 TEC？  
**答：** 不能。只能改用模型等其它途径。

**题 11.** 观测类型为何要和偏差产品对齐？  
**答：** 不同码类型偏差定义不同，错配等于用错改正数。

**题 12.** `TEQC` 在本课清单里主要帮你做什么？  
**答：** 质量检查一类工作（具体能力以该工具文档为准），不是自动输出官方 TEC 产品。

## 7. 加长精讲：把双频课上「透」

### 7.1 开场故事加长版

实验室里最常见的失败，不是公式写错一行，而是**口径混乱**。甲用伪距几何无关不做 DCB；乙用相位平滑但没切弧段；丙把 STEC 和 GIM 的 VTEC 画在同一坐标轴上直接比。三人吵架三天，数据其实都「没算错」，错在没对齐定义。本课的九步清单，就是为了让吵架变成可检查的表格。

### 7.2 频率选择的课堂提醒

入门文献常写 GPS L1/L2。现代数据可能是 L1/L5、或多系统混合。原则不变：两个频率、延迟差携带电离层信息。实务要核对：该频率上是否有稳定码/相位、偏差产品是否覆盖、噪声如何。不要因为「听说 L5 好」就在偏差与类型未对齐时强行上阵。

### 7.3 把「米」变成 TECU：概念上发生了什么？

几何无关组合常常先以长度单位（米）出现。乘（或除）一个与 \(f_1,f_2\) 有关的因子后，变成 TECU。你不必当堂背因子，但必须知道：**软件若用错频率对，尺度会错；若单位当长度输出却当 TECU 解释，故事会崩。** 任何陌生软件，先找「输出单位」一节。

### 7.4 多路径：电离层的影武者

低仰角、水面、玻璃幕墙附近，伪距多路径可以很大，相位也受影响但通常小于伪距。几何无关后，多路径仍可能残留，看起来像「电离层短时抖动」。识别办法：对照仰角、对照载噪比、对照多颗星是否同时抖、对照已知多路径严重的站。别把所有抖都写成空间天气论文。

### 7.5 接收机端偏差为什么难？

卫星 DCB 有服务机构常规估并发布；接收机千差万别，固件、天线、线缆、温度都可能影响。短期课程里，接受「接收机偏差常当参数估」这一现实，比追求「我手算了一个绝对真值」更健康。换接收机、改天线、改固件后，旧的接收机偏差不要无限期沿用。

### 7.6 与第一课薄壳的接口

本课主产物是 **STEC(t)**。只有当你要画地图、要跟 GIM 比竖直场，才强制进入映射。许多科研问题直接分析 STEC 时间序列（例如相对变化、扰动检测）就够。**能不映射就不急着映射**，以免额外假设污染结论。

### 7.7 长问答

问：伪距几何无关已经能出 TEC，为何还要相位？  
答：降噪、看清短时结构；绝对水平仍需伪距或约束。

问：平滑窗口是不是越长越好？  
答：太长会拖尾、削弱真变化；太短噪仍大。按弧段与采样率来，并做敏感性试验。

问：没有外部 DCB 产品能不能做？  
答：能估，但需网解/约束/参考策略；单站绝对水平更难，须在文中声明。

问：实时与事后有何不同？  
答：实时产品延迟与精度策略不同；周跳与偏差处理更苛刻。入门先事后。

问：`Seemala-GPS-TEC` 和 `gnss-tec` 哪个「更对」？  
答：无此问法。比输入要求、偏差策略、默认壳高、社区维护与你的系统是否匹配。

### 7.8 九步清单的「失败模式表」

| 步骤 | 典型失败现象 | 优先排查 |
|---|---|---|
| 读观测 | 全空、时间乱 | 压缩格式、版本、路径 |
| 双频确认 | 组合报错 | 观测类型缺失 |
| 仰角 | 夜间怪值暴增 | 截止角过低 |
| 周跳 | 台阶、分段错 | 探测阈值、弧段 |
| 几何无关 | 尺度离谱 | 频率对、符号 |
| 平滑 | 钝化或假平滑 | 未按弧段、参数 |
| DCB | 整体平移 | 产品、类型对齐 |
| 换算 | 差 10 倍 | 单位、因子 |
| 映射 | 与 GIM 形状拧 | 壳高、IPP、仰角 |

### 7.9 推荐练习路径（仍不强制写代码）

练习 A：用 `georinex`（或其它读库）列出某文件观测类型，证明双频存在。  
练习 B：画某星伪距几何无关与相位几何无关（若工具允许），标出疑似周跳。  
练习 C：同一弧段，对比「未改 DCB」与「改正后」的整体偏移。  
练习 D：高仰角 STEC 映射后与 `CDDIS-IONEX` 某产品插值比一小时，记录差多少 TECU。

### 7.10 讲授用类比剧本（五分钟）

老师拿两根不同刻度的尺量同一根竹竿。先减出「与刻度有关的差」，再宣布：差里有雾的厚度，也有两尺起点不一致（DCB）。然后假装尺子掉了（周跳），让学生看到曲线台阶。最后用细尺描变化、粗尺钉高度（平滑）。五分钟内不写矩阵，只建立神经记忆。

### 7.11 本课强制留下的板书

二、伪距绝对吵，相位相对准，模糊度是零点问题。  
三、几何无关 ≠ 无误差。  
四、先周跳/弧段，再平滑。  
五、DCB 会伪装成 TEC。  
六、清单：读→筛→跳→组合→平滑→偏差→TECU（→可选映射）。

### 7.14 结束朗读稿

当你拥有双频观测，就可以构造几何无关组合，让与频率无关的几何公共项退下，让与电子柱相关的信息上台。伪距提供绝对水平，相位提供精密变化；二者通过弧段内的平滑协作。整周模糊度与周跳提醒你：相位不是自动的绝对真值。差分码偏差会整体平移你的结果，必须处理或诚实声明。从 RINEX 到 STEC，按清单走，每一步都知道不做的代价。算出斜路径总电子含量之后，若要地图，再去第三课读全球离子图与 IONEX。

### 7.20 加餐：把「码延迟」和「相位超前」再说透一点

第一课只让你听说：电离层对码和对相位的一阶表现符号倾向相反。这节课用工程直觉补一口。把电波想成既有「调制在上面的码图案」，又有「底下的载波振荡」。电子柱让码图案的到达变晚（群延迟），又让载波相位的表现走向另一侧（相位超前）。所以当你做双频差分时，伪距几何无关与相位几何无关在公式符号、系数细节上要想清楚，不能两套观测用同一套「想当然的减」。具体符号以你用的教科书或软件文档为准；课堂要求是：**知道它们不是随便同一符号相减就完事。**

### 7.21 加餐：什么叫「弧段」——用通勤比喻

你每天坐地铁上班，车厢连续运行的一段叫一趟。中途断电重启，就算新一趟。相位跟踪也一样：连续锁定、模糊度可视为同一常数的那一段，叫弧段。周跳或失锁，开启新弧段。平滑、估计相对变化，都在弧段内做才有意义。跨弧段硬连，等于把两趟地铁的里程表直接接在一起。

### 7.22 加餐：质量检查为什么要单独成步

有人一拿到 RINEX 就进 TEC 程序。更稳的习惯是：先用 `TEQC` 或 `Anubis` 一类工具看完好率、周跳统计、多路径指标（以各工具实际输出为准）。站点当天若跟踪极差，先修数据或换站，再谈科学解释。垃圾站的「空间天气发现」最容易变成笑话。

### 7.23 加餐：压缩 RINEX 那些名字

你常会遇到 Hatanaka 压缩、crx 一类文件。本仓库点名 `crx2rnx`、`hatanaka`、`RNXCMP`、`GFZRNX`，就是提醒你：读不动文件时，先查是不是压缩格式，而不是怀疑 TEC 理论崩了。工具不会替你做科学判断，但能让你跨过格式门槛。

### 7.24 加餐：把 DCB 讲给完全外行

两台收音机听同一个电台，音量旋钮的「零刻度」可能不一样。你比较两台机器的音量差，以为是电台声音变了，其实是旋钮零点不同。DCB 就像两个频率通道上的零点差。它混进几何无关组合，看起来就像电子柱多了一截。所以要先校准旋钮，再谈天气。

十到三十分：双频与几何无关板书。  
三十到五十分：模糊度、周跳、平滑。  
五十到七十分：DCB 与九步清单。  
七十到八十五分：仓库工具表与检查题。

### 7.27 深度类比课：实验室里的「两壶水」

假设有两壶水，壶身刻度分别代表频率一和频率二。壶里水位总高度像「几何距离 + 公共延迟 + 电离层」。你把两壶水位相减，公共的底座高度消掉，剩下与频率有关的那截差。这截差里，有真正的「雾」（TEC），也有壶底厚度不同（DCB），还有水面波纹（噪声与多路径）。平滑是等波纹小一点再读；周跳是有人突然撞了一下壶，刻度跳了。把这个故事在脑内动画放三遍，几何无关就不抽象了。

### 7.28 逐步清单的「口头禅」

每做一步，强制说出口：  
「我现在在做什么？不做会怎样？用哪个工具？输出单位是什么？」  
四问成习惯，比背任何公式都更能救命。

### 7.29 和闪烁、ROTI 的边界（防窜课）

有人看到 STEC 一分钟变化很快，就写「强闪烁」。慢着：TEC 的时间变化率相关指标（如 ROT/ROTI）与闪烁指数不是自动等同。本课只负责 STEC 怎么来；闪烁课见 `05-scintillation-roti.md`。边界不清，最易在组会上被问倒。

### 7.30 和定位无电离层组合的边界

精密单点定位常构造无电离层线性组合消一阶延迟，那是「避开电离层」，不是「测量 TEC」。本课是反过来：专门把电离层提出来。两条技术路线目的相反，公式家族有亲戚关系，但产品目标不同。听到「无电离层」不要以为等于「得到了 TEC」。

### 7.31 长练习说明文（可当作书面作业题面）

作业题面示例：选取某公开双频测站某日 RINEX。完成：列出观测类型；说明选用的频率对；描述周跳处理策略（即使是「按软件默认」也要写出来）；说明 DCB 产品名称与观测类型是否对齐；给出一颗高仰角卫星的 STEC 曲线截图；与同日某 IONEX 产品在对应穿刺点映射后的 VTEC 对比，讨论差异来源。评分重点在「口径是否说清」，不在「曲线是否漂亮」。

### 7.32 再补常见误解四条

误解九：多系统一起算平均 TEC 一定更好。  
未必。偏差与权重没处理好，平均是灾难。

误解十：采样率越高 TEC 越真。  
高采样有利于看快变化，也放大噪声与文件体积；要匹配科学问题。

误解十一：开源默认参数等于 IGS 分析中心策略。  
默认是作者的选择，不是国际标准自动附身。

误解十二：改正了卫星 DCB 就可以宣布接收机无偏。  
卫星与接收机是两头；只改一头，另一头仍可能坐在你的「TEC」里。

### 7.33 本课收束段落（可朗读）

同学们，第二课的核心不是让你成为偏差专家，而是让你拥有一条从原始观测走到斜路径总电子含量的清醒路线。双频提供可差分的频率依赖；几何无关组合把公共几何推到后台；伪距与相位分工合作；周跳与弧段决定相位能不能用；平滑降低噪声而不是伪造物理；差分码偏差必须被当成一等公民。仓库里的 `gnss-tec`、`pygnss-tec`、`tec-suite`、`Seemala-GPS-TEC`、`Okoh-MATLAB-TEC-from-RINEX`、`IONOLAB-TEC-Software`、`georinex`、`TEQC`、`Gkit-Bias` 等名字，是这条路线上的门牌。下一课我们把许多条斜路径，变成一张可交换的全球或区域图。

若学生能独立写出九步并为每步写「失败现象」，判为优秀。

## 8. 假现象识别：数据质量如何伪装成「风暴效应」（本课加长 · 必读）

> **本节目标**：在你宣称「双频 STEC 看到了磁暴响应」之前，先学会一套质控（QC）心态。很多「重大发现」经不起九步清单与检查表；它们其实是周跳台阶、DCB 平移、多路径抖动、低仰角映射灾难、时间对齐错误。现象分析的第一课是：**先证明它不是假的，再讨论它是什么物理。**

### 8.1 先补词表：QC 与假现象

| 术语 | 人话 | 稍严一点 |
|---|---|---|
| **假现象（artifact）** | 看起来像电离层故事，其实是数据处理伤疤 | 非地球物理起源的信号结构 |
| **质控 QC** | 算 TEC 前后的体检 | Quality Control；拒收/标记坏弧段 |
| **整体平移** | 整条曲线上移或下移一截，形状差不多 | 常联想到 DCB/单位/类型错配 |
| **假台阶** | 某一时刻突然跳一截然后继续 | 常联想到周跳、失锁、弧段拼接错误 |
| **假尖峰** | 孤立的上下刺 | 野值、多路径、跟踪毛刺 |
| **假日变化** | 「每天重复」的奇怪起伏 | 可能是环境多路径随方位重复 |
| **风暴效应（待证）** | 你想归因于磁暴/耀斑的 TEC 变化 | 必须先过 QC 门，再过空间天气门 |
| **一致性检验** | 多星、多站、多产品是否讲同一个故事 | 真现象常更一致；假现象常「只有一条弧段在演」 |

**词表纪律：** 未完成 QC 检查表，口头禁止使用「观测到了风暴效应」；只许说「原始几何无关序列出现某结构，待排除假现象」。

### 8.2 假现象图鉴：六种最像「空间天气」的骗子

#### 骗子 1：周跳台阶 ≈ 「突然暴涨/暴跌」

**长相：** STEC 或几何无关相位在某秒跳了数 TECU，然后在新水平上继续。  
**像什么物理：** 像瞬间注入或抽走电子。  
**为何是假的：** 电子柱不会在一秒内全球改写；单星单站台阶优先怀疑跟踪。  
**怎么拆穿：**  
1. 看是否只发生在一颗星；真大尺度风暴通常多星同向演变（仍可有局部）。  
2. 对照相位几何无关与伪距几何无关：相位跳、伪距不跳 → 周跳嫌疑大。  
3. 用周跳工具或按弧段断开重算。仓库可点名：`cycle-slip-correction`、`DRCycleSlip`。  
**类比：** 电梯楼层显示突然从 10 跳到 15，不是大楼长高了，是传感器丢了计数。

#### 骗子 2：DCB / 类型错配 ≈ 「全天电子柱偏厚」

**长相：** 相对 GIM 或邻站，你的结果整天高（或低）几到十几 TECU，昼夜形状却挺像。  
**像什么物理：** 像持续正暴或「背景 TEC 异常高」。  
**为何是假的：** 仪器零点差会伪装成雾厚。  
**怎么拆穿：**  
1. 查卫星 DCB/OSB 是否改正、观测类型是否对齐。  
2. 换一版偏差产品，看整体平移是否跟着走。  
3. 仓库偏差相关可点名 `Gkit-Bias`。  
**类比：** 两把尺零刻度差一厘米，量所有人身高都「高一厘米」——不是全城突然长高。

#### 骗子 3：低仰角多路径 ≈ 「快变扰动 / 小 TID」

**长相：** 仰角低时 STEC 来回扭；高仰角段却老实。  
**像什么物理：** 像短周期行进式扰动。  
**为何常是假的：** 地面反射随方位/仰角变，几何无关后仍可残留。  
**怎么拆穿：**  
1. 给曲线着色：按仰角染色，看「热闹」是否集中在低仰角。  
2. 提高截止角重跑，热闹是否大减。  
3. 多路径严重站（水面、玻璃幕墙）要降权。  
**类比：** 对着穿衣镜量身高，镜子晃，不是你在跳健身操。

#### 骗子 4：平滑参数过猛 ≈ 「风暴被抹平」或「假缓变」

**长相：** 真的快速变化被拖成慢坡；或周跳台阶被抹成「斜坡式增强」。  
**像什么物理：** 像缓慢的正暴发展。  
**怎么拆穿：** 对比平滑前后；按弧段检查；做参数敏感性（窗口加倍/减半）。  
**纪律：** 平滑是降噪，不是创作物理。

#### 骗子 5：时间/星历错位 ≈ 「相位超前的漂亮相关」

**长相：** 你的「扰动」比官方指数或 GIM 固定偏移一整段时间。  
**像什么物理：** 像前兆或延迟响应（有时真有物理延迟，但先查钟）。  
**怎么拆穿：** 统一时间系统（GPS 时 / UTC）；检查文件名年积日；确认插值到同一历元。  
**类比：** 把昨天的新闻标题贴到今天照片上，故事很惊人，但是假的。

#### 骗子 6：单频/错频率组合 ≈ 「幅度夸张的极端事件」

**长相：** TEC 动辄上百 TECU 的「超级暴」，或出现大面积负 TEC。  
**怎么拆穿：** 回看频率对、符号、米↔TECU 因子；与 `CDDIS-IONEX` 同日产品比数量级。  
**纪律：** 数量级先比像不像地球，再比像不像文献。

### 8.3 宣称风暴效应之前的 QC 检查表（请打印）

把下表当作通行证。**全部勾选前，结论句只能用「疑似 / 待证」。**

#### A. 数据身份

- [ ] 已确认双频（或多频）观测类型存在（可用 `georinex` / `rinex` / `PyRINEX` 列出）  
- [ ] 已写明频率对与系统（GPS/BDS/Galileo…）  
- [ ] 文件日期、测站名、接收机/天线变更已记录  

#### B. 跟踪与弧段

- [ ] 已做或说明周跳探测/修复策略（`cycle-slip-correction`、`DRCycleSlip` 等）  
- [ ] 平滑仅在弧段内进行；跨弧段未硬接  
- [ ] 低仰角段已单独标记或截断  

#### C. 偏差与单位

- [ ] 卫星 DCB/OSB 产品名称与观测类型对齐  
- [ ] 接收机偏差处理策略已声明（估计 / 标定 / 未处理）  
- [ ] 输出单位确认为 TECU；排除 0.1 倍/10 倍事故  

#### D. 质量统计

- [ ] 已用 `TEQC` 或 `Anubis` 等看完好率/周跳/多路径概况（以工具文档为准）  
- [ ] 当天跟踪极差的站已降权或淘汰  

#### E. 一致性（打假核心）

- [ ] **多星：** 至少若干高仰角卫星讲述相近的时间演变（允许幅度差）  
- [ ] **多站（若有）：** 邻近站同向，而非只有一站「孤岛爆发」  
- [ ] **多产品：** 与至少一家 GIM（如 `CDDIS-IONEX` 中某 AC）在映射后的 VTEC 上对比，差异可解释  
- [ ] **指数门：** 扰动时间与 Kp/Dst/OMNI 等指数窗口可对照（入口如 `GFZ-Kp-Index`、`NASA-OMNIWeb`）  

#### F. 表述门

- [ ] 论文/报告句子区分 STEC 与 VTEC  
- [ ] 已写软件 `PROJECTS.json` 名称与版本（如 `gnss-tec`、`Seemala-GPS-TEC`、`pygnss-tec`、`tec-suite`）  
- [ ] 未把 ROT/ROTI 或闪烁自动等同为本课 STEC 曲线（见 `05-scintillation-roti.md`；相关工具如 `Okoh-MATLAB-ROT-ROTI`）  

### 8.4 「真风暴」与「假台阶」对照口诀

| 观察 | 更像真现象 | 更像假现象 |
|---|---|---|
| 空间 | 多站、多星同向演变 | 单星或单站独舞 |
| 时间 | 与指数主相/恢复相可对齐 | 与文件边界/失锁时刻对齐 |
| 形状 | 平滑抬升/下降可持续数十分钟以上 | 一秒台阶后新平台 |
| 仰角 | 高仰角仍见同类演变 | 热闹集中在低仰角 |
| 偏差 | 改正 DCB 后故事仍在 | 一改 DCB 故事消失（变成纯平移） |
| 产品 | 与 GIM 差值同区域同符号 | 与多家 GIM 全面打架且自建独红 |

### 8.5 课堂演练：十分钟打假对话

学生：我看到磁暴那天 STEC 跳了 12 TECU！  
老师：几颗星一起跳？  
学生：……一颗。  
老师：伪距几何无关也跳吗？  
学生：伪距没有，相位有。  
老师：先当周跳。修完弧段再来谈风暴。  
学生：修好后还高 8 TECU，但是全天都高。  
老师：查 DCB 与类型对齐。  
学生：对齐后只剩 2～3 TECU，而且和 GIM 差值同向。  
老师：现在才可以写「与风暴窗口一致的中等增强，幅度约数 TECU，已排除周跳与偏差平移」。

把这段对话背下来，比背公式更能拯救你的组会。

### 8.6 本节新增检查题

**题 A.** 为何「整条曲线相对 GIM 高 8 TECU、形状却很像」优先查 DCB？  
**答：** 偏差常造成整体平移，像雾厚被抬高一截，但日变化形状仍可相似。

**题 B.** 相位几何无关出现台阶、伪距无台阶，优先怀疑什么？  
**答：** 周跳或弧段断裂。

**题 C.** 列出宣称风暴效应前，一致性检验的三项。  
**答：** 多星、多站（若有）、多产品；并尽量与地磁/太阳指数窗口对照。

**题 D.** 举出两个周跳相关、一个质量检查、一个 TEC 估计的 `PROJECTS.json` name。  
**答示例：** `cycle-slip-correction`、`DRCycleSlip`；`TEQC`；`gnss-tec`。

**题 E.** 低仰角段「很热闹」时，你的第一动作是什么？  
**答：** 按仰角染色/提高截止角，区分多路径假抖动与真扰动。

### 8.8 本节朗读稿

双频给了你看见电子柱的眼镜，但眼镜上可能有灰尘。周跳是裂缝，DCB 是度数不准，多路径是旁边有人晃镜子，平滑是擦镜布用过了头。现象分析要求你先擦眼镜、再看风暴。把 QC 检查表当成登机安检：安检不过，故事不得起飞。
