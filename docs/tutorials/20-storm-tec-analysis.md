值班群里常见吵架：

- 甲：「低纬日侧 TEC 明显增强，正相风暴！」  
- 乙：「中纬夜侧 TEC 掉了一大截，负相风暴！」

两人可以**同时正确**。电离层暴不是全球同号旋钮，而是多条因果链在不同纬度、地方时（LT）、暴相上叠加：

| 维度 | 必须填的格子 |
|---|---|
| 符号 | 正相（增强）还是负相（耗空） |
| 哪里 | 磁纬带、经度扇区、日/夜侧 |
| 何时 | 相对 SYM-H 谷值：初相/主相/恢复相 |
| 哪条链 | PPEF？扰动发电机？成分鼓包？风场抬升/下压？ |
| 证据 | 哪家 GIM、何种对照、有无 foF2 / O/N₂ 旁证 |

### 1.1 厨房类比：台风天的整栋楼

- **正相**：某些楼层/朝向，雾被吹浓（电子柱增厚）——常见链：日侧东向穿透电场加强喷泉、或中性风抬升 F 层到复合更慢的高度。  
- **负相**：另一些区域，富分子空气被抬到 F 层，复合加快，雾变稀——中纬「成分鼓包」经典图像。  
- **你的工作**：不要争论「台风让雾变浓还是变稀」；去问**哪一层、哪个朝向、哪个钟点、哪条管道在起作用**。

## 3. 物理原则深讲：三条主因果链（本课新增核心）

把磁暴电离层响应记成三条可独立检验的链。真实事件往往**同时**跑多条，所以地图上正负分区。

### 3.1 链 A — 穿透电场 PPEF（主相、偏快速、日侧低纬常正）

**直觉**：高纬磁层对流电场在区电流「屏蔽」来不及建好时，会穿透到中低纬。对日侧赤道附近，穿透电场常表现为**东向**，加强正常的 **E×B 上涌**（喷泉），把等离子体抬到更高、复合更慢的高度，并沿磁力线输送到 ±15°～±20° 磁纬 → **EIA 峰加强或极向扩展** → 柱含量 **TEC 正相**。

因果链（请背成口诀「风–穿–东–喷–峰–正」）：

1. IMF Bz 南向持续 → 磁层对流增强，高纬电场变强；  
2. 区电流屏蔽滞后（欠屏蔽）→ 部分电场穿透到低纬；  
3. 日侧低纬出现（或加强）东向电场；  
4. E×B 上涌增强 → F 层抬升、喷泉加强；  
5. 双峰 TEC 增加或峰极移 → **日侧低纬/低中纬正相签名**。

**时间指纹**：常在主相附近、相对 SYM-H 变化较「跟得上」（仍受 GIM 分辨率限制）。  
**空间指纹**：优先看日侧、低纬到低中纬；夜侧同机制下电场方向/效应不同，勿照搬。  
**观测配对**：ΔVTEC 日侧正斑块 +（加分）测高仪峰高上升 / 掩星峰抬升。

**课堂警告**：PPEF 是「机制候选」，不是差分图上的自动标签。没有日侧低纬快速正结构，就不要硬贴 PPEF。

### 3.2 链 B — 扰动发电机 DDEF（延迟、可反号、拖到恢复相）

**直觉**：暴时焦耳加热与动量强迫改变全球中性风；风场再驱动低纬「发电机」电场，得到 **扰动发电机电场（DDEF）**。它往往比 PPEF **晚几小时甚至更久**，极性上常与穿透电场的「即时效应」不同，可造成低纬电场减弱、喷泉抑制，或夜侧复杂重组。

因果链（口诀「热–风–电–拖–变号」）：

1. 高纬能量注入 → 热层加热、风场重构；  
2. 改变的中性风在低纬切割磁力线 → 扰动发电机；  
3. 低纬电场相对安静日发生系统性偏移（常讨论西向分量增强等图像）；  
4. 喷泉与 EIA 被压制或改形；  
5. TEC 出现**延迟的**增强/减弱——必须对照「主相之后仍在发展」的时间窗。

**时间指纹**：相对 SYM-H 谷值明显滞后；恢复相仍显著。  
**与 PPEF 对比表**：

| | PPEF | DDEF |
|---|---|---|
| 相对主相 | 偏快、近同步 | 偏慢、延迟 |
| 驱动图像 | 磁层电场穿透 | 热层风→发电机 |
| 教学期望 | 日侧低纬快速正相 | 持续/反号/恢复相变化 |
| 你怎么写 | 「主相附近日侧正斑块，疑穿透」 | 「谷值后数小时仍演变，疑扰动发电机」 |

### 3.3 链 C — 中性成分鼓包 O/N₂（中纬负相的化学心脏）

**直觉**：暴时高纬加热驱动风暴环流，把**分子丰度更高**的空气输送到中纬 F 层高度。F 区电子主要通过与 N₂、O₂ 相关的复合过程损失；O/N₂ 下降 → 有效复合加快 → NmF2/TEC **负相**。这不是「电子被风吹走」的简单图像，而是**化学损失率被成分改变**。

因果链（口诀「热–环流–富分子–O/N₂↓–复合↑–负」）：

1. 极区/高纬焦耳与粒子加热；  
2. 风暴环流与上升运动改变中性成分垂直与水平分布；  
3. 「成分鼓包」抵达中纬 F 区 → O/N₂ 降低；  
4. 复合加快，峰密度下降；  
5. 柱含量下降 → **中纬宽带负 ΔVTEC**；foF2 常同步下降。

**时间指纹**：主相至恢复相都可显著；负相常「拖得比正相久」。  
**空间指纹**：中纬宽带；日夜都可出现，但幅度与 LT、季节强烈相关（季节–UT 效应）。  
**旁证**：foF2↓（`GIRO-DIDBase`）；若有热层 O/N₂ 遥感产品可作机制旁证（教学加分，非作业必需）。

### 3.4 正相 vs 负相：按纬度 × 地方时的「期望草图」（非定律）

把下面当**优先搜索方向**，必须用你的差分图验证：

| 区域 / LT | 更常见倾向 | 优先联想的链 |
|---|---|---|
| 低纬日侧，主相附近 | 正相、EIA 加强/极移 | PPEF → 喷泉 |
| 低纬，主相后数小时 | 可变号或持续变形 | DDEF |
| 中纬，主相～恢复相 | 负相宽带 | 成分鼓包 O/N₂ |
| 中纬，若风场抬升占优 | 局部正相可能 | 风抬升 vs 成分竞争 |
| 高纬 / 极光带 | 耗空、补丁、沉降并存 | 勿用单一符号 |
| 夜侧 vs 日侧 | 符号与幅度常不同 | **必须按 LT 切片** |

**竞争原则**：同一地点，抬升（减少复合）与富分子（增加复合）可打架；谁赢看高度、成分、风场谁占上风——所以「全球平均 TEC」毫无意义。

### 3.5 与喷泉/EIA 的接口（预习 21 课）

PPEF 加强东向电场 → 喷泉↑ → EIA 峰↑ 或峰极移，这是**正相在低纬的几何形态**。分析时不要把「双峰气候」本身叫成风暴；要看**相对对照的 ΔVTEC 与峰位移**。

## 5. GIM 差分：观测主兵器

$$
\Delta\mathrm{VTEC}(\phi,\lambda,t)=\mathrm{VTEC}_\mathrm{storm}-\mathrm{VTEC}_\mathrm{ref}(t_\mathrm{match})
$$

`t_match`：同 UT **或** 同 LT，二选一写进笔记。

- 主 AC：`CDDIS-IONEX` 贯穿始终；交叉 `JPL-IONEX-Rapid`、`ROB-IONEX-Products`、`GFZ-Global-Ionosphere-Maps`、`WHU-IGS-Ionosphere-AC`、`UPC-IONEX-Archive`、`NOAA-SWPC-GloTEC`、`DLR-IMPC-Products`、`ESA-TIO-NRT-TEC`。  
- 读写：`ionex`、`ionex-rs`、`ionex_reader`、`ionex-analyzer`、`ionex-downloader`；差分 `DiffIonMap`；验证意识 `UWM-CDRSK-IGS-Validation`。  
- 色标对称、单位 TECU；海洋/高纬覆盖差处降低措辞。

读图口令：正相候选 = 同策略对照下大范围正 ΔVTEC 且旁证不反向；负相候选 = 中纬宽带负且 ideally foF2↓；混合 = **允许**，写成分区响应。

## 7. 九步分析剧本（交作业标准流程）

### 步骤 1 — 事件钉钉
输入候选日与 SWPC 提示；输出 UTC 起止、暴类型、研究区。

### 步骤 2 — 拉指数
`GFZ-Kp-Index`、`NASA-OMNIWeb`；标 SYM-H 谷值。

### 步骤 3 — 选对照
方案 Q（邻近日）或 R（~27 d）；记录对照日 Kp 证明更安静；禁跨季节硬比。

### 步骤 4 — 下载 GIM
暴日+对照，**同一 AC**（`CDDIS-IONEX` 等）。

### 步骤 5 — 单日形态
`ionex_reader`/`ionex-analyzer` 浏览 VTEC；观察 EIA 与高低纬。

### 步骤 6 — 差分
ΔVTEC；`DiffIonMap` 或自写减格网；执行 §8 十二注视点。

### 步骤 7 — 时间对齐
区域平均 VTEC vs SYM-H；讨论是否「主相快速」像 PPEF、「延迟」像 DDEF（措辞保持候选级）。

### 步骤 8 — 多源旁证
另一家 GIM；`GIRO-DIDBase` foF2；可选 `igs-roti`/`IonoMoni`。冲突则降置信度。

### 步骤 9 — 半页结论
分区正/负/混合；列出启用的机制候选与**未证实**处；所有软件名须在 `PROJECTS.json`。

**加分**：`Seemala-GPS-TEC`/`tec-suite`/`IONOLAB-TEC-Software` 高采样检查 GIM 是否抹平短时峰；磁纬思维用 `apexpy`。

## 9. 工作示例脚本（教学用骨架）

下面示范「读 IONEX → 差分 → 区域平均 vs 指数」的思路。路径与变量名按你本地文件改；**不要**把示例数字抄进报告冒充观测。

```python
# storm_tec_delta_demo.py  — 课堂骨架，非标准库封装
# 建议配合: ionex / ionex_reader / ionex-analyzer；指数来自 NASA-OMNIWeb
import numpy as np

def load_vtec_grid(path):
    """返回 lat, lon, vtec[nt,nlat,nlon]；实际用 ionex 类库解析 IONEX。"""
    raise NotImplementedError("用 ionex 或 ionex_reader 填充")

def match_time_index(times, t_target):
    return int(np.argmin(np.abs(times - t_target)))

def delta_vtec(storm, ref):
    return storm - ref  # 同格网、同匹配策略

def regional_mean(vtec, lats, lons, lat_rng, lon_rng):
    m = ((lats >= lat_rng[0]) & (lats <= lat_rng[1]))
    # 对 lon 掩膜后对空间平均；注意经度跨 180° 时分段
    return np.nanmean(vtec[:, m, :], axis=(1, 2))

# 流程口述:
# 1) storm = load(CDDIS-IONEX 暴日); ref = load(同 AC 对照日)
# 2) 选同 UT 帧: d = delta_vtec(storm[k], ref[k])
# 3) 画 d；再 regional_mean 与 SYM-H 同轴
# 4) 日侧低纬窗 / 中纬窗 分开算，禁止只报全球平均
```

质检口令：同一 AC？匹配策略声明了吗？正负分区是否分开叙述？

## 10. 常见错误

1. 无对照谈正负  
2. 全球平均掩盖分区  
3. 混用分析中心做差分  
4. 把两家 GIM 差当物理  
5. 只有机制形容词、无差分图  
6. 把 PPEF/DDEF 当已证实标签  
7. 只看主相忽略恢复相  
8. 用 `iri2020` 当日输出当对照  
9. ROTI 高就说正相  
10. 夜侧泡耗空一律算风暴负相（先看 21 课 LT/ROTI）

## 12. 测验

**Q1.** 为何「TEC=50 TECU」不能单独叫正相？

## 17. 因果链板书课（45 分钟可讲完的「原则课」）

本节把 §3 三条链展开到「黑板可画」的粒度。初学者不需要会写磁层 MHD，但必须能指着箭头说人话。

### 17.1 总闸门：能量从哪里进门？

太阳风携带南向 IMF Bz 时，磁层顶部重联效率升高，对流电场增强，高纬电离层被「抽打」。热层被焦耳加热，风场改道。于是电离层同时接到两张账单：

1. **电场账单**（快通道）：对流电场 →（可能）穿透到中低纬 → 立刻改 E×B 漂移；  
2. **中性大气账单**（慢通道）：加热 → 风与成分重构 → 发电机电场与化学损失率随后变。

正相/负相的「分区」本质上是：不同纬度接到的账单比例不同。

### 17.2 PPEF 细讲：欠屏蔽为什么会发生？

把区电流想成「自动门禁」：高纬电场一增强，区电流系统会试图把电场屏蔽在高纬。但电流系统建立需要时间。主相急遽增强时，门禁来不及关上，电场「漏」到低纬——这就是教学上说的**欠屏蔽穿透**。

日侧低纬漏进来的东向电场，叠加在安静日的赤道电场上，使上涌加强。等离子体被抬到复合更弱的高度，沿磁力线向磁纬 ±10°～±20°「滑下去」，双峰变高或峰极移。柱积分 TEC 因此在日侧低纬抬头。

**过屏蔽**则相反：有时区电流「关过头」，低纬电场短暂反向，可能抑制喷泉——这能解释为何同一次暴里低纬并非单调正相。分析报告若只截主相一帧，会漏掉反号窗口。

### 17.3 为什么夜侧不能照搬「东向→正相」？

地方时决定背景电场、密度梯度与复合环境。夜侧 F 层本就在复合占优的状态，穿透电场的方向与几何投射也不同于日侧。课堂纪律：**凡写 PPEF，必须同时写 LT 扇区**；夜侧结论单独成段。

### 17.4 DDEF 细讲：风如何变成「反电动势」？

低纬发电机图像：中性风拖着等离子体（或相对切割磁力线）产生电流与极化电场。暴时高纬加热驱动的全球风系改变后，低纬风场不再是安静日的潮汐主导图像，于是发电机输出变了——这就是扰动发电机。

关键教学点：

- **延迟**：风场与热层调整需要时间，故 DDEF 指纹常在 SYM-H 谷值之后；  
- **持续**：恢复相地磁已回升，电离层仍可「记得」风场；  
- **可与 PPEF 反号**：同一经度扇区，早时段正、晚时段负并不矛盾。

### 17.5 成分鼓包细讲：O/N₂ 不是「浓度装饰」，是损失率旋钮

F 区电子损失的有效速率强烈依赖分子中性成分。原子氧 O 参与离子化学的「生产与转换」路径，而 N₂、O₂ 丰度升高往往加快复合相关损失。暴时环流把分子丰度较高的空气送到中纬 F 区高度，O/N₂ 下降，于是：

$$
\mathrm{O/N_2}\downarrow \;\Rightarrow\; \text{有效复合}\uparrow \;\Rightarrow\; N_e\mathrm{(F2)}\downarrow \;\Rightarrow\; \mathrm{TEC}\downarrow
$$

这与「整层被风水平吹走」的卡通不同：即使柱的「几何」还在，**化学寿命**变短也会造成负相。foF2 对峰附近化学更敏感，所以负相有时在测高仪上比在 TEC 上更「干净」——TEC 还含顶部贡献。

### 17.6 风场抬升正相：与成分负相的「拔河」

中纬有时出现正相：风暴中性风把等离子体沿磁力线抬升到更高高度，复合变慢，NmF2 暂升。若同时成分鼓包抵达，两者拔河。结果依赖时刻与纬度。这就是为何中纬不能先验写死「一定负相」，但**统计与经典图像**仍以负相为优先搜索。

### 17.7 季节–UT 不对称：为何同强度暴响应不同？

地磁轴倾斜与太阳日照几何耦合，使同样 Dst 谷值落在不同 UT 时，磁纬与地理纬的日照组合不同，高纬加热与成分输送的路径也不同。分析含义：对照日必须季节相近；跨季节「安静日」可能引入假差分。

## 26. 工作示例：区域平均与「像 PPEF / 像 DDEF」的粗判伪代码

```python
# align_symh_tec.py — 教学示意
# 指数: NASA-OMNIWeb / pysatSpaceWeather；TEC: 自 GIM 区域平均或 Seemala-GPS-TEC

def classify_timing(t_tec_peak, t_symh_min, hours_fast=3.0):
    """粗判时间指纹：快→偏 PPEF 候选；慢→偏 DDEF/成分持续候选。"""
    dt_h = (t_tec_peak - t_symh_min).total_seconds() / 3600.0
    if abs(dt_h) <= hours_fast and dt_h >= -1:
        return "near-main-phase (PPEF-candidate if dayside low-lat positive)"
    if dt_h > hours_fast:
        return "delayed (DDEF/composition-candidate)"
    return "tec-leads-or-unclear (check sampling / wrong region)"

def split_by_lt(vtec_series, lt_hours, day=(10, 18), night=(20, 4)):
    """按地方时掩膜；夜侧跨午夜要特殊处理。"""
    day_mask = (lt_hours >= day[0]) & (lt_hours < day[1])
    # night_mask 略...
    return day_mask
```

使用纪律：返回值是**候选标签字符串**，不是物理证明。GIM 2 h 采样时 `hours_fast=3` 本身很粗糙——在结论里写明。

## 32. 机制补丁：三条链的「谁先谁后」决策口诀

主相附近日侧低纬正且跟得上 SYM-H → 先写 PPEF 候选。  
谷值后数小时低纬仍大变或反号 → 加上 DDEF 候选。  
中纬宽带负且 foF2↓ → O/N₂ 成分鼓包候选优先于「电子被吹走」卡通。  
三者可并存：按纬度×LT×相位填表，禁止强迫全球单标签。
