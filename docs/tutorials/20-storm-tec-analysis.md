> **课堂定位**：现象专题第 2 课。前置：[19](./19-phenomena-overview.md)、[03](./03-gim-ionex.md)、[14](./14-space-weather-case.md)。

值班群常见吵架：甲看日侧低纬增强喊正相，乙看中纬夜侧掉了喊负相——**两人可以同时正确**。电离层暴不是全球同号旋钮。

| 必须填的格子 | 内容 |
|---|---|
| 符号 | 正相（增强）还是负相（耗空） |
| 哪里 | 磁纬带、经度扇区、日/夜侧 |
| 何时 | 相对 SYM-H 谷：初相/主相/恢复相 |

**厨房类比**：正相＝某些朝向雾被吹浓；负相＝富分子空气抬到 F 层复合加快雾变稀。别争「台风让雾变浓还是稀」，去问哪一层、哪个钟点、哪条管道。

## 3. 三条主因果链

真实事件常**同时**跑多条，故地图上正负分区。

### 链 A — PPEF（主相、偏快、日侧低纬常正）

![穿透电场示意](./images/fig-penetrating-efield.png)

> 图源：自制示意。高纬对流电场在欠屏蔽时穿透到低纬——PPEF 的课堂图像，非实测矢量场。


口诀「风–穿–东–喷–峰–正」：

1. IMF Bz 南向 → 高纬对流电场增强；  
2. 区电流屏蔽滞后 → 电场穿透低纬；  
3. 日侧东向电场加强；  
4. E×B 上涌 / 喷泉加强；  
5. EIA 峰加强或极移 → **日侧低纬正相**。

时间偏跟主相；空间优先日侧低纬。无快速日侧正结构就不要硬贴 PPEF。

### 链 B — DDEF（延迟、可反号、拖恢复相）

口诀「热–风–电–拖–变号」：高纬加热改风 → 扰动发电机 → 低纬电场相对安静日偏移 → 喷泉改形 → TEC **滞后**演变。相对 SYM-H 谷值明显偏慢。

| | PPEF | DDEF |
|---|---|---|
| 相对主相 | 偏快 | 偏慢 |
| 驱动 | 磁层电场穿透 | 热层风→发电机 |
| 写法 | 「主相附近日侧正斑块，疑穿透」 | 「谷值后数小时仍演变，疑扰动发电机」 |

### 链 C — 成分鼓包（中纬负相化学心脏）

口诀「热–环流–富分子–O/N₂↓–复合↑–负」：不是「电子被风吹走」，而是**化学损失率被成分改变**。旁证：foF2/NmF2 降、O/N₂ 图（若有）。

![PPEF 加强日侧双峰 vs 安静对照（日夜剖面复用）](./images/fig-tec-day-night.png)

> 图源：自制示意。暴时日侧双峰可被 PPEF「拉高/极移」；勿把气候双峰本身当成正相证据——必须做差分。

## 4. 指数时间线 + GIM 差分

1. 用 `GFZ-Kp-Index`、`NASA-OMNIWeb` 钉：扰动开始、SYM-H 谷、恢复。  
2. 选对照（Q/R/C），写局限。  
3. `CDDIS-IONEX`（或 `JPL-IONEX-Rapid` 等）取**同一 AC** 暴日与对照。  
4. `ionex` / `ionex_reader` / `DiffIonMap` 做 ΔVTEC 地图 + 区域平均时间序列与 SYM-H 同轴。

**机制→观测对照卡**：

| 候选链 | 期望签名 |
|---|---|
| PPEF | 主相附近日侧低纬正 ΔVTEC；可伴峰抬升 |
| DDEF | 谷值后仍演变；可与主相即时效应反号 |
| 成分鼓包 | 中纬持续负相；foF2 降更贴切 |

## 5. 九步剧本（交作业标准）

1. 事件 UTC 与研究区。  
2. Kp 峰值档、SYM-H 谷值与时刻（来源）。  
3. 对照方案 + 一句理由。  
4. 下载的 IONEX `name` 与 AC。  
5. 同 UT（或同 LT 切片）安静 / 暴日 / 差分三图。  
6. 读色标：哪带正、哪带负、约多少 TECU。  
7. 相对谷值的先后。  
8. 旁证：foF2（`GIRO-DIDBase`）/ 掩星 / 第二家 GIM。  
9. 结论：更像哪条链、置信度、主要怀疑。

**读差分图注视点（精简）**：日夜侧是否反号？低纬正斑是否贴赤道？中纬负是否成片？是否只在海洋空洞区「热闹」（假象）？是否与季节–UT 预期冲突？

## 6. 边界、错误、工具

| 别和…搞混 | 分流 |
|---|---|
| 赤道泡 / 高 ROTI | 21 课；暴可调制泡，但 ROTI 羽≠正相斑块 |
| TID 波列 | 22 课；先去趋势多站延迟 |
| 耀斑分钟跳 | 23 课；对齐 GOES 而非 SYM-H |

**常见错误**：全球平均当正相；混用不同 AC 却不声明；无对照就贴 PPEF；把恢复相延迟全叫穿透。

**工具**：`CDDIS-IONEX`、`DiffIonMap`、`ionex-analyzer`、`GFZ-Kp-Index`、`NASA-OMNIWeb`、`NOAA-SWPC`、`GIRO-DIDBase`、`geospacelab`、`pysatSpaceWeather`。
