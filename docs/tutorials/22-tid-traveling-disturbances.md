# 22 · 行进式电离层扰动 TID / MSTID：波状 TEC 残差怎么分析

> **课堂定位**：现象分析专题第 4 课。前置：[19](./19-phenomena-overview.md)、[02](./02-gnss-dualfreq-tec.md)（懂 STEC 时间序列）、[20](./20-storm-tec-analysis.md)、[21](./21-equatorial-anomaly-bubbles.md)（会区分大尺度暴与低纬泡）。  
> **学完应能**：解释 TID/MSTID 在 GNSS 网络里「长什么样」；建立周期/波长的数量级直觉；按步骤从时间序列检测波列；明确与磁暴 TEC、闪烁/泡的边界。  
> **本课重点是检测与描述**，不是推导重力波色散关系全文。

---

## 1. 开场：水面涟漪 vs 整湖抬升 vs 锅里炸油花

继续用「雾/水面」类比，把三种容易混淆的东西钉死：

| 图像 | 电离层对应 | 你看什么 |
|---|---|---|
| 整湖水位涨落 | 风暴大尺度 TEC 正负相（20 课） | GIM 差分、SYM-H |
| 水面一行行涟漪传过 | **TID / MSTID**（本课） | 去趋势 TEC 残差的波状结构 |
| 锅里炸油花乱溅 | 闪烁 / 泡壁不规则（05/21） | S4、ROTI 高频抖 |

TID 的关键词是 **行进（traveling）**：扰动像波一样在水平方向传播，网络里不同站点会依次「点头」。

### 1.1 为什么初学者几乎「看不见」TID？

因为他们常看的是：

- 未去趋势的原始 VTEC（日变化把小波淹死）；  
- 时间分辨率很粗的全球 GIM（空间平滑把中尺度抹平）；  
- 单站却不看邻站相位差（无法证明「行进」）。  

本课训练：**去趋势 → 多站 → 估计周期/传播方向直觉 → 排除暴与闪烁假标签**。

## 3. 数量级直觉（先建立「尺子」，再谈检测）

老师在黑板写三把尺子（记数量级，不记死数字当定律）：

1. **时间**：MSTID 周期常见从十几分钟到约一小时量级；LSTID 往往更长。  
2. **空间**：中尺度水平波长常与「城际～省际」可比（相对全球 GIM 格点而言更细）。  
3. **振幅**：去趋势后 TEC 波动常是几个 TECU 或更小量级——所以被日变化盖住毫不奇怪。  

类比：你要观察湖面涟漪，必须先「滤掉潮汐」；潮汐是日变化，涟漪是 TID。

## 4. 日间 vs 夜间中纬：课堂级分工

| | 日间中纬 | 夜间中纬 |
|---|---|---|
| 常见图像 | 重力波调制电子密度 | 电动力学不稳定/耦合等讨论更多 |
| TEC 残差 | 波列可见 | 波列可见，形态统计或不同 |
| 与 Es/E–F 耦合 | 可能相关话题 | 文献常讨论 |
| 你的作业要求 | 写清 LT=白天 | 写清 LT=夜间，勿混统计 |

**纪律**：机制争辩留给讨论课；本课交观测描述：周期粗估、传播方向粗估、振幅粗估、置信度。

## 5. 在 GNSS 网络时间序列里如何检测（核心技能）

### 5.1 单站预备

1. 从 RINEX 估 STEC/VTEC：`Seemala-GPS-TEC`、`Okoh-MATLAB-TEC-from-RINEX`、`tec-suite`、`gnss-tec`、`IONOLAB-TEC-Software`、`pygnss-tec`、`mitiono`。  
2. 处理周跳；坏弧段剔除。  
3. 映射到 IPP，便于多站按空间排序。`Get_IPP` 可作穿刺点几何辅助。  

### 5.2 去趋势（TID 能否被看见的生死线）

常用思路（概念级）：

- 滑动平均 / 多项式 / 带通，去掉 >2–3 小时的慢变；  
- 或减去「当日拟合日变化」或安静日同 LT。  

输出叫 **TEC 残差 δTEC**。没有 δTEC，就没有本课。

### 5.3 多站「点头」检验——证明 traveling

1. 选一条大致垂直于疑似波峰的站链（南北链或东西链）。  
2. 把各站 δTEC 画在同一张时间图，或做 keogram（纵轴纬度/经度，横轴时间，颜色为 δTEC）。  
3. 若看到**倾斜条纹**，说明结构在迁移 → 支持 TID。  
4. 若所有站同时上下（零延迟），更像大尺度同步变化（暴、耀斑、仪器钟问题等），要小心贴 TID 标签。  

### 5.4 周期与波长的「穷人算法」（教学用）

- **周期**：单站 δTEC 看相邻峰谷时间差，或做简单频谱/小波（有工具更好）。  
- **波长**：两站峰到达时差 Δt 与站距 D、方位假设下估；不准也要写清楚假设。  
- **方向**：哪一侧站先到峰。  

`IRI_TID`、`tidd` 若提供专用流程，以其 README 为准；没有也可用上述手工法交「分析课」作业。

### 5.5 与 ROTI/闪烁的关系

- TID 是相对光滑的波状 δTEC，ROTI 可不显著；  
- 若 ROTI/S4 很高，可能叠加了不规则，或你其实在看泡/暴时湍流——标签分开写。  

工具：`IonoMoni`、`OASIS`、`Okoh-MATLAB-ROT-ROTI`。

## 7. TID vs 风暴 vs 闪烁/泡 —— 对照表（考试爱考）

| 判据 | TID/MSTID | 风暴 TEC | 泡/闪烁 |
|---|---|---|---|
| 地磁 | 可安静（夜间 MSTID 亦然）；LSTID 可伴暴 | SYM-H 显著 | 低纬夜侧为主，暴可调制 |
| 形态 | 波状 δTEC、多站延迟 | 大尺度 ΔVTEC 斑块 | 耗空通道 + 高 ROTI/S4 |
| 空间尺度 | 中/大尺度波 | 区域～全球 | 低纬沿磁力线 |
| GIM | 常看不见 MSTID | 主战场 | 细丝常看不见 |
| 分析主数据 | 密集网 δTEC | GIM 差分 | TEC+ROTI+S4 |

## 8. 常见误解

1. **原始 TEC 曲线有一点弯就是 TID** — 无去趋势、无多站，证据不足。  
2. **全球 IONEX 小波纹 = MSTID** — 多半是产品假象或大尺度。  
3. **有波就有闪烁** — 不必。  
4. **夜间中纬波一定是重力波** — 机制勿武断。  
5. **单站频谱峰 = 证明传播** — 频谱给周期线索，传播要空间延迟。  
6. **把耀斑齐涨当 TID** — 耀斑近乎日侧同步（见 23 课）。  
7. **DCB 日变当成波列** — 检查是否所有卫星/系统同样慢漂。

## 13. 加厚：老师追问清单

- 你的去趋势窗会不会把真实长周期 LSTID 滤掉？  
- 站距是否远小于你声称的波长（采样不足）？  
- 所有卫星方位的 IPP 是否混在同一「站」曲线里造成假波？  
- 是否只在一颗卫星上看到「波」，其实是卫星几何扫描造成？  

对最后一点：IPP 移动会把空间结构扫成时间波动——这是 GNSS TID 分析经典陷阱。缓解：多站一致性、限制 IPP 区域、或短弧分段。

## 14. 加厚：IPP 扫描假波 — 五分钟思想实验

假设天空有一条南北向的静止 TEC 脊。一颗卫星的 IPP 从南扫到北，单站 TEC 也会出现「先低后高再低」。看起来像波，其实是**你在动，结构未必在传**。  
所以「traveling」证据必须来自**不同地理位置的接收机**在相近 IPP 区域的时间延迟，而不是单 IPP 轨迹的起伏。把这点写进笔记，可避免期末最大冤案。

## 15. 加厚：与 19 课签名框架的映射

1. 形态：δTEC 波列 / keogram 斜纹  
2. 时间：周期十几分钟～约小时；可持续数小时  
3. 空间：中纬常见；水平波长中尺度

## 19. 超详细操作剧本：从零到「可答辩的 TID 段落」（分镜）

### 分镜 A（准备日，30–60 min）

打开 `PROJECTS.json`，确认你要克隆或引用的名字存在。建议最小集：

- 数据处理：`Seemala-GPS-TEC` 或 `tec-suite` 或 `gnss-tec` 或 `IONOLAB-TEC-Software`  
- 质量/不规则：`IonoMoni` 或 `OASIS`  
- 指数：`GFZ-Kp-Index`、`NASA-OMNIWeb`  
- 可选 TID：`IRI_TID`、`tidd`  
- 测高旁证：`GIRO-DIDBase`  

写一张「安装/下载状态表」：已装 / 仅浏览文档 / 改日再装。分析课允许「仅浏览文档 + 用手绘示意延迟」，但不得伪造跑通结果。

### 分镜 B（选日，20 min）

挑选标准：

1. 中纬陆地站较密的区域（你能指出至少 5 个公开站）。  
2. 地磁相对安静（避免 LSTID 与风暴故事缠死；若偏要暴时 LSTID，必须额外做 20 课差分）。  
3. 白天或夜间二选一，写死 LT 范围。  

把选日理由写成 5 行——以后的你会感谢现在的你。

### 分镜 C（出 TEC，60–120 min）

对每个站：

1. 输入 RINEX（来源可经 `CDDIS-GNSS-Archive` 等，见 data-access）。  
2. 跑通 TEC 曲线。  
3. 导出时间戳、VTEC、（最好）IPP 纬经度。  
4. 标记可疑弧段。  

失败处理：若软件卡关，降级方案是使用已发表的开放 TEC 序列（若许可）或课程提供的练习 CSV——**必须在报告声明数据不是自己从 RINEX 解算**。诚实降级优于假截图。

### 分镜 D（去趋势实验，45 min）

同一数据试两种窗（例如 1 h 与 2.5 h 滑动）。看：

- 窗太短：波被啃掉，振幅假小；  
- 窗太长：日变化残留，假周期。  

在报告里放「两窗对比」小图，老师会加分，因为这证明你懂方法敏感度——这正是现象分析，而不是按钮美学。

### 分镜 E（传播证据，45 min）

把站按纬度排序。画：

1. 叠置曲线（每站垂直偏移一点，便于看峰对齐）；  
2. 简单 keogram（不会编程就用电子表格着色，丑也可以）。  

用尺子量：峰从站 1 到站 5 的时间差。写出：

> 在约 XXX km 跨度上，峰延迟约 Y min，若假定沿站链传播，粗速度约 …（公式：v≈D/Δt）。若站链不沿传播方向，此速度只是视速度。  

「视速度」三字能让你的结论显得专业且诚实。

### 分镜 F（排除与收尾，30 min）

逐条回答：

- SYM-H 是否在讲另一个故事？  
- 是否低纬事件被你误拿到中纬课？  
- ROTI 平均如何？  
- IPP 扫描能否解释全部延迟？（若延迟随站的地理纬度系统性出现，而单站多卫星一致，说服力↑）  

然后粘贴 §12 模板填空。

## 20. 更多类比与课堂互动题

### 类比：人浪 vs 全体起立

体育场里：

- **全体起立** = 耀斑或大尺度同步 TEC 变化；  
- **人浪** = TID：你看到「波峰」从看台一侧传到另一侧；  
- **散乱跳跃** = 闪烁/不规则。  

互动：让一排同学做人浪，另一排同时起立；观察者只看「高度-时间」要能说出差别——这就是 keogram 训练。

### 类比：拍照曝光

GIM 两小时一帧像「超长曝光」：涟漪糊成一片。密集 GNSS 30 s 采样像「连拍」。用错相机，就会得出「今晚没有涟漪」的假阴性。

## 21. 误解续集与「论文阅读急救」

读 TID 论文时，作者常给：波长、周期、方位角、季节统计。你作为初学者急救问题：

1. 他们用的是 δTEC 还是原始 TEC？  
2. 站网间距是否支撑所称波长？  
3. 是否排除了磁暴日？  
4. 是否把光学 MSTID 与 TEC MSTID 默认同一物？（相关但需证据）  

把这四问贴在文献笔记开头，可避免「摘录数字却不会复现方法」。
