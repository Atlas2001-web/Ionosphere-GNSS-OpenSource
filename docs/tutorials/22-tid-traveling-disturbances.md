## 3. 物理原则深讲（一）：AGW 与电离层耦合直觉

### 3.1 什么是大气重力波（课堂级）？

对流层/对流层顶附近的天气过程、地形、急流等可激发大气波动。空气团在重力与浮力作用下振荡并传播，形成 **AGW**。波带着中性密度、温度、风场的扰动向上或斜向传播，可到达热层高度。

### 3.2 耦合链：中性波如何变成 TEC 波？

口诀「波–风/密–离子–柱–δTEC」：

1. AGW 抵达热层，带来中性风与中性密度的扰动；  
2. 通过碰撞，中性风拖曳离子（尤其在一定高度范围内效率高）；  
3. 离子/电子密度出现沿波相位的增减，并可被磁场约束成各向异性结构；  
4. GNSS 斜路径积分电子含量 → STEC/VTEC 出现波动；  
5. 去掉日变化慢变后，**δTEC 波列**可见。

因此：你在 GNSS 里看到的不是「无线电自己在抖成波」，而是**中性波动调制了等离子体柱**。

### 3.3 为何日间中纬常提 AGW？

日间 F 区有充足光电离背景，AGW 调制相对容易在 TEC 上留下几个 TECU 或更小的波动。夜间光电离弱，电动力学过程（如 Perkins 类图像、E–F 耦合等）讨论更多——机制争辩留给讨论课；作业仍以观测描述为主，但报告须**写明日间/夜间 LT**，勿混统计。

### 3.4 暴时 LSTID 与安静 MSTID

大尺度重力波可在磁暴高纬加热后向中低纬传播，形成 **LSTID**：周期更长、波长更大，常与扰动地磁同期。安静日中纬网里更常抓到 **MSTID**。分流：先看 Kp/SYM-H（`GFZ-Kp-Index`、`NASA-OMNIWeb`）；暴时先做 20 课差分，再分节写 LSTID，勿把大尺度暴斑块叫 MSTID。

## 4. 物理原则深讲（二）：MSTID vs LSTID 尺度尺子

记数量级（尺子，非法条）：

| | MSTID（中尺度） | LSTID（大尺度） |
|---|---|---|
| 周期直觉 | 约十几分钟～约 1 小时量级 | 更长，常约 1–3 小时量级讨论 |
| 水平波长直觉 | 城际～省际（相对全球 GIM 格点更细） | 可达上千公里量级 |
| 常见驱动图像 | 日间 AGW；夜间电动力学等 | 高纬/暴时 AGW 等 |
| GNSS 策略 | 密集网 δTEC；GIM 常看不见 | 有时大网/GIM 粗结构可见，仍建议残差+延迟 |
| 地磁 | 可安静 | 常伴扰动 |

类比：MSTID 是湖面细涟漪；LSTID 是长涌浪；风暴正负相是整湖蓄水量变化。

## 5. 物理原则深讲（三）：GNSS 残差如何「看见」波？

### 5.1 为何必须去趋势？

日变化 TEC 幅度往往远大于 TID 振幅。不去掉 >2–3 小时慢变，涟漪被潮汐淹死。输出 **δTEC**。没有 δTEC，就没有本课。

常用概念：滑动平均、多项式、带通；或减当日拟合/安静日同 LT。窗太短啃掉真波；窗太长残留日变化假周期——报告应做两窗对比。

### 5.2 为何多站延迟证明 traveling？

单站 δTEC 有峰，只说明「这里在晃」。行进要求：空间上分离的接收机在相近时段看到**有序时间延迟**，keogram 呈**斜纹**。全体同时起立（零延迟）更像耀斑同步、大尺度暴、或钟问题——见 23/20 课。

### 5.3 IPP 扫描假波（经典陷阱）

天空有一条**静止** TEC 脊，卫星 IPP 扫过，单站也会先低后高。看起来像波，其实是**你在动**。traveling 证据必须来自**不同地理位置接收机**的延迟，而非单 IPP 轨迹起伏。缓解：多站一致、限制 IPP 区域、短弧分段、多卫星交叉。

### 5.4 与 ROTI/闪烁的关系

TID 是相对光滑的波状 δTEC，ROTI 可不显著。若 ROTI/S4 很高，可能叠加不规则，或你在看泡/湍流——标签分开写。

## 10. 工作示例脚本

```python
# tid_detrend_delay_demo.py
import numpy as np

def detrend_moving_average(vtec, window):
    kernel = np.ones(window) / window
    slow = np.convolve(vtec, kernel, mode='same')
    return vtec - slow

def peak_lag(series_a, series_b, max_lag):
    """返回使相关最大的滞后（采样点数）；教学用。"""
    best, best_lag = -np.inf, 0
    for lag in range(-max_lag, max_lag + 1):
        if lag < 0:
            a, b = series_a[:lag], series_b[-lag:]
        elif lag > 0:
            a, b = series_a[lag:], series_b[:-lag]
        else:
            a, b = series_a, series_b
        n = min(len(a), len(b))
        if n < 10:
            continue
        c = np.corrcoef(a[:n], b[:n])[0, 1]
        if c > best:
            best, best_lag = c, lag
    return best_lag, best

# 口述: 多站 detrend → peak_lag 系统性随纬度变化 → 支持传播
# 若所有站 best_lag≈0 且同相 → 偏同步大尺度，慎贴 MSTID
```

## 26. AGW–IT 耦合细讲：把「波变成 TEC」拆成可画的因果链

上一节给了五步口诀。这里把每一步展开到课堂板书粒度，让你能回答老师追问「碰撞在哪一层起作用」「为什么有的波到不了 F 层」。

### 26.1 步骤 1 — 波从哪里来？

对流层对流、锋面、急流、地形绕流等可激发大气重力波。波在层结大气中传播时，振幅随高度大致按密度反比增长（能量近似守恒图像下的直觉）：越往上空气越稀，同样能量对应更大的位移扰动。因此对流层看起来「不大」的扰动，到热层可能变成显著的风场与密度振荡——**但也更容易破碎、耗散或被风场过滤**。

教学要点：不是「地上打个喷嚏，电离层必有 TID」。要有可到达的传播路径与过滤条件；作业里把 AGW 写为**候选驱动**，除非你有气辉/大气雷达旁证。

### 26.2 步骤 2 — 中性风与中性密度扰动到达热层

AGW 带来：

- **中性风扰动 δu**：水平与垂直分量随波相位变化；  
- **中性密度扰动 δn_n**：压缩与膨胀相位；  
- **温度扰动**：影响尺度高与化学反应速率（进阶加分）。

这些量在不同高度的振幅与相位由色散与背景风决定。你不必算色散，但要知道：**同一地面源，不同周期/水平波长的波，到达 F 区的效率不同**——这为 MSTID 的周期窗提供物理直觉。

### 26.3 步骤 3 — 碰撞把中性运动「传给」离子

在 E 区及 F 区下部，离子–中性碰撞频率较高，中性风能有效拖曳离子。到了 F 区上部，碰撞变弱，离子更「认磁场」：运动被约束在磁力线方向附近，水平强制更困难。

耦合图像（简化）：

1. 中性风沿某一方向推离子；  
2. 磁场使离子响应变成场向/场垂直的组合漂移；  
3. 电子为准中性跟随，形成电子密度的波状调制 δN_e。

因此 TEC 波动往往呈现**磁场对齐的各向异性条纹**（光学 MSTID 条纹也常沿磁力线方向拉长）——这与各向同性「水面圈圈波」不同。

### 26.4 步骤 4 — 从 δN_e(h) 到 δSTEC/δVTEC

GNSS 测量的是路径积分。即使局部 δN_e 只有几个百分点，积分后 δTEC 可能是 0.5–几 TECU 量级（视事件）。关键直觉：

- **层厚与峰附近权重**：F2 峰附近电子多，同样相对扰动对 TEC 贡献大；  
- **斜路径**：低仰角路径更长，振幅可能被放大，但也更容易混进多路径与 IPP 扫描效应；  
- **正负相位**：波的压缩相与稀疏相造成 δTEC 正负交替——这就是残差里的「峰谷列」。

### 26.5 步骤 5 — 去趋势后为何「突然能看见」？

日变化、缓慢的经度结构、接收机偏差慢漂，都属于低频大振幅。TID 是中高频小振幅。去趋势相当于高通/带通，把潮汐滤掉，露出涟漪。物理上波一直在；操作上你以前被背景盖住了。

### 26.6 完整因果链（请背诵并默画）

```
对流层/中层波源
    → AGW 上传（振幅增高，伴随过滤/耗散风险）
    → 热层 δu、δn_n
    → 离子–中性碰撞耦合（高度依赖）
    → δN_e 波状结构（常沿 B 各向异性）
    → 路径积分 → δSTEC/δVTEC
    → 去趋势 → 可见波列
    → 多站延迟 → 证明 traveling
```

缺最后两步，只能说「有波动候选」，不能说「行进式 TID 已证实」。

## 27. 夜间中纬 MSTID：为何不能照搬白天 AGW 故事？

夜间 F 区电子密度更低，光电产生几乎关闭，电动力学不稳定与 E–F 耦合的文献更多。Perkins 不稳定性等图像讨论的是：在特定背景电场、风场与电导率条件下，中纬夜间等离子体可发展出结构并传播。

课堂纪律：

- **日间**：优先写「AGW–IT 耦合候选」；  
- **夜间**：写「夜间中纬电动力学/耦合候选」，**不要**武断写「一定是重力波」；  
- 若有气辉与 TEC 条纹方向一致，可升置信度，但仍是候选。

作业若日夜混在一个统计箱，机制段直接不及格。

## 28. LSTID 与暴时加热：另一条「大涌浪」链

磁暴高纬焦耳加热可像「捶桌子」一样激发大尺度大气响应，向中低纬传播，形成周期更长、波长更大的 TID（LSTID 图像）。因果链：

1. 高纬能量注入与加热；  
2. 大尺度大气波动/风场扰动向外传播；  
3. 中纬 δN_e 与 δTEC 出现长周期行进结构；  
4. 常与 SYM-H 扰动时间窗相关（但不必逐分钟对齐）。

分析策略：**先做 20 课差分**，把大尺度正负相与波状残差分节；暴夜的 LSTID 与安静 MSTID 不要丢进同一个「TID 发生率」盒子。

| 你判的类型 | 站距需求 | 去趋势窗 | GIM 角色 | 地磁 |
|---|---|---|---|---|
| MSTID | 需较密网，站距应小于声称波长的若干分之一 | 避免过短；常见针对数十分钟 | 常看不见，勿用 GIM 否定 MSTID | 可安静 |

## 30. GNSS 残差看见波的「仪器物理」补充

### 30.1 采样定理直觉
声称周期 10 min，却用 15 min 采样，会混叠。教学要求：采样间隔应明显小于声称周期的一半；30 s 数据谈 20 min 周期通常够用，谈 2 min 周期则不够。

### 30.2 多卫星混合假波
把同一「站」曲线里所有卫星 IPP 混平均，可能把不同空间位置的相位搅成怪波。缓解：按卫星分别出 δTEC，或限制 IPP 落在同一小区。

### 30.3 映射函数与穿刺高度
VTEC 映射假设薄壳高度。波结构有三维性时，映射会扭曲振幅，但一般不消灭斜纹延迟证据。报告可声明「使用常规薄壳映射，振幅仅粗估」。

## 41. 色散与过滤：为什么不是所有地面波都能变成 MSTID？

课堂不必解完整色散方程，但要建立三道「过滤器」直觉：

1. **传播窗口**：背景风可把某些相速度的波折射/临界层吸收，使得到达热层的谱变窄；  
2. **耗散**：分子黏性与热传导随高度增强，短波长/高频率波更容易在中层就耗尽；  
3. **耦合效率**：即便中性波到达，若碰撞与磁场几何不利，δN_e 响应也弱。

所以「有对流层天气 ≠ 必有中纬 TEC 波列」。分析上这意味着：阴性结果（安静、去趋势后无斜纹）是合格结论，不必硬找。

### 41.1 周期窗与 MSTID「常见十几分钟到约一小时」从何而来？

经验上 GNSS 网最常报的中尺度波动落在该窗，是观测选择效应与上述过滤共同作用的结果：太短的波难耦合或难与 30 s 采样匹配；太长的又接近日变化/去趋势边界，易被当成慢变或 LSTID。写报告时把周期写成**粗估范围**，并声明对去趋势窗敏感。

## 42. 磁场各向异性：条纹为何常「斜着长」？

电离层等离子体沿磁力线电导率极高，扰动结构容易被拉成场向延展的薄片或条带。光学气辉 MSTID 与 TEC 梯度条纹常表现为相对地理南北有夹角的带状结构。这对站链设计的含义是：

- 最好有接近垂直于条纹走向的站链，延迟才清晰；  
- 若站链几乎平行于条纹，延迟变小，易误判为「同步」或「无 TID」。

作业允许你根据初步条纹方位**事后**说明站链并非最优，并降低速度置信度——这比假装算出精确方位角更科学。
