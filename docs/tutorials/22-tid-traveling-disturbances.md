## 1. 开场：涟漪，不是整湖，也不是油花

| 图像 | 对应 | 看什么 |
|---|---|---|
| 整湖涨落 | 风暴正负相（20） | GIM 差分、SYM-H |
| 一行涟漪传过 | **TID / MSTID** | δTEC 波列 + 站间延迟 |
| 锅里炸油花 | 闪烁/泡壁（05/21） | S4、ROTI |

关键词是 **traveling**：不同站点依次「点头」。看不见 TID，常因未去趋势、只用粗 GIM、或单站无相位差。

![TID 波前（TEC 残差场）示意](./images/fig-tid-wavefront.png)

> **看图要点**
> - **机制**：中性波动调制电子密度，积分后形成可传播的 δTEC 波前。
> - **观测签名**：红蓝斜向条纹 + 箭头方向；标准全球 GIM 往往看不见中尺度纹。
> - **分析用法**：用密集网残差/keogram，勿在粗 GIM 上硬认 MSTID。

## 3. AGW–IT 耦合（原则）

口诀「波–风/密–离子–柱–δTEC」：AGW → 中性风/密度扰动 → 拖曳离子 → Ne 沿相位增减 → 路径积分波动 → 去趋势见波列。  
日间中纬常提 AGW；夜间电动力学图像更多——须**写明 LT**。暴时可激发 LSTID：先看 Kp/SYM-H。

## 4. 尺度尺子

| | MSTID | LSTID |
|---|---|---|
| 周期直觉 | ~十几分钟–约 1 h | 常 ~1–3 h |
| 水平波长 | 城际–省际（相对 GIM 更细） | 可达上千 km |
| GNSS 策略 | 密集网 δTEC | 残差+延迟仍建议 |
| 地磁 | 可安静 | 常伴扰动 |

## 5. 为何必须去趋势？IPP 假波？

日变化幅度远大于 TID 波动；不去趋势只见「一天一鼓包」。

![IPP / 穿刺点几何示意](./images/fig-ipp-pierce-point.png)

> **看图要点**
> - **机制**：射线与薄壳交于 IPP；卫星运动使 IPP 扫过空间梯度。
> - **观测签名**：单站时间序列可出现「假波」，常随卫星弧段系统出现。
> - **分析用法**：多站/多方位交叉；keogram 看一致斜纹与站间延迟；工具 `Get_IPP`。
> 图源：本仓库自制示意（非实测）。

**检测核心**：① 多站高采样 TEC；② 去趋势得 δTEC；③ 叠图/keogram 斜纹？④ 互相关滞后估方向与相速；⑤ 分流暴/泡/耀斑。

## 6. TID vs 暴 vs 泡

| | TID | 风暴 ΔVTEC | 泡/闪烁 |
|---|---|---|---|
| 形态 | 波列、斜纹 | 大斑块正负 | 耗空通道+抖 |
| 多站 | 延迟/人浪 | 可同相大升降 | 局地不规则 |
| 主证据 | δTEC+延迟 | 差分+SYM-H | ROTI/S4 |

## 7. 清单 · 误解 · 测验

**45 分钟最小分析**：3–5 站 → 去趋势 → 目视延迟 → 写周期粗估 → 声明非暴/非泡理由。

| 误解 | 纠正 |
|---|---|
| GIM 涟漪＝MSTID | 分辨率常不够 |
| 单站起伏＝traveling | 无邻站延迟只能叫波动 |
| 暴时一律 MSTID | 先做 20，再分节 LSTID |
| 低纬波纹一定是 TID | 先排除泡（21） |

**口答**：耦合五步；MSTID vs LSTID；为何去趋势；IPP 假波一例。

### 口令

> 去趋势，看人浪；有延迟，才 traveling；GIM 不够细，别硬认涟漪。
