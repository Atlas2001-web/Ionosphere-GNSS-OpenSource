# 06 · 定位里怎么处理电离层？（单频 / 双频 / PPP / RTK）

> **课堂定位**：接 05。你已会分「雾有多厚」（TEC）与「雾碎不碎」（闪烁）。本课换到**定位误差预算**：伪距/载波上的电离层延迟怎么改、怎么消、怎么估、怎么差掉；以及残差图上如何认「慢偏 / 梯度撕 / 跟踪崩」。
> 路线固定为四段：**机制 → 公式拆解（逐步推导）→ 观测签名 → 分析步骤**。

> **写给谁**：第一次在单频手机和双频测绘之间迷路、第一次听说无电离层组合却把它当成 TEC 图、第一次 RTK 固定失败就骂「电离层坏了」的人。

## 0. 开场：三个真实场景

请先合上笔记本，想三件事：

1. **单频手持 vs 双频测绘**：同一片天，单频靠广播模型「猜雾厚」；双频可做无电离层组合「消一阶雾」。有人以为「开了双频 = 电离层归零」——噪声放大、高阶项、闪烁失锁都还在。
2. **短基线 RTK 很香，长基线突然难固定**：差分削的是**公共**延迟。基线变长或暴时梯度变陡，公共性变差；残差从「慢偏」变成「梯度撕裂」。
3. **PPP 收敛锯齿化，值班员只盯 GIM**：GIM 说 TEC 还行，但 ROTI/周跳同窗暴涨——瓶颈在**跟踪层**，不是延迟模型少改了半米。05 课的闪烁账，在这里变成定位日志。

## 1. 词表（先扫一遍，主讲后再回看）

### 1.1 模式与策略

| 术语 | 人话 | 稍严 |
|---|---|---|
| SPP | 单点定位，米级常见 | Single Point Positioning |
| RTK | 流动站+基准站，差分追厘米 | Real-Time Kinematic |
| PPP | 单站精密，靠精密轨道钟差 | Precise Point Positioning |
| 改正（correct） | 用模型/图把延迟减一部分 | 单频广播、GIM 约束 |
| 消除（eliminate） | 组合让一阶电离层系数变 0 | 无电离层组合 IF |
| 差分（difference） | 站间/星间相减削公共项 | 短基线 RTK 经典 |
| 估计（estimate） | 把 STEC 当未知数一起解 | 非差非组合 PPP 等 |

### 1.2 模型、组合与几何

| 术语 | 人话 | 稍严 |
|---|---|---|
| Klobuchar | GPS 电文 8 参数「全球雾况简报」 | 广播单频改正 |
| NeQuick-G | Galileo 单频广播改正族 | ≠ 科研 NeQuick2/IRI 混开关 |
| 无电离层组合（IF） | 加权两频，消一阶 $I$ | ionosphere-free |
| 几何无关组合（GF） | 消几何，留 TEC | 服务测雾，见 02 |
| IPP / 穿刺点 | 视线戳到假定壳的点 | 插值 GIM 用 |
| 映射 $M(E)$ | 斜↔竖的几何放大 | 低仰角很敏感 |
| 一阶延迟 $I(f)$ | $\propto\mathrm{STEC}/f^{2}$ | 码延迟主项 |

### 1.3 残差与故障画像

| 术语 | 人话 | 稍严 |
|---|---|---|
| 慢漂移型 | 位置慢慢偏，跟踪大体还在 | 模型不足 / 高 TEC |
| 梯度撕裂型 | 短基线尚可、长基线崩 | 站间不公共 |
| 闪烁崩盘型 | 周跳、失锁、重收敛 | 跟踪环跟不住 |
| 模糊度固定 | 载波整周「锁死」 | 固定率是 RTK 成绩单 |
| 收敛 | PPP 从粗到精的过程 | 闪烁窗常锯齿化 |

## 2. 先问对问题：你要坐标，还是要大气？

定位软件打开的瞬间，其实在回答两个不同的问题。混为一谈，后面所有残差都会被错怪。

| 你真正需要的 | 更合适的路 | 电离层进账方式 |
|---|---|---|
| 米级导航大概对 | 单频 + Klobuchar/NeQuick-G（有条件再叠 GIM） | **改正**：外部模型给 $I$ 先验，从伪距里减 |
| 分米–厘米坐标（双频） | 无电离层组合为主 | **消除**：组合权重把一阶 $I$ 洗成 0 |
| 短基线工程 RTK | 差分削公共雾；盯暴时残余与闪烁 | **差分**：站间公共延迟相减 |
| 长基线 / 网络 RTK | 区域大气约束；勿幻想差分万能 | 差分 + 区域改正；残余进双差残差 |
| 单站 PPP | IF 消雾，或估 STEC / 加 SSR·GIM 先验 | **消除** 或 **估计**（或两者叠增强） |
| 只要 TEC/GIM 产品 | 回 `lists/01-ionosphere`，不必先跑通全套 PPP | 主产品是大气；走 GF / 建图，不是 IF-PPP |

### 2.1 「要坐标还是要大气」分叉（零基础钉死）

- **要坐标**：电离层是误差预算里的一项「债」。目标是把它改掉、消掉、差掉或估稳，让几何距离 $\rho$ 干净出来。副产品偶尔带 TEC，但摘要主语仍是位置。  
- **要大气**：电离层是科学产品。目标是 STEC/VTEC/GIM；坐标往往已假定或只需米级锚。走几何无关组合与建图工艺（02/03），**不要**先迷路进 PPP 迷宫。

课堂口诀：**同一套双频观测，向右走 IF 为尺子，向左走 GF 为雾厚——菜谱相反，不可混炒。**

### 2.2 误差预算里电离层怎么「进账」？

伪距方程（略去硬件延迟等）把误差排成一桌菜：

$$
P = \rho + c\Delta t + T_{\mathrm{trop}} + I(f) + \varepsilon.
$$

| 账本项 | 典型量级（平静中纬、中高仰角） | 与频率关系 | 本课态度 |
|---|---|---|---|
| 几何 $\rho$ | 要解的未知 | 无 | 主产品（坐标路线） |
| 钟差 $c\Delta t$ | 可达万米级，但可估 | 无 | 每历元估 |
| 对流层 $T$ | 米级（天顶）～数米（低仰角） | 近似无色散 | 模型 / 估参数 |
| **电离层 $I(f)$** | **数米～数十米**（视 STEC 与仰角） | **$\propto 1/f^{2}$** | **改 / 消 / 差 / 估** |
| 噪声 $\varepsilon$ | 码：分米–米；相位：毫米级 | 组合时被放大 | QC 与权重 |

人话：电离层不是「偶尔冒出来的怪偏」，而是**几乎每条伪距都带着的、随频率变化的米级项**。单频不处理 ≈ 把几米到十几米直接喂给最小二乘；双频 IF ≈ 付噪声税换一阶清零；RTK ≈ 赌「两站雾差不多」；PPP 估 STEC ≈ 把雾当成要一起解的未知数。

类比总纲（请背）：

- **改正** ≈ 看天气预报出门——能挡雨，不准到不湿鞋；  
- **消除** ≈ 两只眼睛做立体抵消——消的是一阶色散，不是物理学毕业；  
- **差分** ≈ 两人手拉手走同一片雾——公共偏置相减；  
- **估计** ≈ 把雾厚当成要解的未知数——主产品仍常是坐标，TEC 是副产品或约束。

**机制一句话**：定位软件对电离层必须有态度；态度选错，残差长相会告诉你——但你要会读。

## 3. 电离层如何「长」进伪距？

![同一 STEC 下延迟随频率下降](./images/fig-iono-delay-vs-freq.png)

> **看图要点（为什么画延迟–频率）**
> - **看什么**：同一 STEC 下，伪距一阶延迟随 $1/f^{2}$ 下降；L1 比 L2/L5「短一截」。
> - **为什么**：定位看见的是**等价距离误差（米）**，库存却是 STEC——这张图把「雾厚」翻译成误差预算里的米。单频改正与双频 IF 的全部动机，都从这条曲线长出来。
> - **别误判**：曲线是一阶项；高阶与闪烁跟踪不在这张图上。
> 图源：自制 CC0，见 [`images/SOURCES.md`](./images/SOURCES.md)。

人话三句：

1. 电子柱越厚，码伪距越容易「量长」一截（群延迟）——像拿软尺量雾天的路，雾越厚尺子越「松」；  
2. 频率越低，同一 STEC 造成的延迟越大——这是色散；所以 L2/L5 比 L1「更怕雾」；  
3. 载波相位的一阶符号与伪距相反（相位超前），但本课定位叙事先抓住：**电离层是与频率有关的误差源，进的是米，不是抽象 TECU 标签**。

![GNSS 频段示意](./images/fig-gnss-freq-bands.png)

> **看图要点（为什么看频段）**
> - **看什么**：L1/L2/L5（及多系统频点）落在不同频率。
> - **为什么**：多频不是炫配——两频延迟成固定比例，才给「消雾（IF）」与「测雾（GF）」两条菜谱提供原料。
> - **别误判**：有双频硬件 ≠ 软件已开 IF；配置未备案时禁止说「我已经双频处理了」。
> 图源：自制 CC0 示意。

单频只有一个测量方程：几何距离、钟差、对流层、电离层缠在一起——除非**借入外部模型**给 $I$ 一个先验值，否则分不开。双频则让 $I$ 在两频上成固定比例（$I_2=(f_1/f_2)^{2}I_1$），于是可以消或测。

**进账路径小结（背诵）：** STEC（库存）→ $\times 40.3/f^{2}$ → $I(f)$（米）→ 进入 $P$ 或经改正/组合/差分后再进法方程。

## 4. 单频：只能「改正」，不能魔术消除


![单频模型猜 vs 双频实测](./images/fig-singlefreq-vs-dualfreq.png)

> **看图要点（为什么并排单频 vs 双频）**
> - **看什么**：左图单频靠广播/气候模型「猜雾厚」再减；右图双频从两频观测量出（或消掉）延迟。
> - **为什么**：猜与测是两条完全不同的进账路径——单频残差天花板由模型决定，双频 IF 的天花板改由噪声/高阶/跟踪决定。
> - **别误判**：右图「能量出延迟」≠「电离层等于零」；IF 之后仍可能慢偏或崩盘。
> 图源：自制 CC0。

只有一个频率时，做不了经典 IF 戏法。选项主要是：

### 4.1 广播模型

- **GPS：Klobuchar** — 电文 8 参数，粗、快、全球可用。像「全球平均雾况简报」，不是当地雷达。平静中纬常能改掉相当一部分平均延迟；暴时、低纬、黎明黄昏，简报更容易离谱。  
- **Galileo：NeQuick-G** — 官方单频改正实现；与科研用 NeQuick2 / IRI **用途与输入不要混用**（见 [04](./04-iri-nequick.md)）。

本目录：`Klobuchar-study-code`、`Galileo-NeQuick-G`、`NequickG`、`NeQuickG-ESSR`（`lists/01-ionosphere.md`）。

### 4.2 外源格网（GIM / IONEX）

联网拿到全球/区域图 → 在 IPP 插值 VTEC → 映射成斜路径延迟。比广播细，但要纪律：产品时刻、映射函数、低仰角敏感（见 [03](./03-gim-ionex.md)）。

### 4.3 课堂预期与失败模式

> 单频改正后残差仍在，**不能指望达到双频 IF 的水平**。它解决「别裸奔」，不是「厘米级免检」。

| 常见翻车 | 人话 | 对策 |
|---|---|---|
| 把 Klobuchar 残差当「电离层已清零」 | 简报改掉一部分平均延迟，暴时/低纬仍可留数米 | 摘要必须写「残差仍在」+ 对照双频或 GIM |

| GIM 当「厘米改正」硬塞单频导航 | 全球图平滑、时效与映射都有税 | 写清产品时刻与仰角门限；别承诺测绘级 |
| NeQuick-G 与 NeQuick2/IRI 旋钮混用 | 官方单频改正 ≠ 科研气候脚本 | 回 04；接口票据分家 |

## 5. 双频分叉：IF 为测距，GF 为测雾

![双频几何无关 vs 测距叙事](./images/fig-dualfreq-geometry-free.png)

> **看图要点（为什么强调左右分叉）**
> - **看什么**：同一套双频观测，向左走几何无关（GF）→ TEC；向右走无电离层（IF）→ 更好的距离。
> - **为什么**：「要坐标还是要大气」在双频硬件上落成两条菜谱——配料相同，权重相反，交付物相反。
> - **别误判**：把 IF 残差图拿去当 TEC 图；或把 GF 的 TEC 曲线直接当坐标改正量。
> 图源：自制 CC0。

![无电离层组合直觉与代价](./images/fig-iono-free-combo.png)

> **看图要点（为什么强调代价）**
> - **看什么**：权重把一阶 $I$ 洗掉；同时噪声被放大，高阶项与硬件偏差仍可能留下。
> - **为什么**：消雾不是免费午餐——你付的是「尺子变毛」的税（§11），换来一阶延迟清零。
> - **别误判**：开了 IF = 电离层等于零；IF 免疫闪烁失锁。
> 图源：自制 CC0。

```
双频观测
   ├─► 无电离层组合（IF）──► 服务定位（消一阶延迟）
   └─► 几何无关组合（GF）──► 服务 TEC（测雾厚）
```

IF 的机制动机：两频延迟成 $1/f^{2}$ 比例，选权重使组合后电离层系数变 0，几何距离留下。

代价（考试爱考）：

1. **噪声被放大**；  
2. **高阶项可能残留**；  
3. **偏差/硬件效应**仍在（见 [09](./09-dcb-biases-deep.md)）；  
4. 你得到更好的距离，**不是**电子密度照片。

## 6. RTK 差分削雾；PPP 一个人怎么对付雾？

### 6.1 RTK：公共雾相减

两站近时，看向同一颗卫星的路径穿过的电离层「差不多」。**站间差分**后公共延迟大幅削弱——像两人在同一雾房间用同一把尺子，偏置相减。站间单差后再做星间差分（双差），钟差也被削掉，剩下几何与模糊度——这是经典 RTK 香的根源。

什么时候雾又回来？

- 基线变长 → 站间梯度不可忽略，差分残余 $\Delta I$ 抬头；  
- 暴时 / EIA 加强 / TID 扫过 → 「公共」假设变脆，短基线也可能「撕」；  
- 强闪烁 → 即使短基线、绝对 TEC 不高，周跳与失锁让模糊度难固定。

**RTK 怕的是梯度与跟踪，不只是「TEC 绝对值高」。** 高 TEC 但两站同泡在均匀雾里，差分仍香；低 TEC 但锋面卡在基线中间，照样痛。

### 6.2 PPP：消 / 估 / 增强

单站没有「另一只手」可拉，只能自己对付雾：

| 策略 | 直觉 | 注释 | 典型失败 |
|---|---|---|---|
| 双频 IF | 先消一阶雾再精密测距 | 经典 PPP 常见入口 | 当「电离层毕业」；忽略噪声税与高阶 |
| 非差非组合 / 估 STEC | 每星电离层当参数 | 可加 GIM 约束；科研向 | 把估出的 STEC 直接当 02 课科研产品 |
| 增强改正 | 区域电离层 / SSR 先验 | 「带大气补丁的 PPP」 | 产品时刻错、服务中断当「算法挂了」 |

PPP 再精密，也怕跟踪层崩溃。05 课的闪烁在这里表现为：收敛变慢、周跳、重收敛锯齿。**延迟模型完美，救不了失锁。**

### 6.3 四种态度对照卡（机制收束）

| | 单频改正 | 双频 IF | RTK 差分 | PPP 估/增强 |
|---|---|---|---|---|
| 核心动作 | 减模型 $I$ | 组合消一阶 $I$ | 站间削公共 $I$ | 消或把 $I$ 当参数 |
| 主要代价 | 模型残差 | 噪声放大 | 梯度残余 | 可观测性/收敛 |
| 暴时最怕 | 简报离谱 | 高阶+闪烁 | 梯度撕+闪烁 | 闪烁重收敛 |
| 主产品 | 坐标（粗） | 坐标 | 坐标（相对） | 坐标（+可选 TEC） |

开源套件里电离层常嵌在大仓库中：`RTKLIB`、`gLAB-UPC`、`PRIDE-PPPAR`、`ginan`、`pyrtklib`（`lists/04-gnss-positioning.md`）。先选套件，再读其 Ionosphere / IF 章节。

## 8. 解剖台 A：一阶延迟 $I(f)$——定位看见的米

> 解剖台统一格式：**符号表 → 逐步推导（每步人话）→ 小数值例**。教学核心式与 01 课对齐——把「雾厚」翻译成误差预算里的米。

### 8.1 符号表

$$
I(f)=\frac{40.3}{f^{2}}\,\mathrm{STEC}
$$

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $I(f)$ | 码伪距一阶电离层延迟 | m（定位看见的「多出来的路」） |
| $f$ | 载波频率 | Hz；GPS L1 $\approx 1.57542\times10^{9}$ |
| $\mathrm{STEC}$ | 斜路径电子含量 | $\mathrm{m}^{-2}$；常用 TECU，$1\,\mathrm{TECU}=10^{16}\,\mathrm{m}^{-2}$ |
| $40.3$ | 一阶色散常数 | 约 $\mathrm{m}^{3}\cdot\mathrm{s}^{-2}$ 量级（课堂取 40.3） |
| $P_i$ | 第 $i$ 频伪距 | m |
| $\rho$ | 几何距离 | m；坐标路线的主未知 |

### 8.2 逐步推导（每步人话）

1. **视线积分**得到 STEC：沿接收机→卫星路径把电子数密度积起来——库存单位是 $\mathrm{m}^{-2}$（或 TECU）。  
2. **色散翻译**：乘 $40.3/f^{2}$ → 库存变成**米**。频率越低，同一库存换出的米越多。  
3. **进伪距方程**（略去硬件延迟等）：

$$
P_i=\rho+c\Delta t+T_{\mathrm{trop}}+I_i+\varepsilon_i.
$$

人话：$I_i$ 和几何距离缠在同一把尺子上，最小二乘分不清「站远了」还是「雾厚了」。  
4. **单频死结**：只有一个 $P_1$，条数不够把 $\rho$ 与 $I_1$ 拆开 → 必须**借入模型**给 $I$ 先验（改正）。  
5. **双频开口**：同一 STEC 下 $I_2=(f_1/f_2)^{2}I_1$，两频延迟成固定比例 → 可消（IF）可测（GF）。

### 8.3 小数值例（请手算一遍）

取 $\mathrm{STEC}=20\,\mathrm{TECU}=2.0\times10^{17}\,\mathrm{m}^{-2}$，$f_1=1.57542\times10^{9}\,\mathrm{Hz}$：

$$
I_1\approx\frac{40.3\times 2.0\times10^{17}}{(1.57542\times10^{9})^{2}}\approx 3.25\,\mathrm{m}.
$$

L2（$f_2=1.22760\times10^{9}\,\mathrm{Hz}$）约 $5.35\,\mathrm{m}$。差额约 $2.1\,\mathrm{m}$——GF 测 TEC 看见的「雾差」；IF 则要让这类项在组合里抵消。

再练（误差预算直觉）：若单频完全不改，$I_1\approx 3\,\mathrm{m}$ 量级直接进位置误差；低仰角再乘映射 $M\sim 2$–$3$，可变成近十米——这就是「别裸奔」的定量理由。

**要点**：$I(f)$ 是定位账本上的米，不是摘要里装饰用的 TECU 标签。

## 9. 解剖台 B：无电离层组合——逐步推导

> 格式：**符号表 → 逐步推导 → 小数值例**。目标：找系数，使组合观测里 $I$ 的一阶贡献为 0，几何距离留下。

### 9.1 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $I_1,I_2$ | L1/L2 一阶延迟 | m；$I_2=(f_1/f_2)^{2}I_1$ |
| $P_1,P_2$ | 两频伪距 | m |
| $\alpha_1,\alpha_2$ | IF 组合权重 | 无量纲；常要求 $\alpha_1+\alpha_2=1$ |
| $P_{\mathrm{IF}}$ | 无电离层组合伪距 | m；一阶 $I$ 被洗掉后的「更好尺子」 |
| $f_1,f_2$ | 两载波频率 | Hz |

比例关系（同一 STEC）：

$$
I_1=\frac{40.3}{f_1^{2}}\mathrm{STEC},\qquad
I_2=\frac{40.3}{f_2^{2}}\mathrm{STEC}
\implies
I_2=\frac{f_1^{2}}{f_2^{2}}I_1.
$$

### 9.2 逐步推导（每步人话）

1. **构造线性组合** $P_{\mathrm{IF}}=\alpha_1 P_1+\alpha_2 P_2$。人话：把两把「松紧不同的尺子」按比例加减。  
2. **消雾条件**：希望 $\alpha_1 I_1+\alpha_2 I_2=0$。代入 $I_2=(f_1^{2}/f_2^{2})I_1$ 得

$$
\alpha_1+\alpha_2\frac{f_1^{2}}{f_2^{2}}=0.
$$

3. **保尺度**：常加 $\alpha_1+\alpha_2=1$，让几何距离 $\rho$ 的系数仍为 1（组合后还是「米」，不是奇怪倍数）。  
4. **联立求解**，经典解：

$$
P_{\mathrm{IF}}
=
\frac{f_1^{2}}{f_1^{2}-f_2^{2}}P_1
-
\frac{f_2^{2}}{f_1^{2}-f_2^{2}}P_2.
$$

等价写法：$P_{\mathrm{IF}}=(f_1^{2} P_1-f_2^{2} P_2)/(f_1^{2}-f_2^{2})$。  
5. **相位同型**：把 $P$ 换成 $L$；注意模糊度变成**组合模糊度**（不再是单频整周的简单整数叙事）。  
6. **代价预告**：权重绝对值 $>1$ → 噪声被放大（§11）；高阶项与 DCB 偏差不会被这组权重 magically 清零。

### 9.3 小数值例：权重手算 + 一阶验收

**权重（GPS L1/L2）：**  
$f_1^{2}\approx2.4819\times10^{18}$，$f_2^{2}\approx1.5070\times10^{18}$，$f_1^{2}-f_2^{2}\approx9.749\times10^{17}$。

$$
\frac{f_1^{2}}{f_1^{2}-f_2^{2}}\approx2.546,\qquad
\frac{f_2^{2}}{f_1^{2}-f_2^{2}}\approx1.546.
$$

教学口诀：**约 $2.55\,P_1-1.55\,P_2$**（以你软件文档的精确系数为准）。

**一阶验收**（沿用 $I_1=3.25\,\mathrm{m}$，$I_2=5.35\,\mathrm{m}$）：

$$
I_{\mathrm{IF}}
=
\frac{f_1^{2} I_1-f_2^{2} I_2}{f_1^{2}-f_2^{2}}
\approx
\frac{2.4819\times10^{18}\cdot 3.25-1.5070\times10^{18}\cdot 5.35}{9.749\times10^{17}}
\approx 0.
$$

手算允许四舍五入误差；代数上在一阶模型内恒为 0。

**要点**：IF 消的是**一阶** $40.3\,\mathrm{STEC}/f^{2}$；不是宣称电离层物理学结束。

![双频色散与组合原料](./images/fig-dualfreq-tec.png)

> **看图要点（为什么两频延迟必须不同）**
> - **看什么**：同一 STEC 在两频上延迟不同（色散）。
> - **为什么**：比例固定，才存在一组权重同时满足「消 $I$」与「留 $\rho$」——IF 与 GF 的物理前提都在这里。
> - **别误判**：延迟差本身不是定位误差；GF 用它测雾，IF 用权重把它抵消。
> 图源：自制 CC0。

## 10. 解剖台 C：GIM 改正中的映射 $M(E)$

> 格式：**符号表 → 逐步推导 → 小数值例**。单频或 PPP 约束使用 GIM 时，必须走完「图上的竖直量 → 斜路径米」整条链。

### 10.1 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $E$ | 卫星高度角（仰角） | ° 或 rad；映射的自变量 |
| $M(E)$ | 映射函数 | 无量纲；天顶 $\approx 1$，低仰角 $\gg 1$ |
| $\mathrm{VTEC}$ | 穿刺点竖直 TEC | TECU；来自 IONEX 插值 |
| $\mathrm{STEC}$ | 斜路径 TEC | TECU；$\approx M(E)\cdot\mathrm{VTEC}$（薄壳） |
| $I_{\mathrm{corr}}(f)$ | 用于改正的延迟 | m；从伪距里减掉的那一截 |
| IPP | 穿刺点 | 射线与假定壳的交点 |

教学薄壳映射（形式随软件略异，写报告以文档为准）：

$$
\mathrm{STEC}\approx M(E)\cdot\mathrm{VTEC},\qquad
I_{\mathrm{corr}}(f)=\frac{40.3}{f^{2}}\,M(E)\cdot\mathrm{VTEC}.
$$

### 10.2 逐步推导（每步人话）

1. **求 IPP**：射线戳到假定薄壳的点——改正跟的是这一点的雾，不是测站天顶神话。  
2. **插 VTEC**：在 IONEX 格网（经纬×时间）内插，得到 IPP 处竖直柱。  
3. **乘映射**：$\mathrm{STEC}\approx M(E)\cdot\mathrm{VTEC}$。人话：斜着看雾，柱更长；仰角越低，$M$ 越大。  
4. **换成米**：$I_{\mathrm{corr}}=(40.3/f^{2})\,\mathrm{STEC}$，再从伪距减掉。  
5. **误差同乘**：GIM 的 VTEC 误差、壳高误差、时间错位，都会被 $M(E)$ **一起放大**——低仰角是事故高发区。

![映射函数随仰角变陡](./images/fig-mapping-function.png)

![GIM 改正里的 $M(E)$](./images/fig-mapping-me-curve.png)

> **看图要点（为什么映射曲线必须进课堂）**
> - **看什么**：天顶附近 $M\approx 1$；低仰角 $M$ 陡增。
> - **为什么**：陡增是几何放大，不是「雾突然变厚」——改正米数与改正误差一同被放大。
> - **别误判**：忽略高度角门限仍信改正米数；把映射噪声全怪给「GIM 不准」。
> 图源：自制 CC0。

![薄壳 STEC↔VTEC](./images/fig-stec-vtec-shell.png)

> **看图要点（为什么画薄壳）**
> - **看什么**：竖直柱与斜路径、壳高、穿刺点的几何关系。
> - **为什么**：改正链是「图上的竖直量 → 乘映射 → 变成你视线方向的米」；三问不清（壳高、映射、仰角截止）就没有资格抱怨产品。
> - **别误判**：薄壳是教学近似；真实电离层有厚度，低仰角时近似更脆。
> 图源：自制 CC0。

### 10.3 小数值例

$\mathrm{VTEC}=20\,\mathrm{TECU}$，$E=30°$，设 $M\approx 1.7$：

$$
\mathrm{STEC}\approx 1.7\times 20=34\,\mathrm{TECU}
\quad\Rightarrow\quad
I_1\approx\frac{40.3\times 3.4\times10^{17}}{(1.57542\times10^{9})^{2}}\approx 5.5\,\mathrm{m}.
$$

单频若完全不改，这几米直接进位置误差预算。若 VTEC 本身偏了 $2\,\mathrm{TECU}$，则 $\Delta I_1\approx (2/20)\times 5.5\approx 0.55\,\mathrm{m}$——再乘低仰角更大的 $M$，分米级改正误差很常见。

**课堂事故清单**：产品时刻错、低仰角硬改、壳高默认值不声明、把映射噪声全怪给 GIM。

## 11. 解剖台 D：IF 噪声放大、差分残余、与「估 STEC」

> 格式仍是**符号表 → 逐步推导 → 小数值例**。三块账：消雾的税、差分削不干净的残余、把雾当未知数时你在解什么。

### 11.1 IF 噪声放大

#### 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $\sigma_P$ | 单频伪距噪声标准差 | m；假设两频同量级、独立 |
| $\sigma_{\mathrm{IF}}$ | IF 组合后的噪声标准差 | m |
| $\alpha_1,\alpha_2$ | IF 权重 | 见 §9；$|\alpha|\sim 2.5/1.5$ |

#### 逐步推导（每步人话）

1. IF 是大系数线性组合：$P_{\mathrm{IF}}=\alpha_1 P_1+\alpha_2 P_2$。  
2. 独立噪声误差传播：$\sigma_{\mathrm{IF}}^{2}=\alpha_1^{2}\sigma_P^{2}+\alpha_2^{2}\sigma_P^{2}$。  
3. 代入 L1/L2 权重：

$$
\sigma_{\mathrm{IF}}
\approx
\sqrt{
\left(\frac{f_1^{2}}{f_1^{2}-f_2^{2}}\right)^{2}
+
\left(\frac{f_2^{2}}{f_1^{2}-f_2^{2}}\right)^{2}
}\,\sigma_P
\approx 3\,\sigma_P.
$$

4. 人话：消雾要付「尺子变毛」的税。相位 IF 同理，但相位原始噪声小，税相对可承受——这也是精密定位爱相位的原因之一。

#### 小数值例

设 $\sigma_P=0.3\,\mathrm{m}$（码）：$\sigma_{\mathrm{IF}}\sim 3\times 0.3=0.9\,\mathrm{m}$。  
若相位单频 $\sigma_L=0.003\,\mathrm{m}$，则 $\sigma_{L,\mathrm{IF}}\sim 0.009\,\mathrm{m}$——仍远优于码 IF。**口诀：能上相位就别只拿码 IF 硬刚厘米。**

### 11.2 差分后的电离层残余

#### 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $\Delta I$ | 站间单差后的电离层残余 | m |
| $b$ | 基线长度（或其视线投影） | km |
| $\nabla_{\mathrm{h}}\mathrm{TEC}$ | 水平 TEC 梯度 | TECU/km 量级 |
| $M$ | 映射几何因子 | 无量纲 |

教学直觉式（不必背严式）：

$$
\Delta I
\;\sim\;
(\text{baseline proj.})\times(\text{horiz. TEC grad.})\times(\text{mapping geom.}).
$$

#### 逐步推导（每步人话）

1. 站间单差后，电离层项变成「两站路径之差」——公共大雾被减掉。  
2. 短基线、雾场平滑：$\Delta I\approx 0$，RTK 很香。  
3. 基线拉长或水平梯度变陡：两站不再「同一色块」，$\Delta I$ 上升，双差残差抬升、固定率下跌。  
4. **要会说的那句**：**RTK 怕的是梯度，不只是绝对 TEC 高低。**

#### 小数值例（量级）

设水平梯度 $0.05\,\mathrm{TECU/km}$，基线投影 $50\,\mathrm{km}$，映射 $M\sim 2$：斜路径 TEC 差 $\sim 0.05\times 50\times 2=5\,\mathrm{TECU}$ → L1 残余延迟 $\sim 0.8\,\mathrm{m}$ 量级。短基线 $5\,\mathrm{km}$ 同梯度则小一个数量级——这就是「短基线香、长基线难」的定量直觉。

![TEC 水平梯度示意](./images/fig-tec-gradient.png)

> **看图要点（为什么看色带陡度）**
> - **看什么**：颜色陡变处 vs 均匀色块。
> - **为什么**：长基线跨色带 → 差分残余痛；短基线可能还在同一色块里。
> - **别误判**：绝对 TEC 高但色块均匀，差分仍可香。
> 图源：自制 CC0。

![TEC 水平梯度海岸图（定位用）](./images/fig-tec-gradient-coast.png)

> **看图要点（为什么叠海岸）**
> - **看什么**：EIA 峰区、舌状结构附近色带是否陡；基线是否跨色带；箭头示意梯度方向。
> - **为什么**：水平 $\nabla\mathrm{TEC}$ 才是 RTK/长基线残余的痛点——把基线画在这张「梯度地图」上，比只看 TEC 绝对值更接近值班直觉。
> - **别误判**：示意场；勿把箭头当风速或 TID 相速矢量。

### 11.3 估 STEC 时你在解什么？

#### 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $I^{s}$ 或 $\mathrm{STEC}^{s}$ | 第 $s$ 颗星的电离层参数 | m 或 TECU；常加随机游走 |
| $\mathbf{x}$ | 测站坐标等 | m |
| 约束 | GIM / SSR 先验 | 把参数拉向外部场 |

#### 逐步推导（每步人话）

1. 非差非组合：每颗星留一个电离层参数，与坐标、钟差、对流层一起估。  
2. 可加 GIM/SSR 约束，避免参数「飘」。  
3. 主产品仍常是坐标；顺带输出的 STEC 带着偏差基准与参数化假设——**不是**自动等于 02 课科研 TEC 产品。  
4. 类比：估 STEC 像「把雾厚写进未知数名单」；名单写了 ≠ 你交付的就是气象局正式图。

#### 小数值例（可观测性直觉）

## 12. 残差三种长相（必背）

合上公式，只看残差图与日志——三种脸必须一眼能分。分不清脸，后面的药全开错。

| 类型 | 残差 / 日志直觉 | 时间尺度 | 更像哪类故事 | 第一剂药 |
|---|---|---|---|---|
| **慢漂移型** | 位置偏差缓慢拉大或系统性偏；跟踪大体还在 | 分钟–小时斜坡 | 高 TEC、单频简报失效、GIM 太滑、改正不足 | 换/加改正或开 IF |
| **梯度撕裂型** | 短基线尚可、长基线固定率崩；站间双差残差抬升 | 随基线/锋面 | 暴时大尺度梯度、EIA 加强、TID 扫网 | 缩短基线或区域大气 |
| **闪烁崩盘型** | 周跳浪涌、失锁、可用星骤降、解中断或频繁重收敛 | 秒–分钟刺/断 | 不规则体 / 高 ROTI·S4 窗口 | 拒星、提高屏蔽角、等窗口 |

**口诀：** 偏了 ≠ 撕了 ≠ 抖了。三张脸对应三套药：换/加改正、缩短基线或区域约束、闪烁监测与拒星。

### 12.0 一眼区分（值班三十秒）

1. **先看周跳/失锁曲线**：若与残差「刺」同峰 → 先按崩盘型分诊，别急着调 Klobuchar。  
2. **再看是否「只长大基线」**：短基线香、长基线崩 → 梯度撕裂。  
3. **最后看慢斜坡**：跟踪干净但坐标慢慢偏 → 慢漂移；对照 GIM/改正链。  
4. **混型很常见**：暴日可先慢偏、锋面过境时撕、日落后再崩——**必须拆窗**，禁止一锅炖。

![定位残差三张脸：慢漂 / 梯度撕 / 闪烁崩](./images/fig-residual-three-faces.png)

> **看图要点（为什么三张脸并排）**
> - **看什么**：斜坡 vs 撕裂 vs 乱抖+断弧。
> - **为什么**：长相不同 → 因果不同 → 药不同；同一句「电离层」结案是值班事故。
> - **别误判**：把周跳浪涌当成「改正少了半米」；把长基线固定失败当成「接收机坏了」。
> 图源：自制 CC0。

## 13. 假阳性指纹速查

先排除这些「看起来像电离层、其实不是（或不只是）」的指纹，再开空间天气庭。

| 把 IF 噪声当偏差 | 码 IF 残差毛、相位还行 | 分码/相位看；别只用码 IF 谈厘米 | 改正不足 |

### 15.3 步骤要点（每步补失败模式）

**① 事件窗** — 圈出固定率下跌、RMS 爆表、重收敛时刻；低纬加注地方时。  
**失败模式**：只用世界时、不标地方时 → 低纬日落后气泡窗对不上；窗口切太宽把慢偏与崩盘炖一锅。

**② 备案** — 没有备案，无法判断「没改雾」还是「雾策略对但跟踪挂了」。  
**失败模式**：口头说「开了双频」但日志无 IF 标志；改正产品版本事后回忆。

**③ QC** — `Anubis` / `TEQC` / `georinex`：SNR 乱跳+周跳浪涌 → 向闪烁倾斜；数据干净但位置慢慢偏 → 向延迟倾斜。

**④ 三张图** — 东/北/天误差对时间；周跳计数对时间；双差残差或创新范数（若可输出）。

## 17. 常见误解专节

### 误解 A：「开了双频，电离层就等于零了」

**纠正：** IF 消的是一阶项；噪声放大、高阶、偏差、闪烁跟踪问题都还在。

### 误解 B：「Klobuchar 改完就该和双频一样准」

**纠正：** 广播模型是粗改正。平静中纬「看起来差不多」≠ 暴时/低纬也成立。

### 误解 C：「RTK 很准，所以电离层不存在」

**纠正：** 短基线差分削公共部分；长基线与暴时残余会回来。准是有条件的准。

### 误解 D：「PPP 一定要先估 TEC」

**纠正：** 经典双频 IF-PPP 可以不显式输出 TEC。估 STEC 是策略之一，不是宗教。

### 误解 E：「GIM 代入定位 = 区域精密大气」

**纠正：** 全球图平滑、时间分辨率有限。区域强梯度与闪烁仍可能打穿预期。

### 误解 F：「定位套件里找不到单独 iono 程序 = 没覆盖」

**纠正：** 电离层常嵌在 `RTKLIB` / `gLAB-UPC` / `ginan` / `PRIDE-PPPAR`；按列表读套件。

### 误解 G：「NeQuick-G 和 IRI 调同一组参数就行」

**纠正：** 广播改正 ≠ 科研气候学模型。详见 04，勿混用开关。

### 误解 H：「IF 组合可以当 TEC 图用」

**纠正：** IF 为测距服务；画 TEC 走几何无关（02）。菜谱相反。

### 误解 I：「所有怪残差都怪电离层」

**纠正：** 先问频率与模式，再问空间天气，再问 QC（多路径、周跳、可用星）。误差是一桌菜。

### 误解 J：「TEC 高 = RTK 一定挂」

**纠正：** RTK 怕的是**站间梯度与闪烁**，不是绝对 TEC 高低。两站同泡在均匀高 TEC 雾里，差分仍可香；低 TEC 但锋面卡在基线中，照样痛。

### 误解 K：「PPP 收敛慢就是电离层没改好」

**纠正：** 先看周跳/ROTI/可用星。跟踪崩盘导致的重收敛锯齿，再调 Klobuchar 或换 GIM 也救不了；那是 05 课的账。

### 误解 L：「映射函数随便用，差不了多少」

**纠正：** 低仰角 $M$ 陡增，改正误差一同放大。壳高、映射公式、截止角三问不清，就没有资格抱怨「GIM 不准」。

## 18. 课堂测验（带演算）

**题 2.** 写出 $I(f)=40.3\,\mathrm{STEC}/f^{2}$。STEC 固定，$f$ 加倍，$I$ 如何变？

### 参考要点

1. **改**；单频不能靠经典 IF 魔术消除。  
2. $I\propto 1/f^{2}$ → $f$ 加倍则 $I$ 变为 1/4。  
3. 约 $2.55\,P_1-1.55\,P_2$；一阶 $I_{\mathrm{IF}}\to 0$。  
4. $\sigma_{\mathrm{IF}}\sim 3\times 0.3\approx 0.9\,\mathrm{m}$ 量级。  
5. $\mathrm{STEC}=30\,\mathrm{TECU}$；$I_1\sim 40.3\times 3\times10^{17}/f_1^{2}\approx 5\,\mathrm{m}$ 量级。  
6. 近距公共延迟相似；距离大或暴时公共性变差。  
7. 消：IF；估：STEC 参数；增强：外部电离层/SSR 先验。  
8. 闪烁崩盘（跟踪层）。  
9. GIM 工具链与「解坐标」是不同产品目标。  
10. 如 `RTKLIB`、`gLAB-UPC`、`PRIDE-PPPAR`、`ginan`（答三即可）。  
11. 坐标→IF/RTK/PPP；大气→GF/GIM；IF 权重为消 $I$ 留 $\rho$，GF 相反。  
12. TEC 差 $\sim 0.05\times 40\times 2=4\,\mathrm{TECU}$ → $I_1\sim 0.65\,\mathrm{m}$ 量级。  
13. 参见 §14.1 / §15.3 失败模式表（任答合理即可）。
