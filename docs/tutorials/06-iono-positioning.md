# 06 · 定位里怎么处理电离层？（单频 / 双频 / PPP / RTK）

> 读本讲前，建议具备：伪距与载波的直觉、TEC 会带来延迟的概念（[01](./01-ionosphere-tec-basics.md)）、双频能组合出「与几何无关」量的印象（[02](./02-gnss-dualfreq-tec.md)）。本讲**刻意少写方程**，优先建立「什么时候改、什么时候消、什么时候估」的决策树。

先问两个分流问题：

1. **你的接收机几个频率？**（单频 / 双频 / 多频）  
2. **你要米级，还是分米/厘米级？**（导航大概、测绘精密、科研 PPP）

电离层在伪距上可以造成**数米到数十米**量级的误差（取决于 TEC、仰角、频率）。定位软件必须对电离层有态度，常见三种态度——可以组合使用：

| 态度 | 人话 | 典型场景 |
|---|---|---|
| **改正它** | 用模型或外部图，把延迟减掉一部分 | 单频手机/手持、广播改正 |
| **消掉它** | 双频组合让一阶电离层项抵消 | 双频精密测距、经典 PPP |
| **估出来** | 把每颗星的电离层当未知数，和位置一起解 | 非差非组合 PPP、大气科研 |

还有第四种在工程里极常见：**差分掉它**（RTK/短基线）——两站看同一片天，相减后公共延迟大幅削弱。

---

## 1. 先建立画面：雾、两只眼睛、两支队伍

把电离层想成卫星与接收机之间的一层「电子雾」：

- 雾越浓（TEC 越大），伪距越容易「量长」一截（对码伪距的一阶效应）；  
- 载波相位也会被影响，但符号/解释与伪距不同——本讲只要你记住：**电离层是定位误差源之一，而且与频率有关**。

类比：

1. **单频**像闭上一只眼看世界：只能靠「天气预报」（模型）猜雾有多厚。  
2. **双频**像两只眼睛：利用「不同颜色的光穿雾时延迟不同」这一性质，构造组合去消雾或测雾。  
3. **RTK**像两个人手拉手走：雾对两人差不多，差分后雾的公共部分抵消。  
4. **PPP**像一个人在野外精密测距：靠精密轨道钟差 + 消雾或估雾，慢慢收敛到高精度。

## 2. 单频：只能「改正」，不能「魔术消除」

只有一个频率时，做不了经典的几何无关/无电离层双频戏法，选项主要是：

### 2.1 广播模型（跟着卫星电文走）

- **GPS：Klobuchar**  
  - 是什么：导航电文里播发的 **8 参数**电离层模型，粗、快、全球可用。  
  - 直觉：像一份「全球平均雾况简报」，不是当地雷达。  
  - 预期：好的时候能改掉相当一部分平均延迟，**残差仍在**；暴时、低纬、黎明黄昏，简报更容易离谱。  
  - 本目录条目：`Klobuchar-study-code`（见 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md)）。

- **Galileo：NeQuick-G**  
  - 是什么：Galileo 单频电离层改正采用的 NeQuick 族算法（官方实现面向改正，不是科研画全球图的唯一答案）。  
  - 与「科研用 NeQuick2 / IRI」的关系见 [04-iri-nequick.md](./04-iri-nequick.md)：名字像亲戚，**用途与输入参数不要混用**。  
  - 本目录：`Galileo-NeQuick-G`、`NequickG`、`NeQuickG-ESSR` 等。

### 2.2 外源格网（GIM / IONEX）

若你能联网拿到全球或区域电离层图（IONEX），可在穿刺点插值 **VTEC**，再映射成斜路径延迟。这比广播模型细，但需要：

- 可靠的产品源（如 `CDDIS-IONEX`、`JPL-IONEX-Rapid`）；  
- 读图工具（如 `ionex`、`ionex-rs`、`ionex_reader`）；  
- 映射函数与时间插值的纪律（见第 03 讲）。

### 2.3 单频课堂预期（写进实验报告）

> 单频模型改正后，残差仍在，**不能指望达到双频无电离层组合的水平**。  
> 它解决的是「别裸奔」，不是「厘米级免检」。

---

## 3. 双频：无电离层组合（ionosphere-free）——为测距服务

双频伪距（或相位）可以组成 **无电离层组合**（ionosphere-free，常简称 IF）：利用延迟与频率平方近似成反比的一阶关系，加权组合后让一阶电离层项抵消，几何距离留下。

### 3.1 人话版

两只眼睛看到的「雾的影响」不一样。你把两路测量按特定权重加减，让雾的一阶效应对消，专门服务**精密测距**。

注意目标：

- IF 组合的目的是 **更好的距离观测**；  
- 它**不是**用来画 TEC 图的（画 TEC 用的是另一类「几何无关 / 几何无关 TEC 组合」，见第 02 讲）。

### 3.2 代价清单（考试爱考）

1. **噪声被放大**：组合后测量更「吵」。  
2. **更高阶项仍可能残留**：一阶消了，不等于电离层物理学毕业。  
3. **偏差与硬件效应**：差分码偏差等议题在精密应用里仍会冒头（见 [09-dcb-biases-deep.md](./09-dcb-biases-deep.md)）。  
4. **你得到更好的距离，不是一张电子密度照片。**

### 3.3 和「估 TEC」的分叉路口

```
双频观测
   ├─► 无电离层组合 ──► 服务定位（消延迟）
   └─► 几何无关组合 ──► 服务 TEC（测雾厚）
```

同一套 RINEX，两条科研/工程路。选题时先问：我要坐标，还是要电离层产品？

## 4. RTK：差分把公共电离层「削薄」

**RTK（Real-Time Kinematic）** 直觉：流动站 + 基准站，利用载波相位差分，把公共误差削弱，追求快速厘米级（在条件允许时）。

### 4.1 为什么短基线电离层不那么可怕？

两站距离近时，它们看向同一颗卫星的路径穿过的电离层「差不多」。**站间差分**后，公共延迟大幅抵消。像两个人在同一间有雾的房间用同一把尺子——雾对两人一样偏，相减就消。

### 4.2 什么时候电离层又回来找麻烦？

- **基线变长**：两站雾况不再一样，残余电离层上升；  
- **空间天气暴时 / 强闪烁**：即使短基线，快速起伏与周跳也会让模糊度难固定；  
- **网络 RTK / 区域增强**：用多个参考站或区域大气产品约束残余。

电离层在 RTK 叙事里常常是「差分后的残余敌人」，软件不一定单独输出 TEC 产品——但暴时值班仍要懂电离层，否则只会骂接收机。

本目录定位套件入口：[`lists/04-gnss-positioning.md`](../../lists/04-gnss-positioning.md)，例如 `RTKLIB`、`pyrtklib`、`gLAB-UPC`、`PRIDE-PPPAR`、`ginan` 等。

## 5. PPP：一个人在野外，怎么对付雾？

**PPP（Precise Point Positioning，精密单点定位）** 直觉：不依赖近旁基准站，而依赖精密卫星轨道、钟差等产品，在单站上把位置解到高精度（常需收敛时间）。

电离层策略（教学版，三种）：

| 策略 | 直觉 | 注释 |
|---|---|---|
| 双频无电离层组合 | 先把一阶雾消掉，再精密测距 | 经典 PPP 常见入口 |
| 非差非组合 / 估 STEC | 每颗星的电离层当参数慢慢估 | 可加 GIM 约束或随机游走；科研向 |
| 增强改正 | 用区域电离层/SSR 等当先验 | 接近「带大气补丁的 PPP」 |

### 5.1 不要被套件吓到

开源定位工程里，电离层模块往往**嵌在大仓库中**，不是单独一个 `iono.exe`。你在本目录的正确打开方式是：

1. 先在 [`lists/04-gnss-positioning.md`](../../lists/04-gnss-positioning.md) 选套件（`RTKLIB`、`gLAB-UPC`、`PRIDE-PPPAR`、`ginan`…）；  
2. 再读其文档里「Ionosphere / Atmospheric / IF combination」章节；  
3. 若你其实只想要 TEC 图，请回 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md)，不必先把整套 PPP 跑通。

### 5.2 PPP 与闪烁

PPP 再精密，也怕跟踪层崩溃。第 05 讲的闪烁/ROTI 在这里表现为：收敛变慢、周跳、重收敛。延迟模型完美，救不了失锁。

## 6. 决策树：选题时怎么选改正策略？

```
只要 TEC 产品 / 空间天气图
  └─► 走 lists/01-ionosphere（TEC/GIM），不必先上全套 PPP

单频手持 / 教学演示
  └─► Klobuchar 或 NeQuick-G（广播模型）；有条件再叠加 GIM

双频精密测距（坐标为主）
  └─► 无电离层组合（+ 必要的偏差/产品）

短基线工程 RTK
  └─► 差分；关注暴时残余与闪烁

长基线 / 网络 RTK
  └─► 区域大气约束、网络产品；不要幻想「差分万能」

科研 PPP / 想顺带出 STEC
  └─► 估电离层或引入 GIM 约束；明确你的主产品是坐标还是大气
```

## 7. 把「误差预算」说成人话

定位误差像一桌菜，电离层只是其中一碟：

- 卫星轨道与钟差；  
- 对流层（中性大气延迟）；  
- 电离层；  
- 多路径与天线相位中心；  
- 接收机噪声与偏差；  
- 地球潮汐、相对论……（精密到一定程度才显眼）

初学者常见偏执：**所有怪现象都怪电离层**。更健康的习惯是：

1. 先问频率与模式（单频/双频、SPP/RTK/PPP）；  
2. 再问空间天气（平静还是暴？有没有闪烁？）；  
3. 再问数据质量（周跳、多路径、可用星）。

本目录质量检查可参考 `Anubis`、`TEQC`、`georinex`（[`lists/03-gnss-data.md`](../../lists/03-gnss-data.md)）。

## 9. 常见误解（Misconceptions）

### 误解 A：「我开了双频，电离层就等于零了」

**纠正：** 无电离层组合消的是**一阶**项；噪声放大、高阶、偏差、闪烁导致的跟踪问题都还在。

### 误解 B：「Klobuchar 改完就该和双频一样准」

**纠正：** 广播模型是粗改正。课堂实验若得到「差不多”，多半是平静中纬运气好，或你看的指标太粗。

### 误解 C：「RTK 很准，所以电离层不存在」

**纠正：** 短基线差分把公共部分削了；长基线与暴时残余会回来。准是有条件的准。

### 误解 D：「PPP 一定要先估 TEC」

**纠正：** 经典双频 IF-PPP 可以不显式输出 TEC。估 TEC 是策略之一，不是宗教。

### 误解 E：「GIM 代入定位，就等于做了区域精密大气」

**纠正：** 全球图平滑、时间分辨率有限。区域强梯度、闪烁、本地扰动仍可能打穿你的预期。

### 误解 F：「定位套件里找不到单独 iono 程序 = 本目录没覆盖」

**纠正：** 电离层常嵌在 `RTKLIB` / `gLAB-UPC` / `ginan` / `PRIDE-PPPAR` 等大工程；请按列表读套件，而不是只搜文件名 `iono`。

### 误解 G：「NeQuick-G 和 IRI 调同一组参数就行」

**纠正：** 广播改正与科研气候学模型的输入、用途、版本流程不同。详见第 04 讲，勿混用开关。

## 14. 把「频率」说得更慢一点（零假设补课）

有同学卡在：「为什么双频能消电离层，单频不能？」用极慢的步骤：

1. 电离层对 GNSS 码伪距的一阶影响，大致随 **1/频率²** 变化。频率不同，同一条路径上的「雾造成的额外长度」不同。  
2. 单频只有一个测量方程，你既不知道真正的几何距离，也不知道雾有多厚——两个未知搅在一起，除非引入**外部模型**（Klobuchar/NeQuick-G/GIM）把雾「借」一个值过来。  
3. 双频有两个测量，雾在两个频率上的一阶表现成固定比例关系。于是你可以：  
   - 做线性组合，让雾的一阶系数变成 0 → **无电离层组合**（为距离服务）；或  
   - 做另一种组合，让几何消掉，留下与 TEC 成比例的量 → **几何无关组合**（为 TEC 服务）。  

这就是为什么第 02 讲和第 06 讲必须分家：同样是双频，**组合目的不同**。

类比：两道菜都用「盐和糖」，一道菜的目标是把甜味抵消只留咸感，另一道是把主菜味道去掉只测糖量——配料相同，菜谱相反。

## 15. 映射函数：GIM 改正时最容易踩的坑

单频或 PPP 约束若使用 GIM，流程往往是：

1. 从接收机与卫星方向找到**穿刺点**（ionospheric pierce point，信号穿「薄壳」的位置）；  
2. 在 IONEX 格网上内插该点的 **VTEC**；  
3. 用映射函数把垂直量换成斜路径延迟。

课堂常见事故：

- 用了产品时刻错误的图（快速/最终、时间标签）；  
- 仰角很低时映射很敏感，改正噪声变大；  
- 把「改完还有残差」全部怪罪产品，其实低仰角几何本身就脆。

读图工具仍是 `ionex`、`ionex-rs`、`ionex_reader`；数据入口 `CDDIS-IONEX`、`JPL-IONEX-Rapid` 等。细节见第 03 讲。

## 18. 小结卡片

- **改**：模型/GIM 给单频一条生路。  
- **消**：双频 IF 为一阶延迟服务。  
- **差**：RTK 削公共雾，基线与天气决定残差。  
- **估**：PPP/科研把 STEC 当参数。  
- **抖**：闪烁走跟踪层，另案处理。
