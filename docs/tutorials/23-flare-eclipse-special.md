# 23 · 太阳耀斑与日食专题：突发 TEC 增强与 TEC「空洞」怎么分析

> **课堂定位**：现象分析专题第 5 课（19–23 收官）。前置：[19](./19-phenomena-overview.md)、[20](./20-storm-tec-analysis.md)、[22](./22-tid-traveling-disturbances.md)。  
> **学完应能**：描述耀斑引起的突然电离层扰动在 GNSS TEC 上的签名；描述日食 TEC「洞」的分析思路；按配方使用高采样 GNSS；判断何时闪烁指标重要、何时几乎不相干。  
> **本课不是**太阳物理课，也不要求你会预报耀斑。

## 1. 开场：两种「太阳改写电离层」的剧本，时间尺度完全不同

| 剧本 | 太阳侧 | 电离层侧常见 GNSS 签名 | 钟表 |
|---|---|---|---|
| **耀斑** | 软 X 射线/EUV 突增 | 日侧 TEC **突然抬升**（SID 家族相关） | 分钟级起跳 |
| **日食** | 月球挡光，局部 EUV 减少 | 食带附近 TEC **下降形成空洞** | 随食相，约数十分钟～数小时 |
| （对照）磁暴 | 常经磁层耦合 | 正负相分区，可持续一天以上 | 见 20 课 |

类比：

- 耀斑像**摄影棚突然把主灯打到最大**：被光照到的半边（日侧）立刻亮。  
- 日食像**有人举着遮光板沿一条路径走过**：板下变暗，板外仍亮。  
- 磁暴像**整栋楼的中央空调被台风重设**：各楼层反应慢且不同。

### 1.1 为什么强调「高采样 GNSS」？

标准 IGS GIM 常常 1–2 小时一帧。耀斑 TEC 可在几分钟到十几分钟内完成主要跳变；日食洞的边缘移动也需要更好的时间分辨率来对齐食相。  
因此本课主兵器是：**高采样（如 1 Hz / 30 s）单站或区域网 TEC 时间序列**，GIM 只作背景或「有没有大洞」的粗看。

数据与产品入口（`PROJECTS.json` 的 `name`）：`CDDIS-IONEX`、`NOAA-SWPC`、`NASA-OMNIWeb`、`Seemala-GPS-TEC`、`tec-suite`、`gnss-tec`、`IONOLAB-TEC-Software`、`mitiono`、`Okoh-MATLAB-TEC-from-RINEX`、`OASIS`、`SuperSID`、`geospacelab`、`pysatSpaceWeather`。

## 3. 耀斑：突然 TEC 增强的现象分析

### 3.1 观测签名四件套

1. **形态**：日侧多站 TEC 近乎同步上跳；夜侧弱或无。  
2. **时间**：与 X 射线通量上升同量级对齐。  
3. **空间**：依赖太阳天顶角；近太阳下点附近往往更清楚（直觉）。  
4. **多仪器**：VLF/短波 SID、测高仪、GNSS；本课以 GNSS 为主。  

对照 22 课：耀斑是**同步抬升**，不是 keogram 斜纹。

### 3.2 逐步清单 —— 耀斑套（请打勾）

#### F1 事件钉钉

- [ ] 从 `NOAA-SWPC` 记下耀斑等级、峰值 UTC  
- [ ] 研究区是否处于日侧？夜侧作业要降期望  
- [ ] 可选：用 `NASA-OMNIWeb` / `pysatSpaceWeather` 看是否同日有暴  

#### F2 选站与采样

- [ ] 选日侧若干站；声明采样率（目标 ≤30 s，有 1 Hz 更好）  
- [ ] TEC 工具：`Seemala-GPS-TEC`、`tec-suite`、`gnss-tec`、`IONOLAB-TEC-Software`、`mitiono`、`Okoh-MATLAB-TEC-from-RINEX`、`pygnss-tec`  

#### F3 对照曲线

- [ ] 画 X 射线通量与 TEC 同轴  
- [ ] 标峰值竖线  

#### F4 同步性检验

- [ ] 多站 TEC 是否同相跳？  
- [ ] 若出现明显站间延迟斜纹，标注「可能叠加 TID」，勿全部归因耀斑  

#### F5 幅度与天顶角

- [ ] 记录 ΔTEC（峰前基线 → 峰）  
- [ ] 讨论太阳天顶角  

#### F6 假象排除

- [ ] 接收机钟跳、周跳、数据空洞？  
- [ ] 是否其实是磁暴主相巧合？（SYM-H）  

#### F7 闪烁？

- [ ] 默认可不看 S4；除非同时有强不规则报告  
- [ ] 若要看：`scintkit`、`ismr_downloader`、`ScintPi-1.0-Software`——并写「非本事件主签名」  

#### F8 可选 SIDX / VLF

- [ ] `OASIS` 的 SIDX 类指数（以该仓 README 为准）可作 GNSS 侧耀斑敏感指数  
- [ ] `SuperSID` 作 VLF 旁证  

#### F9 结论模板

> UTC【】发生【等级】耀斑（来源 `NOAA-SWPC`）。日侧站网 TEC 在峰值附近出现【同步】增强，幅度约【】TECU（采样【】）。夜侧【无/弱】。SYM-H【是否叠加暴】。闪烁指标【未用/无显著】。置信度【】。工具 name：【】。

### 3.3 耀斑常见误解

1. **X 级必有巨大 TEC 跳** — 还看日面位置、光谱、季节、本地天顶角。  
2. **GIM 两小时图能精细对齐耀斑峰** — 常常不能。  
3. **夜侧大跳也是耀斑光电离** — 优先查数据错误或其他驱动。  
4. **耀斑 = 闪烁事件** — 通常不是同一现象。  
5. **把缓慢日变化当耀斑** — 无分钟级对齐就降置信。

## 4. 日食：TEC「空洞」的现象分析

### 4.1 图像

遮光板扫过 → 光电离减弱 → TEC 下降 → 出现**相对周围的低值区**，并随食带移动。不是永久洞，而是**暂时、局地、跟随食相**。

### 4.2 逐步清单 —— 日食套

#### E1 几何钉钉

- [ ] 日食日期、类型（全食/环食/偏食）、最大食分路径  
- [ ] 研究站相对食带：中心 / 边缘 / 食带外  

#### E2 对照策略

- [ ] 方案 Q：邻近日同站同 LT  
- [ ] 或同日食带外站对照  
- [ ] 写明不能用「另一季节」硬比  

#### E3 高采样 TEC

- [ ] 食前–食中–食后连续曲线  
- [ ] 标出初亏、食甚、复圆时刻竖线  
- [ ] 工具同 F2 列表  

#### E4 空间形态（若有网）

- [ ] 区域 TEC 图或多站剖面：洞是否沿食带？  
- [ ] GIM（`CDDIS-IONEX`）可看大尺度洞，时间粗；读写 `ionex`/`ionex-analyzer`/`DiffIonMap`  

#### E5 与气候模型的边界

- [ ] 可用 `iri2020` / `IRI-2020-package` 看「无日食气候期望」作对照，但**勿把 IRI 当日当真理**  
- [ ] 观测 − 对照 才是日食洞证据  

#### E6 闪烁？

- [ ] 多数教学日食分析**不需要**闪烁  
- [ ] 默认结论不要写 S4  

#### E7 假象

- [ ] 别把光学「阴天」写进 TEC 因果  
- [ ] 磁暴巧合、仪器维护、站网空洞  

#### E8 结论模板

> 【日食日期】在【站/区】，食甚【UTC】。相对【对照】，VTEC 下降约【】TECU，极小值【领先/落后/接近】食甚【】。空间上【与食带一致/数据不足】。未将闪烁作为主证据。name：【】。

## 5. 何时闪烁指标「重要」或「不重要」？

| 情境 | 闪烁/ROTI | 原因 |
|---|---|---|
| 耀斑 TEC 突增主分析 | 通常不重要 | 主签名是整柱同步增强 |
| 日食 TEC 洞主分析 | 通常不重要 | 主签名是相对缓慢的耗空 |
| 低纬夜侧泡 | 重要 | 见 21 课 |
| 暴时高纬不规则 | 可能重要 | 另题 |
| 导航完好性专题 | 重要 | 用户关心失锁 |

口令：*耀斑看跳，日食看洞，闪烁看抖；别拿抖的尺子量跳与洞。*

## 13. 加厚：误解与假勤奋

1. 用 IRI 输出冒充观测对照却不声明。  
2. 只给全食美学照片，无 TEC 数字轴。  
3. 耀斑结论写「全球 TEC 升」却只有一个站。  
4. 把采样 2 小时的产品画成「尖峰」。  
5. 日食夜侧站硬做「光电离洞」。

## 14. 加厚：多源一致性（耀斑）

## 19. 附录：把「高采样」落到具体文件动作

1. 确认 RINEX 的 INTERVAL 或采样设置。  
2. 若只有 30 s 数据，不要声称分辨 5 s 结构。  
3. 绘图横轴 UTC，竖轴 TECU，事件竖线用虚线。  
4. 导出 CSV：时间、站名、VTEC、（可选）卫星号、IPP。  
5. 备份原始图与处理路径——复现大于一次漂亮截图。

## 20. 附录：耀斑日面位置为何影响响应（直觉级）

同样是 X 级，若爆发靠近日面边缘，到达地球的电离辐射几何与细节可能不同；电离层响应幅度不必与「等级字母」单调绑定。报告应写「等级 + 时间 + 本地天顶角」，而不是只写「X 级所以巨大」。

---

## 21. 附录：日食「恢复」阶段也要画

很多作业只截食甚附近。恢复相能告诉你：洞是否随光电离恢复而回填，是否叠加了别的扰动。把复圆后 1–2 小时仍画上，结论更稳。

## 22. 扩展测验

**Q7.** 为什么「摄影棚主灯」类比适合耀斑而不适合磁暴？  
**Q8.** 日食分析中，食带外对照站的作用？  
**Q9.** 若耀斑峰值时刻 TEC 无跳，优先列哪三个检查？  

**A7.** 耀斑电磁辐射几乎立刻影响日侧；磁暴经太阳风-磁层耦合，响应更慢且分区。  
**A8.** 提供「无挡光」的同时段基线，分离日变化与食致效应。  
**A9.** 是否在夜侧；采样是否过粗；数据是否周跳/中断；以及天顶角是否导致弱响应。

## 27. 课堂板书：一张时间轴画两种事件

## 31. 口试三题（收官必过）

1. 用一分钟说明：为什么耀斑课默认不看闪烁，却必须看采样率？  
2. 画出日食分析的「事件日 − 对照」逻辑，并指出一种错误对照。

**参考答：**  
1. 主签名是整柱电子含量的同步增强，不是小尺度散射；但跳变发生在分钟尺度，粗产品会对不齐。  
2. 同站邻近日或同日食带外；错误例：用另一季节、或只用 IRI 气候场冒充对照。  
3. 看站间是否有系统性延迟斜纹；耀斑应近同步，TID 有行进延迟。
