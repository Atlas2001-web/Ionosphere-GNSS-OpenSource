## 1. 开场：两种「太阳改写电离层」剧本，钟表完全不同

| 剧本 | 太阳侧 | 电离层侧 GNSS 签名 | 钟表 |
|---|---|---|---|
| **耀斑** | 软 X 射线/EUV 突增 | 日侧 TEC **突然抬升**（SID 家族） | 分钟级起跳 |
| **日食** | 月影挡光，局部 EUV 减少 | 食带附近 TEC **下降成洞** | 随食相，数十分钟～数小时 |
| （对照）磁暴 | 经磁层耦合 | 正负相分区，可持续一天以上 | 见 20 课 |
| （对照）TID | 常 AGW/电动力学 | δTEC 斜纹延迟 | 见 22 课 |

类比：

- 耀斑像**摄影棚主灯突然打到最大**：被照到的半边（日侧）立刻亮。  
- 日食像**遮光板沿路径扫过**：板下变暗，板外仍亮。  
- 磁暴像**中央空调被台风重设**：各楼层反应慢且不同。

### 1.1 为什么本课把「采样率」提到与机制同等重要？

标准 IGS GIM 常 1–2 小时一帧。耀斑 TEC 可在几分钟到十几分钟内完成主要跳变；日食洞边缘与食相对齐也需要更好时间分辨率。  
**主兵器：高采样（目标 ≤30 s，有 1 Hz 更好）单站或区域网 TEC 时间序列**；GIM 只作背景或「有没有大洞」的粗看。

## 3. 物理原则深讲（一）：耀斑 EUV/X 射线突然电离

### 3.1 能量从光子到电子——因果链主轴

口诀「焰–谱–照–产–层–柱–跳」：

1. **焰**：太阳局部爆发，软 X 射线与 EUV 辐射通量在短时间内陡升（GOES 等监测 SXR；EUV 亦增强）。  
2. **谱**：不同波长沉积在不同高度——硬一些的 X 射线更易影响较低高度（D/E），EUV 对 E/F 区电离至关重要（课堂记「波段决定层高」）。  
3. **照**：光子只有效作用于**日侧**大气；夜侧几乎收不到这对「突然照明」。  
4. **产**：光电离产生率 $q$ 随通量上升而猛增：中性成分被电离 → 电子密度 $N_e$ 上升。  
5. **层**：E 区与 F 区（及 D 区对短波吸收）均可响应；对 GNSS TEC 而言，**F 区柱贡献往往最大**，但 E 区增强也计入整柱。  
6. **柱**：路径积分电子含量 STEC/VTEC 上升。  
7. **跳**：时间序列上表现为相对基线的**突然抬升**，主跳变常在分钟到十几分钟尺度与 X 射线上升同量级对齐。

### 3.2 为何是「突然」而不是「像磁暴那样拖一天」？

电磁辐射以光速到达地球，日侧大气几乎立刻开始被额外电离。磁暴则要经太阳风–磁层–热层多级耦合，时间尺度更长且分区复杂。故耀斑类比用「主灯」，磁暴用「中央空调重设」。

### 3.3 日侧约束与天顶角 χ

产生率大致随太阳辐射在当地的有效照射变化。太阳天顶角 χ 大（太阳低）时，辐射斜穿，电离路径更长、到达 F 区有效通量几何更不利，**同样 X 级耀斑在晨昏或高纬度日侧边缘的 TEC 跳可能更弱**。夜侧若见「大跳」，优先查周跳、钟跳、数据空洞或其他驱动，而不是硬解释为耀斑光电离。

### 3.4 日面位置与等级字母的诚实关系

同样是 X 级，爆发靠近日面边缘时，到达地球的电离辐射几何与细节可能不同；EUV 与 SXR 的相对贡献也不总与「字母等级」单调绑定。报告应写：**等级 + 峰值 UTC + 研究区是否日侧 + 粗略天顶角直觉**，而不是只写「X 级所以巨大」。

### 3.5 与 SID 家族的关系

突然电离层扰动（SID）是一族现象：短波吸收（D 区）、VLF 相位/振幅异常、GNSS TEC 突增等。本课主做 GNSS TEC；旁证可用 `SuperSID`（VLF）与 `OASIS` 的耀斑敏感指数（以 README 为准）。多源一致可升置信度；缺旁证仍可用高质量 GNSS 对齐及格。

### 3.6 耀斑 vs TID：同步跳还是斜纹？

耀斑日侧多站 TEC **近乎同相**上跳（全体起立）。TID 是 keogram **斜纹**（人浪）。若跳变后叠加行进波，分节写：「耀斑主跳 + 可能叠加 TID」，勿全部归因单一标签。

### 3.7 闪烁为何默认不看？

耀斑主签名是整柱电子含量的同步增强，不是小尺度散射。除非同时有强不规则报告，否则 S4 不是本事件主证据。口令：*耀斑看跳，不看抖。*

## 4. 物理原则深讲（二）：日食光化学——冷却、复合与 TEC 洞

### 4.1 核心图像：遮光板扫过

月球挡住部分太阳圆面 → 到达当地的 EUV/可见光相关电离辐射减弱 → **光电离产生率 q 下降**。电子密度由产生与损失共同决定。q 突然变小时，原有的复合与其他损失过程相对占优，$N_e$ 下降 → TEC 出现相对周围的低值区，并随食带移动——这就是 **TEC「空洞」**。它不是永久洞，而是**暂时、局地、跟随食相**。

### 4.2 因果链（请背）

口诀「挡–q↓–损显–Ne↓–洞–移–复」：

1. **挡**：食分增大，当地有效太阳辐射下降；  
2. **q↓**：光电离产生率下降（E/F 区尤为关键）；  
3. **损显**：复合等损失过程相对变「显眼」（产生不再补得上）；  
4. **冷却直觉**：挡光亦减少加热，热层/电离层温度可下降，进一步影响尺度高、反应速率与中性密度——教学上记「冷却可加强耗空趋势」，定量细节非本课必算；  
5. **Ne↓ / TEC↓**：形成相对对照的空洞；  
6. **移**：洞随月影/食带在地表投影移动；  
7. **复**：复圆后辐射恢复，q 回升，TEC 逐渐回填（恢复相也要画！）。

### 4.3 为何必须有对照？

绝对 TEC 仍有正常日变化。没有「事件日 − 对照」（邻近日同 LT，或同日食带外站），你无法分离「平常下午本来就会降一点」与「食致额外下降」。错误对照：跨季节硬比；只用 `iri2020` 气候场冒充观测对照且不声明。

### 4.4 食甚与 TEC 极小值：允许小延迟

TEC 极小值常接近食甚，但不必零延迟：层高响应、复合时间尺度、多站几何都会造成数分钟级偏移。结论写「极小值接近食甚，延迟约 …（受采样限制）」，不要为了「完美对齐」而改时间轴。

### 4.5 日食 vs 负相风暴 vs 泡

| | 日食洞 | 中纬风暴负相 | 赤道泡 |
|---|---|---|---|
| 驱动 | 挡光→q↓ | 成分/风等（20） | R–T（21） |
| 空间 | 跟食带 | 中纬宽带 | 夜侧低纬通道 |
| 时间 | 对齐食相 | 对齐 SYM-H | 日落后窗 |
| ROTI | 通常非主签名 | 可高可不高 | 壁上常高 |

### 4.6 闪烁默认放下

多数教学日食分析不需要 S4。主签名是相对缓慢的耗空与回填。

## 5. 时间线分析总则（本课方法核心）

无论耀斑还是日食，都强制三条竖线思维：

1. **驱动竖线**：GOES 峰值，或初亏/食甚/复圆；  
2. **响应竖线**：TEC 跳变中点或极小值时刻；  
3. **排除竖线**：SYM-H 是否在讲另一个故事。

把三者画在同一 UTC 轴上。这就是「时间线分析」。缺少驱动竖线的漂亮 TEC 曲线，本课按不及格处理。

## 13. 课堂 60+60：耀斑与日食各一节

## 14. 光化学板书课（原则加厚，35 分钟）

### 14.1 稳态直觉（极简）

大致有「产生 ≈ 损失」的平衡图像。耀斑让产生项突然变大 → 平衡被打破 → Ne 升到新水平。日食让产生项突然变小 → Ne 降。TEC 是 Ne 的高度积分影子。

### 14.2 D/E/F 分层响应（课堂级）

- **D 区**：X 射线可显著增强吸收 → 短波中断；对 TEC 柱贡献相对小，但对 SID 家族重要。  
- **E 区**：EUV/X 均可；耀斑时可明显增强。  
- **F 区**：EUV 关键；对 TEC 跳与日食洞往往贡献最大。  

分析 GNSS TEC 时写「整柱响应」，不要假装分辨了每一层，除非有测高仪/掩星。

### 14.3 日食「冷却」如何进叙述？

挡光减少加热 → 温度下降可改变化学反应速率与中性结构，往往使耗空「更好解释」或略加深。作业允许写：「除 q↓ 外，冷却可能叠加；本分析未独立分离冷却项。」——诚实加分。

### 14.4 时间线草图作业

## 35. 突然电离的高度分工：把「焰谱照产」讲细

老师追问时常问：「耀斑到底电离哪一层？」用下面分层表回答，并强调 GNSS TEC 是**整柱**：

| 层 | 主要相关辐射直觉 | 典型可观测后果 | 对 TEC 柱 |
|---|---|---|---|
| D | 较强 X 射线分量 | 短波吸收、部分 SID | 贡献通常较小 |
| E | EUV + X | 测高仪 E 迹变化、部分 TEC | 中等可能 |
| F | EUV 关键 | foF2/TEC 跳的大头常在此 | **往往最大** |

因果加细：

1. 光子能量决定能电离哪种中性成分、沉积在哪一光学深度；  
2. 较低高度中性密度大，短波 X 射线可在此被强烈吸收 → D/E 响应；  
3. EUV 在更高处仍有效电离 → F 区电子增加；  
4. TEC = ∫Ne dh，故 F 区几个百分点的增强就可造成数 TECU 跳变。

**作业措辞**：写「日侧整柱 TEC 同步增强，符合 E/F 区突然电离图像」；若无测高仪，不要宣称「纯 F 区」或「纯 E 区」。

### 35.1 产生率 q 的最小公式直觉（不要求计算）

象征性写：

$$
q \propto n_n \cdot \sigma \cdot F_\lambda \cdot f(\chi)
$$

其中 *n_n* 中性密度，$\sigma$ 电离截面，$F_\lambda$ 该波段通量，$f(\chi)$ 为天顶角几何因子（χ→90° 变弱）。耀斑时 $F_\lambda$ 陡升；日食时有效 $F_\lambda$ 下降。这就是两套剧本共用的「水龙头旋钮」。

## 36. 日食光化学细讲：复合、时间尺度与「为何不是瞬间空」

### 36.1 损失项不是「一键清空」

电子损失有多种路径（与离子种类、中性成分有关）。日食时 q 下降，Ne 按有效损失时间尺度逐渐降，而非光速变零。故 TEC 洞呈**光滑 U 形谷**，宽度与食分演变相当，而不是 δ 函数尖刺。

### 36.2 冷却如何进入因果链（候选级）

挡光 → 加热减少 → 温度下降 →（可能）改变化学速率系数、中性密度尺度高、甚至风场微调。这些可让 Ne 下降比「只关水龙头」更复杂。分析结论推荐句：

> 「主链为 q↓ 后损失占优；热层冷却可能叠加，本工作未用温度观测分离该项。」

### 36.3 食带边缘站为何洞更浅？

食分小 → 有效辐射降得少 → q 降幅小 → 洞浅。带外对照站应接近「无挡光」。若带外站也出现同等深谷，对照策略或叠加事件（暴）有问题。

### 36.4 偏食/环食/全食

挡光程度不同，q↓ 幅度不同。教学上仍用同一条链，只是期望洞深不同；不要把偏食硬写成「电离层消失」。

## 38. 多站同步性的定量小工具（教学）

```python
def sync_score(series_list, t0_idx, half_win=5):
    """各站在窗口内是否同向增长：返回同向站比例。非发表级指标。"""
    signs = []
    for s in series_list:
        d = s[t0_idx+half_win] - s[t0_idx-half_win]
        signs.append(1 if d > 0 else -1)
    return signs.count(1) / len(signs)
```

耀斑期望 sync_score 接近 1（日侧）。若得分低且呈纬度递变延迟，转 22 课检查 TID 叠加。
