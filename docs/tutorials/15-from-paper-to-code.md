# 15 · 从论文到开源：别只收藏 PDF

## 读电离层论文的「落地四问」

1. 观测是什么？RINEX / IONEX / 测高仪 / 掩星 / 闪烁接收机？
2. 核心算法是现成库还是作者自研？有没有 GitHub/Zenodo？
3. 评价图能否用公开 IGS 站复现？
4. 本仓库 [`PROJECTS.json`](../../PROJECTS.json) 里有没有同任务软件可替代？

## 推荐动作顺序

```
读摘要与数据章节
  → 在本目录 lists/ 搜关键词（TEC、IONEX、ROTI、IRI…）
  → 克隆上游最小例子
  → 先复现「量级与形态」，再追绝对精度
  → 记录：论文方法 vs 你用的开源差异
```

## 常见坑

- 论文用了非公开站网或商业接收机原始数据。
- 「开源」只有绘图脚本，没有估 TEC 核心。
- 把 ML 预报仓当成物理同化复现。

## 维护者自有仓库

如 `SH-GIM`：目录只收录链接。学习球谐 GIM 时，优先对照公开产品与通用库，再决定是否阅读自有代码。
