# 09 · DCB / 硬件延迟：为什么 TEC 数字会「整段平移」

学完 02 你会算几何无关组合，但跑出来的 STEC 常常和别人差一截常数。课堂里最常见的锅，就是 **DCB（Differential Code Bias，差分码偏差）**。

## 先建立直觉

双频伪距里，接收机和卫星的硬件都会让两个频率的码延迟略有不同。几何无关组合把「路径几何」消掉了，却把这种**频率相关的硬件延迟差**留了下来。

人话：你量雾的厚度时，尺子两端各粘了一小段不知道多长的橡皮泥——测出来的「雾厚」会整体偏一截。这段橡皮泥，就是 DCB。

常见相关量：

| 名称 | 谁身上的 | 你什么时候会撞上 |
|---|---|---|
| 卫星 DCB | 卫星端 P1−P2 等 | 用伪距估 TEC、或和 IGS 产品比 |
| 接收机 DCB / IFB | 接收机端 | 单站解、不同接收机混网 |
| 相位模糊度 | 载波 | 相位 TEC 有未知常数，要连弧段解 |

## 为什么 GIM / IONEX 里也有 DCB

IGS 分析中心做全球 GIM 时，往往会**同时估**格网（或球谐）TEC 和一批卫星/接收机 DCB。所以你下载的 IONEX 头里常能看到 DCB 相关信息；把「地图」和「偏差」拆开理解，比对时才不会误判。

## 处理流程（教学版）

1. **选观测量**：伪距几何无关组合噪声大但无模糊度；相位平滑伪距或相位+模糊度约束更常用。
2. **连弧**：周跳要处理，否则相位 TEC 会跳台阶。
3. **估偏差**：单站可把接收机 DCB 与薄壳映射一起估；多站网可把卫星 DCB 当公共参数。
4. **对齐产品**：和 CODE/CAS/JPL 的 DCB 或 GIM 比时，注意参考基准（哪个卫星/接收机被约束为 0）。
5. **只谈变化时**：做扰动、差分 TEC、ROTI 时，常数 DCB 影响小；谈绝对 TECU 时必须较真。

## 和定位的关系（预告 06 的加深）

PPP 里常用无电离层组合（IF），本质上是**绕开**一阶电离层，不是把 DCB 估成 TEC。你若目标是「电子含量科学」，要走 TEC/GIM 路线；若目标是「位置」，IF/双频消电离层往往更直接。两条路都碰偏差，但参数名字和约束习惯不同。
