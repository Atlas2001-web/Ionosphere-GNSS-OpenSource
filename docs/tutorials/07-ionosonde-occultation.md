# 07 · 测高仪、GNSS TEC、掩星：各看什么？如何互补？

> 本讲解决一个选题期最容易混的问题：**电离层观测不止 GNSS 一种**。测高仪、GNSS TEC、GNSS 无线电掩星（RO）看的高度范围、几何和产品形态不同。把它们当成「同一种 TEC」横比，会得到看似矛盾、其实各说各话的图。

先问自己：

1. 你要的是 **柱总量**，还是 **高度廓线**？  
2. 你要 **全球稀疏但立体**，还是 **某站头顶连续**？  
3. 你要对比的是 $N_e(h)$、$f_oF2$、底部积分，还是 GNSS 整柱 TEC？

三种手段合在一起，才像「立体电离层」；单独任何一种都有盲区。

---

## 1. 三个类比（先记住画面，再记表）

| 手段 | 类比 | 你「摸到」的是什么 |
|---|---|---|
| **测高仪（ionosonde）** | **声呐 / 向上探照灯** | 从地面往天顶打短波，听回波，重建头顶附近电子密度结构（尤其 F 层峰值及以下） |
| **GNSS TEC** | **整条视线穿过的雾柱有多厚** | 卫星到接收机整段路径的电子柱积分；不告诉你雾在哪一层最浓 |
| **GNSS 掩星（radio occultation, RO）** | **从侧面切一刀的 CT 切片** | 低轨卫星看 GNSS，信号掠过地球边缘，反演电子密度随高度的廓线 |

再补一句厨房类比：

- 测高仪：用勺子在汤锅**中间深处**搅一搅，感觉分层；  
- GNSS TEC：把锅里的汤**从上到下倒进量杯**，只知道总共多少，不知分层；  
- 掩星：用透明刀片从锅**侧面切开**，看见一层层剖面，但每一刀只切一瞬间、切在轨道允许的位置。

## 2. 一张对比总表（建议打印）

| | **测高仪** | **GNSS TEC** | **GNSS 掩星（RO）** |
|---|---|---|---|
| 几何 | 地基垂直/斜向探测 | 卫星→地面（或 LEO）斜路径 | LEO 接收 GNSS，路径掠过临边 |
| 主要产品 | 离子图；临界频率；虚高；峰值参数等 | **STEC / VTEC**（整柱） | **电子密度廓线** $N_e(h)$ |
| 高度强项 | F2 峰及以下结构清楚 | 柱积分；对峰上等离子体层也敏感 | 从较低高度到 LEO 高度一带的廓线（视产品） |
| 时间特性 | 单站可连续值班 | 有地面网就连续、密 | 随轨道「切片」，单点过境短 |
| 空间覆盖 | 靠台站，洋面稀疏 | 陆地网密，洋面靠船/岛/LEO | 全球可及，但时空采样不均匀 |
| 典型局限 | 难直接给出峰上全程；依赖台站 | **无高度分辨**；要 DCB/映射 | 反演假设、水平平滑；需专业产品链 |

## 3. 测高仪：看「头顶剖开」

### 3.1 它在干什么？

测高仪是一种**短波雷达**：向上发射扫频无线电波，不同频率在不同电子密度高度被反射。回波的时延与频率告诉你：

- 各层**临界频率**（例如 $f_oF2$：F2 层普通波临界频率——人话：这一层「密到什么程度会把这种波弹回来」）；  
- **虚高**等高度相关量；  
- 进一步缩放/反演得到峰值高度 $h_mF2$、峰值密度等。

经典输出叫**离子图（ionogram）**：横轴频率、纵轴虚高的那张「回波图」。

### 3.2 适合什么课题？

- 单站暴时响应、层高抬升/下降；  
- 与 IRI 等模型对比 **峰值参数**；  
- 短波通信与电离层结构教学。

### 3.3 它不擅长什么？

- 直接给出「和 GNSS 完全同定义的整柱 TEC」（积分上限与包含的等离子体层贡献往往不同）；  
- 无台站的大洋正面连续监测。

### 3.4 本目录相关条目（均为 PROJECTS.json 实名）

软件/工具多在 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md)，数据在 [`lists/10-gnss-datasets.md`](../../lists/10-gnss-datasets.md)：

- 门户与数据：`GIRO-portal`、`GIRO-DIDBase`；  
- 下载与社区：`Ionosonde-Data-Downloader`、`HamSCI-ionosonde`、`NICT-Ionosonde-Data`；  
- 缩放/处理：`Autoscala-INGV`、`SAO-Explorer`、`POLAN`；  
- 其它相关：`ionosonde_volgatech`、`jvierine-ionosonde`。

注册与访问提示见 [`docs/data-access.md`](../data-access.md)（GIRO/DIDBase 常需按门户流程注册）。

## 4. GNSS TEC：看「整柱有多厚」

### 4.1 它在干什么？

双频 GNSS 估 **STEC**（斜路径总电子含量），再经映射得到 **VTEC**（垂直总电子含量）。全球地基网密、时间连续，是 **GIM** 与空间天气平面监测的主力。

人话：你量的是「雾柱总厚度」，不是「雾在 300 km 还是 1000 km 最浓」。

### 4.2 适合什么课题？

- 区域/全球 VTEC 图、日变化、暴时平面响应；  
- ROTI（第 05 讲）与定位误差联动；  
- 与模型 TEC 对比（注意积分定义）。

### 4.3 局限（必须会背）

1. **无高度分辨**——层析/同化才能往「立体」走（见进阶讲）。  
2. **DCB/偏差、映射函数**影响绝对值（见第 09 讲）。  
3. 陆地密、海洋疏（除非加 LEO GNSS）。

### 4.4 工具指向

TEC 估计：`gnss-tec`、`pygnss-tec`、`tec-suite`、`Seemala-GPS-TEC`、`Okoh-MATLAB-TEC-from-RINEX`、`IONOLAB-TEC-Software` 等。  
GIM 读写：`ionex`、`mosgim`、`INX_Editor` 等。  
数据：`CDDIS-GNSS-Archive`、`CDDIS-IONEX` 等。

## 5. 掩星：看「侧面切一刀的廓线」

### 5.1 几何直觉

低轨卫星（LEO）上的接收机跟踪正在「沉入」或「升起」于地球边缘的 GNSS 卫星。信号路径在大气/电离层中弯曲与延迟，经反演可得到沿高度的折射或电子密度信息。

人话：**不是站在地面抬头看，而是在太空侧着刀切开地球周围的电离层洋葱。**

### 5.2 适合什么课题？

- 需要 $N_e(h)$ 形状，而不仅是柱总量；  
- 洋面、极区等测高仪稀疏处；  
- 与测高仪峰值、GNSS TEC 联合约束模型或同化。

### 5.3 局限

- 单次 occultation 是短暂「一刀」，不是某经纬点 24 小时连续；  
- 反演有假设，产品有水平平滑；  
- 需要懂数据版本与质量标记，不能当「真值照片」无贴。

### 5.4 本目录相关条目

- 数据门户：`COSMIC-CDAAC`、`COSMIC-GNSS-RO-Data`；  
- 处理/工具：`ROM-SAF-ROPP`、`cosmic-crunch`、`pysatCDAAC`、`awsgnssroutils`；  
- 研究向：`CDAAC_COSMIC-TEC_Data-Research`。

## 6. 高度范围：为什么数字对不上？

写论文最痛的场景：

> 「测高仪 TEC」与「GNSS TEC」差一截，于是有人断言某仪器坏了。

先对齐定义：

| 名称（课堂常用说法） | 大致包含什么 |
|---|---|
| 底部 / 测高仪可探段 | 峰值以下为主，峰上信息有限 |
| GNSS 整柱 TEC | 从接收机到卫星整段，含峰上与等离子体层贡献 |
| 掩星廓线积分到某高度 | 取决于你积分上限与产品有效高度 |

**积分上限不同，数值本来就可差一截。** 对比前写清：比的是 $N_e(h_mF2)$、底部积分，还是 GNSS VTEC。

类比：量「杯子里的水」和量「杯子+吸管+水龙头管道里的水」，当然不同。

## 7. 互补怎么用（课题级配方）

```
测高仪  ──► 峰值高度/密度锚点（台站连续）
掩星    ──► 全球廓线形状与洋面采样
GNSS TEC──► 高时间分辨率柱总量与平面图
    │
    └─► 一起约束 IRI 同化、层析、暴时过程研究
```

### 配方 A：验证经验模型

- IRI（`IRI-Fortran`、`IRI-2026-package`、`PyIRI`、`iri2020`）给出气候学廓线与 TEC；  
- 用测高仪钉 $f_oF2$/$h_mF2$；  
- 用 GNSS VTEC 钉整柱；  
- 用掩星看廓线形状是否「长得像」。

### 配方 B：暴时过程

- GNSS TEC/GIM 看平面谁先涨；  
- 测高仪看峰高是否抬升；  
- 掩星看某几次切片是否出现异常层；  
- ROTI/闪烁（第 05 讲）看是否进入「跟踪危险期」。

### 配方 C：只有一种数据时

- 只有 GNSS：老实做柱总量与 ROTI，别假装有廓线；  
- 只有测高仪：谈峰值与层结构，慎称全球 TEC；  
- 只有掩星：谈廓线统计与采样偏差，慎称连续天气图。

## 8. 常见误解（Misconceptions）

### 误解 A：「都是测电离层，数字应该一样」

**纠正：** 几何、高度积分、反演假设不同。先对齐物理量名称。

### 误解 B：「有了 GNSS TEC，测高仪过时了」

**纠正：** GNSS 无高度分辨；峰值行为常要测高仪或掩星。

### 误解 C：「掩星有廓线，可以取代所有测高仪」

**纠正：** 采样是轨道切片，不是单站 24h 连续离子图。

### 误解 D：「离子图上的虚高 = 真实几何高度」

**纠正：** 虚高与真高有关系但不是同一尺子；缩放/反演有学问（`POLAN`、`Autoscala-INGV`、`SAO-Explorer` 等工具存在的原因）。

### 误解 E：「掩星 TEC 与地基 GNSS TEC 可无脑横比」

**纠正：** 路径几何与积分方式不同；要读产品说明。

### 误解 F：「洋面没有电离层观测」

**纠正：** 测高仪少，但掩星与部分 GNSS（岛站、浮标、LEO）仍提供约束。

## 12. 自测题参考答案

1. 测高仪≈声呐；GNSS TEC≈雾柱厚度；掩星≈侧面切片。  
2. 无高度分辨（柱积分）。  
3. F2 峰及以下结构清楚。  
4. 依赖 LEO 轨道几何，是过境切片而非定点连续。  
5. 积分高度上限与包含的等离子体层等贡献不同。  
6. 测高例：`GIRO-DIDBase`、`Autoscala-INGV`；掩星例：`COSMIC-CDAAC`、`ROM-SAF-ROPP`（其它实名亦可）。  
7. GNSS TEC / GIM 主力。  
8. 测高仪（掩星可辅助廓线）。  
9. 因为峰值、整柱、廓线形状约束不同维度，减少盲区。  
10. 写清比较的是哪一物理量（如 VTEC、$f_oF2$、$N_e(h)$），避免只写「TEC」。

## 14. 把三个「产品流水线」画成流水账

初学者常问：「我点开网站之后到底下载什么？」下面用零假设流水账回答（具体按钮以官网为准，本仓只给方向）。

### 14.1 测高仪流水账

1. 确定台站与时间（暴日？宁静日对照？）。  
2. 在 `GIRO-portal` / `GIRO-DIDBase` 按门户规则注册并检索。  
3. 下载离子图或特征参数（视你课题要原始图还是缩放后的 $f_oF2$ 等）。  
4. 若需自动缩放或读 SAO 一类格式，再找 `Autoscala-INGV`、`SAO-Explorer`、`POLAN`。  
5. 画时间序列：峰频、峰高是否抬升；**先描述，再解释**。

### 14.2 GNSS TEC 流水账

1. 从 `CDDIS-GNSS-Archive` 等拿到 RINEX（或直接用现成 IONEX）。  
2. 用 `georinex` / `TEQC` / `Anubis` 做读取与质量检查。  
3. 用 `gnss-tec` / `pygnss-tec` / `tec-suite` / `Seemala-GPS-TEC` 估 STEC/VTEC。  
4. 若只要地图：`CDDIS-IONEX` + `ionex` 读图即可。  
5. 需要扰动代理时，接第 05 讲 ROTI 工具链。

### 14.3 掩星流水账

1. 明确任务：要 $N_e(h)$ 廓线，还是衍生 TEC 产品？  
2. 打开 `COSMIC-CDAAC` 或 `COSMIC-GNSS-RO-Data` 说明页，完成所需账号/协议。  
3. 用 `pysatCDAAC`、`cosmic-crunch`、`awsgnssroutils`、`ROM-SAF-ROPP` 等处理或转换。  
4. 把廓线放到地图上时，记住：那是「过境点附近的一刀」，不是该格点全天平均。

## 15. 通信与导航读者的「为什么要在乎」

- **短波通信**：测高仪直接关系到可通频率与层结构——这是测高仪的老本行。  
- **航空/卫星导航**：更常先撞上 GNSS TEC 延迟与闪烁；测高仪/掩星用于空间天气态势与模型改进。  
- **科研建模**：三类观测提供不同约束，硬只用一类，模型容易「讨好」那一类而在其它维度翻车。

把用户场景写进开题报告，审稿人会觉得你清醒。

## 17. 对比时的「允许差异」清单（可贴实验室墙）

允许甚至预期出现的差异：

1. 积分高度不同导致的 TEC 偏差；  
2. 测高仪真高 vs 虚高带来的高度解释差；  
3. 掩星水平平滑 vs 测高仪局地结构；  
4. GNSS 映射函数误差在低仰角放大；  
5. 时间对齐不严（测高仪缩放时刻 vs GNSS 历元 vs 掩星过境）。

不可轻易用「仪器坏了」解释的，往往是上表这些。

## 19. 一页纸总结

> 测高仪 = 头顶声呐（峰值结构强，峰上弱，靠台站）。  
> GNSS TEC = 雾柱厚度计（连续平面强，无高度）。  
> 掩星 = 侧面 CT 刀（廓线强，采样是切片）。  
> 互补 = 峰值锚点 + 柱总量 + 廓线形状。  
> 对不上 = 先对齐物理量与积分定义。

## 20. 多仪器现象确认 Playbook（暴 / EIA / TID / 闪烁）

单独一种观测很容易「自圆其说」。空间天气现象确认的稳健做法是：**预先规定「怎样才算确认」**，再按剧本把测高仪、GNSS TEC/ROTI、掩星（必要时再加闪烁仪）排进同一事件窗。本节是可打印的值班剧本。

### 20.1 Playbook 总原则（贴墙）

1. **先对齐物理量，再谈是否矛盾**（VTEC ≠ $f_oF2$ ≠ $N_e(h)$ 某点）。  
2. **先对齐时间与地点**（UTC、地方时、台站与 IPP/掩星切点）。  
3. **每种仪器只问它擅长的问题**（见第 1–5 节）。  
4. **确认等级分明**：单仪器「提示」→ 双仪器「支持」→ 三仪器「确认（仍可有残留不确定）」。  
5. **写否定句**：明确「本事件无法用 X 仪器证明 Y」。

### 20.2 通用七步（任何现象共用）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 | 一句话假设（例：「该夜低纬出现气泡相关不规则体」） | 假设卡 |
| 2 | 列「证实需要什么证据 / 证伪看到什么」 | 证据表 |
| 3 | 选仪器最小集合（不要一上来下载全世界） | 数据购物单 |
| 4 | 各自流水线出图（测高 / TEC / RO / ROTI） | 四类图 |
| 5 | 填「一致 / 冲突 / 缺测」矩阵 | 确认矩阵 |
| 6 | 定确认等级并写边界 | 结论段 |
| 7 | 回目录记录用过的实名条目 | 可重复性 |

### 20.3 确认矩阵模板

行 = 仪器产品；列 = 你的假设要素。单元格填：✅支持 / ❌反对 / ⚪无关或缺测。

示例假设：「暴主相某中纬站 F2 峰抬升，同时整柱 TEC 上升，掩星见峰高异常。」

| | 峰抬升 | 整柱上升 | 廓线峰高异常 | 闪烁增强 |
|---|---|---|---|---|
| 测高仪 $h_mF2$/$f_oF2$ |  | ⚪ | ⚪ | ⚪ |
| GNSS VTEC/GIM | ⚪ |  | ⚪ | ⚪ |
| 掩星 $N_e(h)$ | ⚪ | 视积分 |  | ⚪ |
| ROTI/S4 | ⚪ | ⚪ | ⚪ |  |

把空格填完，才允许在摘要里写「多仪器联合确认」。

## 21. 分现象剧本

### 21.1 磁暴（storm）响应

**擅长提问**

- 测高仪：峰频/峰高是否抬升或「暴时负相」式压制？层结构有无异常？  
- GNSS TEC：平面上正相/负相扰动区域如何迁移？  
- 掩星：若干切片是否支持峰高/峰密变化？  
- ROTI/闪烁：是否进入跟踪危险期（尤其高纬/低纬各自机制）？

**最小证据集（教学建议）**

1. 单站测高仪特征参数时间序列；  
2. 区域 GIM 差分图（暴日减宁静日或减气候学）；  
3. 1–N 条地理位置相关的掩星廓线；  
4. （可选）同窗 ROTI。

**确认口令**

- **提示**：仅 GIM 大范围 TEC 扰动。  
- **支持**：GIM + 测高仪峰值同步合理变化。  
- **较强确认**：再加掩星廓线方向一致，并写明采样稀疏导致的不确定。

**常见假确认**

- 只用 GNSS TEC 就写「F2 层抬升」——柱总量不能直接当峰高。  
- 掩星切点离测高仪台站很远仍声称「同地验证」。

### 21.2 赤道电离异常（EIA）

**画面**：低纬磁赤道两侧 VTEC/峰密形成双峰，中间槽。季节、地方时、太阳活动改变其强度与位置。

**仪器分工**

- GNSS TEC/GIM：看双峰是否出现、槽在哪、地方时演化——**主力**。  
- 测高仪：赤道两侧台站 $f_oF2$ 是否同步偏高；槽区台站是否偏低。  
- 掩星：沿纬度切片是否看到双峰结构（注意轨道与地方时匹配）。  
- 闪烁/ROTI：**不是 EIA 本身的判据**；但强 EIA 夜常与气泡/闪烁共现——要写成「伴随」，勿写成「EIA=闪烁」。

**确认口令**

- 仅单站 TEC 高：不足称 EIA。  
- 纬度剖面上的双峰 + 合理地方时：可称「观测到 EIA 结构」。  
- 双峰 + 两侧测高仪峰频配合：确认等级上升。

### 21.3 TID（行进式电离层扰动）

**画面**：TEC 或峰值参数出现可传播的波状扰动，有水平方向与周期。

**仪器分工**

- GNSS TEC 高采样多站：看扰动锋面传播——**主力**。  
- 测高仪：单站可见周期性峰参变化，但难单独定传播方向。  
- 掩星：偶可切到扰动结构，但不适合当 TID「电影」。  
- ROTI：可能对小尺度破碎敏感；中尺度 TID 与强闪烁要分开讨论。

**确认口令**

- 单站振荡：只是「扰动提示」。  
- 多站时间延迟可拟合传播：达到「TID 支持/确认」门槛。  
- 写清周期、表观速度、方向——没有这些参数，慎用 TID 标签。

### 21.4 闪烁 / 赤道等离子体气泡夜

**仪器分工**

- ROTI / S4/σφ：不规则体与闪烁——**主力**（定义纪律见第 05 讲）。  
- GNSS VTEC：背景与耗空结构（气泡常伴局部 TEC 耗空）。  
- 测高仪：扩散 F（spread-F）等形态可作旁证，但不是 GNSS S4。  
- 掩星：或见耗空/不规则痕迹，采样是切片。

**确认口令**

- 仅 VTEC 耗空：可能气泡候选，未证闪烁。  
- VTEC 耗空 + ROTI 多星抬升：不规则体活动支持。  
- 再加 S4 或测高仪 spread-F：闪烁/气泡叙事更完整。  
- 定位失锁同窗：应用层后果确认（第 06 讲），仍不替代物理指标。

## 22. 冲突怎么裁？（超有耐心）

| 冲突样子 | 先检查 | 可能裁断 |
|---|---|---|
| 测高仪峰参剧烈变，GNSS VTEC 几乎不动 | 积分上限、等离子体层、映射、时间对齐 | 可能峰变但柱被其它高度补偿；或 VTEC 产品过滑 |
| GNSS TEC 大扰动，测高仪平静 | 台站是否在扰动区外；测高仪缩放失败 | 空间不重合或离子图质量 |
| 掩星与测高仪峰高差很多 | 切点距离、水平平滑、真高/虚高 | 先查几何距离是否允许「联合」 |
| ROTI 高但测高仪无 spread-F | 地方时、频率、视线几何 | 不一定矛盾；机制与视场不同 |
| 三仪器只有一仪器响 | 缺测矩阵 | 降级为「单仪器提示」，不要硬升格 |

**裁断句式：**  
「A 与 B 在物理量 X 上冲突；因 A 测的是…、B 测的是…，在…条件下二者本可不一致。故本事件确认等级保持为…。」

## 24. 两小时联合确认演习（课堂）

**题目：** 任选一历史活跃日，验证「低纬夜间不规则体活动是否发生」。

1. 画区域 GIM：看 EIA 是否偏强（背景）。  
2. 选 1–2 个低纬站算 ROTI；填第 05 讲时空清单。  
3. 若有邻近测高仪，查是否有 spread-F 或峰参异常。  
4. 下载 2 条过境掩星廓线，只回答「是否与耗空/峰结构叙事相容」，不宣称连续天气图。  
5. 填确认矩阵，给出确认等级（提示/支持/较强确认）。  
6. 用 §22 句式写 250 字边界说明。

及格标准：不出现「三种仪器数字应完全相等」；不出现「无 S4 却断言 S4」。

## 25. Playbook 专场自测

1. 确认等级三级分别是什么？  
2. 为什么「GIM TEC 上升」不能单独确认「$h_mF2$ 抬升」？  
3. EIA 的主力仪器是什么？闪烁指标在 EIA 研究里应写成什么关系？  
4. TID 标签至少应附哪些传播参数？  
5. 气泡候选与闪烁确认差在哪一环证据？  
6. 掩星与测高仪联合前最该查什么几何量？  
7. 冲突裁断句式里必须出现哪两类信息（物理量差异与等级）？  
8. 列出暴、EIA、TID、闪烁各自的「主力」观测。

### 25.1 参考答案

1. 单仪器提示 → 双仪器支持 → 多仪器确认（仍声明不确定）。  
2. 柱总量不含峰高信息；物理量不同。  
3. GNSS TEC/GIM 主力；闪烁是可能伴随，不是 EIA 判据本身。  
4. 周期、方向、表观速度（及多站延迟依据）。  
5. 耗空/ROTI 可支持不规则体；S4/σφ 或等价正统闪烁证据才升格闪烁确认。  
6. 切点与台站的空间距离/是否允许声称同地。  
7. 各测何量（为何可不一致）+ 最终确认等级。  
8. 暴：TEC+测高（+RO）；EIA：TEC 纬度结构；TID：多站 TEC；闪烁：S4/σφ/ROTI。
