# 05 · 闪烁、S4、σφ、ROTI：和 TEC 图什么关系？

> 本讲假设你已经读过 [01-ionosphere-tec-basics.md](./01-ionosphere-tec-basics.md) 与 [02-gnss-dualfreq-tec.md](./02-gnss-dualfreq-tec.md) 里「TEC 是什么、怎么从双频估」的部分。若那些词还不熟，先回去扫一眼，再回来。

先问自己一个分流问题：**你现在关心的，是「电子有多少」，还是「信号抖不抖」？**

- **TEC / GIM**（总电子含量 / 全球电离层图）回答的是：沿路径或垂直柱里，电子「库存」大概多少。它像天气预报里的「云厚不厚、雾浓不浓」——偏**慢变背景**和大尺度结构。
- **闪烁指标**（S4、σφ、以及代理指标 ROTI 等）回答的是：小尺度不规则性让到达接收机的电场**幅度和相位快速起伏**到什么程度。它直接影响跟踪环能不能锁住、定位解会不会中断。

两者常常在同一片天空同时变坏，但它们**不是同一个物理量**。把 ROTI 图当成 TEC 图、或把 S4 当成「电子多少」的替代品，是课堂与论文里极常见的混用。本讲专门拆开这件事。

---

## 1. 闪烁是什么？（从「星星眨眼」说起）

夜里看星星会「眨眼」，不是星星本身在跳，而是星光穿过大气湍流时被弯来弯去。电离层闪烁（**ionospheric scintillation**）是电波版的同一类故事：

1. GNSS 卫星发来的微波穿过电离层；
2. 电离层里若存在**电子密度不规则体**（小尺度「疙瘩」），电波会发生衍射与折射；
3. 到达地面（或低轨）接收机天线口面的电场，其**幅度**和**相位**随时间快速起伏。

人话：**信号在「抖」**——强度忽明忽暗，相位忽前忽后。专用名词就叫闪烁。

### 1.1 必须会的几个词（每个都给白话）

| 术语 | 白话定义 |
|---|---|
| **不规则体（irregularities）** | 电子密度在空间上不均匀的小块结构，尺度从几百米到几十公里都有；像空气里的湍流泡。 |
| **衍射 / 折射** | 波遇到障碍或折射率起伏时弯折、干涉；结果是接收点上能量重新分配。 |
| **幅度闪烁** | 信号强度（功率）快速起伏。 |
| **相位闪烁** | 载波相位快速起伏。 |
| **跟踪环（tracking loop）** | 接收机里用来「跟上」伪码和载波的闭环；抖太狠会失锁。 |
| **失锁 / 周跳** | 跟丢信号，或载波相位计数出现整周跳变；定位连续性变差。 |

### 1.2 类比集

- **柏油路热浪**：夏天远处景物发「晃」。闪烁是电波穿过「电子湍流」时的晃。
- **透过百叶窗看阳光**：光强一条条明暗——幅度闪烁像明暗条纹扫过天线。
- **说话时被风扇吹麦克风**：音量忽大忽小（幅度），声调发飘（相位）——接收机「听」卫星也类似。

### 1.3 哪里、何时更常见？

- **低纬 / 赤道异常区**：日落后到夜里，等离子体气泡（equatorial plasma bubbles）活跃，幅度闪烁往往很强。
- **高纬**：磁暴、极光活动期间，相位闪烁可以很突出。
- **中纬**：平时相对温和，但强空间天气时仍可出现。

「赤道晚上 TEC 还挺高，同时闪烁也凶」——很常见，因为高背景密度 + 不规则体，更容易把信号搅碎。

## 2. 幅度 vs 相位：为什么要分两本账？

闪烁不是一个数。至少要分：

1. **幅度域**：强度抖不抖 → 常用 **S4**；
2. **相位域**：相位抖不抖 → 常用 **σφ**（读作 sigma-phi）。

为什么分开？因为：

- 幅度猛抖 → 信噪比崩、相关峰变形，码跟踪与数据解调变难；
- 相位猛抖 → 载波跟踪吃力，精密定位、周跳检测、相位 TEC 都会遭殃；
- 有时一边很凶、另一边还好——取决于不规则体谱、频率、几何与接收机带宽。

**课堂纠错：**「闪烁强」四个字太空。写报告请写清：是 S4 高、σφ 高、还是 ROTI 高、还是「定位中断次数多」。

---

## 3. S4 是什么？

**S4（S4 index）** 是描述**信号强度起伏强弱**的无量纲指标。直觉：

> 在一段统计窗口里，强度相对其平均值「晃」得有多厉害。

不必死记公式也能用：

- **S4 ≈ 0**：强度几乎不晃，像平静水面；
- **S4 升高**：晃得明显；经验上常把较高阈值当作「强闪烁」警戒（具体阈值随文献与系统而异，引用时写清来源）；
- S4 针对的是**幅度/强度**，不是 TEC 绝对值。

### 3.1 谁能直接给出靠谱的 S4？

**专用闪烁接收机**（高采样率、专用固件与前端）才是正统来源。它们往往同时输出 S4、σφ、以及原始高速率 IQ 或强度/相位序列。

本目录与闪烁数据下载相关的条目举例：`ismr_downloader`（面向 ISMR 一类闪烁监测数据格式/产品）。条目见 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md)。

### 3.2 普通测绘型 GNSS 接收机呢？

很多 CORS / 测绘接收机只给 1 Hz（甚至更低）的载波与伪距。用它们**硬算**一个「看起来像 S4」的数，往往**采样不够、带宽定义也不对齐**，不能直接等价于专用闪烁仪的 S4。

但你仍可从 TEC 时间变化构造 **ROTI** 等**代理指标**（见后文）——代理有用，别冒充同一观测。

---

## 4. σφ（sigma-phi）是什么？

**σφ** 是载波**相位**在统计窗口内起伏的标准差（定义细节随标准与实现略有差异）。直觉：

> 相位像一根本来该平滑的绳子，被风吹得上下抖——σφ 量这抖的幅度。

- σφ 大 → 相位跟踪困难，周跳与失锁风险上升；
- 高纬暴时，有时人们更先谈相位闪烁；
- 和 S4 一样，正式产品多来自专用闪烁监测链。

类比：S4 像「音量表指针狂跳」，σφ 像「音调/相位在抖音不准」。

---

## 5. ROT 与 ROTI：没有闪烁仪时的「代理听诊器」

### 5.1 ROT

先从双频观测估出 **STEC**（斜路径总电子含量；见第 02 讲）。然后看它随时间变多快：

- **ROT（Rate of TEC）**：TEC 的时间变化率。  
  人话：下一秒比上一秒「电子柱」变了多少。

单位常见为 TECU/min 一类（读文献时核对）。平静时 ROT 相对平滑；有小尺度结构扫过视线时，ROT 会出现毛刺。

### 5.2 ROTI

- **ROTI（ROT Index）**：在滑动时间窗口内，对 ROT 做起伏统计（常见为标准差一类）。  
  人话：**这段时间 TEC 变化率有多「毛」**。

ROTI 高 → 视线方向 TEC「毛刺」多 → **常常**和小尺度不规则体活跃有关，因此被广泛当作闪烁活动的**代理指标（proxy）**，尤其当你只有常规 RINEX、没有专用闪烁仪时。

### 5.3 关键重要的一句话

**ROTI ≠ S4 ≠ σφ。**

它们可以相关很好，也可以在某些频率、季节、地磁条件下分家。物理机制、采样率、观测频段、统计窗口全都可以不同。论文与报告里请写成：

- 「ROTI 升高，提示不规则体活动增强」；  
而不是「ROTI = 闪烁强度 = S4」。

## 6. 和 TEC 图 / GIM 到底什么关系？

把电离层想象成一大锅汤：

| 产品 | 你在看汤的什么 | 时间尺度直觉 |
|---|---|---|
| 平滑 VTEC / GIM | 整锅有多「浓」（大尺度电子含量） | 分钟到小时的背景与大结构 |
| ROTI | 勺子搅动时液面皱纹多不多 | 更短、更「毛」 |
| S4 / σφ | 喝的时候嘴被烫得跳、味道发飘（信号真在抖） | 秒级及以下的起伏效应 |

结构示意：

```
平滑 VTEC / GIM  ──► 大尺度「有多少电子」
        │
        │  同一片天空可以同时
        ▼
高 ROTI / 高 S4 ──► 小尺度「抖不抖 / 毛不毛」
```

典型情景：

1. **赤道夜里**：VTEC 仍可能偏高，同时 ROTI、S4 升高（气泡、不规则体）。  
2. **强 TEC 梯度**：大尺度梯度大，不等于闪烁一定强——还要看不规则体谱与射线几何。  
3. **空间天气监测**：成熟做法常是 **TEC 图 + ROTI/闪烁图一起看**，一张说库存，一张说扰动。

## 7. 闪烁凶的时候，定位会怎样失败？

不必陷入接收机环路方程，记这张「症状表」：

| 现象 | 和闪烁的关系（直觉） |
|---|---|
| 信噪比乱跳 | 幅度闪烁直接相关 |
| 载波失锁、周跳暴增 | 相位闪烁 / 强起伏时常见 |
| 可用卫星数突然变少 | 多颗星同时难跟 |
| RTK 模糊度难固定 | 差分后仍有快速大气残差 + 周跳 |
| PPP 收敛变慢或散架 | 相位质量变差、模型跟不上 |
| 单频导航漂移变大 | 改正模型来不及描述小尺度 |

**人话：** TEC 高像「雾厚，尺子整体偏」；闪烁强像「尺子在手抖，读数乱跳甚至摔地上」。厚雾可以慢慢改；手抖会让系统直接罢工。

工程上还会谈「闪烁对哪个频段更敏感」——通常频率越低越容易抖得凶（同一不规则体环境下），但细节留给专题文献；本讲只要求你建立「频率、几何、接收机能力都会改写症状」的意识。

## 9. 常见误解（Misconceptions）

### 误解 A：「ROTI 高 = 闪烁强 = S4 高」

**纠正：** ROTI 是 TEC 变化率的统计；S4 是强度起伏。相关 ≠ 恒等。写「代理指标」三个字，是负责的说法。

### 误解 B：「有了全球 TEC 图，就不需要闪烁产品」

**纠正：** GIM 像气候态/大尺度天气图，分辨率与时间平滑通常吃掉小尺度。飞机起降要看阵风，不能只看「今天多云」。

### 误解 C：「双频接收机就不会受闪烁影响」

**纠正：** 双频擅长消一阶电离层延迟（见第 06 讲），但闪烁是跟踪层与小尺度问题。双频不是「抗闪烁无敌光环」。

### 误解 D：「中纬永远不用担心闪烁」

**纠正：** 相对低纬少，不代表暴时为零。空间天气事件里，中纬也会出现异常梯度与扰动。

### 误解 E：「用 1 Hz RINEX 算出的 S4 可以和文献里的专用 S4 直接比」

**纠正：** 采样与仪器定义不对齐时，数值不可直接横比。宁可报 ROTI，并写明窗口与采样。

### 误解 F：「TEC 低就一定安全」

**纠正：** 低 TEC 时仍可能有不规则体；高 TEC 也未必处处闪烁。库存与湍流是两本账。

2. **选数据**：只有 RINEX → TEC→ROT→ROTI；有 ISMR/专用数据 → S4/σφ。

4. **先画时间序列再下结论**：单点 ROTI 尖峰可能是周跳或多路径，先做质量检查（可配合 [`lists/03-gnss-data.md`](../../lists/03-gnss-data.md) 中的 `georinex`、`TEQC`、`Anubis` 等）。

   「某站地方时 20–22 时 ROTI 升高，同时低仰角卫星周跳增多；GIM 显示区域 VTEC 偏高。因无专用闪烁仪，本文以 ROTI 为代理，不直接声称 S4。」

## 13. 自测题参考答案

1. TEC/GIM：电子「有多少」（柱含量/大尺度）；闪烁指标：信号「抖不抖」（幅度/相位起伏或其代理）。  
2. S4 → 幅度/强度；σφ → 相位。  
3. ROT 是变化率；ROTI 是窗口内 ROT 起伏的指数（如标准差）。  
4. 物理量、采样、频段、统计定义都可能不同；ROTI 来自 TEC 序列，S4 来自强度起伏。  
5. 采样率与前端/固件不足以支撑与专用仪器同定义的 S4/σφ。  
6. 高背景密度叠加日落后气泡/不规则体，既有电子库存，也有小尺度结构。  
7. 例：ROTI 侧 `igs-roti`、`Okoh-MATLAB-ROT-ROTI`；仿真/处理侧 `gnss-scintillation-simulator`、`scintill-ai` 或 `BiScEF`、`scintkit`、`OASIS`、`IonoMoni` 等（答出四个真实条目即可）。  
8. 更像手抖到跟踪失败；「尺子偏了」更接近慢变电离层延迟。  
9. 一张看大尺度电子含量，一张看小尺度扰动/闪烁风险，互补。  
10. 写明所用指标定义与窗口，说明与 S4/σφ 的关系是统计相关或代理，而非同一观测。

## 14. 再补一层直觉：三种「坏」不要互相顶锅

初学者看到定位变差，容易把锅甩给「电离层」三个字。建议在笔记本里画三列：

| 列 | 典型坏法 | 你优先怀疑 |
|---|---|---|
| A. 慢变延迟 | 位置整体偏几米到几十米，但跟踪还在 | TEC 高、单频模型粗、未用双频消电离层 |
| B. 梯度/残余 | 短基线还行、长基线或暴时 RTK 难固定 | 站间电离层不再公共、网络改正不足 |
| C. 闪烁/不规则体 | 失锁、周跳浪涌、可用星骤降、解直接断 | S4/σφ/ROTI、低纬夜里、暴时高纬 |

本讲主攻 C；A/B 在第 06 讲展开。把病例分诊清楚，工具才选得对：C 类问题去闪烁/ROTI 子类，而不是只下载一张 GIM 指望救命。

### 14.1 和「多路径」怎么分辨？

多路径（信号经地面/建筑物反射）也会让强度与相位难受，尤其低仰角。粗分思路：

- 多路径常随测站环境、方位高度角呈重复几何图案；  
- 闪烁/ROTI 更随地方时、纬度带、地磁活动成片出现，多站可共现；  
- 质量检查工具（如 `Anubis`、`TEQC`）帮你先排除接收机与环境明显异常，再谈空间天气故事。

没有银弹，但「先 QC、再物理」能少写很多尴尬论文。

### 14.2 你离开本讲应能说清的三句话

1. 闪烁是小尺度不规则体造成的幅度/相位快速起伏，不是 TEC 的别名。  
2. S4 管幅度，σφ 管相位，ROTI 是 TEC 变化率起伏的代理，三者勿划等号。  
3. 在本目录用 `lists/01-ionosphere.md` 的闪烁与闪烁/ROTI 子类选工具，数据侧需要时再走 `ismr_downloader` 或 `lists/10-gnss-datasets.md`。

## 15. 深度案例：如何分析「一个闪烁夜」（ROTI vs S4）

下面把整晚分析拆成**可照着做的剧本**。假设你关心的是低纬某 CORS 站地方时约 19–02 时：气泡是否起来、信号是否真抖、定位是否遭殃。你可能只有 RINEX，也可能幸运地还有专用闪烁仪/ISMR。两种数据都按同一套时空纪律走，只是指标换成 ROTI 或 S4/σφ。

### 15.1 开场三问（写进笔记本第一页）

1. **地理带**：赤道异常区？中纬？高纬？决定你先验期待（低纬夜里幅度闪烁常见；高纬暴时相位闪烁更扎眼）。  
2. **你有什么观测**：仅 1 Hz RINEX → 主战场是 ROTI；有 ISMR/闪烁仪 → 可正式谈 S4/σφ，ROTI 仍可作对照。  
3. **对照日**：至少准备一个地磁平静、同季节、同地方时窗口的「安静夜」。没有对照，尖峰很难解释。

### 15.2 时间轴准备（先对齐钟，再谈物理）

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| T0 | 统一用 UTC，同时标注**地方时** | 赤道气泡故事讲的是日落之后，地方时更直觉 |
| T1 | 标出日落与磁地方时大致窗口 | 避免把下午多路径尖峰误当成夜里闪烁 |
| T2 | 选定统计窗口（如 ROTI 常用数分钟窗；S4 跟产品定义走） | 窗口不同，数值不可横比 |
| T3 | 记下地磁指数（Kp/Dst 等，来源写清） | 暴时与宁静日叙事不同 |

**人话：** 闪烁夜分析 = 气象值班：先对表，再看雷达，最后写天气日记。

### 15.3 仅有 RINEX 时的 ROTI 夜班流程

1. **QC 先行**：用 `georinex` / `TEQC` / `Anubis`（见 `lists/03-gnss-data.md`）排除明显钟跳、大量周跳、天线异常。脏数据上的「高 ROTI」是假警报。  
2. **估 STEC**：`gnss-tec` / `pygnss-tec` / `tec-suite` / `Seemala-GPS-TEC` 等（`lists/01-ionosphere.md` TEC 估计子类）。  
3. **算 ROT → ROTI**：`Okoh-MATLAB-ROT-ROTI`、`igs-roti`、`Ionospheric-TEC-ROTI-Interactives` 等。写明采样率与窗口。  
4. **按卫星拆开看**：不要只看「全站平均 ROTI」。某一颗低仰角星的尖峰，可能是多路径或周跳；多颗中高仰角星同时抬升，才更像不规则体扫过天空。  
5. **仰角门限**：先用 ≥20° 或 ≥30° 做一版，再放开低仰角做敏感性——报告里写清。  
6. **与 VTEC 同窗对照**：VTEC 高只说明库存；ROTI 高才提示「毛」。两张图并排，才是完整句子。

### 15.4 有 S4/σφ 时怎么和 ROTI 对照（核心教学点）

| 观察 | 可能含义（课堂级，非判决书） |
|---|---|
| ROTI↑ 且 S4↑ | 不规则体活跃，代理与正统幅度指标同向——叙事最稳 |
| ROTI↑ 但 S4 平 | 可能是 TEC 梯度/大尺度变化进了 ROT，或采样/频率定义不同；**勿强行宣称闪烁强** |
| S4↑ 但 ROTI 平 | 强度在抖，但你的 TEC 估计平滑过度、采样不够，或窗口不对齐 |
| σφ↑ 突出、S4 一般 | 更偏相位闪烁叙事（高纬暴时常见教学案例） |
| 指标都高但定位没事 | 几何好、接收机环路强、或受影响星被剔除——仍应报告风险窗口 |

**一句纪律：** ROTI 回答「TEC 变化率毛不毛」；S4 回答「强度抖不抖」。同向增强 = 好证据链；分家 = 先查定义与 QC，再谈新物理。

### 15.5 空间–时间检查清单（Spatial–Temporal Checklist）

把下面清单复制到实验记录，逐项打勾：

**A. 时间维**

- [ ] 地方时窗口是否落在该纬度带的「易发时段」（低纬：日落后数小时）？  
- [ ] 是否有宁静日同一地方时对照？  
- [ ] 尖峰是持续数十分钟的「片状」，还是单历元毛刺（后者优先查周跳）？  
- [ ] 指标升高是否与地磁扰动时段重叠？不重叠也可能是季节性气泡——分开写。

**B. 空间维**

- [ ] 单站还是多站？邻站是否共现同类抬升？  
- [ ] 穿刺点（IPP）轨迹是否扫过已知 EIA/气泡好发经度？  
- [ ] 是否只有某一方位角扇区的卫星受害（可能是局部结构或环境遮挡）？  
- [ ] 与 GIM/区域 TEC 图比：背景梯度在哪里？ROTI 热区是否落在梯度或赤道槽附近？

**C. 几何与仪器维**

- [ ] 仰角分布、PDOP 是否同时变差？（可参考 `Ionospheric-Scintillation-Maps-and-PDOP` 一类可视化思路）  
- [ ] 接收机类型：测绘型 vs 闪烁仪；采样是否支撑你声称的指标？  
- [ ] 多路径环境是否在该方位角已知很脏？

**D. 定位后果维（衔接到第 06 讲）**

- [ ] 失锁/周跳计数是否在同一窗口浪涌？  
- [ ] RTK 固定率或 PPP 收敛是否变差？  
- [ ] 残差是「慢慢偏」还是「突然散」——前者偏延迟/梯度，后者偏闪烁跟踪。

### 15.6 报告句式模板（可直接改写）

> 某站（纬度带：…）在 UTC …（地方时 …）出现 ROTI 升高；同窗口中高仰角多星共现，邻站亦见类似抬升。宁静日对照无此结构。因仅有 1 Hz RINEX，本文以 ROTI 为不规则体活动**代理指标**，不直接等同 S4。同窗 VTEC 偏高但梯度与 ROTI 热区空间位置为…。定位日志显示周跳/固定率变化为…，故将本次事件归入「小尺度不规则体 + 跟踪压力」而非单纯慢变延迟。

若你有 ISMR：在模板中把「代理」改成「S4/σφ 实测，并与 ROTI 对照，二者同向/分家情况为…」。

### 15.7 迷你案例走查（虚构教学夜，数字请换成你的）

1. 19:10 LT：VTEC 仍高，ROTI 开始毛——气泡「点火」嫌疑。  
2. 20:30 LT：多星 ROTI 峰值，低仰角周跳增多——进入危险期。  
3. 21:00 LT：若有 S4，可见幅度闪烁峰；若无 S4，只写 ROTI 代理。  
4. 23:30 LT：指标回落，固定率恢复——写「事件结束」，并保留 QC 备注。

不要把整晚平均成一个数讲故事；**时间演化**才是闪烁夜的灵魂。

## 18. 把「一夜」拆成可重复的表格工作法

很多同学分析闪烁夜时只截两张图就下结论。更稳的做法是：**先填表，再解释**。下面这张表建议每个事件窗填一行（可复制到实验笔记）。

| 字段 | 你要填的内容 | 填写提示 |
|---|---|---|
| 站名 / 纬度带 | 如 GUAM、低纬 | 决定先验 |
| 日期（UTC）与地方时窗 | 2024-… 19–02 LT | 两套钟 |
| 地磁背景 | 平静 / 活跃 + 指数出处 | 暴与季节性气泡分开 |
| 数据种类 | RINEX only / +ISMR | 决定指标合法性 |
| QC 结论 | 通过 / 存疑（原因） | 不通过则停 |
| VTEC 趋势 | 升高/降低/双峰 | 只描述库存 |
| ROTI 行为 | 峰值时刻、持续时长、多星？ | 代理不规则体 |
| S4/σφ（若有） | 峰值、与 ROTI 同向？ | 正统闪烁 |
| 空间共现 | 邻站有无 | 打假单站噪声 |
| IPP / 方位扇区 | 是否集中某扇区 | 结构 vs 环境 |
| 定位后果 | 周跳、固定率、PPP 状态 | 接到第 06 讲 |
| 一句话归因 | 代理闪烁 / 梯度 / 多路径 / 数据病 | 必须单选主因 |

填完表再写段落：审稿人看到的是「可重复值班记录」，不是「我感觉今晚抖」。

### 18.1 ROTI 窗口与采样：耐心讲一遍

- **采样太稀**：1 Hz 通常够 ROTI 教学；若你对 TEC 又做了强平滑，ROTI 会被「熨平」——假阴性。  
- **窗口太短**：统计不稳，毛刺被放大——假阳性。  
- **窗口太长**：真实短时气泡被平均掉——假阴性。  
- **不同软件默认窗不同**：`igs-roti` 与 `Okoh-MATLAB-ROT-ROTI` 数值不可不注明窗就横比。

课堂练习：同一 STEC 序列，用两个窗口各算一遍 ROTI，把差异写进讨论——这比背公式更有用。

### 18.2 「假闪烁夜」五种常见误诊

1. **未做周跳修复**就把相位 TEC 求导 → ROTI 假峰。  
2. **只看最低仰角那颗星** → 多路径冒充气泡。  
3. **把黄昏对流层湿延迟起伏**和电离层故事混写（少见但发生过）→ 先看双频几何无关量是否也毛。  
4. **GIM 平滑图上看不见小尺度**就断言「无闪烁」→ GIM 本来就不分辨闪烁。  
5. **有 S4 无 ROTI 对照、或有 ROTI 无 QC** → 证据链缺环。

## PRINCIPLES · 闪烁 / ROTI 物理与指标原则深讲（必读）

> 本节是第 05 讲的**原则层加长**：把 Fresnel 尺度、衍射直觉、幅度/相位机制、S4 与 σφ 符号、采样率、ROTI 构造、赤道气泡 vs 高纬驱动、以及整晚分析剧本（含假阳性）一次讲透。前文是地图；这里是地形图。工具名仅引用本仓库 `PROJECTS.json` 的 `name`。

### P1. 先把「抖」钉在波传播上：不规则体 → 相位屏 → 地面干涉图样

GNSS 载波（L 波段）穿过电离层时，若电子密度在横截面上不均匀，折射率就起伏。教学上常把一层不规则体近似成**相位屏（phase screen）**：波穿过屏后，波前被「搓皱」——有的地方相位超前，有的地方落后。再往下自由空间传播一段距离，皱波前会发生**衍射与干涉**，在地面天线口面上形成明暗与相位斑驳的**干涉图样**。卫星相对地面在动、不规则体也在漂，图样就扫过天线——你看到的就是时间序列上的幅度与相位快速起伏，即闪烁。

人话三句：

1. **不规则体**是「雾里的疙瘩」；  
2. **相位屏**是「玻璃上被画花的那一层」；  
3. **闪烁**是「花玻璃后面光斑在地上晃」。

TEC / GIM 回答的是雾**有多厚**（柱含量）；闪烁回答的是雾里**疙瘩有多碎、光斑晃多凶**。厚雾可以不晃；薄雾也可以碎得厉害——两本账。

### P2. Fresnel 尺度：为什么「几公里」这种尺度特别重要？

衍射干涉里有一个特征横向尺度，课堂常称 **Fresnel 尺度** *rF*（量级直觉即可，不必死背推导）：

＄＄
r_F \sim \sqrt{\lambda\,z_{\mathrm{eff}}}
＄＄

- λ：载波波长（GPS L1 约 0.19 m 量级）；  
- zₑբբ：等效传播几何尺度（与不规则体层高、接收机位置有关，教学上可想成「屏到天线的有效距离」）。

对 GNSS L 波段、F 区高度量级的屏，*rF* 常常落在**数百米到数公里**这一档。直觉：

- 不规则体谱在 Fresnel 尺度附近有能量 → 地面干涉对比度容易大 → **幅度闪烁**更显眼；  
- 很大尺度的平滑梯度 → 更像慢慢弯折射线（折射/延迟变化），不一定制造强衍射斑；  
- 极小尺度若能量弱或被仪器带宽滤掉 → 你也「看不见」。

**课堂纠错：**「有不规则体」≠「一定强闪烁」。还要看尺度是否对上 Fresnel、视线几何、背景密度、以及你的采样/带宽能不能抓住起伏。

类比：用手机拍纱窗——纱的孔洞尺度和像素/焦距「对上」时，摩尔纹最明显；孔太大或太细，纹样就淡。Fresnel 尺度就是「和 L 波段衍射最对得上的那档纱孔」。

### P3. 幅度闪烁 vs 相位闪烁：机制分账（不要只背两个希腊字母）

| 账本 | 物理直觉 | 工程症状 | 常用指数 |
|---|---|---|---|
| **幅度闪烁** | 衍射干涉让能量在空间重新分配，天线有时进亮斑、有时进暗斑 | C/N0 乱跳、相关峰变形、码跟踪与解调变难 | **S4** |
| **相位闪烁** | 波前被搓皱 + 不规则体相对运动，载波相位快速抖动 | 载波环吃力、周跳、失锁、相位 TEC 毛刺 | **σφ** |

为什么能「一边凶、一边还好」？

- **谱形状**：有的环境相位起伏谱更陡、能量偏大尺度 → 相位指标先抬头；有的环境 Fresnel 尺度能量足 → 幅度指数更醒目。  
- **频率**：同一不规则体环境下，通常频率越低越容易抖得凶（延迟与相位扰动大致随 1/f² 一类因子变强的直觉），但幅度饱和、多径与接收机实现会改写表象。  
- **几何**：低仰角路径更长、穿刺点扫过结构的相对速度也不同 → 时间谱被「多普勒拉伸」。  
- **接收机**：环路带宽、振荡器、前端滤波决定你「听得见」哪一段起伏。

低纬日落后气泡夜：教学叙事常以**幅度闪烁（S4）**为明星，同时 ROTI 也高。高纬磁暴/极光粒子沉降：教学叙事常先谈**相位闪烁（σφ）**。中纬平时温和，但强空间天气时两本账都可能打开。详见后文 P8。

### P4. S4 定义：符号逐个说清 + 采样率为什么是生死线

教学常用形式（实现细节随标准略有出入，写报告务必引用你所用产品的定义）：

＄＄
\mathrm{S4} = \sqrt{\frac{\langle I^2\rangle - \langle I\rangle^2}{\langle I\rangle^2}}
＄＄

符号账：

| 符号 | 含义 |
|---|---|
| I | 信号**强度**（功率或强度观测量；有的实现用幅度平方） |
| langle·rangle | 在长度 *T* 的统计窗口内的时间平均 |
| 分子 | 强度的方差（「晃了多少」） |
| 分母 | 平均强度的平方（归一化，使 S4 无量纲） |
| 开方 | 回到「相对起伏」的标准差量级 |

直觉阶梯：

- S4≈ 0：强度几乎不晃；  
- S4 升高：相对起伏变大；  
- 强闪烁时可能出现**饱和**（指数不再线性反映「更碎」），文献阈值勿生搬。

**采样率 / 带宽为何致命：**

1. 闪烁起伏的时间谱可延伸到数 Hz 甚至更高（取决于相对速度与尺度）。  
2. 若你只有 1 Hz 的 C/N0 快照，等于用「每秒拍一张」去估「风扇叶片转速」——高频能量被折叠或干脆看不见。  
3. 专用闪烁接收机用高采样（常见数十 Hz 量级，以产品说明书为准）+ 明确前端/环路定义，才谈得上与文献 S4 横比。  
4. 普通 CORS / 测绘接收机输出的 1 Hz（或更低）RINEX，**不宜**硬算一个「冒充专用 S4」的数去和 ISMR 产品比绝对值。

本目录正统闪烁数据入口举例：`ismr_downloader`。处理/指标链举例：`scintkit`、`OASIS`、`OASIS-ohm1122`、`IonoMoni`、`BiScEF`、`scintill-ai`、`gnssutils`。仿真补课：`gnss-scintillation-simulator`、`gnss-scintillation-simulator_2-param`。可视化灵感：`Ionospheric-Scintillation-Maps-and-PDOP`。全部以 `PROJECTS.json` 为准。

### P5. σφ（sigma-phi）定义：相位账本的标准差

教学写法：

＄＄
\sigma_\varphi = \sqrt{\langle(\varphi-\langle\varphi\rangle)^2\rangle}
＄＄

或在去趋势/滤波后的相位残差上取窗口标准差（实现必须写清）。

| 符号 | 含义 |
|---|---|
| φ | 载波相位（弧度或换算后的单位；报告必须声明） |
| langleφrangle | 窗口内均值，或低通趋势 |
| σ_φ | 残差相位的标准差 → 「绳子被风吹抖的幅度」 |

要点：

- σφ 大 → 载波跟踪压力大，周跳与失锁风险升；  
- 高纬暴时课堂案例常先看 σφ；  
- 与 S4 一样，正式产品多来自专用链；用低采样相位序列「山寨 σφ」时，必须声明带宽与去趋势方法，否则不可与文献横比。

**S4 与 σφ 的课堂口诀：** S4 看「灯亮不亮在跳」；σφ 看「音调准不准在飘」。两本账都要会开，报告里禁止只写「闪烁强」四个空字。

### P6. 从 TEC 序列构造 ROT / ROTI：步骤、符号、与 S4 的「相关≠相等」

#### P6.1 先有 STEC

由双频几何无关组合估 **STEC**（斜路径总电子含量）。工具入口（`lists/01-ionosphere.md` TEC 估计子类）：`gnss-tec`、`pygnss-tec`、`tec-suite`、`Seemala-GPS-TEC` 等。QC 先行：`georinex`、`TEQC`、`Anubis`（`lists/03-gnss-data.md`）。脏弧段上的「高 ROTI」是假警报。

#### P6.2 ROT

＄＄
\mathrm{ROT}(t) = \frac{\mathrm{STEC}(t)-\mathrm{STEC}(t-\Delta t)}{\Delta t}
＄＄

| 符号 | 含义 |
|---|---|
| STEC(t) | 时刻 *t* 的斜 TEC（常用 TECU） |
| Δ t | 采样间隔（如 30 s、1 s；必须写进方法） |
| *ROT* | TEC **变化率**（常见单位 TECU/min，读文献核对） |

人话：下一拍比上一拍「电子柱」变了多快。平静时 ROT 相对光滑；小尺度结构扫过视线时出现毛刺。

#### P6.3 ROTI

在长度为 W 的滑动窗口内，对 ROT 做起伏统计，最常见是标准差：

＄＄
\mathrm{ROTI}(t) = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N}\bigl(\mathrm{ROT}_i-\overline{\mathrm{ROT}}\bigr)^2}
＄＄

| 符号 | 含义 |
|---|---|
| W | 窗口时长（如 5 min；软件默认可能不同） |
| N | 窗内 ROT 样本数 |
| overline{ROT} | 窗内 ROT 均值 |
| *ROTI* | 「这段时间变化率有多毛」 |

ROTI 工具举例：`igs-roti`、`Okoh-MATLAB-ROT-ROTI`、`Ionospheric-TEC-ROTI-Interactives`、`roti-gnss-ml`。

#### P6.4 为什么 ROTI ≠ S4 ≠ σφ（必须会答辩）

| 维度 | ROTI | S4 | σφ |
|---|---|---|---|
| 原始观测量 | TEC（相位/伪距导出） | 信号强度 | 载波相位 |
| 物理近邻 | TEC 时间粗糙度 / 不规则体代理 | 衍射导致的强度起伏 | 相位抖动 |
| 典型数据 | 1 Hz 或 30 s RINEX 也可做教学 | 高采样闪烁仪/ISMR | 同上 |
| 可相关？ | 常与闪烁活动同向 | — | — |
| 可恒等？ | **否** | **否** | **否** |

分家情景（写进报告的「免责声明素材」）：

- ROTI↑ 但 S4 平：大尺度 TEC 梯度或弧段问题进了 ROT；或采样/窗口定义不对齐。  
- S4↑ 但 ROTI 平：强度在抖，但 TEC 被平滑过度、采样不够，或窗口错位。  
- σφ↑ 而 S4 一般：更偏相位闪烁叙事（高纬教学经典）。

**负责任句式：**「ROTI 升高，提示视线方向 TEC 变化率起伏增强，作为不规则体活动的**代理指标**；因无专用闪烁仪，本文不将 ROTI 等同为 S4。」

### P7. 窗口与采样的「假阳性 / 假阴性」旋钮

| 旋钮 | 拧太紧/太稀的后果 | 课堂建议 |
|---|---|---|
| TEC 强平滑后再求导 | ROTI 被熨平 → **假阴性** | 平滑参数写进方法；做敏感性 |
| ROTI 窗口过短 | 统计不稳，毛刺放大 → **假阳性** | 与文献窗口对齐并报告 |
| ROTI 窗口过长 | 短时气泡被平均掉 → **假阴性** | 双窗口对照是好练习 |
| 忽略周跳 | 相位 TEC 出台阶 → ROTI **假峰** | QC → 修复/分段后再算 |
| 只盯最低仰角星 | 多路径冒充气泡 → **假阳性** | 中高仰角 + 多星共现 |
| 不同软件默认同窗 | 数值不可横比 | `igs-roti` 与 `Okoh-MATLAB-ROT-ROTI` 必须注明窗 |

课堂练习：同一 STEC，两个窗口各算 ROTI，把差异写进讨论——比背公式更有用。

### P8. 赤道等离子体气泡 vs 高纬：驱动不同，指标叙事也不同

#### P8.1 低纬 / 赤道异常区（EIA）夜侧气泡

- **驱动直觉：** 日落后底部 F 区向上抬升、瑞利–泰勒类不稳定性种子放大，形成赤道等离子体气泡（EPB）及伴随的小尺度不规则体。  
- **地方时：** 故事主角是**日落之后数小时**，用地方时叙事比纯 UTC 更直觉。  
- **指标画像：** 背景 VTEC 往往仍不低；ROTI、S4 易抬升；幅度闪烁常很「出镜」。  
- **空间结构：** 气泡沿磁力线扩展，穿刺点（IPP）扫过耗空通道时，TEC 可局部下降而 ROTI 仍高——「库存」与「毛刺」再次分家。  
- **对照：** 同季节宁静夜、同地方时窗；邻站共现；仰角门限写清。

#### P8.2 高纬（极光带 / 极盖）

- **驱动直觉：** 磁层–电离层耦合、粒子沉降、对流增强、暴时电流体系——与赤道「日落后气泡」不是同一剧本。  
- **时间：** 更跟地磁活动（Kp、Dst/SYM-H 等，出处写清）走，而不是「每晚固定地方时必演」。  
- **指标画像：** **相位闪烁（σφ）** 教学上常更扎眼；ROTI 也可升高，但勿把低纬气泡阈值生搬过来。  
- **误诊：** 把高纬暴时相位失锁写成「赤道气泡」——纬度带都错了。

#### P8.3 中纬

- 平时相对温和；暴时仍可有异常梯度、行扰（TID）与偶发闪烁风险。  
- 「中纬永远安全」是误解（见本讲误解 D）。

**口诀：** 低纬夜看气泡钟（地方时）；高纬暴看地磁钟；中纬别装睡。驱动不同，阈值、先验、报告用词都要换套装。

### P10. 和 TEC 图 / 定位失败的原则边界

| 产品 | 回答 | 勿回答 |

### P12. 离开 PRINCIPLES 你应能对外说清的五句话

1. 闪烁是小尺度不规则体经衍射/干涉造成的幅度与相位快速起伏，不是 TEC 别名。  
2. Fresnel 尺度帮助理解「哪档疙瘩」最会晃信号。  
3. S4 管强度相对起伏，σφ 管相位抖动，两者都强依赖采样与仪器定义。  
4. ROTI 由 TEC 变化率窗口统计而来，是代理不是等式。  
5. 赤道气泡与高纬暴驱动不同；整晚分析必须对表、QC、多星共现、写清假阳性边界。

### P13. 衍射与折射再拆一层：何时「弯」、何时「碎」

课堂把传播效应粗分为两档，有助于选题：

| 档 | 图像 | 主要后果 | 你优先看什么 |
|---|---|---|---|
| **折射 / 大尺度梯度** | 光线被慢慢掰弯，路径延迟变 | 定位偏差、STEC/VTEC 形态、映射误差 | TEC 图、GIM、差分 TEC |
| **衍射 / 小尺度谱** | 波前被搓皱后干涉，能量重新铺开 | 幅度闪烁、深衰落 | S4、高采样强度 |
| **相位屏动力学** | 屏在动、星在动，时间谱被拉伸 | 相位抖动、周跳 | σφ、载波残差 |

同一片赤道夜空可以同时有：气泡壁上的强梯度（折射+TEC 耗空通道）+ 壁内/尾流小尺度（衍射+S4）。所以「TEC 下降」与「S4 上升」可以同窗出现——不是矛盾，是结构分层。

**练习题（口述）：** 若只有平滑 GIM、没有 ROTI/S4，你最多能说什么？答：大尺度库存与粗梯度；不能诚实宣称「无闪烁」或「闪烁很强」。

### P14. 强度、幅度、功率：读 S4 文献时的单位陷阱

不同实现把 I 取为：

- 瞬时功率；  
- 幅度的平方；  
- 已扣除接收机增益漂移后的归一化强度。

若分母用了错误的归一化，S4 会被人为压低或抬高。教学纪律：

1. 先读产品说明里「I 是什么」；  
2. 再看窗口 T（常见 60 s 量级，但以文档为准）；  
3. 最后才和别人的数字比大小。

还有 **S4 校正项**：有的产品输出「去除热噪声贡献」后的 S4。把未校正与已校正混在一张散点图里，相关系数会撒谎。写方法节时抄一句产品字段名，胜过写三句形容词。

### P15. 相位去趋势：σφ 的「隐形开关」

原始载波相位含几何、钟差、慢变电离层。直接对原始相位取标差，得到的不是闪烁 σφ，而是「地球在转」。标准做法是：

- 高通 / 多项式去趋势；或  
- 相位几何无关组合后再滤波；或  
- 产品固件内部已定义的滤波器。

**原则：** 去趋势截止频率太高 → 真闪烁被削（假阴性）；太低 → 慢变泄漏进 σφ（假阳性）。报告必须写滤波规格，否则 σφ 数字不可复现。

类比：量「绳子被风吹的抖」，要先拿掉「人在慢慢收绳」的趋势；收绳动作若被当成风，风级就报错。

### P16. ROTI 与闪烁的统计相关：怎么报才不翻车

论文里常见散点：ROTI vs S4。原则层要求：

1. **同卫星、同穿刺时段、同仰角门限** 再相关；全站平均对全站平均，会糊掉物理。  
2. 报 Spearman/Pearson 时写清样本独立性质疑（时间相关很强）。  
3. 相关高只支持「代理可用」，不支持「可替换校准」。  
4. 分季节、分地磁活动画，往往比「全年一锅」更诚实。

若你的课题是「无闪烁仪地区的风险监测」，ROTI 代理完全站得住脚——前提是措辞是代理，并做假阳性控制（P9.5）。

### P17. 多路径、对流层、闪烁：三张「假面具」

| 面具 | 典型指纹 | 拆法 |
|---|---|---|
| 多路径 | 随方位/高度角重复；建筑反射几何 | 仰角门限、排除已知脏扇区、`Anubis`/`TEQC` QC |
| 对流层湿延迟起伏 | 天气尺度、双频几何无关后应大减 | 看 GF 组合是否仍毛；毛则更像电离层/仪器 |
| 闪烁/不规则体 | 地方时或地磁成片；邻站共现 | 时空清单 + ROTI/S4 |

原则：**先 QC，再物理。** 没有银弹，但顺序错了会写出尴尬论文。

### P18. 频率依赖的直觉板书（不堆严式）

同一不规则体环境，教学板书常写：

- 电离层延迟 ∝ 1/f² 量级直觉；  
- 相位扰动随频率降低而变大的趋势；  
- 幅度闪烁在弱散射区与谱、Fresnel 过滤有关，强散射可饱和。

实务含义：L5/E5a 等与 L1 的闪烁观感可以不同；多频接收机「某个频点先失锁」并不奇怪。写事件报告时按频点分列症状，避免「GNSS 全体完蛋」的笼统句。

### P25. 板书级推导：从「相对速度」到「时间谱为何重要」

设不规则体横向特征尺度为 *L*，卫星–穿刺点相对地面的扫掠速度量级为 vₑբբ。则时间起伏特征频率粗估：

＄＄
f_{\mathrm{char}} \sim \frac{v_{\mathrm{eff}}}{L}
＄＄

- *L* 接近 Fresnel 尺度且 vₑբբ 较大 → f_char 升高 → 需要更高采样才不糊。  
- 低仰角、快速漂移动力学会把同一空间结构「压缩」成更尖的时间尖峰。  

这就是为什么只说「我用了 GNSS 数据」不够：必须说清采样间隔与窗口。`igs-roti` 与 `Okoh-MATLAB-ROT-ROTI` 若默认窗不同，数值差一截仍可能都「没错」——错在你没声明。

### P26. 「代理指标」的伦理三行（建议贴在显示器下方）

1. **定义行：** 我计算的是窗口 *W*、采样 Δ t 下的 ROTI（或产品版 S4/σφ）。  
2. **关系行：** 它与闪烁活动统计相关，但不是 S4 的同义语。  
3. **边界行：** 假阳性已用 QC / 仰角 / 邻站 / 对照日约束；未约束项明示。

三行齐，审稿人不易用「你是不是把 ROTI 当 S4」一枪挑死。缺一行，答辩会很难看。

### P30. 高纬专页：不要把低纬 Playbook 原样粘贴

高纬事件分析把 P9 的「地方时四幕」替换为：

1. **驱动钟：** IMF、Kp、Dst/SYM-H、AE 等（出处写清）——哪一波扰动对应指标抬升。  
2. **空间钟：** 极光卵是否扫过测站纬度；单站故事要有磁纬意识。  
3. **指标钟：** 优先安排 σφ / 相位失锁日志；ROTI 作辅。  
4. **假阳性钟：** 暴时接收机本身过载、数据空洞，也可能制造「假平静」或「假尖峰」。

低纬气泡的日落咒语在这里无效；反之，高纬地磁咒语也不解释宁静赤道夜的季节性气泡。**换纬度先换剧本。**
