## 1. 术语表（每个词钉死）

| 术语 | 定义 | 初学者抓手 |
|---|---|---|
| **数据同化（data assimilation）** | 把观测按误差统计融入模式状态，得到更优**分析场**，并常作为下一时刻预报初值 | 「模式先猜，观测再改」 |
| **状态向量 $x$** | 你要估计/更新的量：VTEC 格网、球谐系数、三维 $N_e$、或模式内部变量 | 先问论文：$x$ 到底是什么维 |
| **背景场 $x_b$** | 同化前模式给出的先验状态（常由上一分析场预报而来） | 「还没看今天观测时的最佳猜测」 |
| **分析场 $x_a$** | 同化观测后的更新状态 | 「看完观测后的最佳估计」 |
| **观测 $y$** | GNSS STEC/VTEC、测高仪、掩星剖面、雷达等 | 必须说清单位、偏差、采样 |
| **观测算子 $H$** | 从状态 $x$ 正演出「观测该长什么样」：路径积分、映射、插值到测站 | 和层析正演是亲戚 |
| **创新（innovation）** | $d = y - H(x_b)$：观测减背景预报观测 | 创新很大 → 模式飘了或观测坏了 |
| **观测误差 / 背景误差** | 你有多信 $y$、有多信 $x_b$ | 决定分析往哪边靠 |
| **增益（gain）** | 把创新分配回状态空间的权重 | 「观测准就多改；测站稀就别改爆」 |
| **分析—预报循环** | $x_a$ 作为初值 → 模式积分到下一时刻 → 新的 $x_b$ | 同化常是循环，不是单次贴图 |
| **3D-Var / 4D-Var / EnKF 等** | 不同同化算法家族 | 入门先懂 $x,y,H$，再选缩写 |
| **经验模式** | IRI、NeQuick 等气候/经验场 | 便宜背景；扰动日可能不够 |
| **物理模式** | 如 `TIE-GCM`、`GEMINI3D`、SAMI 系列 | 更重；物理约束更丰 |
| **GIM 插值** | 不依赖物理预报，直接把 VTEC 采样收成图 | 可以很有用，但不是经典同化 |
| **ML 预报** | 从历史学习未来 | 可借鉴同化思想，机制不同 |

## 2. 一句话定义 + 反定义

**同化** = 模式先给出背景电离层状态；再根据观测（GNSS STEC/VTEC、测高仪、掩星等）和误差设定，更新状态，使**分析场**以及（若进入循环）**后续预报**更接近真实。

它**不是**：

- 把 IONEX 色图直接贴到地球表面（那是产品显示或插值）；  
- 训练一个「明天 TEC」网络就自动叫同化（那是预报/监督学习）；  
- 层析立方体的别名（层析可以作同化组件，但问题提法常不同）；  
- 「谁的图更漂亮谁就同化成功」。

---

## 3. 核心类比三则

### 3.1 天气预报口播

气象上：数值模式先跑出「明天可能的天气」，雷达与探空再把漂移拉回来，然后继续往前预报。电离层同化是同一哲学，只是状态变成电子密度/TEC，观测变成 GNSS 路径积分等。

### 3.2 导航开车

GPS 给你位置观测 $y$；你的运动模型（车能开多快、路网约束）给出背景 $x_b$；融合后得到更稳的当前位置 $x_a$，并预测下一分钟在哪。没有模型，你只是在点之间折线；没有观测，模型会越开越歪。

### 3.3 批改作文

学生作文 = 背景场（有自己的文风与错误模式）；老师红笔 = 观测；改完的作文 = 分析场。若老师乱改（观测误差大）或学生原文被改到不像人话（增益过大），「分析」反而更糟——对应同化里错误的误差设定。

## 4. 最小框图（请能默画、能默讲）

```
经验/物理模式  --时间预报-->  背景场 x_b
                                 │
GNSS / 测高仪 / 掩星 --观测算子 H--> 创新 d = y − H(x_b)
                                 │
                         按误差加权更新 → 分析场 x_a
                                 │
                         作为下一时刻初值 → 再预报 → …
```

### 4.1 课堂三问（答不上就还没读懂那篇 assimilation 论文）

1. **$x$ 是什么？** VTEC 格网、球谐系数，还是三维 $N_e$、或模式的风/中性成分等？维数多少？  
2. **$y$ 是什么？** 斜路径 STEC、垂直 VTEC 产品、foF2、掩星剖面？有没有 DCB？  
3. **$H$ 怎么做？** 路径积分？薄壳映射？插值到 IPP？线性近似还是非线性？

### 4.2 把三问写成「论文阅读卡片」

每读一篇，抄四行：

- $x = \ldots$  
- $y = \ldots$  
- $H = \ldots$  
- 验证数据是否**独立**于被同化观测（避免循环论证）

## 5. 权重与增益：同化的「性格」

直觉：

- 观测很准、背景明显漂 → 分析多信观测，创新多吃进去；  
- 测站稀、观测含偏差、模式有强气候约束 → 不能让单个怪测站把整层电离层拉爆；  
- 背景误差在空间上相关 → 一个测站的创新会「扩散」到周围（像气象里的影响半径）。

**失败模式**：把所有观测误差设成极小 → 分析场变成观测噪声的立体雕塑；把背景误差设成极小 → 同化几乎不更新，等于白跑。

## 6. 同化 vs 插值出图 vs ML 预报（对照总表）

| 维度 | GIM 插值/球谐 | 经典数据同化 | ML 预报仓 |
|---|---|---|---|
| 是否需要时间预报模式 | 通常不需要 | **需要**（或至少有背景生成） | 常直接学映射 |
| 核心数学对象 | 空间拟合 | $x,y,H$ + 误差协方差 | 网络参数/损失 |
| 输出 | 分析图（常无动力预报） | 分析场 + 可续报 | 未来时刻场/序列 |
| 物理约束 | 弱（光滑等） | 由模式带来 | 取决于特征与约束设计 |
| 本仓库例子 | `mosgim`、`SH-GIM`、`ionex` | 背景：`TIE-GCM`、`PyIRI`；观测：`CDDIS-IONEX` 等 | `DeepPredTEC`、`Global-TEC-forecasting-DL`、`SpatioTECformer`、`TEC-MoLLM`、`Ionospheric-VTEC-Forecasting` |
| 常见误叫 | 把 Kriging 叫 4D-Var | 把单次最优插值叫「深度同化」 | 把预测叫 assimilation |

口诀：**插值收当下；同化融模式；ML 赌未来。** 三者可组合，但主标签只能有一个。

## 8. 和层析、GIM 的接口（防止第 11 课知识回潮混乱）

- **GIM**：常提供 $y$（VTEC 产品）或作为对比真值（但若同化了同一 GIM 再拿它验证 = 循环论证）。  
- **层析**：$H$ 常常就是射线积分；层析可看作「强先验下的静态同化特例」，但经典同化强调**模式时间演化**。  
- **DCB**：观测算子再漂亮，STEC 基准歪了，分析场会整层偏——回 [09-dcb-biases-deep.md](./09-dcb-biases-deep.md)。

## 10. 常见误区（请打假）

1. **把 GIM 克里金插值叫做 4D-Var。**  
2. **只用一个分析中心的 IONEX 当「真值」去同化，再拿它验证** — 循环论证。  
3. **忽略 DCB** — 分析场整层偏。  
4. **观测误差设为零** — 把噪声写进电离层。  
5. **ML 预测成功 = 理解了物理同化** — 工程价值与机制解释是两件事。  
6. **背景用 IRI 气候场，却期望完美跟上磁暴分钟级演化** — 气候场不是实时物理。  
7. **把 `ESA-TIO-Forecast-TEC` 与 `CDDIS-IONEX` 最终产品混为同一验证真值** — 时效与策略不同。  
8. **三维可视化很炫 = 同化增量真的大于产品噪声** — 先做第 14 课式的事件复盘思维。

## 15. $H$ 的三种常见「长相」（把抽象变具体）

### 情形 A：状态是 VTEC 格网，观测也是 VTEC

$H$ 近似为「插值到测站或 IPP」：从格网双线性插值出某点 VTEC。简单，但你已经丢掉了斜路径信息，且薄壳假设可能前置在观测预处理里。

### 情形 B：状态是 VTEC（或球谐系数），观测是 STEC

$H$ 含映射：$H(x) \approx m(E)\,x(\mathrm{IPP})$。映射误差进入观测算子，同化会把映射锅部分甩给状态——于是又出现「假空洞/假梯度」。

### 情形 C：状态是三维 $N_e$，观测是 STEC

$H$ 是路径积分（层析正演）。这是信息最丰、也最贵、最病态的组合；常与物理模式或强 IRI 背景一起用。

**练习**：把你读的论文归入 A/B/C；若作者没写清，那就是论文的问题，不是你的问题——你要在卡片上写「未声明」。

## 16. 误差设定的课堂故事

假设安静日中纬：背景 IRI 与真值差约 2～4 TECU，单站 STEC 经 DCB 后仍有约 1～3 TECU 有效不确定（含多路径与映射）。若你把观测误差设成 0.1 TECU，分析会几乎贴站，网格在站间可能出现不物理尖峰。若观测误差设成 20 TECU，同化几乎不更新，磁暴抬升会被模式气候场按住。

**实务建议（教学用，非万能参数）**：先做创新统计——看 $y-H(x_b)$ 的均值与方差；均值长期非零先查偏差；方差量级用来设观测误差的第一猜。然后做参数敏感性：观测误差 ×0.5 / ×2，看分析场是否「面目全非」。

## 17. 「伪同化」学习链：没有超级计算机也能练思维

1. 用 `PyIRI` 或 `IRI-2020-package` 生成某日全球/区域 VTEC 背景。  
2. 用 `CDDIS-IONEX` 当日产品当作「观测图」（注意：这是学习用近似，不是严格最优同化）。  
3. 定义简单更新：$x_a = x_b + K(y - x_b)$，$K$ 取 0.3～0.7 做扫描。  
4. 留出另一家产品（如 `JPL-IONEX-Rapid` 或 `WHU-IGS-Ionosphere-AC`）做独立对比。  
5. 写半页：哪些结构来自 IRI？哪些被观测拉过来？$K$ 过大时边界出现什么假象？

这不是发表级系统，但能把框图从「会背」变成「会操」。
