# 12 · 数据同化入门：把「模型」和「GNSS 观测」缝在一起

## 一句话

**同化** = 在模式预报的基础上，按观测误差与模式误差，把 GNSS TEC / 测高仪 / 掩星等「拉」向更接近真实的状态。

不是简单把 GIM 贴到 IRI 上面；也不是只跑物理模式。

## 为什么 GNSS 人要懂一点

- 业务空间天气（如部分官方 TEC 现报）背后常有同化或偏同化思路。
- 读论文时看到 「assimilate GNSS STEC into …」时，你要能分清：观测算子是什么、更新的是哪些状态变量。

## 最小概念集

| 概念 | 人话 |
|---|---|
| 背景场 | 模式先给一版电离层状态 |
| 观测算子 | 如何从模式状态「正演」出 STEC/VTEC/foF2 |
| 增益 / 权重 | 更信观测还是更信模式 |
| 时间更新 | 下一时刻模式继续往前积，再迎新观测 |

入门只要求：能画这张框图，能指出 GNSS TEC 进的是哪一个接口。

## 和本仓库条目怎么连

- 经验背景：`IRI-*`、`PyIRI`、`Galileo-NeQuick-G`
- 物理背景：`TIE-GCM`、`GEMINI3D`、SAMI 相关
- 观测产品：`CDDIS-IONEX`、`DLR-IMPC`、掩星与测高仪数据源
- 机器学习预报（如 `IonCast-*`、各类 TEC 预报仓）**不是经典同化**，但同属「观测+模型信息融合」大家族，读论文时别混名
