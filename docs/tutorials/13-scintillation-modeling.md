# 13 · 闪烁：从指数到建模

[05-scintillation-roti.md](./05-scintillation-roti.md) 介绍了 S4、σφ、ROTI。本课往「精通」迈一步：什么时候报指数就够，什么时候要建模/仿真，以及本仓库里哪些名字是监测、哪些是仿真器。

---

## 先分清你的需求

| 需求 | 你真正要的 | 典型出口 |
|---|---|---|
| 监测告警 | 今晚/本区域强不强 | ROTI 图、S4 链、告警阈值 |
| 气候统计 | 季节/地方时/太阳活动概率 | 经验气候学模型 |
| 影响评估 | 跟踪是否失锁、定位误差怎么变 | 闪烁仿真 + 接收机/基带模型 |
| 科学研究 | 不规则性谱、气泡演化 | 相位屏、物理/半物理模型 |

课堂原则：**先有监测图，再谈模型。** 没有观测锚定的仿真，只是动画。

---

## ROTI 与 S4 不是同一个东西

- **ROTI（Rate of TEC Index）**：TEC 时间变化率的统计，用双频载波就能做，适合稠密 GNSS 网。  
- **S4 / σφ**：幅度/相位闪烁指数，常靠专用闪烁接收机或高采样观测。

可以相关，甚至可建经验关系，但**不能**把 ROTI 地图直接改名成 S4 交差。

类比：ROTI 像「路面颠簸的加速度计读数」；S4 像「车灯亮度抖得有多狠」。相关，但传感器不同。

## 建模时你在模什么

常见层次（由浅到深）：

1. **指数与阈值**：超过阈值告警；实现快，物理解释弱。  
2. **经验气候学**：按地方时、季节、太阳通量、磁纬给出发生概率或平均强度。  
3. **相位屏 / 弱散射**：把不规则性压成相位屏，传播后得到幅度与相位起伏。  
4. **半物理 / 物理**：耦合气泡、梯度漂移等；开源完整链路少，算力与参数门槛高。

开源程度不一；进 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md) 搜 scintillation / ROTI / ISMR。仿真器有了，仍要问：输入谱参数从哪来？有没有和实测 S4 对照的算例？

---

## 低纬 vs 高纬：别套同一套阈值

- **低纬**：赤道等离子体气泡、日落后增强，和地方时强相关；季节与太阳活动调制明显。  
- **中纬**：常与行进式扰动（TID）等有关，强度通常不如赤道极端（例外存在）。本目录有 `IRI_TID` 等与 TID 相关条目，和闪烁机制不要混为一谈。  
- **高纬**：极光区粒子沉降、片状结构，驱动与 IMF、磁层活动绑得更紧。

把赤道气泡的阈值原封搬到极光区，会出运营笑话。

## 和定位用户怎么对话（衔接 06）

闪烁期优先看：

1. 跟踪状态（失锁、周跳暴增）；  
2. 多星余度与几何；  
3. 是否改用更稳健的跟踪环/衰减策略；  

而不是只盯 VTEC 绝对值。高 TEC 背景可以很平静；强闪烁也可以发生在 TEC 梯度区而非「全球最高 TECU」点。定位侧工具仍是 `RTKLIB`、`gLAB`、`GAMPII-GOOD` 等（[`lists/04-gnss-positioning.md`](../../lists/04-gnss-positioning.md)），但闪烁本身要用监测/仿真条目。

产品侧也可看 `DLR-IMPC` 等是否提供扰动/ROTI 类近实时信息（以各产品说明为准）。

## 实战建议清单

- [ ] 先复现一张公开 ROTI 或闪烁地图形态，再改参数  
- [ ] 明确你的指数定义（采样率、窗口长度、单位）与文献一致  
- [ ] 分磁纬讨论，禁止「全球一个阈值」  
- [ ] 仿真输出要和至少一种实测指数对照  
- [ ] 写报告时分开：监测结论 / 模型假设 / 对定位的含义  

---

## 常见误区

1. **「ROTI 高 = 一定不能定位」** — 还看星座、频率、接收机。  
2. **「有了闪烁仿真就可以不做监测」** — 气候学给概率，当晚实况仍靠观测。  
3. **「ML 预测 S4 等于理解物理」** — 可能有工程价值，但验证集若缺磁暴，会盲目自信。  
4. **「TEC 图能替代闪烁图」** — 见 [01](./01-ionosphere-tec-basics.md) 误区：TEC 大 ≠ 闪烁强。
