## 0. 本课在系列中的位置

第 05 课带你认识 S4、σφ、ROTI 这些**指数**。本课往精通迈一步：

- 什么时候**报指数、画监测图**就够；

## 1. 术语表（全部定义）

| 术语 | 定义 | 初学者抓手 |
|---|---|---|
| **电离层闪烁（scintillation）** | 信号振幅/相位因电离层不规则性而快速起伏 | 像透过热浪看远处物体在抖 |
| **不规则性（irregularities）** | 电子密度小尺度起伏结构 | 闪烁的「路面颠簸」本身 |
| **S4** | 幅度闪烁指数：强度起伏的归一化标准差 | 常需专用接收机或高采样 |
| **σφ（sigma-phi）** | 相位闪烁指数：相位起伏统计 | 与载波跟踪环压力相关 |
| **ROTI** | Rate of TEC Index：TEC 时间变化率的统计量 | 双频载波网即可做，适合稠密 GNSS |
| **ISMR** | Ionospheric Scintillation Monitoring Receiver 一类监测数据/接收机语境 | 真闪烁指数常来自此类 |
| **监测（monitoring）** | 用观测实时/近实时报告「现在强不强」 | 告警、地图、值班 |
| **建模（modeling）** | 用经验/物理/半物理方法描述或仿真闪烁 | 概率、波形、影响评估 |
| **气候学模型** | 按地方时、季节、太阳活动、磁纬给发生概率或平均强度 | 「这一季晚上容易吗」 |
| **相位屏（phase screen）** | 把不规则性压缩成相位调制屏，再传播得到幅度/相位起伏 | 仿真常用中间层 |
| **赤道等离子体气泡（EPB）** | 低纬日落后常见的密度耗空与不规则结构 | 低纬闪烁主角之一 |
| **极光区闪烁** | 高纬与粒子沉降、片状结构等相关的闪烁 | 驱动绑 IMF/磁层活动 |
| **TID** | Traveling Ionospheric Disturbance，行进式扰动 | 可调 TEC，**不等于**闪烁；别混名 |
| **失锁 / 周跳暴增** | 跟踪环跟不住或相位连续性破坏 | 定位用户最痛的表现 |

## 3. ROTI 与 S4：不是同一个东西

### 3.1 定义再钉一次

- **ROTI**：对 TEC 时间导数（或差分）做滑动窗口标准差一类统计；输入主要是双频载波导出的 TEC。  
- **S4 / σφ**：直接描述信号强度/相位起伏；传统上靠闪烁监测接收机或足够高采样的专用处理。

### 3.2 类比（请背下来讲给别人听）

- **ROTI** 像「路面颠簸的加速度计读数」——路是否在抖，用车载加速度计也能感到。  
- **S4** 像「车灯亮度抖得有多狠」——你需要看光强传感器。  
- 相关，甚至可建经验关系，但**不能**把 ROTI 地图直接改名成 S4 交差。

### 3.3 数据需求对照

| | ROTI | S4 / σφ |
|---|---|---|
| 典型数据 | 双频 GNSS 载波（CORS/IGS 网） | 闪烁接收机 / 高采样 ISMR |
| 空间覆盖潜力 | 高（站网密就能出图） | 往往站更少 |
| 物理直接性 | 间接（TEC 变化率代理） | 更直接描述信号起伏 |
| 误用风险 | 当 S4 用；窗口定义不一致 | 采样不足仍硬算 |

本目录可对号：

| 任务 | 条目 |
|---|---|
| ROTI | `igs-roti`、`Okoh-MATLAB-ROT-ROTI`、`roti-gnss-ml`、`Ionospheric-TEC-ROTI-Interactives` |
| 闪烁监测/地图 | `Ionospheric-Scintillation-Maps-and-PDOP`、`ScintPi-1.0-Software`、`scintkit`、`scintill-ai`、`ismr_downloader` |
| 闪烁仿真 | `gnss-scintillation-simulator`、`gnss-scintillation-simulator_2-param` |

## 4. 建模时你在模什么（由浅到深四层）

1. **指数与阈值**  
   超过阈值告警。实现快，物理解释弱。适合值班室第一道闸。

2. **经验气候学**  
   按地方时、季节、太阳通量、磁纬给出发生概率或平均强度。回答「这个月日落后低纬风险高不高」。

3. **相位屏 / 弱散射**  
   把不规则性压成相位屏，电磁波传播后得到幅度与相位起伏；可输出时间序列给接收机仿真。开源入口：`gnss-scintillation-simulator`、`gnss-scintillation-simulator_2-param`。

4. **半物理 / 物理**  
   耦合气泡、梯度漂移不稳定性等。完整开源链路少，算力与参数门槛高。

每一层都要问：**输入参数从哪来？有没有和实测 S4/ROTI 对照的算例？** 进 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md) 搜 scintillation / ROTI / ISMR。

## 5. 低纬 vs 中纬 vs 高纬：别套同一套阈值

### 5.1 低纬（赤道与低磁纬）

- 主角常是**赤道等离子体气泡**与日落后不规则性增强；  
- **地方时**极关键：日落后到夜前半夜往往更紧张；  
- 季节与太阳活动调制明显；磁静日也可能「该闪还闪」。  

运营含义：日落窗口加强值班；阈值按季节/太阳周调整，而不是全年固定。

### 5.2 中纬

- 常与 TID、中纬槽、暴时扰动等相关；  
- 平均强度常不如赤道极端（**例外存在**）；  
- 本目录有 `IRI_TID` 等与 TID 相关条目——TID 调 TEC 结构，**不要**和闪烁机制混为一谈。

### 5.3 高纬（极光区/极盖）

- 与粒子沉降、片状结构、磁层活动、IMF 取向绑得更紧；  
- 地方时规律不同于赤道气泡剧本；  
- 把赤道阈值原封搬到极光区，会出运营笑话。

### 5.4 一张「分纬决策」小表

| 问题 | 低纬优先看 | 高纬优先看 |
|---|---|---|
| 何时紧张 | 日落后地方时 | 磁层/极光活跃时段 |
| 代理指数 | ROTI/S4 + 气泡气候 | S4/σφ + 地磁/极光活动 |
| 阈值 | 分季分太阳活动 | 分磁情，勿用赤道表 |
| 定位对话 | 夜半球低纬链路 | 极区航路/高纬站 |

## 6. 何时指数够用？何时必须建模？

### 6.1 指数往往够用的场景

- 值班告警：「本区域 ROTI/S4 超阈」；  
- 统计气候：「过去十年某站地方时发生频率」；  
- 论文里展示「扰动日空间分布」的第一张图；  
- 与定位日志对齐：失锁时段是否与指数峰同步。

### 6.2 需要建模/仿真的场景

- 要评估「尚未建站区域」的风险；  
- 要输入到接收机跟踪环/基带，看误码与失锁机理；  
- 要做系统设计（天线、环路带宽、多频策略）；  
- 要研究谱参数、相位屏强度与传播几何。

### 6.3 灰色地带

ML 预测 S4（如 `scintill-ai`、`roti-gnss-ml` 一类思路）可能有工程价值，但：

- 验证集若缺磁暴，会盲目自信；  
- 「预测成功」≠「理解物理」；  
- 仍要与监测实况并行，不能取代当晚观测。

## 7. 和定位用户怎么对话（衔接 06）

闪烁期优先看：

1. **跟踪状态**：失锁、周跳暴增、CN0 狂抖；  
2. **多星余度与几何**：能否甩掉受害卫星仍定位；  
3. **接收机策略**：更稳健的跟踪环、多频、衰减策略；  

而不是只盯 VTEC 绝对值。  

重要误区纠正：

- **高 TEC 背景可以很平静**；  
- **强闪烁可以发生在 TEC 梯度/气泡边缘，而非「全球最高 TECU」点**；  
- TEC 图不能替代闪烁图（回 [01-ionosphere-tec-basics.md](./01-ionosphere-tec-basics.md)）。

定位侧工具仍是 `RTKLIB`、`gLAB`、`GAMPII-GOOD`、`PRIDE-PPPAR` 等（[`lists/04-gnss-positioning.md`](../../lists/04-gnss-positioning.md)），但闪烁本身要用监测/仿真条目。产品侧可关注 `DLR-IMPC` 等是否提供扰动/ROTI 类近实时信息（以各产品说明为准）。

## 9. 常见误区（逐条打假）

1. **「ROTI 高 = 一定不能定位」** — 还看星座、频率、接收机与余度。  
2. **「有了闪烁仿真就可以不做监测」** — 气候学给概率，当晚实况仍靠观测。  
3. **「ML 预测 S4 等于理解物理」** — 可能有工程价值，验证集缺事件会翻车。  
4. **「TEC 图能替代闪烁图」** — TEC 大 ≠ 闪烁强。  
5. **「ROTI 地图可以改名 S4」** — 传感器与定义不同。  
6. **「赤道阈值全球通用」** — 高纬驱动剧本不同。  
7. **「中纬 TID 就是闪烁」** — 可相关出现，但机制与指数体系勿混。  
8. **「仿真器有了就不问谱参数来源」** — 输入垃圾则输出动画。

## 10. 课堂类比加餐

### 10.1 雾浓 vs 路面碎石

TEC 像「雾有多厚」（柱总量）；闪烁像「雾里是否有碎石让车灯狂闪」。厚雾不一定碎石多；碎石路也可以出现在雾不最厚的地方。

### 10.2 地震仪 vs 人体感受

ROTI 有点像「用位移计差分看地面是否在抖」；S4 更像「灯是否在闪」。两台仪器都在测「不安分」，但通道不同。

### 10.3 天气预报 vs 气候志

监测 = 今晚实况与临近预报；气候学模型 = 「夏季午后多雷雨」那种概率；物理仿真 = 尝试在计算机里长出那朵雷雨。三者层圈不同。

## 14. 常见失败模式（监测与建模流水线）

| 步骤 | 失败 | 后果 | 缓解 |
|---|---|---|---|
| 定义指数 | 窗口长度与文献不一致 | 无法对比他人图 | 方法节写死参数 |
| 选站 | 只用低高度角 | ROTI 虚高 | 截止角与质量控 |
| 分纬 | 全球单一阈值 | 误警/漏警 | 分磁纬气候表 |
| 仿真 | 无实测对照 | 动画科学 | 强制 S4/ROTI 对照 |
| 解释 | TEC 高当闪烁 | 错误运营决策 | 双图并行：TEC + 闪烁 |
| 高纬 | 只盯地方时 | 错过磁层驱动事件 | 对齐 AE/IMF 等 |

## 17. 「何时指数够用」决策树（口述版）

问自己三连：

1. **我要不要输出信号波形给接收机仿真？**  
   - 否 → 先别上相位屏。  
   - 是 → 进入仿真层，并准备实测对照。  

2. **我的用户是值班员还是系统设计者？**  
   - 值班员 → 指数 + 分纬阈值 + 地图通常够。  
   - 系统设计者 → 需要仿真与参数扫描。  

3. **我有没有当晚/当周的监测锚定？**  
   - 没有 → 任何模型结论只能标成「气候概率/假设情景」。  
   - 有 → 可以写「实况 + 模型解释」。

把这三连写在报告扉页，审稿人会立刻感到你清醒。
