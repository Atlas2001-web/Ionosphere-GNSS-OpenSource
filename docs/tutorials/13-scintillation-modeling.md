# 13 · 闪烁：从指数到建模

05 课介绍了 S4、σφ、ROTI。本课往「精通」迈一步：什么时候报指数就够，什么时候要建模/仿真。

## 两条需求

1. **监测**：某区域今晚闪烁强不强？→ 指数、地图、告警（如 ROTI 图、S4 链）。
2. **影响评估**：接收机跟踪是否失锁、SBAS/精密定位误差如何？→ 往往需要传播/闪烁模型或实测接收机数据。

## ROTI 与 S4 不是同一个东西

- **ROTI**：TEC 时间变化率的统计，用双频载波就能做，适合稠密 GNSS 网。
- **S4 / σφ**：幅度/相位闪烁指数，常靠专用闪烁接收机或高采样。

可以相关，但不能把 ROTI 地图直接改名叫 S4。

## 建模时你在模什么

常见层次：相位屏、弱散射解析、经验气候学（按地方时/季节/太阳活动给出概率）。开源程度不一；进目录 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md) 搜 scintillation / ISMR / ROTI（如 `igs-roti` 等）。

## 实战建议

- 先有监测图，再谈模型。
- 低纬（赤道异常、气泡）与高纬（极光区）机制不同，套同一套阈值阈值会出笑话。
- 定位用户：闪烁期优先看跟踪状态与多星余度，而不是只盯 VTEC 绝对值。

## 什么时候「只报指数」就够

- 台网值班：今晚低纬有没有强闪烁？一张 ROTI/S4 地图 + 阈值即可。  
- 科研对比：不同太阳活动年的发生率统计。

## 什么时候必须上「模型/仿真」

- 要回答接收机环路是否失锁、误码率如何；  
- 要给无实测闪烁接收机的区域做概率预报；  
- 要做系统级仿真（多星座、多频）。

## 低纬 vs 高纬（课堂必提）

赤道等离子体泡与中高纬极光区粒子沉降，驱动不同。把低纬经验公式直接套到极区，是常见作业错误。
