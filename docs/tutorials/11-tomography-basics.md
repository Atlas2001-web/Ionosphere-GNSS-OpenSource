# 11 · 电离层层析：为什么难，但有人仍要做

GIM 多半给出**平面上的 VTEC**。层析想回答：电子密度 \(N_e(h)\) 随高度怎么变——三维或至少二维剖面。

## 课堂类比

医院 CT：X 射线从很多角度穿过人体，反演体内密度。GNSS 层析：卫星—接收机的射线穿过电离层，每条射线积分为 TEC，反演体素里的电子密度。

差别：GNSS 几何很「斜」、仰角受限，而且卫星轨道决定了射线方向不如 CT 自由——所以问题**更病态**。

## 你要心里有数的三件事

1. **观测是积分**：TEC = 路径上 \(N_e\) 的积分；信息量少于完整三维场。
2. **垂直分辨靠先验**：常结合测高仪、掩星、IRI 作约束，否则高度容易糊。
3. **开源参差不齐**：真正可复现的层析仓库比「读 IONEX」少；选工具时看有没有算例数据与论文对照图。

## 和本目录的关系

在 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md) 用「层析 / tomography / 三维」等关键词搜表；找不到成熟套件时，往往是：自己组「TEC 估计 + 优化库 + 先验模型」。物理模式（`GEMINI3D`、`TIE-GCM`）可当正演真值做仿真实验，不等于观测层析软件。

## 建议学习顺序

会做单站 TEC → 会做区域 VTEC 图 → 再读一篇经典 GNSS 层析论文 → 最后碰代码。跳步最容易「能跑出立方体、但无物理」。
