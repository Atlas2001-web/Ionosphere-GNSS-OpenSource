## 0. 从 GIM 多问的那一句

GIM（见 [03](./03-gim-ionex.md)、[10](./10-build-gim-workflow.md)）多半给出**平面上的 VTEC**：某一经纬度上，整根柱子里有多少电子。  
层析（tomography）想多问一句：电子密度 \(N_e\) 随**高度**怎么变——二维剖面或三维体素场。

这一问看起来自然，数学上却像打开了潘多拉盒子：观测仍是路径积分，而未知数变成「每一层、每一格」的密度。信息量不够时，解可以有无穷多个——这就是**病态（ill-posed）**。

本讲不推完所有正则化公式，但要让你：知道难在哪、开源为什么少、什么时候不该碰层析、什么时候值得碰。

## 1. 术语表

| 术语 | 定义 | 初学者抓手 |
|---|---|---|
| **电子密度 \(N_e\)** | 单位体积电子数（如 \(\mathrm{el\,m^{-3}}\)） | TEC 是它的线积分 |
| **层析 / 电离层层析** | 用多条路径积分反演空间（含高度）上的 \(N_e\) | 类似 CT，但几何差很多 |
| **体素（voxel）** | 三维网格单元；每格一个未知密度 | 体素越细，未知数越多 |
| **几何矩阵 \(A\)** | 把密度向量映射成各射线积分的线性算子 | \(y \approx Ax\) |
| **病态问题** | 解不唯一、或不连续依赖于数据；小噪声可导致解巨变 | 「能拟合数据」≠「解正确」 |
| **先验（prior）** | 反演前加入的额外信息：平滑、背景场、测高仪、掩星… | 没有先验，高度向常糊成一坨 |
| **正演（forward）** | 已知 \(N_e\) 算 STEC（路径积分） | 反演的逆过程；仿真验证靠它 |
| **正则化** | 用数学惩罚抑制胡来的解（Tikhonov、平滑、总变差等） | 参数会改答案，必须报告 |
| **hmF2 / foF2** | F2 层峰高 / 临界频率（测高仪常用） | 给垂直结构钉钉子 |
| **GIM vs 层析** | GIM≈柱总量图；层析≈试图要高度结构 | 积分一致仍可高度全错 |

## 2. 课堂类比：医院 CT，但角度很差

### 2.1 CT 为什么相对「好做」

医院 CT：X 射线源和探测器可以绕人体转很多角度，射线方向覆盖接近「从四面八方看清楚」。积分测量多、角度丰富 → 反演虽仍要算法，但信息更足。

### 2.2 GNSS 层析哪里不像 CT

1. **几何很斜**：卫星在天上，接收机在地面（多数情况），射线以大仰角到低仰角穿过，很少有「水平穿射」把各高度层分开。  
2. **角度不自由**：卫星轨道决定方向，你不能像 CT 转台那样想从哪穿就从哪穿。  
3. **垂直分辨天生不足**：许多不同的 \(N_e(h)\) 剖面可以积出几乎相同的 TEC。  
4. **时间在变**：电离层分钟级可变；你还得在「积累足够射线」与「场已变化」之间折中。  
5. **偏差与校准**：STEC 零点受 DCB 影响（第 09 课）；零点错了，三维场可能整层偏。

所以：问题比医学 CT **更病态**。同样能「跑出一张很炫的立方体」，却可能没有唯一物理解。

### 2.3 交通堵车类比（强化病态性）

你只知道若干条「从城南到城北的路上，车流总和」，却想还原每条巷子里有多少车。  
若没有交通规则、单行线、摄像头（先验），解有无穷多：车可以全挤在主干道，也可以均匀洒在小巷——总和一样。  
GNSS TEC 就是「总和」；巷子里的车就是各高度/各体素的电子。

## 3. 最小数学直觉（不堆公式，但要会说话）

把空间分成许多体素，未知密度排成向量 \(\mathbf{x}\)。第 \(i\) 条 GNSS 射线给出积分观测 \(y_i\)（与 STEC 对应），则

\[
\mathbf{y} = A\mathbf{x} + \boldsymbol{\varepsilon}
\]

- \(A\) 的第 \(i\) 行：这条射线穿过各体素的长度（或权重）；构造思路见 `Geometric-Matrix-For-Ionospheric-Tomogrphy`。  
- \(A\) 通常又「胖」又病态：列相关强，很多 \(\mathbf{x}\) 都能几乎拟合 \(\mathbf{y}\)。  
- 直接最小二乘 \(\min\|A\mathbf{x}-\mathbf{y}\|\) 往往噪声放大器。

实务上要加：

1. **背景场**：IRI 等气候场作初值/约束（`IRI-2020-package`、`PyIRI`、`iri2020`、`IRI-2016-package` 等）；  
2. **空间平滑或层相关**：相邻体素别乱跳；  
3. **多源观测**：测高仪、掩星（`CDAAC_COSMIC-TEC_Data-Research`、`COSMIC-CDAAC`、`GIRO-IRTAM`）；  
4. **时间连续**：相邻历元别无故跳变；  
5. **合理边界**：顶底高度、侧向边界条件。

**一句话**：层析 = 积分观测 + 几何矩阵 + **强先验**；缺第三条就在赌运气。

## 4. 你要心里有数的七件事

1. **观测是积分**  
   信息量少于完整三维场；无数种 \(N_e(h)\) 可积出同一 TEC。

2. **垂直分辨靠先验**  
   地面 GNSS 网对 **hmF2** 的约束往往弱于对 TEC 的约束——峰高上下挪一点，柱总量可以几乎不变。

3. **离散化选择会改答案**  
   体素大小、层厚、时间窗口、平滑强度都会改结果。换网格 ≠ 独立验证。

4. **正演与反演必须配套**  
   射线轨迹、椭球、体素穿越算法，要和仿真数据生成时一致，否则「完美复现」是自欺。

5. **开源参差不齐**  
   可复现层析仓远少于「读 IONEX」。选工具看：算例数据、论文对照图、许可。

6. **和 GIM 积分一致不够**  
   柱总量对了，高度结构仍可全错——这是对 GIM 用户与层析用户都重要的警告。

7. **ML 出三维 ≠ 经典层析**  
   经验映射可以有用，但别和基于射线积分的反演混名（见 [12](./12-data-assimilation-intro.md)、[15](./15-from-paper-to-code.md)）。

## 5. 层析 vs GIM：对照表

| 维度 | GIM（典型） | 层析 |
|---|---|---|
| 输出 | VTEC 平面场 | \(N_e\) 剖面/三维 |
| 未知数规模 | 相对少（格网或球谐系数） | 大（体素数 × 时间） |
| 主要假设 | 薄壳映射等 | 体素常值 + 正则化/先验 |
| 病态程度 | 有，但常可运行 | **更重**，尤其垂直向 |
| 验证 | 多家 IONEX、形态学 | 合成真值、测高仪、掩星、雷达 |
| 本仓库入门工具密度 | 高（`ionex`、`mosgim`…） | 低（见下节） |
| 何时该用 | 柱总量监测、定位改正输入 | 研究高度结构、与物理过程对话 |

口诀：**会做稳 GIM 再碰层析；会做合成实验再碰真网。**

## 7. 建议学习顺序（千万别跳）

1. 会做单站 STEC（[02](./02-gnss-dualfreq-tec.md)、[09](./09-dcb-biases-deep.md)）  
2. 会做区域 VTEC 图且通过第 10 课验证清单（[10](./10-build-gim-workflow.md)）  
3. 读一篇经典 GNSS 层析论文，只抓：网格、约束、验证图，不抓「所有公式」  
4. 用 `synthetic_ionospheric_tomography_isl`（或自建正演）在**已知真值**上复现  
5. 再上真实站网；同时上测高仪/掩星  
6. 最后才谈「业务化三维」——多数团队卡在 4→5

跳步最容易的症状：**能跑出立方体，但无物理；换正则化参数，峰高跟着飞。**

## 8. 失败模式清单（层析专场）

| 失败 | 症状 | 缓解 |
|---|---|---|
| 无先验硬反演 | 高度糊、振荡、负密度 | 加 IRI 背景 + 平滑；约束非负 |
| 体素过细 | 「很精细」地拟合噪声 | 先粗网格，再局部加密 |
| 只验证 VTEC | 积分对、剖面错 | 强制剖面验证（测高仪/掩星/合成） |
| 正演不一致 | 仿真虚高成功率 | 同一套射线积分代码 |
| DCB 未处理 | 整层偏置 | 回第 09 课 |
| 时间窗过长 | 把演变当静态 | 缩短窗口或加时间约束 |
| 把 ML 贴图当层析 | 名词污染 | 在报告里分开写方法学类别 |

## 9. 常见误区

- **「三维可视化很炫 = 已经层析成功」** — 先过合成数据与独立剖面。  
- **「体素越细越好」** — 观测不够时，更细 = 更自由拟合噪声。  
- **「和 GIM 积分一致就够了」** — 只说明柱总量，不说明高度。  
- **「有了 GNSS 网就不需要测高仪」** — 垂直钉钉子恰恰常靠互补观测。  
- **「开源少 = 问题不重要」** — 重要且难，所以完整可复现链条少。

## 13. 「先验」到底长什么样？（具象化）

初学者听到 prior 就觉得玄。把它拆成可勾选清单：

1. **气候背景**：用 `PyIRI` / `IRI-2020-package` 生成三维气候场，反演只估「相对气候的增量」。  
2. **平滑**：惩罚相邻体素差的平方（Tikhonov）——像让雾不要无故结硬块。  
3. **峰约束**：测高仪给出 foF2/hmF2，强迫峰值附近符合观测。  
4. **掩星剖面**：在掩星轨迹附近拉近电子密度。  
5. **物理不等式**：密度非负；顶部指数衰减等弱约束。  
6. **时间先验**：Kalman / 滑动：上一时刻分析场作为下一时刻背景（已有同化味道，见第 12 课）。

没有银弹。先验太强：结果看起来像 IRI 克隆；先验太弱：噪声立体化。好论文会做**先验强度扫描**并展示剖面如何变——你也应如此。

## 15. 一节「板书级」推导：为何垂直向不可观

设最简世界：只有两层，密度为 \(x_1\)（下层）、\(x_2\)（上层），厚度均为 \(L\)。一颗天顶卫星的 STEC 近似：

\[
y_{\mathrm{zenith}} = L x_1 + L x_2
\]

你只得到 \(x_1+x_2\) 这一个数。任意把电子从下层挪到上层（保持和不变），天顶观测完全一样。  
再加一颗低高度角卫星：路径穿过两层的长度变为 \(L_1'\)、\(L_2'\)，仍可能高度相关，两行方程的条件数很差——小噪声就会让「下层多、上层少」与「下层少、上层多」对调。

**结论写入笔记本**：垂直不可观不是「你代码写错了」，而是积分几何的结构性缺陷。先验的工作，就是把不可观的方向「按住」。

## 16. 合成实验怎么设计才算「真的练过」

推荐最小协议（可用 `synthetic_ionospheric_tomography_isl` 或自建）：

1. **真值**：用 IRI 或 `GEMINI3D` / `TIE-GCM` 切片生成三维 \(N_e\)。  
2. **正演**：用与反演相同的射线积分生成无噪声 STEC，再加可控噪声与可选 DCB 偏置。  
3. **反演**：只用 GNSS 几何；记录不同正则化参数下的剖面误差。  
4. **盲测**：留一部分掩星/测高仪剖面不参与反演，只用于验证。  
5. **报告**：除了 VTEC RMSE，必须报峰值高度误差、峰值密度误差、垂直相关函数。

若你只会贴三维着色图，没有步骤 4–5，实验室答辩时会被问穿。

## 17. 读论文时的「五字段卡片」

每读一篇 GNSS 层析论文，强制填卡：

| 字段 | 你要抄下来的 |
|---|---|
| 网格 | 水平分辨率、垂直层数与厚度、时间窗 |
| 观测 | 站数、截止角、是否用相位/伪距、DCB 策略 |
| 先验 | 背景模式、平滑形式、多源数据 |
| 验证 | 合成？测高仪？掩星？非独立 GIM？ |
| 开源 | 有无代码/数据；能否复现主图 |

填不出来，就还没读懂。然后再来本仓库 `PROJECTS.json` 里找是否有接近的实现可练。

## 18. 何时不该做层析（决策树）

- 问题其实是「区域 TEC 日变化」→ 做 GIM（第 10 课）。  
- 问题是「今晚闪烁强不强」→ 做 ROTI/S4（第 05、13 课），不是三维密度。  
- 问题是「模式是否跟得上观测」→ 考虑同化（第 12 课）。  
- 只有当你明确需要 **高度结构**（例如与气泡起飞高度、峰高变化、雷达剖面对话），并且能拿到先验/互补观测时，才启动层析。

把「想做三维」从审美动机改成科学动机，是精通者的分水岭。

## 19. 课堂收束：三句带走

1. **层析比 GIM 多问高度，也多付出病态性。**  
2. **没有先验与独立剖面验证的三维图，默认不可信。**  
3. **先合成、后真网；先 GIM 稳、后层析。** 工具入口从 `Geometric-Matrix-For-Ionospheric-Tomogrphy`、`IonoTomo`、`synthetic_ionospheric_tomography_isl` 开始，背景用 `PyIRI` / `IRI-2020-package`，互补用掩星与测高仪相关条目。
