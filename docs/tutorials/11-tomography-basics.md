## 0. 开场：三个真实场景

请先合上笔记本，想三件事：

1. **领导要「三维电离层」**：有人直接把 GIM 的 VTEC 色图旋转成「柱子」假装有高度（那是柱总量，见 [03](./03-gim-ionex.md)、[10](./10-build-gim-workflow.md)）；有人跑出很炫的立方体着色图，却说不清垂直结构从哪来。三维好看 ≠ 层析成功。
2. **测高仪说峰高偏了 40 km，GIM 的 TEC 却几乎不变**：柱积分对峰高上下挪一点不敏感——这正是层析难在垂直向的原因。链回 [07](./07-ionosonde-occultation.md)。
3. **论文写「我们做了 GNSS tomography」**，方法节却是 IRI 气候场加个平滑插值：名字混用是晕源。读摘要先问：观测是不是路径积分？未知是不是三维 $N_e$？先验是什么？验证有没有独立剖面？

## 1. 词表（先扫一遍，主讲后再回看）

### 1.1 层析核心物件

| 术语 | 人话 | 稍严 |
|---|---|---|
| **电子密度 $N_e$** | 单位体积有多少电子 | 如 $\mathrm{el\,m^{-3}}$ 或 $\mathrm{m^{-3}}$ |
| **层析 / GNSS 电离层层析** | 用很多条「路径总和」反推空间（含高度）上的密度 | 多路径积分 → 三维/剖面 $N_e$ |
| **体素（voxel）** | 三维小砖块；每块一个未知密度 | 网格单元；越细未知数越多 |
| **射线 / 路径** | 卫星到接收机的直线（近似） | 穿过若干体素的折线几何 |
| **几何矩阵 $A$** | 「每条射线穿过各砖多长」排成的表 | 线性观测算子：$y \approx Ax$ |
| **病态 / 欠定** | 解不唯一，或噪声会让解疯 | 小扰动 → 解巨变；无数 $x$ 拟合同一 $y$ |
| **先验（prior）** | 反演前就有的额外规矩 | 平滑、IRI 背景、测高仪峰、非负… |
| **正则化** | 用数学罚分禁止胡来的解 | Tikhonov、平滑、总变差等 |
| **正演（forward）** | 已知密度算路径积分 | 反演的逆过程；合成实验靠它 |

### 1.2 邻居们（别认错门）

| 术语 | 人话 | 稍严 |
|---|---|---|
| **GIM / VTEC** | 平面上的柱总量图 | [03](./03-gim-ionex.md)；积分一致仍可高度全错 |

## 3. 为什么柱积分不够？（机制因果）

### 3.1 柱总量回答「有多少」，不回答「在哪一层」

TEC（总电子含量）本质是电子密度沿路径的**线积分**：

$$
\mathrm{STEC} \propto \int N_e\,\mathrm{d}s.
$$

同一积分值，可以被「峰低而厚」「峰高而薄」「双峰」「底部抬升」等无数剖面共享。像只知道「从城南到城北一共有多少车」，却想知道每条巷子里停了几辆——**总和不够拆巷子**。

![STEC / VTEC 与薄壳：积分产品不自动给出高度剖面](./images/fig-stec-vtec-shell.png)

> **看图要点（为什么积分还要再映射）**
> - **看什么**：斜路径积分（STEC）与垂直柱（VTEC）的几何关系。
> - **为什么**：GIM 产品停在柱总量；层析要把积分「摊回」各高度层——信息量不够时必靠先验。
> - **别误判**：VTEC 图上的亮斑 ≠ 峰高已知；映射因子再准，也只是柱量变换，不是层析。
> 图源：自制 CC0。

### 3.2 垂直结构才是许多科学问题的主语

气泡起飞高度、风暴时峰抬升/沉降、与雷达或测高仪剖面对话——这些问的是 $N_e(h)$，不是「这一列加起来多少 TECU」。若你的科学问题其实是区域 TEC 日变化，请回 GIM，不必硬上层析名词。

![电子密度随高度分层：层析想恢复的是这类剖面结构](./images/fig-ne-profile-layers.png)

> **看图要点（为什么要剖面图）**
> - **看什么**：D/E/F 层大致高度与峰的位置感。
> - **为什么**：层析的「成功」应用剖面语言验收（峰高、峰密、层厚），不能只报柱 RMSE。
> - **别误判**：示意分层 ≠ 某次反演真值；真实峰高随地方时与磁暴可移几十 km。
> 图源：自制 CC0。

### 3.3 机制一句话

**观测仍是路径积分；未知却变成「每一层、每一格」的密度 → 信息量结构性不足 → 病态。** 先验与多视角不是装饰，是把不可观方向「按住」的钉子。

## 4. 体素与射线：医院 CT，但角度很差

### 4.1 CT 为什么相对「好做」

医院 CT：X 射线源和探测器可绕人体转很多角度，方向覆盖接近「从四面八方看清楚」。积分测量多、角度丰富 → 反演仍需算法，但信息更足。

### 4.2 GNSS 层析哪里不像 CT

1. **几何很斜**：卫星在天上、接收机在地面（多数情况），射线以大仰角到低仰角穿过，很少有「水平穿射」把各高度层分开。  
2. **角度不自由**：卫星轨道决定方向，你不能像 CT 转台那样想从哪穿就从哪穿。  
3. **垂直分辨天生不足**：许多不同的 $N_e(h)$ 可积出几乎相同的 TEC。  
4. **时间在变**：电离层分钟级可变；须在「积累足够射线」与「场已变化」之间折中。  
5. **偏差与校准**：STEC 零点受 DCB 影响（[09](./09-dcb-biases-deep.md)）；零点错了，三维场可能整层偏。

所以：问题比医学 CT **更病态**。同样能「跑出一张很炫的立方体」，却可能没有唯一物理解。

![站网几何：多视角的「钉子」能钉住哪里](./images/fig-gnss-network-coast.png)

> **看图要点（为什么看站网）**
> - **机制**：层析的「多视角」来自多站 × 多星的射线交叉；站稀处交叉少，垂直更糊。
> - **看什么**：目标区周围有没有站；大洋/荒漠空白处几乎没有水平约束。
> - **别误判**：点得多 ≠ 质控都过关；点稀处三维仍漂亮 → 多半是先验在填空（见第三段）。
> 图源：自制示意 + Natural Earth 海岸线。

### 4.3 交通堵车类比（强化病态性）

你只知道若干条「从城南到城北路上的车流总和」，却想还原每条巷子有多少车。若没有交通规则、单行线、摄像头（先验），解有无穷多：车可全挤在主干道，也可均匀洒在小巷——总和一样。  
GNSS TEC 就是「总和」；巷子里的车就是各高度 / 各体素的电子。

### 4.4 拼乐高砖类比（体素直觉）

把兴趣空域切成许多小砖（体素），每块一个未知密度。每条 GNSS 射线像一根细绳斜着穿过一串砖：观测只告诉你「绳上砖的密度 × 穿过长度」的加权和。砖越多，未知越多；绳的方向越单一，不同砖越「绑」在一起分不开。

## 5. 欠定、多视角与先验：三件救命的东西

### 5.1 欠定是什么意思（机制级）

设未知体素数 $n$，独立有效观测数 $m$。若 $m \ll n$，或 $A$ 的行高度相关（许多射线几乎平行），则方程组欠定 / 病态：  
- 拟合残差可以很小；  
- 解却可以在「零空间」里任意滑动（例如把电子从下层挪到上层，总和几乎不变）。

人话：**能拟合数据 ≠ 解正确。**

### 5.2 多视角补什么

不同仰角、方位、站–星组合，让射线以不同角度切开体素场。交叉越多，水平结构越容易被钉住；**垂直向**仍常弱——因为地面 GNSS 很少有真正的水平穿射。所以「加密站网」能改善水平，却不能单靠它自动解决峰高。

![GIM 格网与 IPP：采样钉子疏密决定哪里有约束](./images/fig-gim-grid-ipps-coast.png)

> **看图要点（为什么叠格网与 IPP）**
> - **看什么**：穿刺 / 采样点疏密与格网；点稀处颜色仍可能很漂亮。
> - **为什么**：层析约束主要活在「有射线穿过 + 交叉」的区域；空洞的漂亮结构要降权。
> - **别误判**：格距细 ≠ 有效分辨率；示意场 ≠ 你的层析输出。
> 图源：自制 CC0 + Natural Earth 海岸线。

### 5.3 先验补什么（具象清单）

初学者听到 prior 就觉得玄。把它拆成可勾选清单：

1. **气候背景**：用 `PyIRI` / `IRI-2020-package` 等生成三维气候场，反演只估「相对气候的增量」。  
2. **空间平滑**：惩罚相邻体素乱跳（Tikhonov）——像让雾不要无故结硬块。  
3. **峰约束**：测高仪 foF2 / hmF2，强迫峰值附近符合观测。  
4. **掩星剖面**：在掩星轨迹附近拉近电子密度。  
5. **物理不等式**：密度非负；顶部弱衰减趋势等。  
6. **时间连续**：相邻历元别无故跳变（已有同化味道，见 [12](./12-data-assimilation-intro.md)）。

没有银弹。先验太强：结果像 IRI 克隆；先验太弱：噪声立体化。好论文会做**先验强度扫描**并展示剖面如何变——你也应如此。

![IRI 气候 vs 测高仪：相册与当天这一刀](./images/fig-iri-vs-ionosonde.png)

> **看图要点（为什么蓝橙并排）**
> - **看什么**：平滑气候廓线与一次探测在峰高、峰密上的差。
> - **为什么**：层析先验常从「相册」出发，观测（GNSS + 可选测高仪）负责写「今天」；差几十 km 峰高常常是气候 vs 天气，不是程序写错。
> - **别误判**：分析处处贴橙线 ≠ 成功（可能过拟合噪声）；蓝线光滑 ≠ 更「物理真」。
> 图源：自制 CC0；细读见 [04](./04-iri-nequick.md)、[07](./07-ionosonde-occultation.md)。

**一句话**：层析 = 积分观测 + 几何矩阵 + **强先验**；缺第三条就在赌运气。

## 6. 和 GIM、同化、测高仪/掩星的接口（防止知识回潮混乱）

![多仪器互补：层析常需要好几杯水一起喝](./images/fig-instruments-complement.png)

> **看图要点（为什么三杯不能兑）**
> - **看什么**：测高仪 / GNSS TEC / 掩星各装不同「杯子」——峰下段、整柱、侧切廓线。
> - **为什么**：层析可以同时喝多杯，但每杯要有自己的正演与误差；强迫数字相等是假验证。
> - **别误判**：数字对不上就判某仪器「错了」；或把 GIM 平面产品当成三维 $N_e$ 真值。
> 图源：自制 CC0；细读见 [07](./07-ionosonde-occultation.md)。

| 邻居 | 与层析的关系 | 常见误用 |
|---|---|---|
| **GIM / IONEX（03/10）** | 柱总量对照；可作粗检「积分是否离谱」 | 只用 VTEC 一致宣称层析成功；把 GIM 当三维真值 |
| **数据同化（12）** | 层析式路径积分常是同化的观测算子 $H$；同化多时间循环与误差协方差 | 把静态层析立方体叫 4D-Var；把任意三维可视化叫同化 |
| **测高仪（07）** | 垂直钉钉子：foF2 / hmF2 / 底部剖面 | 「有 GNSS 网就不需要测高仪」 |
| **掩星 RO（07）** | 侧切 / 近水平路径，补垂直信息 | 把掩星轨迹附近填好就当全区真值 |
| **DCB（09）** | STEC 基准歪 → 整层偏 | 残差平行偏置却猛加密网格 |

![掩星几何：近水平路径是垂直约束的重要来源](./images/fig-gnss-ro-geometry.png)

> **看图要点（为什么画掩星）**
> - **机制**：掩星射线更接近「侧切」，对高度结构的可观性优于多数地面大仰角射线。
> - **看什么**：卫星–LEO–射线相对地球的几何。
> - **别误判**：一条掩星廓线 ≠ 全球层析已解；时空匹配与水平漂移要单独质控。
> 图源：自制 CC0。

![测高仪描迹：峰与临界频率是垂直钉子](./images/fig-ionogram-trace.png)

> **看图要点（为什么留测高仪）**
> - **看什么**：频率–虚高描迹给出峰区信息。
> - **为什么**：地面 GNSS 对 hmF2 弱；测高仪是先验与独立验证的双料角色。
> - **别误判**：顶部常断；描迹断处 ≠ 电子突然为零。
> 图源：自制 CC0。

**对照表（GIM vs 层析）：**

| 维度 | GIM（典型） | 层析 |
|---|---|---|
| 输出 | VTEC 平面场 | $N_e$ 剖面 / 三维 |
| 未知数规模 | 相对少（格网或球谐） | 大（体素数 × 时间） |
| 主要假设 | 薄壳映射等 | 体素常值 + 正则 / 先验 |
| 病态程度 | 有，但常可运行 | **更重**，尤其垂直向 |
| 验证 | 多家 IONEX、形态学 | 合成真值、测高仪、掩星、雷达 |
| 本仓库入门工具密度 | 高 | 低（见 §17） |
| 何时该用 | 柱总量监测、定位改正 | 高度结构、与物理过程对话 |

口诀：**会做稳 GIM 再碰层析；会做合成实验再碰真网。**

## 8. 解剖台 A：射线与体素相交长度——「绳子穿过乐高」

> 格式：**符号表 → 逐步推导 → 小数值例**。把几何矩阵从黑箱变成可手算的加权和。

### 8.1 符号表

| 符号 | 含义 | 单位 / 备注 |
|---|---|---|
| $x_j$ | 第 $j$ 个体素内的电子密度（常假设块内均匀） | $\mathrm{m^{-3}}$（教学可用简化单位） |
| $a_{ij}$ | 第 $i$ 条射线穿过第 $j$ 个体素的长度 | m 或 km |
| $y_i$ | 第 $i$ 条射线的路径积分观测（与 STEC 对应） | 与 $a_{ij}x_j$ 同量纲；实务常换算为 TECU |
| $m,n$ | 射线数、体素数 | — |
| $\varepsilon_i$ | 噪声与模型误差 | 同 $y$ |

理想线性模型：

$$
y_i=\sum_{j=1}^{n} a_{ij}\,x_j+\varepsilon_i.
$$

矩阵写法：$\mathbf{y}=A\mathbf{x}+\boldsymbol{\varepsilon}$。

### 8.2 逐步推导（每步人话）

**步骤 1 — 切砖。**  
把空域分成体素。教学上先想二维格子（经度 × 高度），再推广到三维。每格一个未知 $x_j$。

**步骤 2 — 画绳。**  
一条 GNSS 射线近似为直线段：从接收机到卫星（或到兴趣区顶界）。它会依次穿过一串体素。

**步骤 3 — 量穿过长度。**  
对射线 $i$ 与体素 $j$：若不相交，$a_{ij}=0$；若相交，$a_{ij}=$ 线段在该体素内的长度。这就是几何矩阵的一行——**大多是稀疏的**：一条射线只碰少数体素。

**步骤 4 — 加权求和得观测。**  
密度 × 长度再相加 ≈ 路径积分。人话：绳子上每块砖贡献「砖内密度 × 绳在砖里的长度」。

**步骤 5 — 单位意识。**  
若 $x_j$ 用 $\mathrm{m^{-3}}$、$a_{ij}$ 用 m，则 $\sum a_{ij}x_j$ 单位是 $\mathrm{m^{-2}}$，再除以 $10^{16}$ 等因子可化为 TECU。课堂手算可用「教学单位」：令密度直接用「单位柱密度 / 单位长度」，避免被换算绊倒——但报告真实工作必须写清换算。

### 8.3 小数值例（请手算一遍）

二维三格世界：下层两格 $x_1,x_2$，上层一格 $x_3$（教学简化）。一条近天顶射线只穿 $x_1$ 与 $x_3$，穿过长度各 $50\,\mathrm{km}=5\times10^{4}\,\mathrm{m}$。忽略真实单位换算，设教学密度 $x_1=2$，$x_3=3$（任意教学单位），则

$$
y=a_{1}x_1+a_{3}x_3=50\cdot 2+50\cdot 3=250
$$

（教学长度单位取 km 时）。  
另一条斜射线穿过 $x_2$（$70\,\mathrm{km}$）与 $x_3$（$60\,\mathrm{km}$）：

$$
y'=70\cdot x_2+60\cdot x_3.
$$

**课堂追问**：若只给你 $y$，你能唯一确定 $x_1$ 与 $x_3$ 吗？——不能，只有一个方程两个未知。这就是单射线欠定的最小版本。

**仓库钩子**：构造真实 $A$ 的思路见 `Geometric-Matrix-For-Ionospheric-Tomogrphy`（注意原名拼写 Tomogrphy）。

## 9. 解剖台 B：$y=Ax$ 直觉——「胖矩阵与噪声放大器」

> 格式：**符号表 → 逐步推导 → 小数值例**。说明为何「残差很小」仍可能解全错。

### 9.1 符号表

| 符号 | 含义 |
|---|---|
| $A\in\mathbb{R}^{m\times n}$ | 几何矩阵；$m$ 条射线、$n$ 个体素 |
| $\mathbf{x}$ | 未知密度向量 |
| $\mathbf{y}$ | 观测向量 |
| $A^{+}$ | 伪逆等「形式解」工具（不必深推） |
| $\mathcal{N}(A)$ | $A$ 的零空间：$Av=0$ 的 $v$ |

### 9.2 逐步推导（每步人话）

**步骤 1 — 正问题容易。**  
给定 $\mathbf{x}$，算 $\mathbf{y}=A\mathbf{x}$ 只是矩阵乘法（正演）。合成实验先做这个。

**步骤 2 — 逆问题难。**  
给定 $\mathbf{y}$ 求 $\mathbf{x}$：$n$ 常大于有效 $m$，或 $A$ 列相关强（许多射线方向相似）→ 无数 $\mathbf{x}$ 几乎给出同一 $\mathbf{y}$。

**步骤 3 — 零空间滑动。**  
若 $A\mathbf{v}=0$，则 $A(\mathbf{x}+\mathbf{v})=A\mathbf{x}$。把电子按 $\mathbf{v}$ 的模式在高度间挪动，观测可几乎不变——**垂直不可观方向**常藏在这类 $\mathbf{v}$ 里。

**步骤 4 — 裸最小二乘危险。**  
$\min\|A\mathbf{x}-\mathbf{y}\|^2$ 在病态时会放大噪声：微小 $\delta\mathbf{y}$ 可导致巨大 $\delta\mathbf{x}$。人话：为了贴噪声，解在零空间附近疯狂摆动。

**步骤 5 — 实务结论。**  
必须加先验 / 正则（解剖台 D），或减少未知（粗网格）、或加多源观测（测高仪 / 掩星）。

### 9.3 小数值例（条件差的手感）

两未知 $x_1,x_2$，两观测：

$$
\begin{aligned}
y_1&=1.00\,x_1+1.00\,x_2,\\
y_2&=1.01\,x_1+0.99\,x_2.
\end{aligned}
$$

两行几乎平行。若真值 $(x_1,x_2)=(10,10)$，则 $y_1=20$，$y_2=20$。若噪声把 $y_2$ 改成 $20.2$，形式解会剧烈摆动（可试：解变得远离 $(10,10)$）。  
**人话**：行相关 ≈ 角度不够；GNSS 层析的垂直向经常是这种感觉的高维版。

## 10. 解剖台 C：两层玩具世界——「为何垂直向不可观」

> 格式：**符号表 → 逐步推导 → 小数值例**。把 §3 的机制写成可手算的两层方程。

### 10.1 符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| $x_1,x_2$ | 下层 / 上层密度 | 教学单位 |
| $L$ | 天顶时每层厚度 | km |
| $L_1',L_2'$ | 低仰角时穿过两层的长度 | km |
| $y_{\mathrm{z}},y_{\mathrm{low}}$ | 天顶 / 低仰角观测 | 同 $L x$ |

### 10.2 逐步推导（每步人话）

**步骤 1 — 只有天顶。**  

$$
y_{\mathrm{z}}=L x_1+L x_2=L(x_1+x_2).
$$

你只得到 $x_1+x_2$。任意把电子从下层挪到上层（和不变），天顶观测完全一样。

**步骤 2 — 再加低仰角。**  
路径变斜，长度变为 $L_1',L_2'$：

$$
y_{\mathrm{low}}=L_1' x_1+L_2' x_2.
$$

看起来有两个方程两个未知——但若 $L_1'/L_2'\approx L/L$（几何仍高度相关），条件数很差：小噪声就会让「下层多、上层少」与「下层少、上层多」对调。

**步骤 3 — 写入笔记本。**  
垂直不可观不是「你代码写错了」，而是积分几何的结构性缺陷。先验的工作，就是把不可观方向「按住」。

### 10.3 小数值例

取 $L=50$，真值 $x_1=4$，$x_2=6$，则 $y_{\mathrm{z}}=500$。  
低仰角设 $L_1'=80$，$L_2'=90$，则 $y_{\mathrm{low}}=320+540=860$。  
现保持 $y_{\mathrm{z}}$ 不变，令 $x_1'=2$，$x_2'=8$（和仍为 10）：天顶观测仍是 $500$。低仰角变为 $160+720=880$——只差 $20$（约 2%）。若观测噪声大于此差，你无法稳健区分这两种垂直分配。

![Chapman 型剖面：峰高挪一点，柱总量可变很少](./images/fig-chapman-ne-h.png)

> **看图要点（为什么看 Chapman 剖面）**
> - **机制**：峰高上下挪，柱积分可几乎不变——与两层玩具同一家族的不可观性。
> - **看什么**：峰的位置与形状；想象峰平移后曲线下面积。
> - **别误判**：气候 Chapman 形 ≠ 磁暴真剖面；层析若只拟合面积，峰会「漂」。
> 图源：自制 CC0。

![穿刺点示意：大仰角射线对高度分层的杠杆更弱](./images/fig-ipp-pierce-point.png)

> **看图要点（为什么回到 IPP）**
> - **看什么**：射线与壳 / 层的交点几何。
> - **为什么**：大仰角近似「整柱一根绳」；要垂直分辨，需要斜路径交叉 + 先验/互补观测。
> - **别误判**：IPP 密 ≠ 垂直已解。
> 图源：自制 CC0。

## 11. 解剖台 D：正则与先验如何「钉」住解

> 格式：**符号表 → 逐步推导 → 小数值例**。把「必须先验」翻译成可写的罚项。

### 11.1 符号表

| 符号 | 含义 |
|---|---|
| $x_b$ | 背景场（如 IRI 气候三维） |
| $\lambda$ | 正则强度旋钮 |
| $L$ | 平滑算子（如差分：相邻体素之差） |
| $J(x)$ | 总代价 |

教学常用形式：

$$
\min_{x}\ \|Ax-y\|^2+\lambda\|L(x-x_b)\|^2.
$$

人话：第一项贴观测，第二项贴先验/平滑；$\lambda$ 调两者比重。

（非负约束、峰约束等可再加；此处只钉直觉。）

### 11.2 逐步推导（每步人话）

**步骤 1 — 第一项：别离数据太远。**  
残差 $\|Ax-y\|$ 要小，否则没吃进观测。

**步骤 2 — 第二项：别在零空间里乱跑。**  
$L(x-x_b)$ 惩罚「相对背景乱跳」或「相邻体素撕裂」。$\lambda$ 大 → 更像背景；$\lambda$ 小 → 更贴观测（也更易吃噪声）。

**步骤 3 — $\lambda$ 是性格旋钮，不是真理常数。**  
必须扫描并报告：峰高、峰密、剖面如何随 $\lambda$ 变。只展示「最好看」的一组 = 不及格。

**步骤 4 — 与同化的亲戚关系。**  
若把背景误差与观测误差写成协方差，更新会更像 [12](./12-data-assimilation-intro.md) 的增益语言。层析短窗静态求解 ↔ 同化循环推进：主标签仍应分开。

### 11.3 小数值例（$\lambda$ 扫描手感）

回到两层：$x_1+x_2$ 由天顶钉死为 $10$。无先验时，解可取 $(0,10)$、$(5,5)$、$(9,1)$…  
令背景 $x_b=(4,6)$，罚 $(x_1-4)^2+(x_2-6)^2$，并约束 $x_1+x_2=10$。则唯一解仍是 $(4,6)$——先验在和约束的直线上选出一点。  
若背景改成 $(3,7)$，解贴向 $(3,7)$。  
**人话**：观测钉住「和」；先验钉住「怎么分」。GNSS 层析的垂直向，经常接近这种分工。

**课堂追问**：若 $\lambda\to\infty$，结果是什么？——克隆背景，观测几乎白跑。若 $\lambda\to0$ 且无其它约束？——噪声立体化或回到欠定族。

## 12. 三种长相（必背）

| 签名 | 你在图上看到什么 | 机制一句话 | 先查什么 |
|---|---|---|---|
| **A. 合理三维** | 峰高/峰密与独立测高仪或掩星同量级；水平结构尺度与站网/物理过程匹配；射线残差无系统花纹 | 观测 + 适度先验，不可观方向被按住但未毒化 | 独立剖面；合成真值 RMSE |
| **B. 射线伪影** | 沿高频射线方向出现条纹、斜带、「管状」高低密度；换截止角或站网花纹跟着转 | 几何采样各向异性；正则不足或网格过细拟合射线方向 | 射线密度图；换几何重跑 |
| **C. 空洞填数** | 测站空白区（海洋、荒漠）仍出现精致涡旋/峰；关掉 GNSS 观测后结构几乎不变 | 先验 / 背景在唱戏；观测没钉到那里 | 射线覆盖图；「无观测区」掩膜 |

> - **看什么**：平滑、单峰、随高度隆起的层状结构——教学上的「合理长相」锚点。
> - **为什么**：真电离层当然可比这复杂，但第一眼若满屏斜条纹或棋盘，先疑伪影而非「新物理」。
> - **别误判**：像 Chapman ≠ 一定对；不像 ≠ 一定错——要靠独立剖面与覆盖图裁决。

### 12.1 「变好」的可操作判据（教学版）

1. **独立剖面**：留出测高仪 / 掩星 / 合成真值；报 hmF2、NmF2（或峰密）、垂直 RMSE，不只报 VTEC。  
2. **覆盖诚实**：出射线密度或体素命中次数图；无命中区标「先验主导」。  
3. **残差无花纹**：$y-Ax$ 对仰角/方位无系统条纹；整天平行偏置先查 DCB（[09](./09-dcb-biases-deep.md)）。  
4. **参数扫描**：$\lambda$、网格、时间窗至少两组对比，峰高别跟着飞到不可信。

### 12.2 假阳性指纹速查

| 看起来像 | 其实可能是 |
|---|---|
| 「三维很炫、分辨率超细」 | 体素过细拟合噪声；有效分辨远粗于标称格距 |
| 「与 GIM 的 VTEC 完美一致」 | 只说明柱总量；高度仍可全错 |
| 「海洋上出现精致气泡」 | 空洞填数 / 背景模式伪结构 |
| 「沿卫星轨迹一条亮管」 | 射线伪影 |
| 「换个 $\lambda$ 峰高跳 80 km」 | 垂直不可观未被钉住 |

## 13. 积分一致仍可高度全错（签名级警告）

两篇论文层析结果在 300 km 高度差很多，但 VTEC 差不多——你首先应怀疑：**垂直分配被先验或零空间滑动主导**，而不是「谁的 TEC 算错了」。  
验收顺序建议：覆盖图 → 独立剖面 → 再看柱积分。反过来验收，容易被「积分漂亮」收买。

## 14. 何时该做层析？（选题决策树）

## 15. 数据与几何检查清单（建议打印）

**步骤 1 — 定义未知 $x$。**  
水平范围、垂直顶底与层厚、时间窗长度、是否多历元耦合。  
失败模式：论文不写体素数与层厚。

**步骤 2 — 准备 $y$（STEC）与质控。**  
双频组合、DCB、仰角截止、周跳/野值规则。  
失败模式：零点偏置整层歪；回 [09](./09-dcb-biases-deep.md)。

**步骤 3 — 构造 / 核对 $A$。**  
射线轨迹、椭球、体素穿越算法与正演一致。  
失败模式：仿真用一套积分、反演用另一套 → 「完美复现」自欺。仓库入口：`Geometric-Matrix-For-Ionospheric-Tomogrphy`。

**步骤 4 — 画覆盖图。**  
每体素被穿过次数、射线仰角–方位直方图、时间窗内场是否可当静态。  
失败模式：空洞区当观测区宣传。

**步骤 5 — 选先验并扫描。**  
IRI 背景（`PyIRI`、`IRI-2020-package`…）、平滑 $\lambda$、可选测高仪/掩星。  
失败模式：只展示一组「最好看」参数。

**步骤 6 — 先合成、后真网。**  
`synthetic_ionospheric_tomography_isl` 或自建：真值 → 正演 → 加噪 → 反演 → 盲测剖面。  
失败模式：跳过合成直接真网炫图。

**步骤 7 — 独立验证。**  
留出测高仪 / 掩星 / 合成真值；强制报峰高与峰密误差。  
失败模式：只用 VTEC / 自家 GIM。

## 17. 和本仓库怎么连（catalog hooks）

在 [`lists/01-ionosphere.md`](../../lists/01-ionosphere.md) 用「层析 / tomography」检索。可直接点名：

| 条目 | 你拿它干什么 |
|---|---|
| `Geometric-Matrix-For-Ionospheric-Tomogrphy` | 理解 / 构造几何矩阵 $A$（注意原名拼写 Tomogrphy） |
| `IonoTomo` | 层析相关实现入口（先读 README 与算例） |
| `synthetic_ionospheric_tomography_isl` | **合成数据**：在已知真值上练手，强力推荐 |

配套上游能力与数据：

- STEC：`gnss-tec`、`pygnss-tec`、`tec-suite`、`Seemala-GPS-TEC`、`Okoh-MATLAB-TEC-from-RINEX`、`IONOLAB-TEC-Software`  
- 背景场：`IRI-2020-package`、`PyIRI`、`iri2020`、`IRI-2016-package`、`Galileo-NeQuick-G`、`NeQuickJRC`  
- 掩星：`CDAAC_COSMIC-TEC_Data-Research`、`COSMIC-CDAAC`、`pysatCDAAC`  
- 测高仪 / IRTAM 线索：`GIRO-IRTAM`、`PyIRTAM`  
- 物理正演真值：`GEMINI3D`、`TIE-GCM`、`pytiegcm`、`SAMI3-4.00`、`sami2py`（仿真 ≠ 观测层析软件）

### 17.1 建议学习顺序（千万别跳）

1. 会做单站 STEC（[02](./02-gnss-dualfreq-tec.md)、[09](./09-dcb-biases-deep.md)）  
2. 会做区域 VTEC 图且通过第 10 课验证清单  
3. 读一篇经典 GNSS 层析论文，只抓：网格、约束、验证图  
4. 用 `synthetic_ionospheric_tomography_isl`（或自建正演）在**已知真值**上复现  
5. 再上真实站网；同时上测高仪 / 掩星  
6. 最后才谈「业务化三维」——多数团队卡在 4→5

跳步最容易的症状：**能跑出立方体，但无物理；换正则化参数，峰高跟着飞。**

### 17.2 合成实验最小协议

1. **真值**：IRI 或 `GEMINI3D` / `TIE-GCM` 切片生成三维 $N_e$。  
2. **正演**：与反演相同的射线积分；加可控噪声与可选 DCB。  
3. **反演**：只用 GNSS 几何；记录不同 $\lambda$ 下剖面误差。  
4. **盲测**：留一部分掩星 / 测高仪剖面不参与反演。  
5. **报告**：VTEC RMSE + 峰值高度误差 + 峰值密度误差 + 覆盖图。

### 17.3 读论文「五字段卡片」

| 字段 | 你要抄下来的 |
|---|---|
| 网格 | 水平分辨率、垂直层数与厚度、时间窗 |
| 观测 | 站数、截止角、相位/伪距、DCB 策略 |
| 先验 | 背景模式、平滑形式、多源数据 |
| 验证 | 合成？测高仪？掩星？非独立 GIM？ |
| 开源 | 有无代码/数据；能否复现主图 |

## 18. 常见误解专节（请打假）

| 编号 | 误解 | 纠正 |
|---|---|---|
| M1 | 三维可视化很炫 = 层析成功 | 先过合成与独立剖面；看覆盖图 |
| M2 | 体素越细越好 | 观测不够时，更细 = 更自由拟合噪声 |
| M3 | 和 GIM 积分一致就够了 | 只说明柱总量，不说明高度 |
| M4 | 有了 GNSS 网就不需要测高仪 | 垂直钉钉子恰恰常靠互补观测 |
| M5 | 开源少 = 问题不重要 | 重要且难，完整可复现链条少 |
| M6 | ML 出三维 = 经典层析 | 经验映射可有用，勿与射线反演混名 |
| M7 | 残差很小 = 解正确 | 病态下可在零空间滑动；残差不辨垂直 |
| M8 | 正则 $\lambda$ 有唯一正确值 | 必须扫描；报告峰高敏感性 |
| M9 | 空洞区精致结构是新发现 | 先疑先验填数 |
| M10 | 静态层析立方体可叫 4D-Var | 主标签回 [12](./12-data-assimilation-intro.md) 分清 |

## 19. 课堂测验（建议 25 分钟，含演算）

**Q1.** 用 CT 类比，列出 GNSS 层析至少三条「角度很差」的原因。

**Q2.** 为什么地面 GNSS 网对 **hmF2** 的约束往往弱于对 TEC 的约束？

**Q3.** 两篇论文层析在 300 km 高度差很多，但 VTEC 差不多。你首先怀疑什么？

**Q4.** 解释病态性：为何「残差很小」仍可能解完全错？

**Q5.** 相交题：射线穿过体素 A 长度 40 km、体素 B 长度 60 km，教学密度 $x_A=2$、$x_B=5$。忽略单位换算，路径积分观测 $y$ 是多少？

**Q6.** 两层题：$L=50$，天顶观测给出 $x_1+x_2=10$。背景先验倾向 $(4,6)$。在只有「和约束 + 贴背景」时，解是什么？若无先验，解唯一吗？

**Q7.** 列出做层析前必须具备的三个上游能力（用本系列课号）。

**Q8.** 写出本仓库两个层析相关条目名，并说明为何合成数据实验应先于真网。

**Q9.** 对照表：射线伪影 vs 空洞填数——各给出一个「图上长相」与「先查什么」。

**Q10.** GIM 与层析在输出与验证策略上的核心差别是什么？（四句话内）

**参考要点**：Q2 峰高上下挪时柱积分可几乎不变；Q3 垂直分配 / 先验主导；Q4 零空间滑动；Q5 $y=40\cdot2+60\cdot5=380$；Q6 解 $(4,6)$，无先验不唯一；Q7 如 02/09、10、07；Q8 `Geometric-Matrix-For-Ionospheric-Tomogrphy`、`synthetic_ionospheric_tomography_isl` 等；Q9 见 §12；Q10 柱总量图 vs 三维/剖面，验证从 IONEX 形态学升级到独立剖面。

## 21. 板书八行 · 符号速查 · 口述检查

**板书八行**：

1. 层析多问高度，也多付病态性。  
2. 观测是积分：$y_i=\sum_j a_{ij}x_j$。  
3. $y=Ax$；$A$ 胖、列相关 → 零空间可滑。  
4. 天顶只钉 $x_1+x_2$；垂直靠先验。  
5. $\min\|Ax-y\|^2+\lambda\|L(x-x_b)\|^2$。  
6. 签名三脸：合理 / 射线伪影 / 空洞填数。  
7. 先合成、后真网；验收看剖面不是只看 VTEC。  
8. GIM 稳了再碰层析；DCB 是闸门。

**口述检查（30 秒）**：不看笔记，能否向同学讲清「为何积分对了高度仍可错」并手算 Q5、Q6？

## 23. 课堂收束：五句带走

1. **层析比 GIM 多问高度，也多付出病态性**——柱积分不够拆巷子。  
2. **$y=Ax$**：相交长度构成 $A$；裸最小二乘是噪声放大器。  
3. **垂直向常靠先验钉住**；多视角改善水平，测高仪/掩星补垂直。  
4. **签名三脸**：合理三维 / 射线伪影 / 空洞填数——先看覆盖与独立剖面。  
5. **先合成、后真网；先 GIM 稳、后层析。** 工具入口：`Geometric-Matrix-For-Ionospheric-Tomogrphy`、`IonoTomo`、`synthetic_ionospheric_tomography_isl`；背景用 `PyIRI` / `IRI-2020-package`；互补用掩星与测高仪相关条目。
