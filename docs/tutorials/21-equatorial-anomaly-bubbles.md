# 21 · 赤道异常与等离子体泡：EIA 峰、耗空通道与 ROTI 羽状结构

> **课堂定位**：现象分析专题第 3 课。前置：[19](./19-phenomena-overview.md)、[05](./05-scintillation-roti.md)、[20](./20-storm-tec-analysis.md)（会做差分即可）。  
> **学完应能**：区分 EIA「双峰气候」与叠加其上的等离子体泡；描述泡在 TEC/ROTI 上的签名；按季节/地方时做分析工作流；完成逐步清单并写出可复核结论。  
> **本课不做**：完整 Rayleigh–Taylor 线性理论推导；也不把 `SAMI3-4.00` 跑通当成交作业标准。

---

## 1. 开场：为什么「赤道附近 TEC 有两个鼓包」不是新闻，而「鼓包上破了个洞还在抖」才是新闻？

把低纬电离层想成**喷泉广场**：

- 白天，电场把赤道附近的等离子体「喷」上去，再沿磁力线滑向南北，于是磁纬大约 ±10°～±20° 出现两道**电子含量峰**，赤道槽在中间——这就是 **赤道电离异常 EIA**（Appleton anomaly）。  
- 到了日落后，底部 F 层条件合适时，不稳定性能长出**低密度空洞**，像气泡上浮，形成 **赤道等离子体泡 EPB**（常与扩展 F、闪烁一起被讨论）。  

老师在黑板上画：先画平滑双峰（EIA），再在夜侧峰上挖通道、画毛刺（泡 + 不规则）。**分析的第一纪律：先承认 EIA 背景，再谈泡。**

### 1.1 两个常被混为一谈的词

| 词 | 是什么 | 典型观测签名 |
|---|---|---|
| **EIA** | 大尺度双峰结构（气候+日变化） | VTEC 地图南北两峰、赤道槽 |
| **EPB / 等离子体泡** | 叠加的低密度不规则结构 | 夜侧 TEC 耗空通道、高 ROTI、高 S4、扩展 F |

类比：EIA 是「两道固定的山脊地貌」；泡是「雨季在山脊上冲出的冲沟还伴着碎石滚动」。冲沟需要地貌当背景才能被认识。

### 1.2 交付物

1. [ ] 能用人话解释喷泉与双峰。  
2. [ ] 能列出泡的 TEC/ROTI/闪烁/测高仪签名。  
3. [ ] 能说明季节与地方时为何关键（至少课堂级直觉）。  
4. [ ] 能跑完 §7 分析工作流并填表。

## 3. EIA：在 VTEC 图上怎么「确认双峰」而不是「脑补双峰」

### 3.1 安静日标准动作

1. 从 `CDDIS-IONEX` 取一安静日（Kp 低）。  
2. 用 `ionex`/`ionex_reader`/`ionex-analyzer` 画日侧 UT 的全球或区域 VTEC。  
3. 沿某经度做纬度剖面：应看到两峰一槽（季节/经度会变形，允许不完美）。  
4. 用磁纬重标横轴（思维上或用 `apexpy`），双峰更「对称」的情况常见。  

### 3.2 EIA 分析要回答的问题（不是建模问题）

- 今日峰在哪些磁纬？相对安静对照，峰更强还是更弱？更极向还是更赤道？  
- 槽多深？  
- 东西半球是否不对称？  
- 是否被风暴调制（回到 20 课）？  

### 3.3 EIA 的季节/地方时直觉

- 日侧最容易看见经典双峰；  
- 季节与磁倾角、太阳天顶角共同塑造强度；  
- **不要**用一张夜侧图否定 EIA 的存在。  

业务/区域图也可参考：`INPE-TEC-Maps-IONEX`、`ROB-European-TEC`（欧洲偏中纬，EIA 弱）、`eSWua-TEC`、`CAS-BDsmart-Iono-Products`。

## 4. 等离子体泡：观测签名四件套

套用 19 课框架：

1. **形态**：夜侧低纬 TEC 耗空通道、断裂的峰、羽状向外扩展；有时在差分/去趋势图更清楚。  
2. **时间**：日落后至午夜前后常见；与 PRE 时间窗相关（直觉级）。  
3. **空间**：沿磁力线映射到南北低纬；可远离磁赤道数百公里量级（视事件）。  
4. **多仪器**：ROTI/S4 升高；测高仪扩展 F；掩星密度洞；雷达（若有）羽状回波。  

**关键句**：只有 GIM 上浅浅一凹、无 ROTI/闪烁旁证时，**不要高置信喊泡**——可能是平滑或 EIA 变形。

### 4.1 TEC 上怎么看

- 单站：某方位卫星 STEC/VTEC 突然掉一截再恢复，像「咬了一口」。  
- 网络：相邻站相继出现耗空，可估漂移（研究级；开源里可见光流类思路，如现象开源册中的 EPB 漂移工具，本仓库以 ROTI/TEC 工具为主）。  
- 地图：标准 IGS GIM 可能**抹掉**细丝；区域高分辨 TEC 或密集网更合适。单站加工：`Seemala-GPS-TEC`、`tec-suite`、`IONOLAB-TEC-Software`、`gnss-tec`、`Okoh-MATLAB-TEC-from-RINEX`、`mitiono`、`pygnss-tec`。

### 4.2 ROTI 上怎么看

- 泡壁梯度大 → ROTI 高；  
- 可做 ROTI 地图或时间序列与 TEC 耗空叠图；  
- 工具：`Okoh-MATLAB-ROT-ROTI`、`Ionospheric-TEC-ROTI-Interactives`、`IonoMoni`、`OASIS`、`igs-roti`、`TEC_gradient_computation`、`roti-gnss-ml`。  

**OASIS** 文档示例常把 ROTI 与夜间赤道泡对照——适合当教学旁证入口（以该仓 README 为准）。

### 4.3 闪烁何时必须看

若问题是「导航会不会失锁/误差爆」，只谈 TEC 耗空不够，要看 `scintkit`、`ScintPi-1.0-Software`、`ismr_downloader`、`BiScEF`、`ionopy`、`Ionospheric-Scintillation-Maps-and-PDOP`。  
记住：闪烁强 ≠ TEC 平均高；常与不规则共存。

### 4.4 测高仪与掩星

- 扩展 F：`GIRO-DIDBase`、`GIRO-portal`、`HamSCI-ionosonde`。  
- 密度洞/羽：`COSMIC-CDAAC`、`COSMIC-IONPRF-Ne-TEC`、`IonOccAnalysis`。

## 5. 季节与地方时：分析前先查「日历与钟表」

### 5.1 为什么老师总问 LT？

泡的「生长窗」强烈依赖日落后的电动力学与密度梯度。你若把 LT=14 的图拿来找泡，像中午去河边找萤火虫。

### 5.2 季节直觉（课堂级）

不同经度扇区（美洲、非洲、东南亚等）的泡季节偏好经典文献讨论很多；你的作业要求是：

- 写明扇区与月份；  
- 与同月安静夜对照；  
- 不要把「某一年某一夜没有泡」推广成「该季节永不发生」。  

### 5.3 风暴夜 vs 安静夜

磁暴可以抑制或促进泡（视时段与电场），所以 20 课与 21 课会打架——**分开写**：先判是否暴时调制，再判是否有泡签名。

## 6. 逐步分析工作流（完整操作清单）

### 步骤 A — 声明问题

- [ ] 我要研究的是：EIA 形态 / 泡检测 / 二者关系 / 闪烁影响？  
- [ ] 经度扇区、日期、LT 范围写在第一行。  

### 步骤 B — 定磁赤道思维

- [ ] 标出研究区相对磁赤道的位置（`apexpy` 或地图目视）。  
- [ ] 决定用地理纬还是磁纬画剖面（推荐磁纬解释）。  

### 步骤 C — 建立 EIA 背景

- [ ] 安静日 VTEC 图 + 纬度剖面（`CDDIS-IONEX` + `ionex-analyzer` 等）。  
- [ ] 记录双峰大致磁纬与槽深（读色标/剖面，不编造）。  

### 步骤 D — 事件日 TEC

- [ ] 同 LT 或同 UT 策略写清；画出事件日 VTEC。  
- [ ] 做差分或至少目视对比：峰位移？新出现耗空通道？  

### 步骤 E — ROTI / 梯度

- [ ] 计算或浏览 ROTI（`IonoMoni`/`OASIS`/`Okoh-MATLAB-ROT-ROTI`/`igs-roti`）。  
- [ ] 检查高 ROTI 是否与 TEC 耗空边缘重合。  

### 步骤 F — 地方时切片

- [ ] 只保留日落后至午夜（或你扇区文献常用窗）讨论泡。  
- [ ] 日侧异常另标为 EIA/风暴，不贴泡标签。  

### 步骤 G — 多源旁证

- [ ] 测高仪是否扩展 F？  
- [ ] 有无闪烁 S4？  
- [ ] 有无掩星密度洞？  
- [ ] 缺旁证则置信度降档。  

### 步骤 H — 排除假象

- [ ] GIM 平滑是否可能？需要加密站网？  
- [ ] 周跳/DCB 造成假掉线？（单站必查）  
- [ ] 两台接收机/两系统是否重复看到？  

### 步骤 I — 结论模板

> 在【扇区】【日期】【LT 范围】，EIA 背景为【双峰简述】。事件呈现【TEC 耗空通道/无】，ROTI【升/不升】，测高仪扩展 F【有/无/未查】。故泡判定置信度【低/中/高】。主要怀疑【……】。工具：【列出 name】。

### 步骤 J — （可选）与模式对照

仅当观测结论已写完：可浏览 `SAMI3-4.00`/`GEMINI3D` 文献图，**不**把模式输出标成观测。

## 7. 常见误解

1. **双峰 = 泡** — 否，双峰是 EIA。  
2. **TEC 低 = 泡** — 赤道槽也低；要看夜侧通道 + 不规则指标。  
3. **有 ROTI 必有强闪烁** — 相关但不等价；频段与几何有关。  
4. **全球 GIM 看清细丝泡** — 常常不能。  
5. **泡只在磁赤道正上方** — 可映射到低纬。  
6. **暴夜一定有/一定无泡** — 视条件；要数据。  
7. **用 IRI 双峰证明当天 EIA 增强** — IRI 是气候，需观测对照。  
8. **把 TID 波纹叫羽状泡** — 中纬波状结构见 22 课。

## 9. 测验

**Q1.** EIA 与 EPB 各一句话。  
**Q2.** 为什么分析泡要先画 EIA 背景？  
**Q3.** 列出泡的四件套签名中「多仪器」至少两项。  
**Q4.** 为何标准 IGS GIM 对细丝泡可能不够？  
**Q5.** 点名：2 个 TEC 估计工具、2 个 ROTI 相关、1 个测高仪数据、1 个掩星数据。  
**Q6.** 日侧低纬 TEC 双峰加强，优先怀疑泡还是 EIA/风暴调制？  

### 答案要点

**A1.** EIA=双峰大尺度结构；EPB=低密度泡状不规则结构。  
**A2.** 否则把槽/峰变形误认为泡。  
**A3.** ROTI/S4、扩展 F、掩星密度洞等。  
**A4.** 时空平滑与分辨率不足。  
**A5.** 例：`Seemala-GPS-TEC`、`tec-suite`；`IonoMoni`、`igs-roti`；`GIRO-DIDBase`；`COSMIC-CDAAC`。  
**A6.** EIA/风暴调制；泡优先在日落后找。

## 11. 加厚：对照表——EIA 变形 vs 泡通道 vs 风暴负相

| 特征 | EIA 变形 | 泡通道 | 中纬风暴负相 |
|---|---|---|---|
| 地方时 | 常日侧显著 | 日落后为主 | 日夜皆可，暴驱动 |
| 形态 | 峰强/峰移/槽变 | 窄耗空+壁陡 | 宽带耗空 |
| ROTI | 可不高 | 常高 | 可高可不高 |
| 扩展 F | 不必有 | 常有 | 不一定 |
| 纬度 | 低纬双峰系统 | 低纬沿磁力线 | 中纬为主 |

课堂练习：给三张示意图（口述），让同学只根据上表归类——**归类训练比背定义更重要**。

## 12. 加厚：单站「咬一口」时间序列阅读步骤

1. 选日落后可见低仰角与高仰角卫星各若干（仰角过低多路径风险大，要声明）。  
2. 用 `Seemala-GPS-TEC` 或 `tec-suite` 出 STEC/VTEC。  
3. 检查周跳标记；周跳处禁止当泡。  
4. 看是否在 10–60 分钟尺度出现深度耗空又部分恢复。  
5. 同步画 ROTI；无 ROTI 软件时至少画 dTEC/dt 粗代理，并声明非标准 ROTI。  
6. 邻站是否复现？单站孤证置信度低。

## 15. 小结与口令

1. **先 EIA，后泡。**  
2. **泡 = 耗空形态 + 地方时窗 + 不规则指标 + 旁证。**

## 16. 九十分钟精讲稿：老师怎么带着做（可当助教手册）

### 16.1 前 20 分钟：只画山，不挖沟

禁止提到泡。只完成：安静日 VTEC、纬度剖面、磁赤道位置。提问：「峰在哪？槽在哪？若我现在喊泡，错在哪里？」——逼出「背景先立住」。

### 16.2 中 40 分钟：进入夜侧

换成日落后切片。先目视 TEC，再开 ROTI。规则：**TEC 通道与 ROTI 峰不对齐，就写「疑似，待查」**，不准直接定案。

### 16.3 后 20 分钟：假象审讯

故意展示一张含周跳的单站曲线，让同学投票「是不是泡」。揭示周跳后，强调步骤 H。

### 16.4 最后 10 分钟：填对照表 + 口令

每人填 §11 一行，齐声口令。

## 17. 经度扇区思维：为什么「别人论文的季节规律」不能直接抄

美洲扇区、非洲扇区、亚洲扇区的磁偏角、陆地站网密度、季节泡发生率曲线并不相同。你的分析报告必须写：

- 我的扇区是 ____；  
- 我参考的气候期望来自 ____（若无可写「未引用气候，仅事件分析」）；  
- 因此我**不**把单事件推广为全球季节定律。  

这是现象分析成熟度的标志：区分「事件检测」与「气候学统计」。气候学需要多年样本（可浏览 `igs-roti` 产品思路），不是一晚作业能完成。

## 18. 与闪烁课（05/13）如何衔接而不重复

- 05/13 教指数含义与建模/监测边界；  
- 本课教**何时**把高 S4/ROTI **归因到泡**。  
归因句式：「在 EIA 背景下，LT 窗内，TEC 耗空与 ROTI/S4 同现 → 泡相关闪烁。」  
若只有高 S4 无 TEC 通道，写「不规则/闪烁存在，泡形态未证实」。

仿真仓 `gnss-scintillation-simulator` 可帮助学生理解「不规则→闪烁」，但不可替代当晚观测。
