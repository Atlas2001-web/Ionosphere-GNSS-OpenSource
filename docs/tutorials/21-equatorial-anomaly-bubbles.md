低纬电离层像**喷泉广场**：

- **白天**：电场把赤道附近等离子体「喷」上去，再沿磁力线滑向南北 → 磁纬约 ±10°～±20° 两道电子含量峰，中间槽 → **赤道电离异常 EIA**（Appleton anomaly）。  
- **日落后**：底部 F 层若「重的在上、轻的在下」类比成立，不稳定性能长出低密度空洞上浮 → **赤道等离子体泡 EPB**，常伴扩展 F 与闪烁。

| 词 | 是什么 | 典型签名 |
|---|---|---|
| **EIA** | 大尺度双峰（气候+日变化） | VTEC 南北两峰、赤道槽 |
| **EPB** | 叠加的低密度不规则结构 | 夜侧 TEC 耗空通道、高 ROTI、高 S4、扩展 F |

类比：EIA 是两道山脊；泡是雨季冲沟加碎石滚动。冲沟必须放在地貌上才认得清。

## 3. 物理原则深讲（一）：喷泉效应与 EIA 双峰

### 3.1 因果链：从电场到两座山

口诀「东–上–散–峰–槽」：

1. 日侧低纬存在（气候上常见）**东向电场**；  
2. 地磁场在赤道近水平北向 → **E×B 漂移竖直向上**；  
3. 赤道 F 区等离子体被抬升到更高高度；  
4. 沿磁力线向南北扩散/滑落（重力与压力梯度等共同参与的输运图像）；  
5. 在磁纬约 ±10°～±20° 形成密度/TEC **双峰**，磁赤道附近相对成**槽**。

这不是「赤道没电子」，而是电子被重新分配成双峰几何。VTEC 地图上的双峰是喷泉的**柱积分影子**。

### 3.2 为什么必须用磁纬？

喷泉沿**磁力线**组织。地理赤道与磁赤道有偏角，不同经度扇区磁偏角不同，所以地理纬剖面上的双峰可能歪斜；换成磁纬，对称性往往更好。工具：`apexpy`。

### 3.3 喷泉强弱调制什么？

- 东向电场加大 → 上涌加强 → 峰更高或更极向（暴时 PPEF 也可这样做，见 20 课）；  
- 电场减弱/西向 → 上涌弱 → 双峰收缩；  
- 中性风、季节、太阳天顶角改变背景密度与扩散条件 → 同一电场下双峰形态仍可变。

### 3.4 在 VTEC 图上「确认双峰」的动作

1. `CDDIS-IONEX` 取安静日（Kp 低）；  
2. `ionex`/`ionex_reader`/`ionex-analyzer` 画日侧 UT；  
3. 沿某经度做纬度剖面：两峰一槽；  
4. 磁纬重标横轴；  
5. 记录峰磁纬与槽深（读图，不编造）。

区域产品：`INPE-TEC-Maps-IONEX`、`eSWua-TEC`、`CAS-BDsmart-Iono-Products` 等；欧洲 `ROB-European-TEC` 偏中纬，EIA 弱，勿硬找双峰。

**EIA 分析问题清单**：今日峰在哪些磁纬？相对对照更强/更弱/更极向？槽多深？东西不对称？是否被风暴调制（回 20 课）？

## 4. 物理原则深讲（二）：Rayleigh–Taylor 直觉与 EPB

### 4.1 水杯类比（课堂级，非严格推导）

经典 R–T：重流体叠在轻流体之上，界面受扰会上涌成泡。赤道日落后的底部 F 层，在适当条件下出现「等效重上轻下」的不稳定配置：密度梯度方向与有效重力（含电动力学等效）满足生长条件时，小扰动指数增长，形成低密度上升通道——等离子体泡。

你需要记住的不是公式全文，而是：

1. **需要陡的向上密度梯度区**（底部 F 层）；  
2. **向上漂移/抬升有利于进入不稳定窗**（PRE 常被讨论）；  
3. **生长需要时间**，故多在日落后数小时内被观测到；  
4. 非线性阶段形成耗空通道、羽状结构、泡壁陡梯度与湍流级联 → 闪烁。

### 4.2 PRE：为什么「日落后」是关键词？

预反转增强（PRE）：日落后赤道向上漂移常出现短暂增强，把 F 层抬高，底部梯度进入更易不稳定的状态。于是：

⇒ F ⇒ R – T ⇒

PRE 上涌；层抬高；生长率↑；EPB 更可能出现。

反过来说：你拿 LT=14 的图找泡，像中午找萤火虫。

### 4.3 泡如何映射到南北低纬？

不稳定常在磁赤道附近底部激发，但低密度结构沿磁力线延伸，南北低纬测站也能看到耗空与闪烁。所以「泡只在地理赤道正上方」是错的。

### 4.4 风暴夜：抑制还是促进？

穿透电场与扰动发电机可加强或抑制 PRE/上涌，故暴夜泡可增可减。20 课与 21 课分开写：先判暴时电场调制，再判是否有泡签名。

## 5. 物理原则深讲（三）：为何 TEC 耗空与 ROTI 羽状常成对？

### 5.1 TEC 耗空通道 —— 「沟」

泡内部电子密度显著低于周围，GNSS 斜路径穿过泡时 STEC/VTEC 出现「咬一口」式下降；网络地图上呈夜侧低纬耗空通道或羽状低值区。

### 5.2 ROTI 升高 —— 「沟边碎石」

ROTI 刻画 TEC 时间变化率的起伏。泡**壁**存在极陡水平/斜向梯度，卫星几何扫描或泡漂移使 TEC 快速变化 → ROTI 高。泡中心「空」不一定抖得最厉害，**边缘**往往 ROTI 最亮。

故教学期望签名是：

| 位置 | TEC | ROTI |
|---|---|---|
| 泡内通道 | 低（耗空） | 中等或视几何 |
| 泡壁 | 梯度大 | **常最高** |
| 安静 EIA 峰 | 高而光滑 | 可不高 |
| 赤道槽（气候） | 低 | **未必高** |

**关键句**：只有 GIM 浅凹、无 ROTI/闪烁，**不要高置信喊泡**。

### 5.3 羽状结构 WHY

非线性发展阶段，低密度区可向上及向更高纬扩展，形成 plume。羽的茎多扎在夜侧磁赤道附近；羽缘 ROTI 亮。若暴时 EIA 极向扩展被看花眼，对照 SYM-H，谨慎写「经典安静夜 EPB 羽」。

### 5.4 闪烁与 ROTI 的关系

小尺度不规则散射造成 S4/σφ。ROTI 是 TEC 率代理，与闪烁相关但不等价（频段、几何、积分路径不同）。导航问题必须看闪烁：`scintkit`、`ScintPi-1.0-Software`、`ismr_downloader`、`BiScEF`。

## 6. 季节与经度：分析前先查日历与扇区

### 6.1 为何经度扇区不能照抄？

美洲、非洲、亚洲扇区的磁偏角、磁力线几何、季风/对流层波强迫、站网密度不同，泡的季节偏好曲线不同。报告必须写：

- 我的扇区是 ____；  
- 气候期望来自 ____（或写「未引用气候，仅事件分析」）；  
- **不**把单夜推广成全球季节定律。

### 6.2 季节直觉（课堂级）

不同扇区在二分/至日附近的发生率差异是经典文献话题。作业要求：写明月份与扇区；与同月安静夜对照；禁止「某一年某夜无泡 ⇒ 该季永不发生」。

### 6.3 LT 窗

泡讨论默认落在日落后至午夜前后（扇区文献可调整）。日侧双峰加强优先想 EIA/风暴调制，不贴泡标签。

## 9. 工作示例脚本骨架

```python
# epb_tec_roti_demo.py — 课堂骨架
# TEC: Seemala-GPS-TEC / tec-suite / gnss-tec
# ROTI: Okoh-MATLAB-ROT-ROTI 思路 或 IonoMoni / OASIS

import numpy as np

def moving_roti(stec, dt_s, window_s=300.0):
    """粗代理：窗口内 dSTEC/dt 的 RMS，非标准产品定义，报告须声明。"""
    d = np.diff(stec) / dt_s
    n = int(window_s / dt_s)
    out = np.full(len(stec), np.nan)
    for i in range(n, len(d)):
        out[i] = np.sqrt(np.mean(d[i-n:i]**2))
    return out

def flag_depletion(vtec, baseline, thresh_tecu=5.0):
    """相对基线的耗空标记；基线可以是滑动高分位或对照日同 LT。"""
    return (baseline - vtec) >= thresh_tecu

# 分析口述:
# 1) 日落后弧段: depletion 与 roti 峰是否在壁上对齐
# 2) 邻站是否复现；单站孤证降置信
# 3) 同步查 GIRO-DIDBase 扩展 F
```

## 11. 常见误解

1. 双峰=泡 → 否，双峰是 EIA。  
2. TEC 低=泡 → 槽也低；要夜侧通道+不规则指标。  
3. 有 ROTI 必有强闪烁 → 相关≠等价。  
4. 全球 GIM 看清细丝 → 常常不能。  
5. 泡只在磁赤道正上方 → 可映射低纬。  
6. 暴夜一定有/无泡 → 视电场条件。  
7. IRI 双峰证明当天 EIA 增强 → IRI 是气候。  
8. 中纬 TID 波纹当羽状泡 → 见 22 课。  
9. 只会喊 R–T 不会看 ROTI 对齐 → 原则与证据缺一不可。

## 25. 喷泉效应：把 E×B 讲到「可画矢量」

在黑板上画磁赤道截面：

1. **B** 水平向北（简化）；  
2. **E** 东向（日侧气候图像）；  
3. 右手定则给出 **v_E×B** 向上。

向上的漂移把赤道等离子体送到更高的 L 壳，随后沿磁力线向南北「倾倒」。南北落点大约在磁纬十几度，于是柱含量出现双峰。若东向 E 加强（例如暴时穿透），倾倒点更极向——这就是 20 课日侧正相与 EIA 极移的接口。

**练习**：不看笔记，画出 E、B、v 三个箭头，并标出「峰」应出现的大致磁纬带。画不出者回去抄 §3.1。

### 25.1 为什么 TEC 双峰不等于 NmF2 双峰完全同步？

TEC 是整柱；喷泉抬升会改变峰高与层厚。有时峰密度变化与柱含量变化比例不同。加分旁证：掩星 Ne(h)（`COSMIC-CDAAC`、`IonOccAnalysis`）看峰高是否上升。

## 26. Rayleigh–Taylor：从「水杯」到「生长窗清单」

严格线性理论涉及通量管积分的生长率公式，本课不推导。把公式换成**生长窗清单**（全部满足才「更可能」）：

| 清单项 | 安静日典型 | 你怎么查 |
|---|---|---|
| 地方时在日落后窗 | 是 | 写 LT 范围 |
| F 层被抬高（PRE 线索） | 常讨论 | 测高仪 h'F / 漂移产品若有 |
| 底部存在陡升梯度 | 常见于抬高后 | 掩星/测高剖面 |
| 种子扰动存在 | 重力波/噪声等 | 教学上可写「假设存在种子」 |
| 抑制因素不强 | 西向风、碰撞等 | 暴时可能大变 |

清单用于**组织观察**，不是预报器。缺测高仪时，用「LT 窗 + TEC/ROTI 签名」降级证明泡的存在，机制窗写「未直接验证 PRE」。

### 26.1 非线性之后发生什么？（直觉）

线性阶段：小扰动变大。非线性：耗空通道形成、极化电场发展、结构垂直拉长成羽、级联出小尺度不规则 → 闪烁。故同一事件可同时有：大尺度 TEC 洞（GNSS 网）、中尺度梯度（ROTI）、小尺度散射（S4）。三尺不要混用。

## 27. 「TEC↓ + ROTI↑」成对的几何课

想象卫星 IPP 扫过一条南北向耗空通道：

- 进入壁前：TEC 高、变化慢 → ROTI 低；  
- 穿越陡壁：TEC 急降 → ROTI 爆高；  
- 通道内部：TEC 低、或许较平 → ROTI 回落；  
- 穿出另一壁：再次 ROTI 峰。

所以时间序列上常见「双 ROTI 峰夹着 TEC 谷」。若只有 TEC 谷无 ROTI，可能是宽缓槽或平滑产品；若只有 ROTI 无耗空，可能是别的梯度锋或不规则。

# pair_signature_note.py

def wall_peaks(t, vtec, roti, max_lag_min=20):
    i_min = int(np.argmin(vtec))
    # 在谷两侧窗口找 roti 极大 —— 教学演示用
    return i_min

## 48. 机制补丁：喷泉与 R–T 的「开关清单」各三问

**喷泉三问**：有东向 E 吗？上涌了吗？双峰/槽在磁纬上清楚吗？

三问答「否」时，机制段降为「数据不足，仅形态描述」。
