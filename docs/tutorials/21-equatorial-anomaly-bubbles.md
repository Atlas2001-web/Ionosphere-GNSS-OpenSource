![赤道异常 EIA：双峰与槽的示意剖面](./images/fig-eia-twin-crests.png)

> 图源：本仓库自制示意，非某日实测。 开场：双峰是山，泡是沟——先认地貌再谈冲沟

低纬电离层像**喷泉广场**：

- **白天**：电场把赤道附近等离子体「喷」上去，再沿磁力线滑向南北 → 磁纬约 ±10°～±20° 两道电子含量峰，中间槽 → **赤道电离异常 EIA**（Appleton anomaly）。  
- **日落后**：底部 F 层若「重的在上、轻的在下」类比成立，不稳定性能长出低密度空洞上浮 → **赤道等离子体泡 EPB**，常伴扩展 F 与闪烁。

黑板上先画平滑双峰，再在夜侧峰上挖通道、画毛刺。**第一纪律：先承认 EIA 背景，再谈泡。**

| 词 | 是什么 | 典型签名 |
|---|---|---|
| **EIA** | 大尺度双峰（气候+日变化） | VTEC 南北两峰、赤道槽 |
| **EPB** | 叠加的低密度不规则结构 | 夜侧 TEC 耗空通道、高 ROTI、高 S4、扩展 F |

类比：EIA 是两道山脊；泡是雨季冲沟加碎石滚动。冲沟必须放在地貌上才认得清。

## 3. 物理原则深讲（一）：喷泉效应与 EIA 双峰

### 3.1 因果链：从电场到两座山

口诀「东–上–散–峰–槽」：

1. 日侧低纬存在（气候上常见）**东向电场**；  
2. 地磁场在赤道近水平北向 → **E×B 漂移竖直向上**；  
3. 赤道 F 区等离子体被抬升到更高高度；  
4. 沿磁力线向南北扩散/滑落（重力与压力梯度等共同参与的输运图像）；  
5. 在磁纬约 ±10°～±20° 形成密度/TEC **双峰**，磁赤道附近相对成**槽**。

这不是「赤道没电子」，而是电子被重新分配成双峰几何。VTEC 地图上的双峰是喷泉的**柱积分影子**。

### 3.2 为什么必须用磁纬？

喷泉沿**磁力线**组织。地理赤道与磁赤道有偏角，不同经度扇区磁偏角不同，所以地理纬剖面上的双峰可能歪斜；换成磁纬，对称性往往更好。工具：`apexpy`。

### 3.3 喷泉强弱调制什么？

- 东向电场加大 → 上涌加强 → 峰更高或更极向（暴时 PPEF 也可这样做，见 20 课）；  
- 电场减弱/西向 → 上涌弱 → 双峰收缩；  
- 中性风、季节、太阳天顶角改变背景密度与扩散条件 → 同一电场下双峰形态仍可变。

### 3.4 在 VTEC 图上「确认双峰」的动作

1. `CDDIS-IONEX` 取安静日（Kp 低）；  
2. `ionex`/`ionex_reader`/`ionex-analyzer` 画日侧 UT；  
3. 沿某经度做纬度剖面：两峰一槽；  
4. 磁纬重标横轴；  
5. 记录峰磁纬与槽深（读图，不编造）。

区域产品：`INPE-TEC-Maps-IONEX`、`eSWua-TEC`、`CAS-BDsmart-Iono-Products` 等；欧洲 `ROB-European-TEC` 偏中纬，EIA 弱，勿硬找双峰。

**EIA 分析问题清单**：今日峰在哪些磁纬？相对对照更强/更弱/更极向？槽多深？东西不对称？是否被风暴调制（回 20 课）？

## 4. 物理原则深讲（二）：Rayleigh–Taylor 直觉与 EPB

### 4.1 水杯类比（课堂级，非严格推导）

经典 R–T：重流体叠在轻流体之上，界面受扰会上涌成泡。赤道日落后的底部 F 层，在适当条件下出现「等效重上轻下」的不稳定配置：密度梯度方向与有效重力（含电动力学等效）满足生长条件时，小扰动指数增长，形成低密度上升通道——等离子体泡。

你需要记住的不是公式全文，而是：

1. **需要陡的向上密度梯度区**（底部 F 层）；  
2. **向上漂移/抬升有利于进入不稳定窗**（PRE 常被讨论）；  
3. **生长需要时间**，故多在日落后数小时内被观测到；  
4. 非线性阶段形成耗空通道、羽状结构、泡壁陡梯度与湍流级联 → 闪烁。

### 4.2 PRE：为什么「日落后」是关键词？

预反转增强（PRE）：日落后赤道向上漂移常出现短暂增强，把 F 层抬高，底部梯度进入更易不稳定的状态。于是：

$$
\text{PRE 上涌} \;\Rightarrow\; F\text{ 层抬高} \;\Rightarrow\; R\text{–}T\text{ 生长率↑} \;\Rightarrow\; \text{EPB 更可能出现}
