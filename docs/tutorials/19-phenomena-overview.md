# 19 · 现象分析总览：什么叫「看现象」，不是「做模型」

> **课堂定位**：现象分析专题的第一课（19–23）。前置建议读过 [01](./01-ionosphere-tec-basics.md)、[03](./03-gim-ionex.md)、[05](./05-scintillation-roti.md)、[07](./07-ionosonde-occultation.md)。  
> **学完应能**：用自己的话区分「现象分析」与「建模/仿真」；列出安静日 vs 扰动日的观测签名清单；知道该先看哪张图（VTEC、ROTI、foF2、掩星剖面）；并能在 `PROJECTS.json` 里点到对口工具名。  
> **本课不做**：推导流体方程、教你改 TIE-GCM 源码、背某次磁暴的 TEC 数字。

## 1. 开场：老师为什么要单独开「现象分析」课？

同学们，前面入门课（01–04）和进阶课里，大量时间花在「量是什么、产品怎么读、模型何时能用」。这很重要——但用户反馈里有一句扎心的话：

> 「目录里建模讲得够多了；我真正不会的是：看到一张 TEC 图，怎么判断『这是正相风暴』『这是等离子体泡』『这是 TID』？」

**现象分析**回答的是：**在天空/数据里发生了什么？证据是什么？如何排除假象？**  
**建模**回答的是：**我能否用方程/经验公式/同化系统复现或预报它？**

两者都重要，但顺序常被颠倒：很多人一上来就跑 `IRI-2020-package` / `TIE-GCM` / `SAMI3-4.00`，却从未认真做过「扰动日 − 安静日」差分图，也从未把 SYM-H 时间轴和区域平均 TEC 对齐。本专题（19–23）把顺序拨正：**先学会读现象，再决定要不要建模**。

### 1.1 一个厨房类比（贯穿 19–23）

把电离层想成**整栋大楼的通风与雾气系统**：

| 类比 | 对应物理 | 分析时你在做什么 |
|---|---|---|
| 雾有多厚 | TEC / VTEC | 量「平均电子柱」 |
| 雾在剧烈翻滚 | ROTI / 闪烁 | 量「小尺度不规则」 |
| 某一层楼的浓度峰值 | foF2 / NmF2（测高仪） | 量「F2 峰」而非整柱 |
| 电梯井里高度方向的剖面 | 掩星 Ne(h) | 量「竖直结构」 |
| 大楼被台风抽打 | 磁暴 / 耀斑 / 日食 | 外部驱动 |
| 天气预报软件 | IRI / 环流模式 | **建模**——猜雾会怎样 |
| 闭路电视回放 + 温湿度记录 | GIM 差分 + 指数时间线 | **现象分析**——回放发生了什么 |

老师强调：同一栋楼，「猜明天雾多厚」和「回放昨晚几点哪层楼起雾」是两种本事。本课练后者。

## 2. 词表：本节每个术语必须先定义

### 2.1 分析哲学词

| 术语 | 人话 | 稍严一点 |
|---|---|---|
| **现象（phenomenon）** | 天空里可重复识别的一类事件/结构 | 有可观测签名的物理过程表现 |
| **现象分析** | 用多源观测证明「是哪一类现象、何时何地、强弱如何」 | 观测驱动的识别、量化、归因与假象排除 |
| **建模（modeling）** | 用方程或经验公式生成「假数据」或预报 | 前向模拟 / 经验气候 / 同化预报 |
| **观测签名（signature）** | 这类现象在数据上「长什么样」 | 形态+尺度+时间线+多仪器一致性 |
| **假象（artifact）** | 看起来像现象、其实是数据处理问题 | 空洞填补、平滑、DCB、分析中心差等 |
| **对照日（baseline）** | 用来做减法的「正常日子」 | quiet day 或太阳自转周对照等 |
| **差分图** | 扰动 − 对照 | 突出异常，削弱气候背景 |
| **多源一致性** | 不止一家产品、不止一种仪器说同一句话 | 降低「产品假象」概率 |

### 2.2 观测与产品词（复习 + 钉牢）

| 术语 | 人话 | 现象分析里怎么用 |
|---|---|---|
| **VTEC** | 竖直方向电子柱厚度 | 看大尺度增强/耗空、EIA 双峰、风暴正负相 |
| **STEC** | 斜路径电子柱 | 单站时间序列、残差波状结构（TID）的原料 |
| **GIM / IONEX** | 全球/区域 VTEC 地图产品 | 风暴差分、EIA 气候形态的公开底图 |
| **ROTI** | TEC 变化率的「抖不抖」指数 | 泡、不规则体、梯度陡峭区的代理，**不是**平均 TEC |
| **S4 / σφ** | 幅度/相位闪烁 | 真正的信号发抖；高采样接收机才稳 |
| **foF2** | F2 层临界频率 | 峰密度代理；测高仪点测，不是整柱 |
| **NmF2** | F2 峰电子密度 | 与 foF2 可换算；风暴负相常先看它 |
| **掩星（RO）** | 卫星掩星测 Ne 剖面 | 看高度结构：峰抬升、底部掏空、顶部增强 |
| **Kp** | 三小时地磁活动档 | 快速筛选安静/扰动 |
| **Dst / SYM-H** | 环电流强度指数 | 钉磁暴主相/恢复相（SYM-H 时间分辨率更高） |
| **地方时（LT）** | 当地太阳钟 | 赤道泡、EIA、日侧耀斑都强依赖 LT |
| **磁纬** | 相对地磁赤道的纬度 | EIA 峰、泡扩展、风暴季节效应都用磁纬思维 |

### 2.3 词表纪律（写进笔记本第一页）

1. **禁止**把 ROTI 高说成「TEC 很高」。  
2. **禁止**把 IRI 气候图当成「当天观测」。  
3. **禁止**只看全球平均 TEC 就说「全球正相风暴」。  
4. **允许**先猜现象类型，但必须列出「支持证据」和「反对证据」。

## 3. 主讲解：现象分析 vs 建模 vs 建图——三件不同的事

### 3.1 三列对照表（请抄板书）

| 维度 | 现象分析 | 建模/仿真 | 产品制作（如 GIM） |
|---|---|---|---|
| 核心问题 | 发生了什么？证据？ | 机制能否复现/预报？ | 如何从多站估一张图？ |
| 输入重心 | 观测产品 + 指数时间线 | 驱动参数 + 物理/经验方程 | RINEX/STEC + 偏差处理 |
| 输出重心 | 分类、形态描述、事件报告 | 模拟场、预报场 | IONEX/格网 VTEC |
| 成功标准 | 可复核、可排除假象 | 与观测定量一致（另议题） | 精度/覆盖/时效 |
| 初学者陷阱 | 把平滑假象当物理 | 没观测就「验证」模型 | 把建图误差当风暴 |

类比：现象分析像**刑侦取证**；建模像**用物理引擎重演案情**；GIM 建图像**画一张全国雾厚填色图给大家用**。刑侦不会因为「引擎好玩」就跳过现场照片。

### 3.2 「观测签名」四件套——识别任何现象的统一框架

以后每遇到一个候选现象，强制填这四格：

1. **形态签名**：在地图/时间序列上长什么样？（双峰？波状？羽状耗空？突然跳升？）  
2. **时间尺度**：分钟？小时？天？与驱动指数的先后关系？  
3. **空间尺度**：局地？经度扇区？半球？全球？依赖地方时/磁纬吗？  
4. **多仪器签名**：VTEC 说了什么？ROTI/闪烁呢？foF2 呢？掩星剖面呢？地磁/太阳指数呢？

**例：赤道等离子体泡（预习 21 课）**  
- 形态：夜侧低纬 TEC 耗空通道 / 羽状结构；ROTI 高；  
- 时间：日落后数小时内；  
- 空间：沿磁力线、可扩展到低纬；  
- 多仪器：测高仪扩展 F、闪烁 S4、掩星密度洞——若只有全球 GIM 略凹、无 ROTI，证据弱。

### 3.3 安静日 vs 扰动日：分析的「零点」

没有零点，就没有「异常」。

**安静日（Quiet）直觉**：地磁活动低（例如 Kp 多数时段偏低）、无大耀斑、区域 TEC 日变化「像教科书气候」。  
**扰动日（Disturbed）直觉**：磁暴、强耀斑、高速流到达、或你研究的特殊事件日。

对照策略（与 [14](./14-space-weather-case.md) 一致，本课钉概念）：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| Q：事件前安静日 | 选 Kp 低、无大耀斑的邻近日 | 季节/太阳活动接近 | 可能仍有中等扰动「漏网」 |
| R：约 27 天前 | 太阳自转周近似 | 抑制部分太阳旋转气候 | 季节漂移；不一定更安静 |
| C：气候中位数 | 同月同地方时多年中位数 | 稳定 | 抹掉年际；不适合单事件归因 |

**课堂硬规矩**：笔记第一行必须写「对照方案字母 + 为何选 + 该对照不能证明什么」。

## 4. 你手里有哪些「眼睛」？——可观测量速查

现象分析不是只有 VTEC 一张图。下面按「眼睛」分类；每只眼睛都写清**擅长**与**盲区**。

### 4.1 VTEC 地图（GIM / 区域图）

- **擅长**：全球/区域大尺度形态——EIA 双峰、风暴正负相斑块、日食 TEC「洞」的粗轮廓。  
- **盲区**：小尺度泡细丝、TID 短波、闪烁本身；GIM 平滑会抹掉结构。  
- **仓库入口**：数据 `CDDIS-IONEX`、`JPL-IONEX-Rapid`、`ROB-IONEX-Products`、`GFZ-Global-Ionosphere-Maps`、`WHU-IGS-Ionosphere-AC`、`UPC-IONEX-Archive`、`NOAA-SWPC-GloTEC`、`DLR-IMPC-Products`、`ESA-TIO-NRT-TEC`；读写 `ionex` / `ionex-rs` / `ionex_reader` / `ionex-analyzer` / `ionex-downloader`；差分辅助可关注 `DiffIonMap`。

### 4.2 ROTI / TEC 梯度 / 不规则体指数

- **擅长**：告诉你「电子柱在抖、梯度陡」——泡、极区不规则、强梯度锋面。  
- **盲区**：不告诉你平均 TEC 升高还是降低；高 ROTI ≠ 高 TEC。  
- **仓库入口**：`igs-roti`、`Okoh-MATLAB-ROT-ROTI`、`Ionospheric-TEC-ROTI-Interactives`、`IonoMoni`、`OASIS`、`TEC_gradient_computation`、`roti-gnss-ml`。

### 4.3 单站/网络 GNSS TEC 时间序列

- **擅长**：高时间分辨率；去趋势后看 TID 波列；耀斑突增的分钟尺度。  
- **盲区**：单站无法单独给出全球形态；DCB/周跳可造假波。  
- **仓库入口**：`Seemala-GPS-TEC`、`gnss-tec`、`tec-suite`、`IONOLAB-TEC-Software`、`Okoh-MATLAB-TEC-from-RINEX`、`mitiono`、`pygnss-tec`、`TEC-calculation-MATLAB`、`TEC_calculation_RINEX3`。

### 4.4 测高仪 foF2 / 电离图

- **擅长**：F2 峰密度与高度变化；扩展 F（与泡相关）；Es。  
- **盲区**：点测、夜间缩放困难、不能替代 TEC 整柱。  
- **仓库入口**：`GIRO-DIDBase`、`GIRO-portal`、`GIRO-IRTAM`、`HamSCI-ionosonde`、`NICT-Ionosonde-Data`、`Autoscala-INGV`。

### 4.5 GNSS 无线电掩星剖面

- **擅长**：Ne(h) 形状——峰抬升、底部耗空、多层结构。  
- **盲区**：时空稀疏；单条掩星不是「全球地图」。  
- **仓库入口**：`COSMIC-CDAAC`、`COSMIC-GNSS-RO-Data`、`COSMIC-IONPRF-Ne-TEC`、`CDAAC_COSMIC-TEC_Data-Research`、`IonOccAnalysis`、`awsgnssroutils`。

### 4.6 闪烁监测（S4 / σφ / ISMR）

- **擅长**：通信/导航可用性直接相关的抖动。  
- **盲区**：需要专用/高采样数据；与 VTEC 变化可不同步。  
- **仓库入口**：`scintkit`、`ScintPi-1.0-Software`、`ismr_downloader`、`BiScEF`、`ionopy`、`Ionospheric-Scintillation-Maps-and-PDOP`；仿真（非观测分析）`gnss-scintillation-simulator`。

### 4.7 驱动与空间天气指数

- **擅长**：给现象「时间轴钉子」。  
- **仓库入口**：`GFZ-Kp-Index`、`NOAA-SWPC`、`NOAA-SWPC-Planetary-K`、`NASA-OMNIWeb`、`pysatSpaceWeather`、`geospacelab`、`BoM-SWS`、`ESA-SWE-SSA`、`NICT-WDC-Ionosphere-SpaceWeather`。

### 4.8 综合读图/实验室框架（可选）

- `geospacelab`、`Kamodo`、`pysat`、`viresclient`、`apexpy`（磁纬坐标）、`eSWua-TEC`。

## 5. 通用现象分析检查清单（打印可贴墙）

把下面清单复制到每次事件笔记。**19 课要求你先会跑清单，不要求一次做完所有专题。**

### 5.1 开场钉钉（15–20 分钟）

- [ ] UTC 日期与研究区域写在第一行  
- [ ] 候选现象类型（可多选）：风暴 TEC / EIA / 泡 / TID / 耀斑 / 日食 / 不确定  
- [ ] 驱动线索：Kp、SYM-H/Dst、耀斑等级、日食路径——先列「将要查」的来源名  
- [ ] 对照方案：Q / R / C，并写一句理由  

### 5.2 最低可观测量组合（按现象勾选）

- [ ] 至少一张 VTEC（或区域 TEC）图 + 同时刻对照差分  
- [ ] 至少一条区域平均或代表站 TEC 时间序列（与指数同轴）  
- [ ] （泡/不规则）ROTI 或闪烁指标  
- [ ] （峰密度/扩展 F）foF2 或电离图摘要  
- [ ] （高度结构）至少 1–N 条掩星剖面（若事件允许）  
- [ ] 两家分析中心或两种独立产品交叉（防假象）  

### 5.3 读图五问（对着图大声回答）

1. **哪里**异常？（磁纬、经度、日夜侧）  
2. **何时**开始/最强/结束？（相对 SYM-H 谷值或日落的延迟）  
3. **增强还是耗空？**整体平移还是结构重排（如 EIA 峰移动）？  
4. **平滑尺度上是否可信？**GIM 是否可能抹掉你声称的小结构？  
5. **另一只眼睛同意吗？**ROTI/foF2/掩星/另一家 GIM？  

### 5.4 结论写作门槛（半页即可）

- [ ] 只写从图/表读到的量级与形态，不编造论文数字  
- [ ] 明确「支持现象 X」的证据列表与「仍存疑」列表  
- [ ] 声明主要数据产品 `name`（与 `PROJECTS.json` 一致）  
- [ ] 若用了模型，单独开小节，且不把模型输出标成「观测」

## 6. 安静 vs 扰动：课堂演示剧本（不假设你有私有数据）

### 步骤 A：选两天

用 `GFZ-Kp-Index` 或 `NOAA-SWPC-Planetary-K` 公开页面/数据，选：  
- 一天 Kp 持续偏低 → 安静候选；  
- 一天出现高 Kp 且 SYM-H 明显下降 → 扰动候选。  

### 步骤 B：下同一家 GIM

从 `CDDIS-IONEX` 下两天同一分析中心产品（例如同一 AC 的 final/rapid，勿混用策略极不同的图却不声明）。用 `ionex` 或 `ionex_reader` 打开。

### 步骤 C：画三张图

1. 安静日某世界时的 VTEC；  
2. 扰动日同一世界时（或同一地方时切片）VTEC；  
3. 差分 = 扰动 − 安静。  

### 步骤 D：口头报告模板（60 秒）

「差分图在【区域】出现【正/负】异常，量级约【从色标读取】TECU；时间上相对 SYM-H【超前/落后/同时】；我【有/无】ROTI 旁证；因此初步判断更像【正相风暴斑块 / 负相耗空 / 仅为产品差】，置信度【低/中/高】，因为【一条理由】。」

老师评分点：是否读色标、是否提对照、是否提假象可能——**不**看你是否「猜中标准答案」。

## 7. 常见误解（Misconceptions）

### 误解 1：「有模型输出就算分析了现象」

**纠正**：模型输出是假设下的结果。没有观测签名对照，那是「演示模型」，不是现象分析。

### 误解 2：「全球平均 TEC 升了 = 正相风暴」

**纠正**：正/负相常分区、分地方时、分半球出现。必须看地图与磁纬结构（见 20 课）。

### 误解 3：「ROTI 高 = 电子很多」

**纠正**：ROTI 高 = TEC **变化率**起伏大。平均 TEC 可以很低但边缘很陡。

### 误解 4：「GIM 上看到小波纹 = MSTID」

**纠正**：标准 IGS GIM 时空分辨率常不足以分辨中尺度 TID。TID 分析更依赖密集 GNSS 网去趋势时间序列（见 22 课）。

### 误解 5：「测高仪 foF2 降了 = TEC 一定降」

**纠正**：峰密度与整柱可不完全同步（峰高变化、顶部/底部贡献）。要 TEC 与 foF2 对照着说。

### 误解 6：「两家 GIM 差 5 TECU 就是发现了新物理」

**纠正**：先当产品差。用 `UWM-CDRSK-IGS-Validation` 一类验证思路，或至少第三家交叉。

### 误解 7：「现象分析不需要关心 DCB」

**纠正**：做绝对 TEC 气候或跨接收机合并时，DCB 可造成「假风暴」。相对差分、同站去趋势有时更稳——但你必须声明策略（见 09 课）。

## 10. 课堂测验（先自己做，再看答案）

**Q1.** 用一句话区分现象分析与建模。  
**Q2.** 为什么说「ROTI 不是 TEC」？举一个 TEC 低但 ROTI 高的情境。  
**Q3.** 对照方案 Q 与 R 各有什么主要风险？  
**Q4.** 若要判断「F2 峰是否被抬升」，VTEC 地图够不够？还应看什么？  
**Q5.** 列出读图五问。  
**Q6.** 从 `PROJECTS.json` 点名：一个 IONEX 数据源、一个 ROTI 相关、一个测高仪数据入口、一个掩星数据入口。  
**Q7.** 下列哪项更像假象而非物理？（A）两家 GIM 差几 TECU 且差在海洋空洞区（B）日落后低纬 ROTI 与 TEC 耗空通道同时出现（C）SYM-H 主相后中纬出现持续负 TEC 差分  

### 答案要点

**A1.** 现象分析用观测证明「发生了什么」；建模用方程/经验生成或预报场。  
**A2.** ROTI 描述变化率起伏；泡壁/耗空边缘常 TEC 低但梯度大 → ROTI 高。  
**A3.** Q：可能选到「看起来安静其实不干净」的日子；R：季节与太阳旋转不完全等价，对照日也可能扰动。  
**A4.** 不够；应看测高仪 hmF2/foF2 或掩星 Ne(h)。  
**A5.** 哪里、何时、正负/结构、平滑是否可信、另一只眼睛是否同意。  
**A6.** 示例：`CDDIS-IONEX`；`igs-roti` 或 `IonoMoni`；`GIRO-DIDBase`；`COSMIC-CDAAC`。（其他正确组合亦可）  
**A7.** （A）更像产品/覆盖假象；（B）（C）更像物理签名。

## 13. 加厚：从「看到一张图」到「写出可复核段落」的完整操作剧本

很多同学卡在：图有了，但报告只有「TEC 有变化」五个字。下面给你一段**可直接套用**的写作骨架，以及每一步对应的质检问题。

### 13.1 写作骨架（中文报告 300–500 字）

1. **事件句**：在 UTC【日期】，研究区【……】，候选现象为【……】。  
2. **驱动句**：同期 Kp 峰值约【档】，SYM-H 最低约【nT】（来源：`GFZ-Kp-Index` / `NASA-OMNIWeb` 等）。  
3. **数据句**：VTEC 采用【分析中心】IONEX（经 `CDDIS-IONEX`），读写用【`ionex`/`ionex_reader`/…】；对照方案为【Q/R/C】。  
4. **形态句**：差分图显示【日侧/夜侧】【磁纬带】出现【正/负】异常，色标读取约【ΔTECU】；结构呈【斑块/双峰位移/通道/波状——选一，勿堆砌】。  
5. **时间句**：异常相对 SYM-H 谷值【提前/滞后约 X 小时 / 同时】（若只有日分辨率产品，写「受产品时间分辨率限制，只能谈到某 UT 切片」）。  
6. **旁证句**：【有/无】ROTI（`igs-roti`/`IonoMoni`）；【有/无】foF2（`GIRO-DIDBase`）；【有/无】掩星（`COSMIC-CDAAC`）。旁证与 VTEC【一致/冲突/缺失】。  
7. **置信度句**：鉴于【产品平滑/单源/多源一致】，置信度【低/中/高】；主要怀疑是【……】。  
8. **下一步句**：若继续，应【加密 GNSS 网 / 换高采样 / 加测高仪 / 不做建模直到……】。

### 13.2 质检问题（写完必须自问）

- 我有没有把「色标感觉」写成精确到 0.1 TECU 的假精度？  
- 我有没有在没有 ROTI 的情况下断言「等离子体泡」？  
- 我有没有把 IRI/`iri2020` 气候图标成观测？  
- 我提到的每个软件名是否都能在 `PROJECTS.json` 找到？  

### 13.3 观测组合决策树（课堂练习用）

```
你的问题是什么？
├─ 大尺度增强/耗空在哪？ → VTEC 地图差分（GIM）
├─ 小尺度抖不抖？ → ROTI / S4
├─ 峰密度/峰高？ → 测高仪 foF2/hmF2
├─ 高度上哪里被掏空/抬升？ → 掩星 Ne(h)
├─ 分钟级突然跳变？ → 高采样 GNSS TEC（见 23 课）
└─ 波状行进结构？ → 密集网 TEC 残差（见 22 课）
```

记住：决策树是「先选眼睛」，不是「先选模型」。

### 13.4 与「产品制作课」「建模课」如何和平共处

- 学完 10 课（建 GIM）后，你更懂 GIM **可能平滑掉什么**——这对现象分析是加分，不是让你改行去做球谐。  
- 学完 04 课（IRI/NeQuick）后，你应能说出：气候模型可作**背景参照**，但事件归因必须靠观测差分。  
- 学完 11–12 课（层析/同化）后，把同化分析场当「观测」前，先问：同化窗、先验、观测算子是否可能制造你看到的结构？

### 13.5 迷你案例：同一张「赤道双峰」图的三种错误读法

1. **错误读法 A**：「双峰就是等离子体泡。」——否。双峰是 EIA 气候形态；泡是叠加的耗空/不规则。  
2. **错误读法 B**：「双峰比昨天强，一定是磁暴正相。」——未必。可能是地方时切片不同、或太阳天顶角季节变化。先做同 LT 对照。  
3. **错误读法 C**：「掩星没扫到峰，所以 EIA 不存在。」——否。掩星稀疏，单条未穿过不等于无 EIA。  

正确姿势：先承认 EIA 背景，再问「今日相对安静对照，峰更强/更弱/更极向？是否另有 ROTI 通道？」——这正是 21 课的入口。

### 13.6 本日口令（下课前齐声）

> 先签名，后模型；先差分，后故事；先多源，后自信。

**Q9.** 决策树里「分钟级突然跳变」为何不优先看标准 2 小时 GIM？

### 答案要点

**A8.** 因为你理解平滑、空洞、DCB 与约束如何制造假结构，从而降低把假象当物理的概率。

## 12. 小结（带回去的三句话）

1. **现象分析是刑侦，不是先开物理引擎。**  
2. **观测签名 = 形态 + 时间 + 空间 + 多仪器；缺一就降置信度。**  
3. **每只眼睛都有盲区：VTEC、ROTI、foF2、掩星要组合，并永远警惕产品假象。**
