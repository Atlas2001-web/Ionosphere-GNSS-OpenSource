# 19 · 现象分析总览：什么叫「看现象」，不是「做模型」

> **课堂定位**：现象分析专题第一课（19–23）。前置：[01](./01-ionosphere-tec-basics.md)、[03](./03-gim-ionex.md)、[05](./05-scintillation-roti.md)、[07](./07-ionosonde-occultation.md)。  
> **学完应能**：区分现象分析与建模；列出安静日 vs 扰动日观测签名；知道先看哪张图（VTEC / ROTI / foF2 / 掩星）；能在 `PROJECTS.json` 点到对口 `name`。  
> **本课不做**：流体方程推导、改 TIE-GCM、背某次磁暴 TEC 数字。

## 1. 开场：先读现象，再谈模型

![现象签名拼贴：安静形态 vs 扰动签名](./images/fig-phenomena-gallery.png)

> **看图要点**
> - **机制**：不同驱动改的是柱含量、不规则或高度结构，拼贴里各格代表一类签名族。
> - **观测签名**：日夜剖面、泡/耗空、TID 波纹、Ne(h) 形态彼此不可互换。
> - **分析用法**：拿到未知图先对号入座「像哪一格」，再选眼睛与对照。
> 图源：本仓库自制示意拼贴（非实测）。

![全球 VTEC 海岸线底图：先认地理格局](./images/fig-vtec-global-coast.png)

> **看图要点**
> - **机制**：日侧柱含量整体偏高，低纬可显 EIA 双峰雏形；海岸线帮助把「斑块」落到大洲/大洋。
> - **看什么**：对照海岸与磁纬带，先认哪里高/低，再谈扰动差分。
> - **别误判**：示意场非某日实测；勿把平滑色块当成泡丝或 MSTID。
> 图源：本仓库自制示意场 + Natural Earth 海岸线（非实测事件）。

用户常说：目录里建模讲得多，但看到 TEC 图却不会判断「正相风暴 / 泡 / TID」。  
**现象分析**：天空/数据里发生了什么？证据？如何排除假象？  
**建模**：方程或经验公式能否复现/预报？  
顺序拨正：**先读现象，再决定要不要建模**。

### 1.1 厨房类比（精炼）

| 类比 | 物理 | 你在做什么 |
|---|---|---|
| 雾有多厚 | TEC / VTEC | 量柱含量 |
| 雾在翻滚 | ROTI / 闪烁 | 量小尺度不规则 |
| 某层楼峰值 | foF2 / NmF2 | 量 F2 峰，非整柱 |
| 电梯井剖面 | 掩星 Ne(h) | 量竖直结构 |
| 台风抽打大楼 | 磁暴 / 耀斑 / 日食 | 外部驱动 |
| 天气预报软件 | IRI / 环流模式 | **建模** |
| 监控回放 | GIM 差分 + 指数 | **现象分析** |

## 2. 词表（必会）

| 术语 | 人话 |
|---|---|
| 现象分析 | 用多源观测证明「是哪类、何时何地、强弱」 |
| 观测签名 | 形态 + 尺度 + 时间线 + 多仪器一致 |
| 假象 | 空洞填补、平滑、DCB、分析中心差等 |
| 对照日 / 差分图 | quiet baseline；扰动 − 对照 |
| VTEC / STEC | 竖直/斜路径电子柱 |
| ROTI | TEC 变化率「抖不抖」——**不是**平均 TEC |
| foF2 / NmF2 | F2 峰频率/密度（点测） |
| Kp / SYM-H | 地磁活动；SYM-H 钉主相谷值 |
| 地方时 LT / 磁纬 | 泡、EIA、耀斑都强依赖 |

**纪律**：禁止 ROTI 高＝TEC 高；禁止把 IRI 气候图当观测；禁止只看全球平均就断言「全球正相」。

## 3. 三件不同的事 + 签名四件套

| 维度 | 现象分析 | 建模 | GIM 建图 |
|---|---|---|---|
| 问题 | 发生了什么？ | 机制能否复现？ | 如何估一张图？ |
| 输入 | 观测 + 指数 | 驱动 + 方程 | RINEX/STEC |
| 成功 | 可复核、排假象 | 与观测定量一致 | 精度/覆盖 |

刑侦取证 ≠ 开物理引擎 ≠ 画全国雾厚图。

**观测签名四件套**（每遇候选现象强制填）：形态；时间；空间；多仪器。  
**安静对照**：Q＝事件前安静邻近日；R≈27 天太阳自转；C＝同月气候中位数。

![日夜 TEC 纬度剖面示意](./images/fig-tec-day-night.png)

> **看图要点**
> - **机制**：昼侧喷泉/EIA 使双峰醒目；夜侧产生率下降，柱含量整体偏低。
> - **观测签名**：磁纬剖面「两峰一槽」在 LT 下午更强，夜侧峰弱或消失。
> - **分析用法**：先认气候日变化，再做扰动差分；勿把气候双峰当正相证据。
> 图源：本仓库自制示意（非实测）。

![Chapman 层 / 产生率剖面示意](./images/fig-chapman-layer.png)

> **看图要点**
> - **机制**：Chapman 把光电离产生率与 $N_e(h)$ 写成峰高 $h_m$、标高 $H$ 的解析剖面。
> - **观测签名**：F2 峰附近 $N_e$ 最大；产生率峰略偏下层（教学示意）。
> - **分析用法**：对照掩星/测高仪剖面时，先问峰高与峰密是否一起动，再谈整柱 TEC。
> 图源：本仓库自制示意（非实测）。

## 4. 你手里有哪些「眼睛」？

![分层 + Ne 剖面示意](./images/fig-ne-profile-layers.png)

> **看图要点**
> - **机制**：D/E/F 分层沉积不同；VTEC 是整柱积分，峰与高度需另眼。
> - **观测签名**：F2 峰主导柱贡献；D/E 扰动可强影响吸收却少动 GNSS TEC。
> - **分析用法**：谈「峰抬升/掏空」用 foF2 或掩星；谈「大尺度正负相」用 VTEC。
> 图源：本仓库自制示意（非实测）。

![Chapman Ne 与分层对照](./images/fig-chapman-ne.png)

> **看图要点**
> - **机制**：Chapman 峰密与分层示意对照，强调峰密度 ≠ 整柱。
> - **观测签名**：峰高/峰密变化时，柱含量可不按同比例变。
> - **分析用法**：读现象前先分清「峰」与「柱」各用哪只眼睛。
> 图源：本仓库自制示意（非实测）。

![ROTI 空间图示意](./images/fig-roti-map-schematic.png)

> **看图要点**
> - **机制**：ROTI 标出 TEC 变化率起伏的空间热点，多贴赤道夜侧泡活动。
> - **观测签名**：日落后低纬 ROTI 羽/热点；与平均 TEC 高低无必然同号。
> - **分析用法**：拿 ROTI 图时先对 LT 与磁纬；勿把热点读成「电子很多」。
> 图源：本仓库自制示意（非实测）。

![双频 TEC 几何无关组合示意](./images/fig-dualfreq-tec.png)

> **看图要点**
> - **机制**：电离层延迟 $\propto 1/f^2$；双频差分消掉几何，剩 STEC（+偏差）。
> - **观测签名**：L2 延迟大于 L1；几何无关组合幅度随 STEC 线性涨。
> - **分析用法**：读 TEC 前先确认频率对、DCB/模糊度处理口径（见 02）。
> 图源：本仓库自制示意（非实测）。

![STEC→VTEC 映射函数 / 薄壳示意](./images/fig-mapping-function.png)

> **看图要点**
> - **机制**：薄壳假设下 STEC $= M(e)\times$ VTEC；$M$ 随高度角降低而增大。
> - **观测签名**：低仰角斜路径 TEC 明显高于天顶；映射误差在低仰角放大。
> - **分析用法**：组网/GIM 时声明壳高与截止高度角；对比 IPP 扫描假波（见 22）。
> 图源：本仓库自制示意（非实测）。

| 眼睛 | 擅长 | 盲区 | 仓库入口（点名） |
|---|---|---|---|
| VTEC / GIM | 大尺度正负相、EIA | 小泡丝、短波 TID | `CDDIS-IONEX`、`ionex`、`DiffIonMap`、`JPL-IONEX-Rapid` |
| ROTI / 闪烁 | 抖、陡梯度、泡壁 | 不给平均 TEC 升降 | `igs-roti`、`IonoMoni`、`OASIS`、`Okoh-MATLAB-ROT-ROTI` |
| 单站 TEC | 高时间分辨率、TID/耀斑 | 单站无全球形态 | `Seemala-GPS-TEC`、`tec-suite`、`gnss-tec` |
| foF2 | 峰密度、扩展 F | 点测≠整柱 | `GIRO-DIDBase`、`NICT-Ionosonde-Data` |
| 掩星 Ne(h) | 峰抬升、底部掏空 | 时空稀疏 | `COSMIC-CDAAC`、`IonOccAnalysis` |
| 指数 | 时间轴钉子 | 本身不是 TEC | `GFZ-Kp-Index`、`NASA-OMNIWeb`、`NOAA-SWPC` |

## 5. 检查清单与读图五问

**开场钉钉**：UTC 日期与区域；候选现象；驱动线索；对照方案 Q/R/C。  
**最低组合**：VTEC + 差分；TEC 与指数同轴；泡看 ROTI；峰看 foF2；高度看掩星；两家产品交叉。  
**读图五问**：① 哪里？② 何时（相对 SYM-H/日落）？③ 增强还是耗空？④ GIM 平滑是否可信？⑤ 另一只眼睛同意吗？  
**结论门槛**：只写读到的量级与形态；列支持/存疑；声明产品 `name`。

## 6. 课堂演示（安静 vs 扰动）

1. 用 `GFZ-Kp-Index` / `NOAA-SWPC-Planetary-K` 选安静日与高 Kp+SYM-H 下降日。  
2. 从 `CDDIS-IONEX` 下**同一分析中心**两天产品。  
3. 画三张：安静 VTEC、扰动 VTEC、差分。  
4. 60 秒口述：区域、正负、色标、相对 SYM-H、有无 ROTI、判断与置信度。

评分看：是否读色标、提对照、提假象——不看是否「猜中标准答案」。

## 7. 常见误解（速查）

| 误解 | 纠正 |
|---|---|
| 有模型输出＝分析了现象 | 无观测签名对照只是演示模型 |
| 全球平均 TEC 升＝正相风暴 | 正负常分区、分 LT（见 20） |
| ROTI 高＝电子很多 | ROTI＝变化率起伏；泡壁常 TEC 低而抖 |
| GIM 小波纹＝MSTID | 标准 GIM 分辨率常不够（见 22） |
| foF2 降＝TEC 必降 | 峰与整柱可不完全同步 |
| 两家 GIM 差几 TECU＝新物理 | 先当产品差，第三家交叉 |

### 小结

1. 现象分析是刑侦，不是先开物理引擎。  
2. 签名＝形态+时间+空间+多仪器；缺一降置信度。  
3. 每只眼睛有盲区；永远警惕产品假象。
